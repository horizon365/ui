Nuxt UI proporciona componentes de prosa**Prose con un hermoso estilo para su contenido de markdown. Ya sea que renderice el markdown con una biblioteca o use componentes de prosa directamente, Nuxt UI aplica su sistema de diseño para que su contenido se adapte automáticamente al tema de su aplicación.

::framework-only
#nuxt
:::div

::::note
Los componentes de prosa se habilitan automáticamente cuando se usan [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc), [`@nuxt/content`](https://github.com/nuxt/content) o [`@comark/nuxt`xph016https://comark.dev/rendering/nuxt).xph023<br>De lo contrario, habilite la opción [`prose`](/docs/getting-started/installation/nuxt#prosexph0xxph0222x en su xph0006x:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
Para la instalación y configuración de Nuxt Content, consulte la guía de integración de **Content.
::::

:::

#vue
:::note
Para utilizar componentes de prosa con Vue, debe habilitar la opción [`prose`](/docs/getting-started/installation/vue#prose) en su `vite.config.ts`:

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```

## Utilización

::framework-only
#nuxt
:::div
Hay varias formas de renderizar contenido con estilo:

1. **Markdown rendering**: utilice ContentRenderer, MDC, Markdown o MarkdownDocument para renderizar el Markdown con estilo de prosa automático
2. **Direct Vue usage**: importa y usa componentes de prosa directamente en tus plantillas de Vue
:::

#vue
:::div
Hay varias formas de renderizar contenido con estilo:

1. **Markdown rendering**: use Markdown o MarkdownDocument para renderizar Markdown con estilo de prosa automático
2. **Direct Vue usage**: importa y usa componentes de prosa directamente en tus plantillas de Vue
:::

### With ContentRenderer: badge{label="Nuxt only" color="warning" class="align-text-top"} (en inglés)

Al usar [`@nuxt/content`](https://github.com/nuxt/content), renderice las páginas de su colección con el componente [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer):

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### Con el componente MDC: badge{label="Nuxt only" color="warning" class="align-text-top"}

Cuando se utiliza [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) o [`@nuxt/content`](https://github.com/nuxt/content), se utiliza el componente [`<MDC>`](https://github.com/nuxt-content/mdc) para representar cadenas de marcado:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc` está siendo desaprobado a favor de [Comark](https://comark.dev). Sus archivos de descuento existentes son compatibles, no se necesitan cambios de contenido.
::

### Con el componente Markdown

[Comark](https://comark.dev) representa la reducción de precios con soporte integrado para streaming. Representa los tokens de forma incremental a medida que llegan, lo que lo hace ideal para las respuestas de chat de IA y cualquier otro contenido dinámico de reducción de precios.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
El plugin `shiki` agrega resaltado de sintaxis a los bloques de código. Use el prop `:streaming` al renderizar contenido que llega de forma incremental, como las respuestas de IA.

Para admitir el modo oscuro, agregue el siguiente CSS a su hoja de estilos:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
Consulte el componente **Chat** para obtener un ejemplo completo del uso de Comark para renderizar mensajes de chat de IA.

### With MarkdownDocument (Edición española)

Utilice el componente [`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code) para renderizar un `MarkdownDocument` preanalizado sin enviar ningún código de analizador o complemento al navegador. Esto es útil cuando el análisis se realiza en el servidor, en un paso de compilación o a través de una API.

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

### Con componentes de Prose

Utilice los componentes de prosa directamente en las plantillas de Vue para un control máximo:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## MDC sintaxis

Los elementos de Markdown se asignan automáticamente a los componentes en prosa: `# Heading` se convierte en `<ProseH1>`, `**bold**` se convierte en `<ProseStrong>`, `` `code` `` se convierte en `<ProseCode>`, y así sucesivamente.

[MDC Syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) va más allá al permitirle usar los componentes de Vue directamente dentro de la reducción de precios.

## Temas

Anular cualquier estilo de componente de prosa en la configuración de la aplicación:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
