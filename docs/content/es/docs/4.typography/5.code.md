## Bloques de código

::tip
De forma predeterminada, los temas Shiki `material-theme-lighter` y `material-theme-palenight` se utilizan para el modo claro y oscuro respectivamente. Cuando se usa `@nuxt/content`, puede cambiar esto a través de la clave [`content.build.markdown.highlight`]() en su `nuxt.config.ts`. Cuando se usa el modo independiente `@nuxtjs/mdc`, configure los temas a través de la tecla [`mdc.highlight`](). Cuando utilice [Comark](https://comark.dev), configure los temas a través de las opciones del plugin `shiki`.

Para admitir el modo oscuro con Comark, agregue el siguiente CSS a su hoja de estilo:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

::

::tip
El icono del nombre de archivo es representado por el componente `ProseCodeIcon` y contiene un conjunto de iconos predefinidos que puede personalizar en la configuración de su aplicación:

::framework-only
#Nuxidad
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vista
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Estos iconos de nombre de archivo provienen de la colección [`vscode-icons`](https://icones.js.org/collection/vscode-icons), que está separada de los iconos `lucide` que utilizan el resto de los componentes, y se resuelven a pedido desde la extensión de archivo. Instale `@iconify-json/vscode-icons` para servirlos localmente y sin conexión, como cualquier otra colección.

### Botón de copia

Cada bloque de código tiene un botón de copia incorporado que copiará el código a su portapapeles.

Configure el prop `copy` en `false` para ocultar el botón, o pase el prop [Button](/docs/components/button) para personalizarlo.

::tip
Puede cambiar el icono a través de las teclas `ui.icons.copy` y `ui.icons.copyCheck` en la configuración de su aplicación:

::framework-only
#nuxidad
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vista
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```

### Línea resaltada

Resalta líneas específicas para llamar la atención sobre partes importantes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#El Código

````mdc
```ts [nuxt.config.ts] {2}
export default defineNuxtConfig
  módulos:['@ nuxt/ui'],//Esta línea está resaltada
  css: ['/assets/css/main.css']
})
```
````

### Código diff

Use the `diff` language to show changes between code versions.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#Código

````mdc
```diff [nuxt.config.ts]
export default defineNuxtConfig
  Módulos:[
-   '@ nuxt/ui-pro '(en inglés)
+   '@nuxt/ui '(en inglés)
  ]
})
```
````
