::tip
De forma predeterminada, los temas Shiki `material-theme-lighter` y `material-theme-palenight` se utilizan para el modo claro y oscuro respectivamente. Al usar `@nuxt/content`, puede cambiar esto a través de la clave [`content.build.markdown.highlight`](xph0666) en su `nuxt.config.ts`. configure los temas a través de la clave [`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations). Cuando use [Comarkxph073https://comark.dev), configure los temas a través de las opciones del complemento `shiki`.

Para admitir el modo oscuro con Comark, agregue el siguiente CSS a su hoja de estilo:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

### Archivo

Los bloques de código admiten la visualización del nombre del archivo con detección automática de iconos.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts [nuxt.config.ts]
export default defineNuxtConfig
  módulos:['@ nuxt/ui']
})
```
````

::

::tip
El icono del nombre de archivo es representado por el componente `ProseCodeIcon` y contiene un conjunto de iconos predefinidos que puede personalizar en la configuración de su aplicación:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Estos iconos de nombre de archivo provienen de la colección [`vscode-icons`](https://icones.js.org/collection/vscode-icons), que está separada de los iconos `lucide` que utilizan el resto de los componentes, y se resuelven a pedido desde la extensión de archivo.
::

Botón ### Copiar

Cada bloque de código tiene un botón de copia incorporado que copiará el código a su portapapeles.

Configure el accesorio `copy` en `false` para ocultar el botón, o pase los accesorios [Button](/docs/components/button) para personalizarlo.

::tip
Puede cambiar el icono a través de las teclas `ui.icons.copy` y `ui.icons.copyCheck` en la configuración de su aplicación:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

### Line resaltado

Resalta líneas específicas para llamar la atención sobre partes importantes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
export default defineNuxtConfig
  módulos:['@ nuxt/ui'],//Esta línea está resaltada
  css: ['/assets/css/main.css']
})
```
````

### Código diff

Utiliza el lenguaje `diff` para mostrar los cambios entre versiones de código.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export default defineNuxtConfig
  Módulos:[
-   '@ nuxt/ui-pro '(en inglés)
+   '@ nuxt/ui '
  ]
})
```
````
