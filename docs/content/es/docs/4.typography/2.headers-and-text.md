## Encabezamientos

Usa encabezados para organizar tu contenido y hacerlo más fácil de leer.

Los encabezados se pueden envolver en un enlace de anclaje cuando tienen un `id`, con un icono de hash que se muestra en el hover para `H2` y `H3` (en pantallas grandes) para que los lectores puedan vincular directamente a una sección.

Los enlaces de anclaje están habilitados de forma predeterminada para `H2` a `H4` cuando se usa `@nuxt/content`, y deshabilitados de lo contrario, [Comark](https://comark.dev) incluido.Use el componente [`Theme`ph014/docs/components/theme) con el prop `anchor` para alternarlos para una sección de su aplicación:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
Al usar `@nuxt/content`, los enlaces de anclaje están habilitados para `H2`, `H3` y `H4` de forma predeterminada. Puede controlar su [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks) (por ejemplo, para desactivarlos para las interfaces de chat de AI), así como la generation[xph034https://content.nuxt.com/docs/getting-started/configuration#toc) en su `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
