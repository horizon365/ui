@000@@Encabezamientos

Usa encabezados para organizar tu contenido y hacerlo más fácil de leer.

Los encabezados se pueden envolver en un enlace de anclaje cuando tienen un `id`, con un icono de hash que se muestra en el hover para `H2` y `H3`(en pantallas grandes) para que los lectores puedan vincular directamente a una sección.

Los enlaces de anclaje están habilitados por defecto para `H2` a `H4` cuando se usa `@nuxt/content`, y deshabilitados de otra manera,[Comark](https://comark.dev) incluido. Utilice el componente [`Theme`](/docs/components/theme) con el componente `anchor` prop para alternarlos para una sección de su aplicación:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxidad
:::div

::::note
Cuando se utiliza `@nuxt/content`, los enlaces de anclaje están habilitados para `H2`,`H3` y `H4` por defecto. Puede controlar su [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)(por ejemplo, para desactivarlos para las interfaces de chat de IA), así como la [toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc) en su `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
