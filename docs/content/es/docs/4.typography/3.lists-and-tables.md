## Listados

Markdown admite listas ordenadas, ordenadas y anidadas para diversas necesidades de contenido.

### Listas desordenadas

Utilice listas no ordenadas para elementos sin una secuencia específica. Comience cada elemento con un símbolo `-`.

::tabs{class="gap-0"}

::code-preview{label="preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Soy un elemento de lista.
- I es otro elemento de la lista.
- I soy el último elemento de la lista.

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### Listas ordenadas

Use listas ordenadas cuando el orden de los elementos sea importante, como los pasos de un proceso.

::tabs{class="gap-0"}

::code-preview{label="Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. I soy un elemento de lista.
2. I es otro elemento de la lista.
3. I soy el último elemento de la lista.

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### Listados anidados

Cree listas jerárquicas con subelementos para estructuras complejas. Indique los subelementos con cuatro espacios para anidar.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Soy un elemento de lista.
  - I es un elemento de lista anidado.
  - I soy otro elemento de lista anidado.
- I es otro elemento de la lista.
  - Otro elemento anidado
    - Objeto anidado profundo
    - Otro elemento anidado profundo
  - Volver al segundo nivel

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### Listas mixtas

Puede combinar listas ordenadas y no ordenadas para jerarquías complejas.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Primer paso importante
   - Sub-requisito A
   - Sub-requisito B
2. Segundo paso importante
   - Otro sub-artículo
   - Subartículo final
3. El último paso

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## Tables (Edición española)

Presentar datos estructurados en filas y columnas con claridad. Las tablas son ideales para comparar datos o enumerar propiedades.

::tabs{class="gap-0"}

::code-preview{label="Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| El Prop    | por defecto   | Tipo                     |
|---------|-----------|--------------------------|
| xf070x|           | `string`x{lang="ts-type"} (Edición española)|
| xf073x| xf074x      | `string`xx{lang="ts-type"} (Edición española)|
| xf077x| `neutral`| `string`xx{lang="ts-type"} (Edición española)|

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
