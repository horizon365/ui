## ¿ Qué son las habilidades?

Las habilidades son archivos de conocimiento estructurados que dan a los agentes de codificación de IA contexto sobre una biblioteca, marco o base de código. A diferencia de los servidores MCP que proporcionan acceso a herramientas en tiempo real, las habilidades se cargan directamente en el contexto del agente para que pueda hacer referencia a ellas a lo largo de la conversación.

Nuxt UI proporciona una habilidad **usage que enseña a los agentes de IA cómo crear interfaces de usuario con Nuxt UI: instalación, tematización, componentes, composiciones, formularios, superposiciones y diseños.

## Servicio

La habilidad de uso proporciona a los agentes de IA un conocimiento completo sobre la construcción con Nuxt UI v4.

- Instalación de Nuxt, Vue, Laravel y AdonisJS
- Tematización y branding con colores semánticos y variables CSS
- Todos los 125 + componentes con accesorios y patrones de uso
Xph007xComposables (Xph008x, Xph009x, Xph010x)
- Validación de formularios con esquema estándar
Composición - Layout (Dashboard, Docs, Chat, Editor)
- Plantillas oficiales de inicio

La habilidad incluye referencias adicionales que el agente de IA carga a pedido en función de la tarea, manteniendo las respuestas enfocadas y eficientes en el contexto.

::note
Una vez instalada, puede invocar la habilidad escribiendo `/nuxt-ui` en el chat de su agente.
::

### Skills CLI (Edición española)

La CLI [`skills`](https://skills.sh) es la forma más fácil de instalar la habilidad de interfaz de usuario de Nuxt. Admite más de 35 agentes, incluidos Cursor, Claude Code, Codex, Windsurf, Cline y más.

```bash
npx skills add nuxt/ui
```

Puede dirigirse a agentes específicos con la bandera `--agent`:

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

O instalarlo globalmente para que la habilidad esté disponible en todos sus proyectos:

```bash
npx skills add nuxt/ui --global
```

Si la clonación desde GitHub es lenta en su red, puede instalar directamente desde el sitio web:

```bash
npx skills add https://ui.nuxt.com
```

::tip
Visita [skills.sh](https://skills.sh) para obtener más información sobre el ecosistema de habilidades y explorar las habilidades disponibles.
::

### Cursor (Edición española)

#### Instalación rápida

Haga clic en el botón de abajo para instalar la habilidad de interfaz de usuario de Nuxt directamente en Cursor:

::u-button
---
to: "cursor://anysphere.cursor-deeplink/install-skill?url=https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui"
label: Install Skill
color: neutral
icon: i-simple-icons-cursor
---
::

#### Configuración manual

1. Abre el cursor y ve a "Configuración">"Habilidades"
2. Haga clic en "Añadir habilidad" e ingrese la siguiente URL:

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
