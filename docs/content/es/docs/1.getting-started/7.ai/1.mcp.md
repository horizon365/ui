## ¿ Qué es el MCP?

MCP (Model Context Protocol) es un protocolo estandarizado que permite a los asistentes de IA acceder a fuentes de datos y herramientas externas. Nuxt UI proporciona un servidor MCP que permite a los asistentes de IA como Claude Code, Cursor y Windsurf acceder directamente a la información de componentes, código fuente y ejemplos de uso.

El servidor MCP proporciona acceso estructurado a nuestra biblioteca de componentes, lo que facilita a las herramientas de IA comprender y ayudar con el desarrollo de la interfaz de usuario de Nuxt.

## Recursos disponibles

El servidor MCP de Nuxt UI proporciona los siguientes recursos para la detección:

- **`resource://nuxt-ui/components`**: Examinar todos los componentes disponibles con categorías
- **`resource://nuxt-ui/composables`**: Examinar todos los composables disponibles con categorías
- **`resource://nuxt-ui/examples`**: Examinar todos los ejemplos de código disponibles
- **`resource://nuxt-ui/templates`**: Examinar todas las plantillas de proyecto disponibles
- **`resource://nuxt-ui/documentation-pages`**: Examinar todas las páginas de documentación disponibles

Puede acceder a estos recursos con herramientas como Claude Code utilizando `@`.

## Herramientas disponibles

El servidor MCP de Nuxt UI proporciona las siguientes herramientas organizadas por categoría:

### Herramientas de búsqueda

- **`search-components`**: Buscar componentes por nombre, categoría o intención. Nombres alternativos como `"segmented control"` o `"combobox"` se comparan y los resultados se clasifican por relevancia. Sin parámetros, enumera todos los componentes.
- **`search-composables`**: Búsqueda de composables por nombre o descripción.
- **`search-icons`**: Busca iconos en las colecciones de Iconify (por defecto `lucide`). Devuelve nombres de iconos en el formato `i-{prefix}-{name}` utilizado por Nuxt UI

### Herramientas de componentes

- **`get-component`**: Recupera la documentación y los detalles de los componentes. Soporta un parámetro `sections` (`usage`, `examples`, `api`, `theme`, `changelog`) para obtener solo partes específicas y reducir el tamaño de la respuesta.
- **`get-component-metadata`**: Recupera metadatos para un componente incluyendo props, slots y eventos (ligero, sin contenido de documentación). Props son compactos por defecto, pase `full: true` para los esquemas de prop recursivos sin procesar

### Herramientas de Documentación

- **`search-documentation`**: Busca páginas de documentación por título, descripción o sección. Sin parámetros, enumera todas las páginas. Use `section` para filtrar (por ejemplo, `"getting-started"`, `"components"`)
- **`get-documentation-page`**: recupera el contenido de la página de documentación por ruta URL. admite un parámetro `headings` para obtener solo secciones h2 específicas (por ejemplo, `["Usage", "API"]`) y reducir el tamaño de la respuesta.

### Herramientas de plantilla

- **`list-templates`**: enumera todas las plantillas de interfaz de usuario de Nuxt disponibles con filtrado de framework opcional
- **`get-template`**: recupera la descripción, características y enlaces de una plantilla

### Herramientas de ejemplo

- **`list-examples`**: muestra los nombres de todos los ejemplos de interfaz de usuario disponibles
- **`get-example`**: Recupera el código fuente de un ejemplo de interfaz de usuario

### Herramientas de migración

- **`get-migration-guide`**: recupera la guía de migración y las instrucciones de actualización para esta versión de Nuxt UI

## Limit herramientas disponibles

Configure el encabezado HTTP opcional `X-MCP-Tools` en una lista de nombres de herramientas separados por comas para exponer solo las herramientas que necesita su asistente.

Utilice los nombres exactos de las herramientas MCP de kebab-case, por ejemplo:

```json
{
  "X-MCP-Tools": "search-components,get-component"
}
```

Ningún encabezado expone todas las herramientas, un encabezado vacío no expone ninguna herramienta y un nombre de herramienta desconocido devuelve un error de configuración.

## Prompts disponibles

El servidor MCP de Nuxt UI proporciona indicaciones guiadas para flujos de trabajo comunes:

- **`find-component-for-usecase`**: Encuentre el mejor componente para su caso de uso específico
- **`implement-component-with-props`**: Generar una implementación completa de componentes con los accesorios adecuados
- **`setup-project-with-template`**: Obtenga instrucciones de configuración guiadas para las plantillas de proyecto

Puede acceder a estos recursos con herramientas como Claude Code utilizando `/`.

### claude código

::note{icon="i-lucide-info"}
**Asegúrese de que el código Claude esté instalado.** Visite la documentación de [Anthropic ](https://docs.anthropic.com/en/docs/claude-code/quickstart) para obtener instrucciones de instalación.

Añadir el servidor utilizando el comando CLI:

```bash
claude mcp add --transport http nuxt-ui https://ui.nuxt.com/mcp
```

### claude escritorio

#### Instrucciones de instalación:

1. Abra Claude Desktop y vaya a "Configuración">"Desarrollador".
2. Haga clic en "Editar configuración". Esto abrirá el directorio local de Claude.
Modifica el archivo `claude_desktop_config.json` con la configuración personalizada del servidor MCP.

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://ui.nuxt.com/mcp"
      ]
    }
  }
}
```

4. Restart Claude Desktop app. El servidor MCP de la interfaz de usuario de Nuxt debería estar registrado.

### Gemini CLI (Edición española)

#### Instrucciones de instalación:

1. Localice el archivo de configuración de la CLI de Gemini (normalmente, el archivo.gemini/settings.json o el especificado en su entorno).
2. Agregue la siguiente configuración a su objeto mcpServers:

```json [~/.gemini/settings.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "httpUrl": "https://ui.nuxt.com/mcp"
    }
  }
}
```

3. Reinicie la sesión de su terminal o vuelva a cargar la CLI. Las herramientas del servidor MCP de la interfaz de usuario de Nuxt estarán disponibles para su uso.

### GitHub Agente de copiloto

::note{icon="i-lucide-info"}
**Repository administrator access required.** Esto es necesario para configurar los servidores MCP para el agente de codificación Copilot de GitHub.
::

Si ya ha configurado servidores MCP en [Visual Studio Code](#visual-studio-code), reemplace la clave `servers` por `mcpServers` y agregue una clave `tools` que especifique qué herramientas están disponibles para Copilot.

#### Instrucciones de configuración:

1. Navegar a su repositorio de GitHub
2. Ir a **Settings**> **Código y automatización**> **Copilot**> **Agente de codificación **
3. En la sección configuración**MCP, agregue la siguiente configuración:
  ```json
  {
    "mcpServers": {
      "nuxt-ui": {
        "type": "http",
        "url": "https://ui.nuxt.com/mcp",
        "tools": ["*"]
      }
    }
  }
  ```
4. Click para guardar

#### Validación de la configuración:

Para verificar que el servidor MCP está configurado correctamente:

1. Crear un problema en su repositorio y asignarlo a Copilot
2. Espera a que el copiloto cree una solicitud de extracción
3. En la solicitud de extracción, haga clic en Ver sesión en el evento de línea de tiempo "Copiloto comenzó a trabajar"
4. Haga clic en el botón de puntos suspensivos (...) en la parte superior derecha, luego haga clic en Copiloto en la barra lateral
5. Expanda el paso Iniciar servidores MCP para ver las herramientas Nuxt configuradas

Para obtener más información sobre el uso de MCP con el agente de codificación GitHub Copilot, consulte el agente de codificación [Extend con MCP](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp).

### GitHub Copilot CLI

#### Instrucciones de instalación:

1. Start GitHub Copilot CLI en modo interactivo.
2. Ejecutar `/mcp add`.
3. Rellena el formulario de configuración con:
   - **Servidor Name**: `nuxt-ui`
   - **Servidor Tipo de servidor: `HTTP`
   - x**URL**: `https://ui.nuxt.com/mcp`
   - **Headers**: dejar vacío
   - **Herramientas **: `*`
4. Pulse <kbd>Ctrl</kbd> + <kbd>S</kbd> para guardar. El servidor MCP está disponible inmediatamente sin reiniciar la CLI.

O agregue el servidor directamente a `~/.copilot/mcp-config.json`:

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "tools": ["*"]
    }
  }
}
```

Utilice `/mcp show` para confirmar que el servidor está configurado y disponible.

Para obtener más detalles, consulte [Adding MCP servers for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers).

::note{icon="i-lucide-info"}

## Ejemplos de uso

Una vez configurado, puede hacer preguntas a su asistente de IA como:

-  "Lista de todos los componentes de interfaz de usuario Nuxt disponibles"
-  "Obtener documentación de componentes del botón"
-  "Mostrar sólo los ejemplos de uso del botón"
-  "¿ Qué accesorios acepta Input?"
-  "Buscar componentes relacionados con la forma"
-  "Buscar iconos de flecha en lucide"
-  "Lista de plantillas de tablero"
-  "Obtener instrucciones de configuración de plantillas"
-  "Mostrar guía de instalación"
-  "Obtener la guía de migración"
-  "Lista de ejemplos"
-  "Obtener código de ejemplo de ContactForm"

El asistente de inteligencia artificial utilizará el servidor MCP para obtener datos JSON estructurados y proporcionar asistencia guiada para la interfaz de usuario de Nuxt durante el desarrollo.
