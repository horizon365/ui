## Configuración

### Añadir a un proyecto de Nuxt

::steps{level="4"}

#### Instalar el paquete Nuxt UI

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### Añadir el módulo de interfaz de usuario de Nuxt en su `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
No hay necesidad de añadir `@nuxt/icon`, `@nuxt/fonts` o `@nuxtjs/color-mode` a su matriz `modules` ya que Nuxt UI los registra automáticamente.Puede configurar estos módulos en su `nuxt.config.ts` utilizando las teclas `icon`, `fonts` y `colorMode`.
::

#### Importe Tailwind CSS y Nuxt UI en su CSS

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
Cuando se utiliza [Nuxt Layers](https://nuxt.com/docs/getting-started/layers), el módulo genera automáticamente directivas [xph044](https://tailwindcss.com/docs/functions-and-directives#source-directive) para cada directorio de capa, asegurando que Tailwind CSS escanee todos los archivos fuente de capa para clases de utilidad.
::

::callout{icon="i-simple-icons-visualstudiocode"}
Se recomienda instalar la extensión [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) para VSCode y añadir los siguientes ajustes:

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### Envuelva su aplicación con el componente de aplicación

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
El componente `App` configura la configuración global y es necesario para **Toast**, **Tooltip** y **superposiciones programáticas **.
::

::

Xph190xOpciones

Puede personalizar la interfaz de usuario de Nuxt proporcionando opciones en su `nuxt.config.ts`.

### x`prefix` (Edición española)

Utilice la opción `prefix` para cambiar el prefijo de los componentes.

- xDefault: `U`{lang="ts-type"} por defecto

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### x`fonts`

Utilice la opción `fonts` para activar o desactivar el módulo [`@nuxt/fonts`](https://github.com/nuxt/fonts).

- Default: `true`{lang="ts-type"} (en inglés)

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### x`colorMode`

Utilice la opción `colorMode` para activar o desactivar el módulo [`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode).

- Default: `true`x{lang="ts-type"} (en inglés)

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### x`theme.colors` (Edición española)

Utilice la opción `theme.colors` para definir los alias de color dinámicos utilizados para generar el tema de los componentes.

- Default: `['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"} por defecto

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
Cada alias genera un conjunto completo de tonos y variantes `--ui-color-*` en los temas de componentes que tienen variantes de color, ya sea que la aplicación lo use o no. Recorte la lista a los alias que realmente usa y conserve `error` si usa formularios, ya que los estilos de validación dependen de él.
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
Obtenga más información sobre la personalización del color y la tematización en la sección Tema.
::

### x`theme.transitions` (Edición española)

Utilice la opción `theme.transitions` para habilitar o deshabilitar las transiciones en los componentes.

- Default: `true`{lang="ts-type"} por defecto

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
Esta opción agrega la clase `transition-colors` a los componentes con estados activos o estacionarios.
::

### x`theme.unstyled`: badge{label="4.9+" class="align-text-top"}

Utilice la opción `theme.unstyled` para eliminar todas las clases de tema predeterminadas de los componentes, manteniendo solo su estructura y las clases que proporcione a través de `class`, `ui` o `app.config.ui`.

- Default: `false`x{lang="ts-type"} por defecto

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
Esto elimina también las clases **structural** (posicionamiento, transiciones, flex/grid), no solo las cosméticas.Los componentes pesados en la disposición como `Modal`, `Drawer` o `Calendar` necesitarán que vuelva a suministrar su diseño, similar al modo sin estilo de PrimeVue.
::

Xph310xx`theme.defaultVariants` (Edición española)

Utilice la opción `theme.defaultVariants` para anular las variantes `color` y `size` predeterminadas para los componentes.

Sólo los valores predeterminados que son exactamente `primary` o `md` se sustituyen, por lo que Avatar mantiene `color: 'neutral'` y Separator mantiene `size: 'xs'`.

- Default: `{ color: 'primary', size: 'md' }`{lang="ts-type"} (en inglés)

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### x`theme.prefix` y badge{label="4.2+" class="align-text-top"}

Utilice la opción `theme.prefix` para configurar el mismo prefijo que estableció en su importación de Tailwind CSS. Esto garantiza que los componentes de la interfaz de usuario de Nuxt utilicen las clases de utilidad y las variables CSS prefijadas correctas.

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
Es posible que tenga que habilitar `fonts.processCSSVariables` para usar la opción de prefijo con el módulo `@nuxt/fonts`:

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

Esto prefijará automáticamente todas las clases de utilidad Tailwind y las variables CSS en los temas de componentes de interfaz de usuario de Nuxt:

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Obtenga más información sobre el uso de un prefijo en la documentación de Tailwind CSS.
::

### x`prose`

Utilice la opción `prose` para forzar la importación de los componentes de Nuxt UI [`Prose`](/docs/typography) incluso si no está instalado `@nuxtjs/mdc`, `@nuxt/content` o `@comark/nuxt`.

- Default: `false`{lang="ts-type"} (en inglés)

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc`: badge{label="Deprecated" color="warning" class="align-text-top"} (en inglés)

En su lugar, utilice la opción [`prose`](#prose).

### x`content`

Utilice la opción `content` para forzar la importación de los componentes de prosa y contenido de la interfaz de usuario de Nuxt, incluso si no está instalado `@nuxt/content`.

- Default: `false`{lang="ts-type"} (en inglés)

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### x`experimental.componentDetection`: badge{label="4.1+" class="align-text-top"}

Utilice la opción `experimental.componentDetection` para habilitar la detección automática de componentes para el tree-shaking. Esta función escanea su código fuente para detectar qué componentes se utilizan realmente y solo genera el CSS necesario para esos componentes (incluidas sus dependencias).

- Default: `false`{lang="ts-type"} (en español)
Tipo de teléfono: `boolean | string[]`{lang="ts-type"}

**Habilitar la detección automática: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

** Incluye componentes adicionales para uso dinámico: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
Cuando se proporciona una matriz de nombres de componentes, se habilita la detección automática y se garantiza que estos componentes (junto con sus dependencias) se incluirán. Esto es útil para componentes dinámicos como `<component :is="..." />` que no se pueden analizar estáticamente.
::

## Liberaciones continuas

La interfaz de usuario de Nuxt utiliza [pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new) para versiones de vista previa continuas, proporcionando a los desarrolladores acceso instantáneo a las últimas funciones y correcciones de errores sin esperar a versiones oficiales.

Se crean versiones de vista previa automáticas para todos los commits y PRs de la rama `v4`.Utilízalos reemplazando la versión de tu paquete con el hash de commit o número de PR específico.

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new** comentará automáticamente los PR con la URL de instalación, lo que facilita la prueba de cambios.
::
