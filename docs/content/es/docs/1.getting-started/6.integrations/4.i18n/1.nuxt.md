## Uso

::note{to="/docs/components/app"}
La interfaz de usuario de Nuxt proporciona un componente **App** que envuelve su aplicación para proporcionar configuraciones globales, incluido el soporte `locale`.
::

### Localidad

Utilice el prop `locale` con la configuración regional que desea utilizar desde `@nuxt/ui/locale`:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Cada localidad tiene una propiedad `code` (por ejemplo, `en`, `en-GB`, `fr`) que determina el formato de fecha/hora en componentes como [Calendar](/docs/components/calendar), [InputDate](xph030) y [InputTime](xph034).
::

### Localización personalizada

Puede crear su propia configuración regional utilizando la utilidad [defineLocale](/docs/composables/define-locale):

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Mira el parámetro `code`, allí necesitas pasar el código ISO del idioma. Ejemplo:

* x`hi` Español (idioma)
* `de-AT`: alemán (idioma) como se usa en Austria (región)

::

### Extend Localidad

Puede personalizar una configuración regional existente anulando su `messages` o `code` utilizando la utilidad [extendLocale](/docs/composables/extend-locale):

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Localidad dinámica

Para cambiar dinámicamente entre idiomas, puede usar el módulo [Nuxt I18n](https://i18n.nuxtjs.org/).

::steps{level="4"}

#### Instalar el paquete Nuxt I18n

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

Añadir el módulo Nuxt I18n en su `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### Configurar el accesorio `locale` usando `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### Localización automática de enlaces: badge{label="4.7+" class="align-text-top"}

Cuando se instala `@nuxtjs/i18n`, el componente [Link](/docs/components/link) localiza automáticamente los enlaces internos utilizando el ayudante `$localePath`.Esto significa que no necesita envolver manualmente sus enlaces con `localePath()` o `localeRoute()`.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
Los enlaces externos y las URL absolutas se detectan automáticamente y omiten la localización. Todavía puede usar manualmente `localePath()` o `localeRoute()` si es necesario.
::

::

### Dirección dinámica

Cada locale tiene una propiedad `dir` que será utilizada por el componente `App` para establecer la direccionalidad de todos los componentes.

En una aplicación multilingüe, es posible que desee establecer los atributos `lang` y `dir` en el elemento `<html>` de forma dinámica en función de la configuración regional del usuario, lo que puede hacer con el componente [useHead](https://nuxt.com/docs/api/composables/use-head):

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
