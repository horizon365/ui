@@pH002@@Uso de la aplicación

::note{to="/docs/components/app"}
Nuxt UI proporciona un componente **App** que envuelve su aplicación para proporcionar configuraciones globales, incluida la prop.
::

@0006@Proyecto

Utilice el prop `locale` con la configuración regional que desea utilizar desde `@nuxt/ui/locale`:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Cada locale tiene una propiedad `code`(por ejemplo,`en`,`en-GB`,`fr`) que determina el formato de fecha/hora en componentes como [Calendar ](/docs/components/calendar),[InputDate](/docs/components/input-date) y [InputTime](/docs/components/input-time).
::

### Localización personalizada

Puede crear su propia configuración regional utilizando la utilidad [defineLocale](/docs/composables/define-locale):

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Mire el parámetro `code`, allí necesita pasar el código iso del idioma. Ejemplo:

* `hi` Español (Español)
* `de-AT`: alemán (idioma) como se usa en Austria (región)

::

### Extender la ubicación

Puede personalizar una configuración regional existente anulando su `messages` o `code` usando la utilidad [extendLocale](/docs/composables/extend-locale):

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Localización dinámica

Para cambiar dinámicamente entre idiomas, puede utilizar el módulo [Nuxt I18n](https://i18n.nuxtjs.org/).

::steps{level="4"}

#### Instalar el paquete Nuxt I18n

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### Agregue el módulo Nuxt I18n en su `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### Establecer el `locale` prop usando `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### Localización automática del enlace: badge{label="4.7+" class="align-text-top"}

Cuando el `@nuxtjs/i18n` está instalado, el componente [Link](/docs/components/link) localiza automáticamente los enlaces internos utilizando el ayudante `$localePath`. Esto significa que no necesita envolver manualmente sus enlaces con `localePath()` o `localeRoute()`.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
Los enlaces externos y las URL absolutas se detectan automáticamente y omiten la localización. Puede utilizar manualmente `localePath()` o `localeRoute()` si es necesario.
::

::

### Dirección dinámica

Cada locale tiene una propiedad `dir` que será utilizada por el componente `App` para establecer la direccionalidad de todos los componentes.

En una aplicación multilingüe, es posible que desee establecer los atributos `lang` y `dir` en el elemento `<html>` dinámicamente en función de la configuración regional del usuario, lo que puede hacer con el [useHead](https://nuxt.com/docs/api/composables/use-head) componible:

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
