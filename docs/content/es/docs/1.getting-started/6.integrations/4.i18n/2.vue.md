## Uso

::note{to="/docs/components/app"}
La interfaz de usuario de Nuxt proporciona un componente **App** que envuelve su aplicación para proporcionar configuraciones globales, incluido el soporte `locale`.
::

### Localidad

Utilice el prop `locale` con la configuración regional que desea utilizar desde `@nuxt/ui/locale`:

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
Cada localidad tiene una propiedad `code` (por ejemplo, `en`, `en-GB`, `fr`) que determina el formato de fecha/hora en componentes como [Calendar](/docs/components/calendar), [InputDate](xph030) y [InputTime](xph034).
::

### Localización personalizada

Puede crear su propia configuración regional utilizando la utilidad [defineLocale](/docs/composables/define-locale):

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
Mire el parámetro `code`, allí debe pasar el código iso del idioma. Ejemplo:

* x`hi` Español (idioma)
* `de-AT`: alemán (idioma) como se usa en Austria (región)

::

### Extend Localidad

Puede personalizar una configuración regional existente anulando su `messages` o `code` utilizando la utilidad [extendLocale](/docs/composables/extend-locale):

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### Localización dinámica

Para cambiar dinámicamente entre idiomas, puede usar el complemento [Vue I18n](https://vue-i18n.intlify.dev/).

::steps{level="4"}

#### Instalar el paquete Vue I18n

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### Use el plugin Vue I18n en su `main.ts`

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

#### Configurar el accesorio `locale` con `useI18n`

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

::

### Dirección dinámica

Cada locale tiene una propiedad `dir` que será utilizada por el componente `App` para establecer la direccionalidad de todos los componentes.

En una aplicación multilingüe, es posible que desee establecer los atributos `lang` y `dir` en el elemento `<html>` de forma dinámica en función de la configuración regional del usuario, lo que puede hacer con el componente [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head):

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
