@@pH002@@Uso de la información

Nuxt UI registra automáticamente el módulo [`@nuxtjs/color-mode`](https://github.com/nuxt-modules/color-mode) por ti, por lo que no se requiere configuración adicional.

@008@Componentes

Puede utilizar los componentes integrados [ColorModeAvatar](/docs/components/color-mode-avatar) o [ColorModeImage](/docs/components/color-mode-image) para mostrar diferentes imágenes para el modo claro y oscuro y el [ColorModeButton](/docs/components/color-mode-button), Componentes [ColorModeSwitch](/docs/components/color-mode-switch) o [ColorModeSelect](/docs/components/color-mode-select) para cambiar entre los modos claro y oscuro.

También puede utilizar el [useColorMode](https://color-mode.nuxtjs.org/usage/basic) composable para construir su propio componente personalizado:

```vue [ColorModeButton.vue]
<script setup lang="ts">
const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark) {
    colorMode.preference = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <ClientOnly v-if="!colorMode?.forced">
    <UButton
      :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
      color="neutral"
      variant="ghost"
      :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
      @click="isDark = !isDark"
    />

    <template #fallback>
      <div class="size-8" />
    </template>
  </ClientOnly>
</template>
```

@@pH063@@Configuración

Puede desactivar el módulo `@nuxtjs/color-mode` con la opción `ui.colorMode` en su `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```
