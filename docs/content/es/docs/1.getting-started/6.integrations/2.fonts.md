@@pH000@@Uso del producto

Nuxt UI registra automáticamente el módulo [`@nuxt/fonts`](https://github.com/nuxt/fonts) por ti, por lo que no se requiere configuración adicional.

@@pH006@Declaración

Para utilizar una fuente en su aplicación de interfaz de usuario de Nuxt, simplemente puede declararla en su CSS.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

@@P015@Configuración

Puede desactivar el módulo `@nuxt/fonts` con la opción `ui.fonts` en su `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
