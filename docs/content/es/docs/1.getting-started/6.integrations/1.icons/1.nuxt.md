@@pH002@@Uso de la información

Nuxt UI registra automáticamente el módulo [`@nuxt/icon`](https://github.com/nuxt/icon) por ti, por lo que no se requiere configuración adicional.

### Icon Componente

Puede usar el componente [Icon](/docs/components/icon) con un prop `name` para mostrar un icono:

::component-code{slug="icon"}
---
Props:
  Nombre: i-lucide-lightbulb
  Categoría:"Size-5"
---
::

::note
Puede utilizar cualquier nombre de la colección <https://iconify.design>. Navegar por ellos fácilmente en <https://icones.js.org> o buscar directamente desde su asistente de IA utilizando la herramienta MCP [`search-icons`](/docs/getting-started/ai/mcp#available-tools).
::

### Componente de accesorios

Algunos componentes también tienen un prop `icon` para mostrar un icono, como el [Button](/docs/components/button) por ejemplo:

::component-code{slug="button"}
---
Ignora:
  @27@color
  @28@Variación
Props:
  i-lucide-sun
  Variación: Subtil
Los slots:
  por defecto: Button
---
::

@@29@@Colecciones

### Iconify conjunto de datos

Se recomienda encarecidamente instalar los datos de icono localmente con:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Por ejemplo, para usar el icono `i-uil-github`, instale su colección con `@iconify-json/uil`. De esta manera, los iconos se pueden servir localmente o desde sus funciones sin servidor, lo que es más rápido y confiable tanto en SSR como en el lado del cliente.

La instalación de la colección también permite a Nuxt UI incrustar los iconos que utiliza en el paquete del cliente en el momento de la compilación, por lo que están disponibles en el primer renderizado en lugar de cargarse bajo demanda en tiempo de ejecución. Esto sucede automáticamente para los iconos propios de Nuxt UI, de la colección `lucide` de forma predeterminada. Añádelos a `@nuxt/icon`'s [`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle) en su `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

O habilite `clientBundle.scan` para agrupar todos los iconos utilizados en su aplicación escaneando su fuente, por lo que no tiene que enumerarlos uno por uno:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

El escaneo solo lee los archivos `.vue`,`.jsx`,`.tsx`,`.md`,`.mdc`,`.mdx`,`.yml` y `.yaml`, y solo coincide con los nombres de los iconos escritos como cadenas literales. como son los nombres construidos dinámicamente como `i-lucide-${name}`. Configure `globInclude` para escanear esos archivos también. Reemplaza la lista predeterminada, así que mantenga las extensiones que todavía necesita:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

Los nombres dinámicos aún se pueden agrupar cuando conoce todo el conjunto en el momento de la compilación, al enumerarlos en `clientBundle.icons`. Los nombres que solo existen en tiempo de ejecución, como los iconos que provienen de una API, no se pueden agrupar en absoluto. Se cargan a pedido desde la ruta `/api/_nuxt_icon` cuando su aplicación se procesa en el servidor, con la API de Iconify como alternativa, y desde la API de Iconify directamente cuando utiliza `nuxt generate` o `ssr: false`.

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
Lea más sobre esto en la documentación `@nuxt/icon`.
::

### Colecciones locales personalizadas

Puede usar archivos SVG locales para crear una colección de Iconify personalizada.

Por ejemplo, coloca los archivos SVG de tus iconos en una carpeta de tu elección, por ejemplo,`./app/assets/icons`:

```bash
assets/icons
├── add.svg
└── remove.svg
```

En su `nuxt.config.ts`, agregue un elemento en `icon.customCollections`:

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

Puedes usar iconos como este:

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
Lea más sobre esto en la documentación `@nuxt/icon`.
::
