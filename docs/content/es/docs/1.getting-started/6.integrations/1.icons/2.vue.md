@@pH002@@Uso de la información

La interfaz de usuario de Nuxt incluye un componente `Icon` respaldado por [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/), por lo que no se requiere configuración adicional.

### Icon Componente

Puede utilizar el componente [Icon](/docs/components/icon) con un prop `name` para mostrar un icono:

::component-code{slug="icon"}
---
Props:
  Nombre: i-lucide-lightbulb
  Categoría:'Size-5'
---
::

::note
Puede utilizar cualquier nombre de la colección <https://iconify.design>. Navegar por ellos fácilmente en <https://icones.js.org> o buscar directamente desde su asistente de IA utilizando la herramienta MCP [`search-icons`](/docs/getting-started/ai/mcp#available-tools).
::

::warning
Cuando se utilizan colecciones con un guión (`-`), es necesario separar el nombre del icono del nombre de la colección con dos puntos (`:`) como `@iconify/vue` no maneja este caso como `@nuxt/icon`.

Obtenga más información sobre la convención de nombres [Iconify ](https://iconify.design/docs/icon-components/vue/#icon).
::

### Componente de accesorios.

Algunos componentes también tienen un prop `icon` para mostrar un icono, como el [Button](/docs/components/button) por ejemplo:

::component-code{slug="button"}
---
Ignora:
  @39@color
  - Variación
Props:
  i-lucide-sun
  Variación: Subtil
Los slots:
  por defecto: Button
---
::

## Colecciones

### Iconify conjunto de datos

Se recomienda encarecidamente instalar los datos de icono localmente con:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Por ejemplo, para usar el icono `i-lucide-lightbulb`, instale su colección con `@iconify-json/lucide`.

La instalación de la colección permite a Nuxt UI incrustar los iconos que utiliza en su compilación, por lo que se renderizan de inmediato durante SSR y funcionan completamente sin conexión en lugar de ser recuperados de la API de Iconify en tiempo de ejecución. Esto sucede automáticamente para los propios iconos de Nuxt UI, de la colección `lucide` por defecto.

Para agrupar otros iconos, como los que se anulan o se utilizan en otra parte de la aplicación, agréguelos a la opción `icon.clientBundle.icons` en su `vite.config.ts`:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
Puede utilizar el formulario `i-{collection}-{name}` o `{collection}:{name}`, por ejemplo `i-lucide-heart` o `lucide:heart`, y `i-material-symbols-menu` o `material-symbols:menu`. Instale cada colección a la que haga referencia con `@iconify-json/{collection_name}`.
::

Para agrupar los iconos que utiliza sin enumerarlos uno por uno, habilite `scan` en su lugar. Escanea su fuente para usos de iconos de sus colecciones instaladas y los agrupa, de la misma manera que `@nuxt/icon`'s `clientBundle.scan` funciona:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

El escaneo solo lee los archivos `.vue`,`.jsx`,`.tsx`,`.md`,`.mdc`,`.mdx`,`.yml` y `.yaml`, y solo coincide con los nombres de iconos escritos como cadenas literales. como son los nombres construidos dinámicamente como `i-lucide-${name}`. Configure `globInclude` para escanear esos archivos también. Reemplaza la lista predeterminada, así que mantenga las extensiones que todavía necesita:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

Los nombres dinámicos aún se pueden agrupar cuando conoce todo el conjunto en el momento de la compilación, enumerándolos en `clientBundle.icons`. Los nombres que solo existen en tiempo de ejecución, como los iconos que provienen de una API, no se pueden agrupar en absoluto y se cargan desde la API de Iconify a pedido.

Los iconos cuya colección no está instalada aún se cargan desde la API de Iconify en tiempo de ejecución, por lo que instale cada colección que use con `@iconify-json/{collection_name}`. Para optar por no agrupar por completo, establezca `icon.clientBundle` a `false`.
