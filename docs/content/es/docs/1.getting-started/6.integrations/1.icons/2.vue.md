## Uso

La interfaz de usuario de Nuxt incluye un componente `Icon` respaldado por [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/), por lo que no se requiere configuración adicional.

Componente ### Icon

Puede utilizar el componente [Icon](/docs/components/icon) con un prop `name` para mostrar un icono:

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
Puede utilizar cualquier nombre de la colección <https://iconify.design>.Examínelos fácilmente en <https://icones.js.org> o busque directamente desde su asistente de IA utilizando la herramienta MCP [`search-icons`xph022/docs/getting-started/ai/mcp#available-tools).
::

::warning
Cuando se utilizan colecciones con un guión (`-`), es necesario separar el nombre del icono del nombre de la colección con dos puntos (`:`) ya que `@iconify/vue` no maneja este caso como `@nuxt/icon`.

Obtenga más información sobre la convención de nombres [Iconify ](https://iconify.design/docs/icon-components/vue/#icon).
::

### Componentes accesorios

Algunos componentes también tienen un prop `icon` para mostrar un icono, como el [Button](/docs/components/button) por ejemplo:

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## colecciones

### Iconify Dataset (Edición española)

Se recomienda encarecidamente instalar los datos de icono localmente con:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Por ejemplo, para usar el icono `i-lucide-lightbulb`, instale su colección con `@iconify-json/lucide`.

La instalación de la colección permite a Nuxt UI incrustar los iconos que utiliza en su compilación, por lo que se renderizan de inmediato durante SSR y funcionan completamente sin conexión en lugar de ser recuperados de la API de Iconify en tiempo de ejecución.

Para agrupar otros iconos, como los que se anulan o utilizan en otra parte de la aplicación, agréguelos a la opción `icon.clientBundle.icons` en su `vite.config.ts`:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
Puede usar el formulario `i-{collection}-{name}` o `{collection}:{name}`, por ejemplo, `i-lucide-heart` o `lucide:heart`, y `i-material-symbols-menu` o `material-symbols:menu`.
::

Para agrupar los iconos que usa sin enumerarlos uno por uno, habilite `scan` en su lugar. Escanea su fuente en busca de usos de iconos de sus colecciones instaladas y los agrupa, de la misma manera que funciona `clientBundle.scan` de `@nuxt/icon`:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

El escaneo solo lee los archivos `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` y `.yaml`, y solo coincide con los nombres de iconos escritos como cadenas literales. como son los nombres construidos dinámicamente como `i-lucide-${name}`. Configure `globInclude` para escanear esos archivos también. Reemplaza la lista predeterminada, así que mantenga las extensiones que todavía necesita:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

Los nombres dinámicos aún se pueden agrupar cuando conoce todo el conjunto en el momento de la compilación, enumerándolos en `clientBundle.icons`. Los nombres que solo existen en tiempo de ejecución, como los iconos que provienen de una API, no se pueden agrupar en absoluto y se cargan desde la API de Iconify a pedido.

Los iconos cuya colección no está instalada aún se cargan desde la API de Iconify en tiempo de ejecución, por lo que instale cada colección que use con `@iconify-json/{collection_name}`.
