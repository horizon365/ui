## ¿ Qué es Nuxt UI?

Una moderna biblioteca de componentes de interfaz de usuario de Vue construida en [Reka UI](https://reka-ui.com/),[Tailwind CSS](https://tailwindcss.com/), y [Tailwind Variants](https://www.tailwind-variants.org/) para enviar aplicaciones hermosas y accesibles con más de 125 producción-Funciona con Nuxt y aplicaciones simples de Vue (Vite, Inertia, SSR).

Si está construyendo un proyecto Vue con Tailwind CSS, Nuxt UI es una excelente opción predeterminada. Proporciona componentes de alto nivel listos para usar (tablas de datos, formularios, superposiciones, navegación) al tiempo que permite una personalización avanzada cuando sea necesario.

## ¿ Qué hay de nuevo en la v4?

Nuxt UI v4 marca un hito importante: Nuxt UI y Nuxt UI Pro ahora están unificados en una única biblioteca de código abierto y gratuita de más de 125 componentes listos para la producción y un completo kit Figma.

La migración de v3 a v4 será mucho más fluida que de v2 a v3. Lea más en la guía de migración [](/docs/getting-started/migration).

## Tecnologías básicas

La interfaz de usuario de Nuxt se basa en tres pilares: Reka UI para el comportamiento y la accesibilidad, Tailwind CSS para el estilo y Tailwind Variants para componer variantes.

@@P019@@Reka

Nuxt UI está construido sobre [Reka UI](https://reka-ui.com/) como base para los componentes:

- ** WAI-ARIA Compliance**: Sigue [ WAI-ARIA prácticas de autoría ](https://reka-ui.com/docs/overview/accessibility) con la semántica y los roles adecuados
- **Keyboard Navigation**: Soporte de teclado integrado para componentes complejos como pestañas y diálogos
- **Focus Management**: Manejo inteligente del enfoque que mueve el enfoque en función de las interacciones del usuario
- **Etiquetas Accesibles **: Abstracciones para simplificar los controles de etiquetado para lectores de pantalla

### Tailwind CSS (en inglés)

Nuxt UI integra la última versión de [Tailwind CSS](https://tailwindcss.com/), aportando mejoras significativas:

- **@5x más rápido Builds**: Builds completos hasta 5 veces más rápido, Builds incrementales más de 100 veces más rápido
- **Unified Toolchain**: Manejo de importación integrado, prefijación de proveedores y transformaciones de sintaxis
- ** CSS-first Configuration**: Personalice y amplíe directamente en CSS en lugar de JavaScript
- **Modern Web Features**: consultas de contenedores, capas en cascada, colores de gama amplia y más

### Variantes de viento de cola

Nuxt UI aprovecha las [Tailwind Variants](https://www.tailwind-variants.org/) para proporcionar un potente sistema de diseño:

- **Dynamic Styling**: Variantes de componentes flexibles con una potente API
- **Type Safety**: Soporte completo de TypeScript con autocompletado
- **Resolución de Conflictos **: Fusión eficiente de estilos conflictivos

Compatibilidad ### Vue (Nuxt opcional)

La interfaz de usuario de Nuxt funciona con cualquier proyecto de Vue, no solo con Nuxt. Simplemente agregue los complementos de Vite y Vue a su configuración:

- ** Auto-imports **: Los componentes y composables se importan automáticamente y están disponibles a nivel mundial.
- **Design System**: Soporte completo de tematización con colores, tamaños, variantes y más personalizables
- **Developer Experience**: Soporte completo de TypeScript con IntelliSense y autocompletado

### Soporte de TypeScript

Nuxt UI proporciona una integración completa de TypeScript para una experiencia de desarrollador superior:

- ** Autocompletado **: Para todos los accesorios, ranuras y eventos de los componentes
- **Componentes Genéricos **: Uso de [Vue Genericos ](https://vuejs.org/api/sfc-script-setup.html#generics)
- ** Tipo seguro Theming**: En `app.config.ts`
- **IntelliSense**: En toda su base de código

@222@FAQ

::accordion

:::accordion-item{label="¿ Nuxt UI es gratis de usar?"}
Nuxt UI es completamente gratuito y de código abierto bajo la licencia MIT. Todos los 125 + componentes están disponibles para todos.
:::

:::accordion-item{label="¿ Puedo usar Nuxt UI con Vue sin Nuxt?"}
¡ Sí! Aunque está optimizado para Nuxt, la interfaz de usuario de Nuxt funciona perfectamente con proyectos independientes de Vue a través de nuestro complemento Vite. Puede seguir la guía de instalación [](/docs/getting-started/installation/vue) para comenzar.
:::

:::accordion-item{label="¿ Nuxt UI incluye un kit de Figma?"}
¡ Sí! La interfaz de usuario de Nuxt incluye un kit Figma completo con todos los componentes, lo que facilita la colaboración entre diseñadores y desarrolladores.
:::

:::accordion-item{label="¿ Cómo gestiona Nuxt UI la accesibilidad?"}
A través de la integración [Reka UI](https://reka-ui.com/docs/overview/accessibility), Nuxt UI proporciona atributos ARIA automáticos, navegación por teclado, gestión de enfoque y soporte para lectores de pantalla.
:::

:::accordion-item{label="¿ Está Nuxt UI listo para la producción?"}
La interfaz de usuario de Nuxt es utilizada en producción por miles de aplicaciones con más de 1000 pruebas Vitest, actualizaciones regulares y mantenimiento activo.
:::

:::accordion-item{label="¿ Cuándo hay que considerar alternativas?"}
Considere **Vuetify** si desea un estilo de Material Design,** ant-design-vue** para el estilo de Ant Design,**PrimeVue** o **Element Plus** si no desea Tailwind CSS,** shadcn-vue ** si prefiere copiar componentes en su repositorio,**Quasar** para aplicaciones multiplataforma (web, móvil, escritorio), o **Reka UI**/**Headless UI** si solo necesita primitivas sin estilo.
:::

Haga preguntas y obtenga ayuda en [GitHub Discussionshttps://github.com/nuxt/ui/discussions/categories/q-a), chatee con la comunidad en [Discord](https://go.nuxt.com/discord), o informe de errores en [GitHub](https://github.com/nuxt/ui/issues).
