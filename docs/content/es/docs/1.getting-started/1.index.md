## ¿ Qué es Nuxt UI?

Una moderna biblioteca de componentes de interfaz de usuario de Vue construida sobre [Reka UI](https://reka-ui.com/), [Tailwind CSS](https://tailwindcss.com/) y [Tailwind Variants](xph011) para enviar aplicaciones hermosas y accesibles con más de 125 componentes listos para producción.

Si está construyendo un proyecto Vue con Tailwind CSS, Nuxt UI es una excelente opción predeterminada. Proporciona componentes de alto nivel listos para usar (tablas de datos, formularios, superposiciones, navegación) al tiempo que permite una personalización avanzada cuando sea necesario.

Tecnologías ## Core

La interfaz de usuario de Nuxt se basa en tres pilares: Reka UI para el comportamiento y la accesibilidad, Tailwind CSS para el estilo y Tailwind Variants para componer variantes.

### Reka UI (Edición española)

La interfaz de usuario de Nuxt está construida sobre [Reka UI](https://reka-ui.com/) como base para los componentes:

- **WAI-ARIA Compliance**: Sigue las prácticas de autoría [WAI-ARIA ](xph043) con la semántica y los roles adecuados
- **Keyboard Navigation**: Soporte de teclado integrado para componentes complejos como pestañas y diálogos
- **Focus Management**: Manejo inteligente del enfoque que mueve el enfoque según las interacciones del usuario
- **Etiquetas accesibles **: Abstracciones para simplificar los controles de etiquetado para lectores de pantalla

### Tailwind CSS (Edición española)

La interfaz de usuario de Nuxt integra la última versión de [Tailwind CSS](https://tailwindcss.com/), que aporta mejoras significativas:

- **5x Faster Builds**: Builds completos hasta 5 veces más rápido, Builds incrementales más de 100 veces más rápido
- **Unified Toolchain**: Manejo de importaciones integrado, prefijación de proveedores y transformaciones de sintaxis
- **CSS-first Configuration**: Personalizar y extender directamente en CSS en lugar de JavaScript
- **Modern Web Features**: consultas de contenedores, capas en cascada, colores de amplia gama y más

### Variantes de Tailwind

La interfaz de usuario de Nuxt aprovecha las variantes de Tailwind ](https://www.tailwind-variants.org/) para proporcionar un potente sistema de diseño:

- **Dynamic Styling**: Variantes de componentes flexibles con una potente API
- **Type Safety**: Soporte completo de TypeScript con autocompletado
- **Resolución de conflictos**: Fusión eficiente de estilos conflictivos

Compatibilidad con ### Vue (Nuxt opcional)

La interfaz de usuario de Nuxt funciona con cualquier proyecto de Vue, no solo con Nuxt. Simplemente agregue los complementos de Vite y Vue a su configuración:

- **Autoimports**: Componentes y composables se importan automáticamente y están disponibles globalmente
- **Design System**: Soporte completo de tematización con colores, tamaños, variantes y más personalizables
- **Developer Experience**: Soporte completo de TypeScript con IntelliSense y autocompletado

## FAQ (en inglés)

::accordion

:::accordion-item{label="¿ Nuxt UI es gratis de usar?"}
Nuxt UI es completamente gratuito y de código abierto bajo la licencia MIT. Todos los 125 componentes están disponibles para todos.
:::

:::accordion-item{label="¿ Puedo usar Nuxt UI con Vue sin Nuxt?"}
¡ Sí! Aunque está optimizado para Nuxt, la interfaz de usuario de Nuxt funciona perfectamente con proyectos independientes de Vue a través de nuestro complemento Vite. Puede seguir la guía de instalación [](/docs/getting-started/installation/vue) para comenzar.
:::

:::accordion-item{label="¿ Nuxt UI incluye un kit de Figma?"}
¡ Sí! La interfaz de usuario de Nuxt incluye un Figma Kit](https://go.nuxt.com/figma-ui) [complete con todos los componentes, lo que facilita la colaboración entre diseñadores y desarrolladores.
:::

:::accordion-item{label="¿ Cómo gestiona Nuxt UI la accesibilidad?"}
A través de la integración [Reka UI](https://reka-ui.com/docs/overview/accessibility), Nuxt UI proporciona atributos ARIA automáticos, navegación por teclado, gestión de enfoque y soporte para lectores de pantalla.
:::

:::accordion-item{label="¿ Está Nuxt UI listo para la producción?"}
La interfaz de usuario de Nuxt es utilizada en producción por miles de aplicaciones con más de 1000 pruebas Vitest, actualizaciones regulares y mantenimiento activo.
:::

:::accordion-item{label="¿ Cuándo hay que considerar alternativas?"}
Considere **Vuetify** si desea un estilo de diseño de materiales, **ant-design-vue** para el estilo de diseño de hormigas, **PrimeVue** o **Element Plus** si no desea Tailwind CSS, **shadcn-vue** si prefiere copiar componentes en su repositorio, **Quasar** para aplicaciones multiplataforma (web, mobile, desktop), or **Reka UI**/**Headless UI** if you only need unstyled primitives.
:::

:::accordion-item{label="¿ Dónde puedo obtener ayuda?"}
Haz preguntas y obtén ayuda en GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a), chatea con la comunidad en [Discord](https://go.nuxt.com/discord) o informa de errores en [GitHub](xph284).
:::
