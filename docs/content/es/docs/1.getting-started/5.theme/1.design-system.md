## Tailwind CSS (en inglés)

Tailwind CSS utiliza una configuración CSS primero, lo que le permite definir sus tokens de diseño con la directiva [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive) directamente en su CSS.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
Consulte la documentación de Tailwind CSS para ver todas las opciones de personalización de variables de tema disponibles.
::

::tip
Tailwind CSS v4 cambió su [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) para que los botones usen `cursor: default` en lugar de `cursor: pointer` para que coincidan con los valores predeterminados del navegador.

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### Fuentes (Edición española)

Utilice las variables de tema `--font-*` para personalizar las utilidades de la familia de fuentes ](https://tailwindcss.com/docs/font-family#customizing-your-theme) en su proyecto.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

::framework-only
#nuxt
:::note{to="/docs/getting-started/integrations/fonts"}
Las fuentes definidas aquí se cargan y optimizan automáticamente por el módulo `@nuxt/fonts`.
:::
::

### colores

Utilice las variables de tema `--color-*` para personalizar sus colores](https://tailwindcss.com/docs/colors#customizing-your-colors) o [override los colores predeterminados ](https://tailwindcss.com/docs/colors#overriding-default-colors).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme static {
  /* Override default green color */
  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;

  /* Define new custom color */
  --color-brand-50: #fef2f2;
  --color-brand-100: #fee2e2;
  --color-brand-200: #fecaca;
  --color-brand-300: #fca5a5;
  --color-brand-400: #f87171;
  --color-brand-500: #ef4444;
  --color-brand-600: #dc2626;
  --color-brand-700: #b91c1c;
  --color-brand-800: #991b1b;
  --color-brand-900: #7f1d1d;
  --color-brand-950: #450a0a;
}
```

::warning
Al agregar colores personalizados, asegúrese de definir todos los tonos de `50` a `950` para cada color.
::

### Puntos de ruptura

Utilice las variables de tema `--breakpoint-*` para personalizar sus puntos de interrupción ](https://tailwindcss.com/docs/responsive-design#customizing-your-theme).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

### motion

Utilice las variables de tema `--ease-*` para personalizar la facilidad ](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme) de las animaciones y transiciones de movimiento en su proyecto.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

Las animaciones de entrada y salida se ejecutan en `--ease-out`, las animaciones de carga indeterminadas en `--ease-in-out`, por lo que anulan estos dos tiempos de la biblioteca.

::note
When `prefers-reduced-motion` is set, overlays fade in place instead of scaling or sliding and motion transitions are disabled.
::

Sistema de color ## Color

El sistema de color de la interfaz de usuario de Nuxt está diseñado en torno a **naming** semántico en lugar de valores de color específicos. Este enfoque hace que su interfaz de usuario sea más fácil de mantener y facilita el cambio de tema.

### Colores semánticos

Cada alias se define en función de un color de su configuración `@theme`, que puede ser cualquier color que defina además de la paleta CSS por defecto de Tailwind [](https://tailwindcss.com/docs/colors).

| El color| por defecto| Descripción|
| --- | --- | --- |
| `primary`x{color="primary"} (Edición española)| `green`| CTA principales, navegación activa, elementos de marca, enlaces importantes|
| `secondary`x{color="secondary"}| `blue` también| Botones secundarios, acciones alternativas, elementos de interfaz de usuario complementarios|
| `success`x{color="success"} (Edición española)| `green`| Mensajes de éxito, estados completados, confirmaciones positivas|
| `info`x{color="info"} (Edición española)| `blue`| Alertas de información, tooltips, texto de ayuda, notificaciones neutrales|
| `warning`x{color="warning"} (Edición española)| `yellow`| Mensajes de advertencia, estados pendientes, elementos que requieren atención|
| `error`x{color="error"} (Edición española)| `red` también| Mensajes de error, errores de validación, acciones destructivas|
| Xph150x también| `slate`| Texto, fronteras, fondos, estados discapacitados|

Estos colores semánticos están disponibles en el prop `color` de los componentes de la interfaz de usuario de Nuxt:

::component-code{slug="button"}
---
props:
  color: primary
slots:
  default: Save Changes
---
::

::note
Pruebe el menú de tema: prose-icon{name="i-lucide-palette" class="text-primary"} en el encabezado para ver instantáneamente cómo los diferentes esquemas de color afectan a toda la interfaz de usuario, o abra el editor ](/theme) para personalizar todo a la vez.
::

### Runtime Configuración

::framework-only
#nuxt
:::div
Puede configurar estos colores en tiempo de ejecución en su archivo [`app.config.ts`](https://nuxt.com/docs/4.x/directory-structure/app/app-config) bajo la tecla `ui.colors`, lo que permite la personalización dinámica del tema sin reiniciar el servidor:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#vue
:::div
Puede configurar estos colores en tiempo de ejecución en su archivo `vite.config.ts` bajo la tecla `ui.colors`, lo que permite la personalización dinámica del tema:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
Solo puedes usar colores que existan en tu tema.
- Use los colores predeterminados de Tailwind ](https://tailwindcss.com/docs/colors) (como `blue`, `green`, `zinc`)
- Defina colores personalizados primero usando la directiva `@theme` (como `brand` en nuestro ejemplo anterior)
::

### Extend colores

Es posible que desee definir colores semánticos adicionales más allá de los valores predeterminados, como la adición de un color `tertiary`:

::framework-only
#nuxt
:::div
En primer lugar, registre el nuevo color en su `nuxt.config.ts` bajo la tecla `ui.theme.colors`:

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

Luego, asígnalo en tu `app.config.ts` bajo la clave `ui.colors`:

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#vue
:::div
Registre y asigne el nuevo color en su archivo `vite.config.ts`:

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

Por último, utilice este nuevo color en los componentes que admiten el accesorio `color` o [as una class](/docs/getting-started/theme/css-variables):

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
