@@pH000@colores

Nuxt UI proporciona clases de utilidad CSS de Tailwind para cada color semántico que defina, por lo que puede usar nombres de clase como`text-error`o`bg-success`:

::code-preview
[Archivo]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[Archivo]{class="text-secondary text-sm px-4 py-1.5 inline-block"}
[Respuesta]{class="text-success text-sm px-4 py-1.5 inline-block"}
[Información]@
[Advertencia]@@
[Error]

#El Código
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

Cada clase de utilidad utiliza una variable CSS para establecer su color para los modos claro y oscuro:

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
Puede ajustar el tono que usa cada clase de utilidad para el modo claro y oscuro en su archivo `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
No puede usar `primary: 'black'` en su [**config**]() porque `black` no tiene múltiples tonos. Para usar blanco o negro sólido como color primario, configurarlo directamente en su archivo `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

## Focus: badge{label="4.9+" class="align-text-top"}

La interfaz de usuario de Nuxt aplica un esquema `focus-visible` en cada elemento interactivo, teñido con el prop `color` del componente, por ejemplo,`outline-primary/25` cuando `color="primary"` o `outline-inverted/25` cuando `color="neutral"`.

Si prefiere un solo color de contorno en toda su aplicación, independientemente del color del componente, puede agregar una regla global en su archivo `main.css`:

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

La primera regla tiñe el contorno de enfoque de cada componente, la segunda alinea el anillo de recolor aplicado en el enfoque por variantes con un borde visible como `outline` o `subtle`, incluyendo tarjetas que resaltan cuando su enlace está enfocado.

::note
Asegúrese de declarar estas reglas fuera de cualquier `@layer` para que tengan prioridad sobre los colores establecidos por los temas de los componentes.Tenga en cuenta que la primera regla también tiñe el contorno de enfoque nativo de sus propios elementos, y variantes que recolorean un `border` en foco como [FileUpload](/docs/components/file-upload) o [ContentSurround](/docs/components/content-surround)seguir el componente `color`.
::

@278@RT2780

Nuxt UI reemplaza las utilidades `rounded-*` por defecto de Tailwind CSS con un sistema unificado de radio de borde, por lo que puede usar las utilidades normales [border radius ](https://tailwindcss.com/docs/border-radius) como `rounded-xs` o `rounded-2xl`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]@286 @
[sm]@287 @
[md]@288 @
[lg]@289 @
[xl]@290 por @
[2xl]@291
[3xl]@292

#Código
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

Estas clases de utilidad se calculan en función de una variable CSS global `--ui-radius`, que define el valor de radio base aplicado a todos los componentes para una apariencia consistente.

```css
:root {
  --ui-radius: 0.25rem;
}
```

Cada utilidad multiplica este valor base:

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
Puede personalizar el valor del radio base en su archivo `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
Cambiar `--ui-radius` también afecta a las clases `rounded-xs` a `rounded-3xl` en su propio marcado y componentes de terceros, no solo en los componentes de la interfaz de usuario de Nuxt.
::

::note
Pruebe el menú de tema: prose-icon {name="i-lucide-palette" class="text-primary"} en el encabezado de arriba para cambiar el valor del radio base.
::

@@334@Contenedor

La interfaz de usuario de Nuxt proporciona una variable CSS `--ui-container` que controla el ancho máximo del componente [Container](/docs/components/container).

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
Puede personalizar este valor en su archivo `main.css` para ajustar los anchos de los contenedores de manera consistente en toda la aplicación:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

@358@@Encabezado

La interfaz de usuario de Nuxt proporciona una variable CSS `--ui-header-height` que controla la altura del componente [Header](/docs/components/header).

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
Puede personalizar este valor en su `main.css` para ajustar la altura del encabezado de manera consistente en toda la aplicación:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
