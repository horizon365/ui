## Diseño

Componentes estructurales básicos para organizar el diseño de su aplicación y establecer una base consistente para su interfaz de usuario.

:components-list{category="layout"}

## Elemento

Bloques de construcción de interfaz de usuario esenciales que incluyen botones, insignias, avatares, iconos y otros elementos de interfaz fundamentales para crear experiencias de usuario intuitivas y consistentes.

:components-list{category="element"}

## Form (Edición española)

Componentes de formulario completos para crear experiencias interactivas de entrada de usuario, incluidas entradas de texto, selecciones, casillas de verificación, grupos de radio, interruptores, deslizadores y validación de formulario completa.

:components-list{category="form"}

## Información

Componentes para mostrar y organizar datos, incluyendo tablas, acordeones, carruseles, líneas de tiempo, árboles y perfiles de usuario.

:components-list{category="data"}

## Navegación

Componentes para la navegación del usuario y wayfinding, incluyendo menús, migas de pan, paginación, pestañas, steppers, enlaces y paletas de comandos.

:components-list{category="navigation"}

## Superpuesto

Elementos flotantes de la interfaz de usuario que aparecen sobre el contenido principal, incluidos modales, popovers, información sobre herramientas, cajones, diapositivas y menús contextuales.

:components-list{category="overlay"}
