## Quelles sont les compétences?

Les compétences sont des fichiers de connaissances structurés qui donnent aux agents de codage d'IA un contexte sur une bibliothèque, un cadre ou une base de code. Contrairement aux serveurs MCP qui fournissent un accès aux outils en temps réel, les compétences sont chargées directement dans le contexte de l'agent afin qu 'il puisse les référencer tout au long de la conversation.

Nuxt UI fournit une compétence **usage qui enseigne aux agents d'IA comment créer des interfaces utilisateur avec Nuxt UI: installation, thèmes, composants, composables, formulaires, superpositions et mises en page.

## Utilisation

La compétence d'utilisation donne aux agents d'IA des connaissances complètes sur la construction avec Nuxt UI v4.

- Installation pour Nuxt, Vue, Laravel et AdonisJS
- Thème et branding avec des couleurs sémantiques et des variables CSS
- All 125 + composants avec accessoires et modèles d'utilisation
- Composables (`useToast`, `useOverlay`, `defineShortcuts`)
- Validation de formulaire avec schéma standard
composition - Layout (tableau de bord, Docs, Chat, Éditeur)
- Modèles de démarrage officiels

La compétence comprend des références supplémentaires que l'agent d'IA charge à la demande en fonction de la tâche, en gardant les réponses ciblées et efficaces en fonction du contexte.

::note
Une fois installée, vous pouvez invoquer la compétence en tapant `/nuxt-ui` dans le chat de votre agent.
::

### Skills CLI

La CLI [`skills`](https://skills.sh) est le moyen le plus simple d'installer la compétence Nuxt UI. Il prend en charge plus de 35 agents, y compris Cursor, Claude Code, Codex, Windsurf, Cline, et plus encore.

```bash
npx skills add nuxt/ui
```

Vous pouvez cibler des agents spécifiques avec l'indicateur `--agent`:

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

Ou installer globalement pour que la compétence soit disponible dans tous vos projets:

```bash
npx skills add nuxt/ui --global
```

Si le clonage à partir de GitHub est lent sur votre réseau, vous pouvez installer directement depuis le site Web à la place:

```bash
npx skills add https://ui.nuxt.com
```

::tip
Visitez [skills.sh](https://skills.sh) pour en savoir plus sur l'écosystème des compétences et parcourir les compétences disponibles.
::

#### Configuration manuelle

1. Ouvrez le curseur et allez dans "Paramètres">"Compétences"
2. Cliquez sur "Ajouter une compétence" et entrez l'URL suivante:

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
