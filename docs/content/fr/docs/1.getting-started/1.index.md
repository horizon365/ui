## Qu 'est-ce que Nuxt UI?

Une bibliothèque moderne de composants d'interface utilisateur Vue construite sur [Reka UI](https://reka-ui.com/),[Tailwind CSS](https://tailwindcss.com/), et [Tailwind Variants](https://www.tailwind-variants.org/) pour expédier des applications belles et accessibles avec plus de 125 productions-Fonctionne avec les applications Nuxt et plain Vue (Vite, Inertia, SSR).

Si vous construisez un projet Vue avec Tailwind CSS, Nuxt UI est un excellent choix par défaut. Il fournit des composants de haut niveau prêts à l'emploi (tables de données, formulaires, superpositions, navigation) tout en permettant une personnalisation avancée si nécessaire.

## Quoi de neuf dans la v4?

Nuxt UI v4 marque une étape majeure: Nuxt UI et Nuxt UI Pro sont désormais unifiés en une bibliothèque unique, entièrement open source et gratuite de plus de 125 composants prêts pour la production et un kit Figma complet.

La migration de la v3 vers la v4 sera beaucoup plus fluide que celle de la v2 vers la v3. Pour en savoir plus, consultez le guide de migration [](/docs/getting-started/migration).

## Technologies de base

Nuxt UI est construit sur trois bases: Reka UI pour le comportement et l'accessibilité, Tailwind CSS pour le style et Tailwind Variants pour la composition de variantes.

### Reka UI

Nuxt UI est construit sur [Reka UI](https://reka-ui.com/) comme base pour les composants:

- ** WAI-ARIA Compliance**: Suit [ WAI-ARIA authoring practices](https://reka-ui.com/docs/overview/accessibility) avec la sémantique et les rôles appropriés
- **Keyboard Navigation**: prise en charge intégrée du clavier pour les composants complexes tels que les onglets et les dialogues
- **Focus Management**: Gestion intelligente de la mise au point qui déplace la mise au point en fonction des interactions utilisateur
- **Accessible Labels**: Abstractions pour simplifier les contrôles d'étiquetage pour les lecteurs d'écran

### Tailwind CSS (en anglais)

Nuxt UI intègre le dernier [Tailwind CSS](https://tailwindcss.com/), apportant des améliorations significatives:

- **@5x plus rapide Builds**: Builds complets jusqu'à 5x plus rapide, builds incrémentiels plus de 100x plus rapide
- **Unified Toolchain**: Gestion intégrée des importations, préfixation du fournisseur et transformations de syntaxe
- ** CSS-first Configuration**: Personnalisez et étendez directement en CSS au lieu de JavaScript
- **Modern Web Features**: requêtes de conteneurs, couches en cascade, couleurs à large gamme, et plus encore

### Variantes de tailwind

Nuxt UI tire parti de [Tailwind Variants](https://www.tailwind-variants.org/) pour fournir un système de conception puissant:

- **Dynamic Styling **: Variantes de composants flexibles avec une API puissante
- **Type Safety**: Support complet de TypeScript avec complétion automatique
- **Résolution des conflits **: Fusion efficace de styles conflictuels

Compatibilité ### Vue (Nuxt en option)

Nuxt UI fonctionne avec n'importe quel projet Vue, pas seulement Nuxt. Ajoutez simplement les plugins Vite et Vue à votre configuration:

- ** Auto-imports **: Les composants et les composables sont automatiquement importés et disponibles dans le monde entier
- **Design System**: prise en charge complète de la thématique avec couleurs, tailles, variantes personnalisables et plus encore
- **Developer Experience**: Support complet de TypeScript avec IntelliSense et auto-complétion

### TypeScript support

Nuxt UI fournit une intégration complète de TypeScript pour une expérience de développement supérieure:

- ** Auto-complétion **: Pour tous les accessoires, créneaux horaires et événements des composants
- **Composants génériques **: Utilisation de [Vue Generics](https://vuejs.org/api/sfc-script-setup.html#generics)
- ** Theming**: Dans `app.config.ts`
- **IntelliSense**: Tout au long de votre base de code

::accordion

:::accordion-item{label="Nuxt UI est-il gratuit à utiliser?"}
Nuxt UI est entièrement gratuit et open source sous licence MIT. Tous les 125 composants sont disponibles pour tous.
:::

:::accordion-item{label="Puis-je utiliser Nuxt UI avec Vue sans Nuxt?"}
Oui oui! Bien qu 'optimisée pour Nuxt, l'interface utilisateur de Nuxt fonctionne parfaitement avec les projets Vue autonomes via notre plugin Vite. Vous pouvez suivre le guide d'installation [](/docs/getting-started/installation/vue) pour commencer.
:::

:::accordion-item{label="Nuxt UI inclut-il un kit Figma?"}
Oui oui! Nuxt UI inclut un kit Figma complet [](https://go.nuxt.com/figma-ui) avec tous les composants, ce qui facilite la collaboration entre concepteurs et développeurs.
:::

:::accordion-item{label="Comment Nuxt UI gère l'accessibilité?"}
Grâce à l'intégration [Reka UI](https://reka-ui.com/docs/overview/accessibility), Nuxt UI fournit des attributs ARIA automatiques, la navigation au clavier, la gestion de la mise au point et la prise en charge des lecteurs d'écran.
:::

:::accordion-item{label="Nuxt UI est-il prêt pour la production?"}
Nuxt UI est utilisé en production par des milliers d'applications avec plus de 1000 tests Vitest, des mises à jour régulières et une maintenance active.
:::

:::accordion-item{label="Quand devrais-je envisager des alternatives?"}
Considérez **Vuetify** si vous voulez un style Material Design,** ant-design-vue** pour le style Ant Design,**PrimeVue** ou **Element Plus** si vous ne voulez pas de Tailwind CSS,** shadcn-vue ** si vous préférez copier des composants dans votre dépôt,**Quasar** pour les applications multi-plateformes (web, mobile, bureau), ou **Reka UI**/**Headless UI** si vous avez seulement besoin de primitives non stylisées.
:::
