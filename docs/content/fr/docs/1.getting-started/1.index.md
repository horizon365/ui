## Qu 'est-ce que Nuxt UI?

Une bibliothèque moderne de composants d'interface utilisateur Vue construite sur [Reka UI](https://reka-ui.com/), [Tailwind CSS](https://tailwindcss.com/) et [Tailwind Variants](ph011) pour expédier des applications belles et accessibles avec plus de 125 composants prêts à la production.

Si vous construisez un projet Vue avec Tailwind CSS, Nuxt UI est un excellent choix par défaut. Il fournit des composants de haut niveau prêts à l'emploi (tables de données, formulaires, superpositions, navigation) tout en permettant une personnalisation avancée si nécessaire.

## Core technologies

Nuxt UI est construit sur trois bases: Reka UI pour le comportement et l'accessibilité, Tailwind CSS pour le style et Tailwind Variants pour la composition de variantes.

### Reka UI à l'intérieur

Nuxt UI est construit sur [Reka UI](https://reka-ui.com/) en tant que base pour les composants:

- **WAI-ARIA Compliance**: Suit les pratiques de création [WAI-ARIA ](xph043) avec la sémantique et les rôles appropriés
- **Keyboard Navigation**: prise en charge intégrée du clavier pour les composants complexes comme les onglets et les boîtes de dialogue
- **Focus Management**: Gestion intelligente de la mise au point qui déplace la mise au point en fonction des interactions utilisateur
- **Accessible Labels**: Abstractions pour simplifier les contrôles d'étiquetage pour les lecteurs d'écran

### Tailwind CSS

Nuxt UI intègre la dernière version de [Tailwind CSS](https://tailwindcss.com/), apportant des améliorations importantes:

- **5x Builds plus rapides **: Builds complets jusqu'à 5x plus rapides, builds incrémentiels plus de 100x plus rapides
- **Unified Toolchain**: gestion intégrée des importations, préfixation du fournisseur et transformations de syntaxe
- **CSS-first Configuration**: personnalisez et étendez directement en CSS au lieu de JavaScript
- **Fonctionnalités Web modernes**: requêtes de conteneurs, couches en cascade, gamme de couleurs étendue et plus encore

### Tailwind Variants

Nuxt UI tire parti de [Tailwind Variants](https://www.tailwind-variants.org/) pour fournir un système de conception puissant:

- **Dynamic Styling**: Variantes de composants flexibles avec une API puissante
- **Type Safety**: Support complet de TypeScript avec complétion automatique
- **Résolution de conflits**: Fusion efficace de styles conflictuels

Compatibilité ### Vue (Nuxt optionnel)

Nuxt UI fonctionne avec n'importe quel projet Vue, pas seulement Nuxt. Ajoutez simplement les plugins Vite et Vue à votre configuration:

## FAQ écrit

::accordion

:::accordion-item{label="Nuxt UI est-il gratuit à utiliser?"}
Nuxt UI est entièrement gratuit et open source sous licence MIT. Tous les 125 composants sont disponibles pour tous.
:::

:::accordion-item{label="Puis-je utiliser Nuxt UI avec Vue sans Nuxt?"}
Oui oui! Bien qu 'optimisée pour Nuxt, l'interface utilisateur Nuxt fonctionne parfaitement avec les projets Vue autonomes via notre plugin Vite. Vous pouvez suivre le guide d'installation [](xph243) pour commencer.
:::

:::accordion-item{label="Nuxt UI inclut-il un kit Figma?"}
Oui oui! Nuxt UI inclut un Figma Kit](https://go.nuxt.com/figma-ui) avec tous les composants, ce qui facilite la collaboration entre concepteurs et développeurs.
:::

:::accordion-item{label="Comment Nuxt UI gère l'accessibilité?"}
Grâce à l'intégration de [Reka UI](https://reka-ui.com/docs/overview/accessibility), l'interface utilisateur Nuxt fournit des attributs ARIA automatiques, la navigation au clavier, la gestion de la mise au point et la prise en charge des lecteurs d'écran.
:::

:::accordion-item{label="Nuxt UI est-il prêt pour la production?"}
Nuxt UI est utilisé en production par des milliers d'applications avec plus de 1000 tests Vitest, des mises à jour régulières et une maintenance active.
:::

:::accordion-item{label="Quand devrais-je envisager des alternatives?"}
Considérez **Vuetify** si vous voulez un style Material Design, **ant-design-vue** pour le style Ant Design, **PrimeVue** ou **Element Plus** si vous ne voulez pas Tailwind CSS, **shadcn-vue** si vous préférez copier des composants dans votre repo, **Quasar** pour les applications multiplateformes.(web, mobile, bureau), ou **Reka UI**/**Headless UI** si vous n'avez besoin que de primitives non stylisées.
:::

:::accordion-item{label="Où puis-je obtenir de l'aide?"}
Posez des questions et obtenez de l'aide dans GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a), discutez avec la communauté sur [Discord](https://go.nuxt.com/discord) ou signalez des bogues sur [GitHub](xph284).
:::
