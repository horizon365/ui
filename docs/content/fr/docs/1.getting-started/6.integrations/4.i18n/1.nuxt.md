## Utilisation

::note{to="/docs/components/app"}
Nuxt UI fournit un composant **App** qui enveloppe votre application pour fournir des configurations globales, y compris le prop `locale`.
::

### Localité

Utilisez la prop `locale` avec la locale que vous souhaitez utiliser à partir de `@nuxt/ui/locale`:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Chaque locale possède une propriété `code` (par exemple, `en`, `en-GB`, `fr`) qui détermine le format de date/heure dans des composants tels que [Calendar](/docs/components/calendar), [InputDate](xph030) et [InputTime](xph034).
::

### Custom locale (région personnalisée)

Vous pouvez créer vos propres paramètres régionaux en utilisant l'utilitaire [defineLocale](/docs/composables/define-locale):

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Regardez le paramètre `code`, vous devez y passer le code iso de la langue.

* x`hi` Hindi (langue anglaise)
* x`de-AT`: allemand (langue) tel qu 'il est utilisé en Autriche (région)

::

### Extend régional

Vous pouvez personnaliser une locale existante en remplaçant son `messages` ou `code` à l'aide de l'utilitaire [extendLocale](/docs/composables/extend-locale):

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Localisation dynamique

Pour basculer dynamiquement entre les langues, vous pouvez utiliser le module [Nuxt I18n](https://i18n.nuxtjs.org/).

::steps{level="4"}

#### Installer le paquet Nuxt I18n

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### Ajouter le module Nuxt I18n dans votre `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### Définir le prop `locale` avec `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### Localisation automatique des liens: badge{label="4.7+" class="align-text-top"}

Lorsque `@nuxtjs/i18n` est installé, le composant [Link](/docs/components/link) localise automatiquement les liens internes à l'aide de l'assistant `$localePath`.Cela signifie que vous n'avez pas besoin d'envelopper manuellement vos liens avec `localePath()` ou `localeRoute()`.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
Les liens externes et les URL absolues sont détectés automatiquement et ignorent la localisation. Vous pouvez toujours utiliser manuellement `localePath()` ou `localeRoute()` si nécessaire.
::

::

### Direction dynamique

Chaque locale possède une propriété `dir` qui sera utilisée par le composant `App` pour définir la directionnalité de tous les composants.

Dans une application multilingue, vous pouvez définir les attributs `lang` et `dir` sur l'élément `<html>` de manière dynamique en fonction des paramètres régionaux de l'utilisateur, ce que vous pouvez faire avec le composable [useHead](https://nuxt.com/docs/api/composables/use-head):

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
