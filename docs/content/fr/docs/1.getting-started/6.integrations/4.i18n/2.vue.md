Vous cherchez la version **Nuxt**?
::

@@ph002@utilisation

::note{to="/docs/components/app"}
Nuxt UI fournit un composant **App** qui enveloppe votre application pour fournir des configurations globales, y compris la prop `locale`.
::

@@pH006@@région

Utilisez la prop `locale` avec les paramètres régionaux que vous souhaitez utiliser à partir de `@nuxt/ui/locale`:

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
Chaque région a une propriété `code`(par exemple `en`,`en-GB`,`fr`) qui détermine le format de date/heure dans des composants tels que [Calendrier ](/docs/components/calendar),[InputDate](/docs/components/input-date) et [InputTime](/docs/components/input-time).
::

### Localisation personnalisée

Vous pouvez créer votre propre locale en utilisant l'utilitaire [defineLocale](/docs/composables/define-locale):

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
Regardez le paramètre `code`, vous devez y passer le code iso de la langue. Exemple:

* `hi`(langue anglaise)
* `de-AT`: allemand (langue) tel qu 'il est utilisé en Autriche (région)

::

### Extension de locale

Vous pouvez personnaliser un paramètre régional existant en remplaçant son `messages` ou `code` en utilisant l'utilitaire [extendLocale](/docs/composables/extend-locale):

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### Localisation dynamique

Pour basculer dynamiquement entre les langues, vous pouvez utiliser le plugin [Vue I18n](https://vue-i18n.intlify.dev/).

::steps{level="4"}

#### Installer le package Vue I18n

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### Utilisez le plugin Vue I18n dans votre `main.ts`

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

#### Définir le `locale` prop en utilisant `useI18n`

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

::

### Direction dynamique

Chaque locale possède une propriété `dir` qui sera utilisée par le composant `App` pour définir la directionnalité de tous les composantes.

Dans une application multilingue, vous voudrez peut-être définir les attributs `lang` et `dir` sur l'élément `<html>` dynamiquement en fonction des paramètres locaux de l'utilisateur, ce que vous pouvez faire avec le composable [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head):

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
