@@ph000@utilisation

Nuxt UI enregistre automatiquement le module [`@nuxt/fonts`](https://github.com/nuxt/fonts) pour vous, aucune configuration supplémentaire n'est donc nécessaire.

@@ph006@Déclaration

Pour utiliser une police dans votre application Nuxt UI, il vous suffit de la déclarer dans votre CSS. Elle sera automatiquement chargée et optimisée pour vous.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

### Configuration

Vous pouvez désactiver le module `@nuxt/fonts` avec l'option `ui.fonts` dans votre `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
