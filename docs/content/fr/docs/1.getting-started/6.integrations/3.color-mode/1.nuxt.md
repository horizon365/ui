@@ph002@utilisation

Nuxt UI enregistre automatiquement le module [`@nuxtjs/color-mode`](https://github.com/nuxt-modules/color-mode) pour vous, aucune configuration supplémentaire n'est donc nécessaire.

@@008@composants

Vous pouvez utiliser les composants intégrés [ColorModeAvatar](/docs/components/color-mode-avatar) ou [ColorModeImage](/docs/components/color-mode-image) pour afficher différentes images pour les modes clair et sombre et le @@@@ColorModeButton](/docs/components/color-mode-button), Composants [ColorModeSwitch](/docs/components/color-mode-switch) ou [ColorModeSelect](/docs/components/color-mode-select) pour basculer entre les modes clair et sombre.

Vous pouvez également utiliser le [useColorMode](https://color-mode.nuxtjs.org/usage/basic) composable pour construire votre propre composant personnalisé:

```vue [ColorModeButton.vue]
<script setup lang="ts">
const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark) {
    colorMode.preference = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <ClientOnly v-if="!colorMode?.forced">
    <UButton
      :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
      color="neutral"
      variant="ghost"
      :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
      @click="isDark = !isDark"
    />

    <template #fallback>
      <div class="size-8" />
    </template>
  </ClientOnly>
</template>
```

### Configuration

Vous pouvez désactiver le module `@nuxtjs/color-mode` avec l'option `ui.colorMode` dans votre `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```
