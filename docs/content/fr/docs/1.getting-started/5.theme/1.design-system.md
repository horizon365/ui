## Tailwind avec CSS

Tailwind CSS utilise une configuration CSS-first, vous permettant de définir vos jetons de conception avec la directive [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive) directement dans votre CSS. Cela rend votre thème portable, maintenable et facile à personnaliser.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
Consultez la documentation CSS de Tailwind pour connaître toutes les options de personnalisation des variables de thème disponibles.
::

::tip
Tailwind CSS v4 a changé son [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) pour que les boutons utilisent `cursor: default` au lieu de `cursor: pointer` pour correspondre aux valeurs par défaut du navigateur.

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

@@28@fonds

Utilisez les variables de thème `--font-*` pour personnaliser les utilités de la famille de polices ](https://tailwindcss.com/docs/font-family#customizing-your-theme) dans votre projet.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

#numérique
:::note{to="/docs/getting-started/integrations/fonts"}
Les polices définies ici sont automatiquement chargées et optimisées par le module `@nuxt/fonts`.
:::

### Couleurs

Utilisez les variables de thème `--color-*` pour [personnaliser vos couleurshttps://tailwindcss.com/docs/colors#customizing-your-colors) ou [annuler les couleurs par défaut ](https://tailwindcss.com/docs/colors#overriding-default-colors).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme static {
  /* Override default green color */
  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;

  /* Define new custom color */
  --color-brand-50: #fef2f2;
  --color-brand-100: #fee2e2;
  --color-brand-200: #fecaca;
  --color-brand-300: #fca5a5;
  --color-brand-400: #f87171;
  --color-brand-500: #ef4444;
  --color-brand-600: #dc2626;
  --color-brand-700: #b91c1c;
  --color-brand-800: #991b1b;
  --color-brand-900: #7f1d1d;
  --color-brand-950: #450a0a;
}
```

::warning
Lorsque vous ajoutez des couleurs personnalisées, assurez-vous de définir toutes les nuances de `50` à `950` pour chaque couleur.
::

### points de rupture

Utilisez les variables de thème `--breakpoint-*` pour [personnaliser vos points de rupture ](https://tailwindcss.com/docs/responsive-design#customizing-your-theme).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

@@ph104@@motion

Utilisez les variables de thème `--ease-*` pour personnaliser la facilité ](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme) des animations et des transitions de mouvement dans votre projet.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

Les animations d'entrée et de sortie s'exécutent sur `--ease-out`, les animations de chargement indéterminées sur `--ease-in-out`, donc en remplaçant ces deux rediffusions de la bibliothèque.

::note
Lorsque `prefers-reduced-motion` est défini, les superpositions s'estompent au lieu de s'adapter ou de glisser et les transitions de mouvement sont désactivées.
::

## système de couleur

Le système de couleurs de Nuxt UI est conçu autour du **nommage sémantique ** plutôt que des valeurs de couleurs spécifiques. Cette approche rend votre interface utilisateur plus facile à maintenir et facilite le changement de thème.

### Couleurs sémantiques

L'interface utilisateur Nuxt fournit des alias de couleur sémantiques qui décrivent le **purpose** de la couleur. Chaque alias est défini en fonction d'une couleur de votre configuration `@theme`, qui peut être n'importe quelle couleur que vous définissez en plus de la palette CSS Tailwind par défaut ](https://tailwindcss.com/docs/colors).

| Couleur| Défaut| Description|
| --- | --- | --- |
| @@|@@@ 133 @| CTA principaux, navigation active, éléments de marque, liens importants|
| @@|@@@ 136 @| Boutons secondaires, actions alternatives, éléments complémentaires de l'interface utilisateur|
| @@|@@@ 139 @| Messages de réussite, états terminés, confirmations positives|
| @@|@@@ 142 @| Alertes d'information, infobulles, texte d'aide, notifications neutres|
| @@|@@@ 145 @| Messages d'avertissement, états en attente, éléments nécessitant une attention|
| @@|@@@ 148 @| Messages d'erreur, erreurs de validation, actions destructives|
| @@@ 150 @|@@@ 151 @| Texte, frontières, arrière-plans, états handicapés|

Ces couleurs sémantiques sont disponibles dans la prop `color` des composants de l'interface utilisateur Nuxt:

::component-code{slug="button"}
---
Props:
  Couleur: primaire
Slots:
  Par défaut: Sauvegarder les modifications
---
::

::note
Essayez le menu thème: prose-icon {name="i-lucide-palette" class="text-primary"} dans l'en-tête pour voir instantanément comment les différents schémas de couleurs affectent l'ensemble de l'interface utilisateur, ou ouvrez l'éditeur de thème ](/themepour tout personnaliser en même temps!
::

### Configuration d'exécution

::framework-only
#numérique
:::div
Vous pouvez configurer ces couleurs au moment de l'exécution dans votre fichier [`app.config.ts`]() sous la touche `ui.colors`, ce qui permet une personnalisation dynamique du thème sans redémarrer le serveur:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#vue
:::div
Vous pouvez configurer ces couleurs à l'exécution dans votre fichier `vite.config.ts` sous la touche `ui.colors`, ce qui permet une personnalisation dynamique du thème:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
Vous ne pouvez utiliser que les couleurs qui existent dans votre thème.
- Utilisez les couleurs par défaut de [Tailwind ](https://tailwindcss.com/docs/colors)(comme `blue`,`green`,`zinc`)
- Définissez d'abord les couleurs personnalisées en utilisant la directive `@theme`(comme `brand` dans notre exemple ci-dessus)
::

### Étendre les couleurs

Vous pouvez définir des couleurs sémantiques supplémentaires au-delà des valeurs par défaut, comme l'ajout d'une couleur `tertiary`:

::framework-only
#numérique
:::div
Tout d'abord, enregistrez la nouvelle couleur dans votre `nuxt.config.ts` sous la touche `ui.theme.colors`:

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

Ensuite, assignez-le dans votre `app.config.ts` sous la clé `ui.colors`:

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#vue
:::div
Enregistrez et attribuez la nouvelle couleur dans votre fichier `vite.config.ts`:

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

Enfin, utilisez cette nouvelle couleur dans les composants qui prennent en charge le `color` prop ou [en tant que classe](/docs/getting-started/theme/css-variables):

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
