@@pH000@couleurs

Nuxt UI fournit des classes utilitaires CSS Tailwind pour chaque [sémantique color](/docs/getting-started/theme/design-system#semantic-colors) que vous définissez, de sorte que vous pouvez utiliser des noms de classe comme `text-error` ou `bg-success`:

::code-preview
[réf. nécessaire]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[Résumé]{class="text-secondary text-sm px-4 py-1.5 inline-block"}
[Résultat]{class="text-success text-sm px-4 py-1.5 inline-block"}
[Infos]{class="text-info text-sm px-4 py-1.5 inline-block"}
[Avertissement]{class="text-warning text-sm px-4 py-1.5 inline-block"}
[Erreur]{class="text-error text-sm px-4 py-1.5 inline-block"}

#code
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

Chaque classe d'utilitaire utilise une variable CSS pour définir sa couleur pour les modes clair et sombre:

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
Vous pouvez ajuster la teinte que chaque classe d'utilitaire utilise pour le mode clair et sombre dans votre fichier `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
Vous ne pouvez pas utiliser `primary: 'black'` dans votre [**config**]() car `black` n'a pas plusieurs nuances.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

::

```css [Dark]
  --ui-text-muted: var(--ui-color-neutral-400);
```

```css [app/assets/css/main.css]
}

.dark {
  --ui-text: white;
}
```

Pour modifier plusieurs de ces variables à la fois,[attribuez plutôt une couleur différente à `neutral`](/docs/getting-started/theme/design-system#runtime-configuration) dans votre configuration.

## Focus: badge{label="4.9+" class="align-text-top"}

Nuxt UI applique un schéma `focus-visible` sur chaque élément interactif, teinté avec le prop `color` du composant, par exemple `outline-primary/25` lorsque `color="primary"` ou `outline-inverted/25` lorsque `color="neutral"`.

Si vous préférez une seule couleur de contour pour l'ensemble de votre application, quelle que soit la couleur du composant, vous pouvez ajouter une règle globale dans votre fichier `main.css`:

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

La première règle teinte le contour du focus de chaque composant, la seconde aligne la recoloration de l'anneau appliquée au focus par des variantes avec une bordure visible comme `outline` ou `subtle`, y compris des cartes qui mettent en évidence lorsque leur lien est mis au focus.

::note
Assurez-vous de déclarer ces règles en dehors de tout `@layer` afin qu 'elles aient préséance sur les couleurs définies par les thèmes des composants. Gardez à l'esprit que la première règle teinte également le contour de focus natif de vos propres éléments, et des variantes recolorant un `border` sur le focus comme [FileUpload](/docs/components/file-upload) ou [ContentSurround](/docs/components/content-surround)Continuez à suivre le composant `color`.
::

@@ph278@radius

Nuxt UI remplace les utilitaires `rounded-*` par défaut de Tailwind CSS avec un système de rayon de bordure unifié, de sorte que vous pouvez utiliser des utilitaires de rayon de bordure réguliers ](https://tailwindcss.com/docs/border-radius) comme `rounded-xs` ou `rounded-2xl`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]@@@ 286 @
[sm]@@@ 287 @
[md]@@@ 288 @
[lg]@@@ 289 @
[xl]@@@ 290 @
[2xl]@@@ 291 @
[3xl]@@@ 292 @

#code
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

Ces classes d'utilité sont calculées sur la base d'une variable CSS globale `--ui-radius`, qui définit la valeur du rayon de base appliquée à tous les composants pour un aspect cohérent.

```css
:root {
  --ui-radius: 0.25rem;
}
```

Chaque utilitaire multiplie cette valeur de base:

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
Vous pouvez personnaliser la valeur du rayon de base dans votre fichier `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
La modification de `--ui-radius` affecte également les classes `rounded-xs` à `rounded-3xl` sur votre propre balisage et sur des composants tiers, et pas seulement sur les composants de l'interface utilisateur Nuxt.
::

::note
Essayez le menu thème: prose-icon {name="i-lucide-palette" class="text-primary"} dans l'en-tête ci-dessus pour modifier la valeur du rayon de base.
::

## Conteneur

Nuxt UI fournit une variable CSS `--ui-container` qui contrôle la largeur maximale du composant [Container](/docs/components/container).

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
Vous pouvez personnaliser cette valeur dans votre fichier `main.css` pour ajuster les largeurs de conteneur de manière cohérente tout au long de votre application:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

@@ph358@header

Nuxt UI fournit une variable CSS `--ui-header-height` qui contrôle la hauteur du composant [Header](/docs/components/header).

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
Vous pouvez personnaliser cette valeur dans votre `main.css` pour ajuster la hauteur de l'en-tête de manière cohérente tout au long de votre application:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
::

@@ph378@corps

Nuxt UI applique des classes par défaut à l'élément `<body>`{lang="html"} de votre application pour une thématisation cohérente entre les modes clair et sombre:

```css
body {
  @apply antialiased text-default bg-default scheme-light dark:scheme-dark;
}
```
