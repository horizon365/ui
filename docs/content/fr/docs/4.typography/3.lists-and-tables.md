## listes

Markdown prend en charge les listes non ordonnées, ordonnées et imbriquées pour divers besoins de contenu.

### Listes non répertoriées

Utilisez des listes non ordonnées pour les éléments sans séquence spécifique. Commencez chaque élément par un symbole `-`.

::tabs{class="gap-0"}

::code-preview{label="preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I est un élément de liste.
- I est un autre élément de liste.
- I est le dernier élément de la liste.

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### Listes commandées

Utilisez des listes ordonnées lorsque l'ordre des éléments est important, comme les étapes d'un processus. Commencez chaque élément par un numéro.

::tabs{class="gap-0"}

::code-preview{label="preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. I est un élément de liste.
2. I est un autre élément de liste.
3. I est le dernier élément de la liste.

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### Listes imbriquées

Créez des listes hiérarchiques avec des sous-éléments pour les structures complexes. Retrait des sous-éléments par quatre espaces pour l'imbrication.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I est un élément de liste.
  - I est un élément de liste imbriqué.
  - I est un autre élément de liste imbriqué.
- I est un autre élément de liste.
  - Autre élément imbriqué
    - Objet imbriqué profond
    - Un autre élément imbriqué profond
  - Retour au deuxième niveau

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### Listes mixtes

Vous pouvez combiner des listes ordonnées et non ordonnées pour des hiérarchies complexes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Première étape importante
   - Sous-exigence A
   - Sous-exigence B
2. Deuxième étape importante
   - Autre sous-article
   - Dernier sous-point
3. Étape finale

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## Tables

Présentez clairement des données structurées en lignes et en colonnes. Les tableaux sont idéaux pour comparer des données ou répertorier des propriétés.

::tabs{class="gap-0"}

::code-preview{label="preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| Prop à    | Défaut   | type                     |
|---------|-----------|--------------------------|
| `name`|           | `string`x{lang="ts-type"}|
| `size`| `md`      | `string`x{lang="ts-type"}|
| `color`| `neutral`| `string`x{lang="ts-type"}|

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
