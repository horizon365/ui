::tip
Par défaut, les thèmes Shiki `material-theme-lighter` et `material-theme-palenight` sont utilisés respectivement pour le mode clair et le mode sombre. Lorsque vous utilisez `@nuxt/content`, vous pouvez modifier ceci via la clé [`content.build.markdown.highlight`]() dans votre `nuxt.config.ts`. Lorsque vous utilisez le mode autonome `@nuxtjs/mdc`, configurer les thèmes via la clé [`mdc.highlight`](). Lorsque vous utilisez [Comark](https://comark.dev), configurez les thèmes via les options du plugin `shiki`.

Pour prendre en charge le mode sombre avec Comark, ajoutez le CSS suivant à votre feuille de style:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

::tip
L'icône du nom du fichier est rendue par le composant `ProseCodeIcon` et contient un ensemble d'icônes prédéfinies que vous pouvez personnaliser dans la configuration de votre application:

::framework-only
#numérique
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Ces icônes de nom de fichier proviennent de la collection [`vscode-icons`](), qui est séparée des icônes `lucide` utilisées par le reste des composants, et sont résolues à la demande à partir de l'extension de fichier. Installer `@iconify-json/vscode-icons` pour les servir localement et hors ligne, comme toute autre collection.
::

### Copier bouton

Chaque bloc de code possède un bouton de copie intégré qui copiera le code dans votre presse-papiers.

Définissez l'accessoire `copy` sur `false` pour masquer le bouton, ou passez les accessoires [Button](/docs/components/button) pour le personnaliser.

::tip
Vous pouvez modifier l'icône via les touches `ui.icons.copy` et `ui.icons.copyCheck` dans la configuration de votre application:

::framework-only
#numérique
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```

### Ligne surlignée

Mettez en surbrillance des lignes spécifiques pour attirer l'attention sur les parties importantes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
export default définition ({
  modules: ['@ nuxt/ui'],//Cette ligne est surlignée
  css: ['/assets/css/main.css']
})
```
````

### Code diff

Utilisez le langage `diff` pour afficher les modifications entre les versions du code.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export default définition ({
  Modules: [
-   '@ nuxt/ui-pro '
+   '@ nuxt/ui '
  ]
})
```
````
