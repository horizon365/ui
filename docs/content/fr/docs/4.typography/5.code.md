La surbrillance syntaxique est disponible pour des dizaines de langages de programmation.

```vue
    </UButton>
  </div>
```

::tip
Par défaut, les thèmes Shiki `material-theme-lighter` et `material-theme-palenight` sont utilisés respectivement pour le mode clair et le mode sombre. Lorsque vous utilisez `@nuxt/content`, vous pouvez modifier cela via la touche [`content.build.markdown.highlight`](ph0666) dans votre `nuxt.config.ts`. Lorsque vous utilisez `@nuxtjs/mdc` autonome, configure les thèmes via la clé [`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations). Lorsque vous utilisez [Comarkxph073https://comark.dev), configurez les thèmes via les options du plugin `shiki`.

Pour prendre en charge le mode sombre avec Comark, ajoutez le CSS suivant à votre feuille de style:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

### Fichier

Les blocs de code prennent en charge l'affichage du nom de fichier avec détection automatique d'icônes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts [nuxt.config.ts]
export default définition ({
  modules: ['@ nuxt/ui']
})
```
````

::

::tip
El icono del nombre de archivo es representado por el componente `ProseCodeIcon` y contiene un conjunto de iconos predefinidos que puede personalizar en la configuración de su aplicación:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Ces icônes de nom de fichier proviennent de la collection [`vscode-icons`](https://icones.js.org/collection/vscode-icons), qui est séparée des icônes `lucide` utilisées par le reste des composants, et sont résolues à la demande à partir de l'extension de fichier.
::

bouton ### Copy

Chaque bloc de code possède un bouton de copie intégré qui copiera le code dans votre presse-papiers.

Réglez l'accessoire `copy` sur `false` pour masquer le bouton, ou passez les accessoires [Button](xph143) pour le personnaliser.

::tip
Vous pouvez modifier l'icône à l'aide des touches `ui.icons.copy` et `ui.icons.copyCheck` dans la configuration de votre application:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

### Line soulignant

Mettez en surbrillance des lignes spécifiques pour attirer l'attention sur les parties importantes.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

````mdc
export default définition ({
  modules: ['@ nuxt/ui'],//Cette ligne est surlignée

})
```
````

### Code diff

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export default définition ({
  Modules: [
-   '@ nuxt/ui-pro '
+   '@ nuxt/ui '
  ]
})
```
````
