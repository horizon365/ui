### Zoom

Par défaut, les images prennent en charge le zoom interactif: cliquer sur une image l'ouvre dans une superposition modale avec des transitions fluides, permettant aux utilisateurs d'examiner les détails de plus près.

Pour éviter de zoomer sur une image spécifique, ajoutez l'attribut `:zoom="false"`.

::code-preview{class="[&>div>p]:my-0"}
![Image sans zoom](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}

#code

```mdc
![Image without zoom](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}
```

::

### taille

Les images s'adaptent automatiquement à leur conteneur tout en conservant le format d'aspect. Vous pouvez contrôler le dimensionnement par le biais d'attributs Markdown ou HTML si nécessaire.
