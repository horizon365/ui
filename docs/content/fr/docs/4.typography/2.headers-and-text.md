## Téléchargements

Utilisez des en-têtes pour organiser votre contenu et le rendre plus facile à lire

Les en-têtes peuvent être enveloppés dans un lien d'ancrage quand ils ont un `id`, avec une icône de hachage affichée sur le survol pour `H2` et `H3` (sur de grands écrans) afin que les lecteurs puissent lier directement à une section.

Les liens d'ancrage sont activés par défaut pour `H2` à `H4` lors de l'utilisation de `@nuxt/content`, et désactivés autrement, [Comark](https://comark.dev) inclus. Utilisez le composant [`Theme`ph014/docs/components/theme) avec le prop `anchor` pour les basculer pour une section de votre application:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
Lorsque vous utilisez `@nuxt/content`, les liens d'ancrage sont activés pour `H2`, `H3` et `H4` par défaut. Vous pouvez contrôler leur [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks) (par exemple, pour les désactiver pour les interfaces de chat AI) ainsi que la générationxph0333xtoc ](https://content.nuxt.com/docs/getting-started/configuration#toc) dans votre `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
