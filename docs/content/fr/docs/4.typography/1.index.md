Nuxt UI fournit des composants **Prose magnifiquement stylisés pour votre contenu de markdown. Que vous affichiez la markdown avec une bibliothèque ou que vous utilisiez directement des composants de prose, Nuxt UI applique son système de conception pour que votre contenu s'adapte automatiquement au thème de votre application.

::framework-only
#nuxt
:::div

::::note
Les composants Prose sont automatiquement activés lors de l'utilisation de [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc), [`@nuxt/content`](xph013) ou [`@comark/nuxt`xph016https://comark.dev/rendering/nuxt).<br><br>Sinon, activez l'option [`prose`](](ph0222x dans votre `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
Pour l'installation et la configuration de Nuxt Content, consultez le guide **Content integration**.
::::

:::

#vue
:::note
Pour utiliser des composants en prose avec Vue, vous devez activer l'option [`prose`](/docs/getting-started/installation/vue#prose) dans votre `vite.config.ts`:

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::

## Utilisateur

::framework-only
#nuxt
:::div
Il existe plusieurs façons de rendre le contenu stylisé:

1. **Markdown rendu **: utilisez ContentRenderer, MDC, Markdown ou MarkdownDocument pour rendre le marquage avec un style de prose automatique
2. **Direct Vue usage**: importez et utilisez des composants en prose directement dans vos modèles Vue
:::

#vue
:::div
Il existe plusieurs façons de rendre le contenu stylisé:

1. **Markdown rendu **: utilisez Markdown ou MarkdownDocument pour rendre Markdown avec un style de prose automatique
2. **Direct Vue usage**: importez et utilisez des composants de prose directement dans vos modèles Vue
:::

### Avec ContentRenderer: badge{label="Nuxt only" color="warning" class="align-text-top"}

Lorsque vous utilisez [`@nuxt/content`](https://github.com/nuxt/content), affichez les pages de votre collection avec le composant [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer):

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### Avec le composant MDC: badge{label="Nuxt only" color="warning" class="align-text-top"}

Lorsque vous utilisez [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) ou [`@nuxt/content`](https://github.com/nuxt/content), utilisez le composant [`<MDC>`](https://github.com/nuxt-content/mdc) pour rendre les chaînes de démarquage:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc` est obsolète en faveur de [Comark](https://comark.dev). Vos fichiers de démarquage existants sont compatibles, aucun changement de contenu n'est nécessaire.
::

### Avec Markdown composant

[Comark](https://comark.dev) rend la démarche avec prise en charge intégrée du streaming. Il rend les jetons de manière incrémentielle à mesure qu 'ils arrivent, ce qui le rend idéal pour les réponses de chat AI et tout autre contenu de démarche dynamique.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
Le plugin `shiki` ajoute la surbrillance de la syntaxe aux blocs de code. Utilisez la prop `:streaming` lors du rendu du contenu qui arrive incrémentiellement, comme les réponses AI.

Pour prendre en charge le mode sombre, ajoutez le CSS suivant à votre feuille de style:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
Voir le composant **Chat** pour un exemple complet d'utilisation de Comark pour rendre les messages de chat AI.

### Avec MarkdownDocument

Utilisez le composant [`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code) pour rendre un `MarkdownDocument` pré-analysé sans envoyer de code d'analyseur ou de plugin au navigateur. Ceci est utile lorsque l'analyse se produit sur le serveur, dans une étape de construction ou via une API.

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

### Avec composants Prose

Utilisez les composants de prose directement dans les modèles Vue pour un contrôle maximal:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

Syntaxe ## MDC

Les éléments Markdown sont automatiquement mappés aux composants en prose: `# Heading` devient `<ProseH1>`, `**bold**` devient `<ProseStrong>`, `` `code` `` devient `<ProseCode>`, et ainsi de suite.

[MDC Syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) va plus loin en vous permettant d'utiliser les composants Vue directement à l'intérieur du markdown. Il est supporté par Nuxt Content, Nuxt MDC et Comark.

## Thème

Remplacer tout style de composant en prose dans la configuration de votre application:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
