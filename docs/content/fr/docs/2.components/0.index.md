## Laiement

Composants structurels de base pour organiser la mise en page de votre application et établir une base cohérente pour votre interface utilisateur.

:components-list{category="layout"}

## élément

Les blocs de construction de l'interface utilisateur essentiels, y compris les boutons, les badges, les avatars, les icônes et d'autres éléments d'interface fondamentaux pour créer des expériences utilisateur intuitives et cohérentes.

:components-list{category="element"}

## Formulaire

Composants de formulaire complets pour créer des expériences de saisie utilisateur interactives, notamment des entrées de texte, des sélections, des cases à cocher, des groupes radio, des commutateurs, des curseurs et une validation complète du formulaire.

:components-list{category="form"}

## Données

Composants pour l'affichage et l'organisation des données, y compris les tableaux, les accordéons, les carrousels, les chronologies, les arbres et les profils utilisateur.

:components-list{category="data"}

## Navigation

Composants pour la navigation de l'utilisateur et l'orientation, y compris les menus, les fils d'Ariane, la pagination, les onglets, les steppers, les liens et les palettes de commandes.

:components-list{category="navigation"}

## Découvrir

Éléments d'interface utilisateur flottants qui apparaissent au-dessus du contenu principal, y compris les modaux, les popovers, les infobulles, les tiroirs, les diapositives et les menus contextuels.

:components-list{category="overlay"}

## Page d'accueil

Des sections de marketing et de contenu prédéfinies pour créer des pages de destination, des blogs, des pages de tarification et d'autres documents marketing.

:components-list{category="page"}

::note{to="https://github.com/nuxt-ui-templates/saas" target="_blank"}
Découvrez le template **SaaS ph008x sur GitHub pour un exemple concret.
::

## tableau de bord

Composants spécialisés pour la création de tableaux de bord dynamiques avec panneaux redimensionnables, barres latérales pliables, barres d'outils et fonctionnalités de recherche.

:components-list{category="dashboard"}

::note{icon="i-simple-icons-github"}
Découvrez les modèles de tableau de bord [`Nuxt`](https://github.com/nuxt-ui-templates/dashboard) et [`Vue`](xph018) sur GitHub pour un exemple réel.
::

## AI Chat

Composants pour la construction d'interfaces conversationnelles et de chatbots, alimentés par le [Vercel AI SDKph022xhttps://ai-sdk.dev/).

:components-list{category="chat"}

::note{icon="i-simple-icons-github"}
Découvrez les modèles [`Nuxt`](https://github.com/nuxt-ui-templates/chat) et [`Vue`](xph0333x) AI Chat sur GitHub pour un exemple réel.

Composants pour la construction d'un éditeur de texte enrichi prenant en charge les types de contenu Markdown, HTML et JSON, optimisés par [TipTap](https://tiptap.dev/).

:components-list{category="editor"}
