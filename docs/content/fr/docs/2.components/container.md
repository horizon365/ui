## Utilisation

Utilisez l'emplacement par défaut pour centrer et limiter la largeur de votre contenu.

::tip{to="/docs/getting-started/theme/css-variables#container"}
Sa largeur maximale est contrôlée par la variable CSS `--ui-container`.
::

::component-example
---
name: 'container-example'
props:
  class: 'w-full'
---
::
