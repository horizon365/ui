## 使用法

`badge`コンポーネントのデフォルトスロットでmarkdownを使用して、[ Badge ](/docs/components/badge)をコンテンツに表示します。

::code-preview

:::badge
** v4.0.0 **
:::

#コード

```mdc
::badge
**v4.0.0**
::
```
