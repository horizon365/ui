## Codeブロック

コードブロックは`ProsePre`コンポーネントによってレンダリングされ、[Shiki](https://github.com/shikijs/shiki)によるシンタックスハイライト付きです。

::tabs{class="gap-0"}

::code-preview{label="プレビュー" class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts
export defineNuxtConfig {
  モジュール['@ nuxt/ui']
})
```
````

### 言語

シンタックスハイライトは、数十のプログラミング言語で利用できます。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <UButton @click="updateMessage">
      Click me
    </UButton>
  </div>
</template>
```

#code

````html
```vue
<script setup lang="ts">
const message = ref 'Hello World！'

関数updateMessage {
  message. value ='ボタンがクリックされました！'
}
</script>

<template>
  <div>
    <h1> {{ message }} </h1>
    <UButton @click="updateMessage">
      クリックする
    </UButton>
  </div>
</template>
```
````

::

::tip
デフォルトでは、`material-theme-lighter`と`material-theme-palenight` Shikiテーマはそれぞれライトモードとダークモードに使用されます。`@nuxt/content`を使用する場合は、`nuxt.config.ts`の[`content.build.markdown.highlight`](https://content.nuxt.com/docs/getting-started/configuration#highlight)キーでこれを変更できます。スタンドアロン`@nuxtjs/mdc`を使用する場合は、[`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations)キーでテーマを設定します。[Comark](https://comark.dev)を使用する場合は、`shiki`プラグインオプションでテーマを設定します。

Comarkでダークモードをサポートするには、以下のCSSをスタイルシートに追加します。

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

### Filename

コードブロックは自動アイコン検出でファイル名表示をサポート。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts [nuxt.config.ts]
export defineNuxtConfig {
  モジュール['@ nuxt/ui']
})
```
````

::

::tip
ファイル名アイコンは`ProseCodeIcon`コンポーネントによってレンダリングされ、アプリ設定でカスタマイズできる定義済みのアイコンのセットが含まれています。

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
これらのファイル名アイコンは[`vscode-icons`](https://icones.js.org/collection/vscode-icons)コレクションから来ています。このコレクションは他のコンポーネントが使用する`lucide`アイコンとは別のもので、ファイル拡張子から要求に応じて解決されます。`@iconify-json/vscode-icons`をインストールして、他のコレクションと同様にローカルでオフラインで提供します。
::

### Copyボタン

各コードブロックには、コードをクリップボードにコピーするコピーボタンが組み込まれています。

`copy`プロパティを`false`に設定してボタンを非表示にするか、[Button](/docs/components/button)プロパティを渡してカスタマイズします。

::tip
アプリ設定の`ui.icons.copy`キーと`ui.icons.copyCheck`キーでアイコンを変更できます。

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::
::

### Lineハイライト

特定の線をハイライトして重要な部分に注意を引く。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
export defineNuxtConfig {
  modules：['@ nuxt/ui']，//この行はハイライトされます
  css ['～/assets/css/main.css']
})
```
````

::

### コード差分

コードバージョン間の変更を表示するには`diff`言語を使用します。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export defineNuxtConfig {
  モジュール[
-    '@ nuxt/ui—pro'
+    '@ nuxt/ui'
  ]
})
```
````
