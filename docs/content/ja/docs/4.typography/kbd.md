## 使用法

`kbd`コンポーネントを使用して、コンテンツ内に[ Kbd ](/docs/components/kbd)を表示します。

::code-preview{class="[&>div]:*:my-0"}
kbd {value="meta"}

#コード

```mdc
:kbd{value="meta"} :kbd{value="K"}
```

::
