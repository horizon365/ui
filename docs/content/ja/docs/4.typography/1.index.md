Nuxt UIは、美しくスタイルされた**Proseコンポーネント**をマークダウンコンテンツに提供します。ライブラリを使ってマークダウンをレンダリングする場合でも、散文コンポーネントを直接使用する場合でも、Nuxt UIはデザインシステムを適用し、コンテンツをアプリケーションのテーマに自動的に適応させます。

::framework-only
#nuxt
:::div

::::note
散文コンポーネントは、[`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) [`@nuxt/content`](https://github.com/nuxt/content)または[`@comark/nuxt`](https://comark.dev/rendering/nuxt).<br><br>を使用すると自動的に有効になります。`nuxt.config.ts`で[`prose`](/docs/getting-started/installation/nuxt#prosexph02xオプションを有効にします。

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
Nuxt Contentのインストールとセットアップについては、**Content integration**ガイドを参照してください。
::::

:::

#vue
:::note
Vueで散文コンポーネントを使用するには、`vite.config.ts`で[`prose`](/docs/getting-started/installation/vue#prose)オプションを有効にする必要があります。

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::
::

## 使用法

::framework-only
#nuxt
:::div
スタイル付きコンテンツをレンダリングする方法は複数あります。

1. **Markdownレンダリング** ContentRenderer、MDC、Markdown、MarkdownDocumentを使用して、自動散文スタイルでmarkdownをレンダリングする
2. **Direct Vue usage**散文コンポーネントをVueテンプレートに直接インポートして使用する
:::

#vue
:::div
スタイル付きコンテンツをレンダリングする方法は複数あります。

1. **Markdownレンダリング** MarkdownまたはMarkdownDocumentを使用して自動散文スタイルでmarkdownをレンダリングする
2. **Direct Vue usage**散文コンポーネントをVueテンプレートに直接インポートして使用する
:::

::

### ContentRenderer付きbadge{label="Nuxt only" color="warning" class="align-text-top"}

[`@nuxt/content`](https://github.com/nuxt/content)を使用する場合、コレクションページを[`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer)コンポーネントでレンダリングします。

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### MDCコンポーネント付き：badge{label="Nuxt only" color="warning" class="align-text-top"}

[`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc)または[`@nuxt/content`](https://github.com/nuxt/content)を使用する場合は、[`<MDC>`](https://github.com/nuxt-content/mdc)コンポーネントを使用してマークダウン文字列をレンダリングします。

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc`は、[Comark](https://comark.dev)を支持して非推奨となりました。既存のmarkdownファイルは互換性があり、内容を変更する必要はありません。
::

### With Markdownコンポーネント

[Comark](https://comark.dev)は、ストリーミングをサポートしたマークダウンをレンダリングします。トークンが到着すると徐々にレンダリングされるため、AIチャット応答やその他の動的なマークダウンコンテンツに最適です。

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
`shiki`プラグインは、コードブロックにシンタックスハイライトを追加します。AIレスポンスなど、インクリメンタルに到着するコンテンツをレンダリングする場合は、`:streaming`プロパティを使用します。

ダークモードをサポートするには、以下のCSSをスタイルシートに追加します。

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
Comarkを使用してAIチャットメッセージをレンダリングする完全な例については、**Chat**コンポーネントを参照してください。
::

### With MarkdownDocument

[`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code)コンポーネントを使用して、パーサーやプラグインコードをブラウザーに送らずに事前に解析された`MarkdownDocument`をレンダリングします。これは、サーバー上、ビルドステップ、またはAPI経由で解析が行われる場合に便利です。

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### 散文コンポーネント付き

Vueテンプレートで直接散文コンポーネントを使用して最大限に制御します。

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## Theme

アプリ設定の散文コンポーネントのスタイルを上書きします。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
