## リスト

Markdownは様々なコンテンツニーズに対応しています。

### 順序付けされていないリスト

特定の順序のない項目には順序付けられていないリストを使用します。各項目は`-`記号で開始します。

::tabs{class="gap-0"}

::code-preview{label="プレビュー" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- リスト項目です。
- 私は別のリスト項目です。
- 私は最後のリスト項目です。

#コード

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### 注文リスト

プロセスのステップなど、項目の順序が重要な場合は、順序付きリストを使用します。

::tabs{class="gap-0"}

::code-preview{label="プレビュー" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. リスト項目です。
2. 別のリスト項目です。
3. 私は最後のリスト項目です。

#コード

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### ネストされたリスト

複雑な構造のサブ項目を含む階層リストを作成します。サブ項目を4つのスペースでインデントしてネストします。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- リスト項目です。
  - ネストされたリスト項目です。
  - 私は別のネストされたリスト項目です。
- 別のリスト項目です。
  - 別のネストされたアイテム
    - 深いネストされたアイテム
    - 別の深いネストされたアイテム
  - 第2レベルに戻る

#コード

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### 混合リスト

複雑な階層の順序付きリストと順序なしリストを組み合わせられます。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. 最初の主要なステップ
   - サブ要件A
   - サブ要件B
2. 第2の主要ステップ
   - 別のサブアイテム
   - 最終サブ項目
3. 最終ステップ

#コード

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## テーブル

行と列の構造化データを明確に表示します。テーブルはデータの比較やプロパティの一覧に最適です。

::tabs{class="gap-0"}

::code-preview{label="プレビュー" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| プロップ    |デフォルト   |タイプ                     |
|---------|-----------|--------------------------|
| `name`|           | `string`{lang="ts-type"}|
| `size`| `md`| `string`{lang="ts-type"}|
| `color`| `neutral`| `string`{lang="ts-type"}|

#コード

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
