## 見出し

見出しを使用してコンテンツを整理し、読みやすくします。

見出しに`id`が付いている場合はアンカーリンクで囲むことができ、`H2`と`H3`（大画面）のホバーにハッシュアイコンが表示されるので、読者はセクションに直接リンクできる。

アンカーリンクは、`@nuxt/content`を使用している場合、`H2`～`H4`で有効になり、それ以外の場合は無効になります。[ Comark ](https://comark.dev)が含まれています。[`Theme`](/docs/components/theme)コンポーネントを使用します。アプリのセクションでそれらを切り替えるためのprop

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
`@nuxt/content`を使用する場合、デフォルトで`H2`、`H3`、`H4`のアンカーリンクが有効になっています。[ generation ](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)を制御できます。たとえば、AIチャットインターフェイスで無効にする

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
