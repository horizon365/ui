## Heads

見出しを使用してコンテンツを整理し、読みやすくします。

見出しに`id`がある場合はアンカーリンクでラップすることができ、`H2`と`H3`（大画面）のホバー時にハッシュアイコンが表示されるので、読者はセクションに直接リンクできる。

`@nuxt/content`を使用している場合は、`H2`から`H4`に対してアンカーリンクがデフォルトで有効になっています。[Comark](https://comark.dev)が含まれています。[`Theme`](/docs/components/theme)コンポーネントと`anchor`プロパティを使用して、アプリケーションのセクションでアンカーリンクを切り替えることができます。

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
`@nuxt/content`を使用している場合、`H2`、`H3`、`H4`に対してアンカーリンクがデフォルトで有効になっています。[generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)例えば、AIチャットインターフェイスで無効にすると[toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc)を`nuxt.config.ts`で制御できます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
