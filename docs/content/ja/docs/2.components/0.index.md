## Layout

アプリケーションのレイアウトを整理し、UIの一貫した基盤を確立するためのコア構造コンポーネント。

:components-list{category="layout"}

## Element

ボタン、バッジ、アバター、アイコン、その他の基本的なインターフェイス要素を含む、直感的で一貫性のあるユーザーエクスペリエンスを作成するための不可欠なUIビルディングブロック。

:components-list{category="element"}

## Form

テキスト入力、選択、チェックボックス、ラジオグループ、スイッチ、スライダー、完全なフォーム検証など、インタラクティブなユーザー入力エクスペリエンスを構築するための包括的なフォームコンポーネント。

:components-list{category="form"}

## Data

テーブル、アコーディオン、カルーセル、タイムライン、ツリー、ユーザープロファイルなど、データを表示および整理するためのコンポーネント。

:components-list{category="data"}

## Navigation

メニュー、パンくず、ページネーション、タブ、ステッパー、リンク、コマンドパレットなど、ユーザーナビゲーションとウェイファインディングのためのコンポーネント。

:components-list{category="navigation"}

## オーバーレイ

モーダル、ポップオーバー、ツールチップ、引き出し、スライドオーバー、コンテキストメニューなど、メインコンテンツの上に表示されるフローティングUI要素。

:components-list{category="overlay"}

## Page

ランディングページ、ブログ、価格ページ、その他のマーケティング資料を作成するための事前構築されたマーケティングおよびコンテンツセクション。

:components-list{category="page"}

::note{to="https://github.com/nuxt-ui-templates/saas" target="_blank"}
実際の例については、GitHubの** SaaS template**をご覧ください。
::

## Dashboard

サイズ変更可能なパネル、折りたたみ可能なサイドバー、ツールバー、検索機能を備えた動的ダッシュボードを構築するための専用コンポーネント。

:components-list{category="dashboard"}

::note{icon="i-simple-icons-github"}
実際の例については、GitHubの[`Nuxt`](https://github.com/nuxt-ui-templates/dashboard)および[`Vue`](https://github.com/nuxt-ui-templates/dashboard-vue)ダッシュボードテンプレートをご覧ください。
::

## AIチャット

[Vercel AI SDK](https://ai-sdk.dev/)を搭載した対話型インターフェイスとチャットボットを構築するためのコンポーネント。

:components-list{category="chat"}

::note{icon="i-simple-icons-github"}
実際の例については、GitHubの[`Nuxt`](https://github.com/nuxt-ui-templates/chat)および[`Vue`](https://github.com/nuxt-ui-templates/chat-vue) AIチャットテンプレートをご覧ください。
::

## Editor badge{label="4.3+" class="align-text-top"}

[TipTap](https://tiptap.dev/)を搭載した、markdown、HTML、JSONコンテンツタイプをサポートするリッチテキストエディタを構築するためのコンポーネント。

:components-list{category="editor"}

::note{to="https://github.com/nuxt-ui-templates/editor" target="_blank"}
実際の例については、GitHubの**Editor template**をご覧ください。
::

::note{to="https://github.com/nuxt-ui-templates/docs" target="_blank"}
