## 使用法

PageColumnsコンポーネントは、応答性の高い複数列レイアウトでコンテンツを表示します。[PageCard](/docs/components/page-card)コンポーネントやその他の要素とうまく連携し、モバイルでは1列から大きな画面では複数列に対応します。
