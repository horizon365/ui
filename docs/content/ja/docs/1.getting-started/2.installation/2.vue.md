## Setup

### Vueプロジェクトに追加

::steps{level="4"}

#### Nuxt UIパッケージをインストールする

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```


```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]

```

#### x`vite.config.ts`{lang="ts-type"}にNuxt UI Viteプラグインを追加

::code-group{sync="vite"}

```ts [vite.config.ts (Vite)]{3,8}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui()
  ]
})
```

```ts [vite.config.ts (Laravel Inertia)]{3,20-22}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import laravel from 'laravel-vite-plugin'

export default defineConfig({
  plugins: [
    laravel({
      input: ['resources/js/app.ts'],
      refresh: true
    }),
    vue({
      template: {
        transformAssetUrls: {
          base: null,
          includeAbsolute: false
        }
      }
    }),
    ui({
      router: 'inertia'
    })
  ]
})
```

```ts [vite.config.ts (AdonisJS Inertia)]{3,15-17}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import adonisjs from '@adonisjs/vite/client'
import inertia from '@adonisjs/inertia/client'

export default defineConfig({
  plugins: [
    adonisjs({
      entrypoints: ['inertia/app/app.ts'],
      reload: ['resources/views/**/*.edge']
    }),
    inertia(),
    vue(),
    ui({
      router: 'inertia'
    })
  ]
})
```

::

::tip
Nuxt UIは`unplugin-auto-import`と`unplugin-vue-components`を登録し、`auto-imports.d.ts`と`components.d.ts`の型宣言ファイルを生成します。おそらくこれらをgitignoreして`tsconfig`に追加したいでしょう。

```json [tsconfig.app.json]
{
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue", "auto-imports.d.ts", "components.d.ts"]
}
```

```bash [.gitignore]
# Auto-generated type declarations
auto-imports.d.ts
components.d.ts
```

::

::warning
これらの宣言ファイルはViteが実行されたときにのみ書き込まれます。デフォルトの`create-vue` `build`スクリプトは`vue-tsc`を`vite build` `run-p type-check "build-only {@}"`と並列に実行します。したがって、クリーンチェックアウトではファイルが存在する前にタイプチェックが開始され、`Cannot find name 'useToast'`のようなエラーで失敗することがあります。代わりにビルド後にタイプチェックを実行して、宣言が最初に生成されるようにしてください。

```json [package.json]
{
  "scripts": {
    "build": "run-s build-only type-check"
  }
}
```

::

::tip
内部的には、Nuxt UIはテーマタイプを解決するためにカスタムエイリアスに依存しています。TypeScriptを使用している場合は、`vite.config.ts`で自動補完を有効にするために、これらのエイリアスを`tsconfig`ファイルに追加してください。

```json [tsconfig.node.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui": [
        "./node_modules/.nuxt-ui/ui"
      ]
    }
  }
}
```

```json [tsconfig.app.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui/*": [
        "./node_modules/.nuxt-ui/ui/*"
      ]
    }
  }
}
```

####  Nuxt UI Vueプラグインを使用する

::code-group{sync="vite"}

```ts [src/main.ts (Vite)]{3,14}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

app.use(router)
app.use(ui)

app.mount('#app')
```

```ts [resources/js/app.ts (Laravel Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import ui from '@nuxt/ui/vue-plugin'
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers'
import { createApp, h } from 'vue'

const appName = import.meta.env.VITE_APP_NAME || 'Laravel x Nuxt UI'

createInertiaApp({
  title: title => (title ? `${title} - ${appName}` : appName),
  resolve: name =>
    resolvePageComponent(
      `./pages/${name}.vue`,
      import.meta.glob<DefineComponent>('./pages/**/*.vue')
    ),
  setup({ el, App, props, plugin }) {
    createApp({ render: () => h(App, props) })
      .use(plugin)
      .use(ui)
      .mount(el)
  }
})
```

## Options

`vite.config.ts`でオプションを提供することで、Nuxt UIをカスタマイズできます。

### `prefix`

コンポーネントのプレフィックスを変更するには、`prefix`オプションを使用します。

- デフォルト`U`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prefix: 'Nuxt'
    })
  ]
})
```

### `ui`

Nuxt UIの設定を提供するには`ui`オプションを使用します。これはNuxtの`app.config.ts`の`ui`キーに相当するVueキーです。

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'green',
          neutral: 'slate'
        }
      }
    })
  ]
})
```

### `dts`

自動インポートされたコンポーネントとコンポジットの宣言ファイルの生成を有効または無効にするには、`dts`オプションを使用します。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      dts: false
    })
  ]
})
```

### `icon`

`icon`オプションを使用して、[Icon](/docs/components/icon)コンポーネント`size` `mode` `customize`のデフォルトのpropsを設定し、ビルド時に`clientBundle`を通してアイコンをバンドルする設定をします。Nuxt UI自身のアイコンのバンドルは、コレクションがインストールされたときにデフォルトで有効になります。オプトアウトするには`clientBundle: false`を設定します。

- デフォルト`{}`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      icon: {
        mode: 'svg',
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

::note{to="/docs/getting-started/integrations/icons/vue#collections"}
アイコンコレクションとクライアントバンドルの詳細については、**Icons**のドキュメントを参照してください。
::

### `colorMode`

`colorMode`オプションを使用して、`@vueuse/core`からカラーモード統合を有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```

### `theme.colors`

`theme.colors`オプションを使用して、コンポーネントテーマの生成に使用される動的カラーエイリアスを定義します。

- デフォルト`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: ['primary', 'error']
      }
    })
  ]
})
```

::note
各エイリアスは、アプリケーションが使用しているかどうかにかかわらず、色バリアントを持つコンポーネントテーマ内の`--ui-color-*`シェードとバリアントの完全なセットを生成します。リストを実際に使用するエイリアスにトリミングし、フォームを使用する場合は`error`を保持します。バリデーションスタイルは`error`に依存します。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
色のカスタマイズとテーマの詳細については、テーマセクションをご覧ください。
::

### `theme.transitions`

`theme.transitions`オプションを使用して、コンポーネントのトランジションを有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        transitions: false
      }
    })
  ]
})
```

::note
このオプションは、ホバーまたはアクティブ状態のコンポーネントに`transition-colors`クラスを追加します。
::

### `theme.unstyled` badge{label="4.9+" class="align-text-top"}

`theme.unstyled`オプションを使用して、コンポーネントからすべてのデフォルトのテーマクラスを削除し、その構造と`class`、`ui`、または`app.config.ui`を通じて提供するクラスのみを保持します。

- デフォルト`false`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        unstyled: true
      }
    })
  ]
})
```

::warning
これにより**structural**クラスポジショニング、トランジション、フレックス/グリッドも削除されます。`Modal`、`Drawer`、`Calendar`のようなレイアウトが重いコンポーネントは、PrimeVueのスタイルなしモードと同様にレイアウトを再供給する必要があります。
::

### `theme.defaultVariants`

`theme.defaultVariants`オプションを使用して、コンポーネントのデフォルトの`color`および`size`バリアントをオーバーライドします。

デフォルト値は`primary`または`md`のみ置き換えられるため、Avatarは`color: 'neutral'`を保持し、Separatorは`size: 'xs'`を保持します。

- デフォルト`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        defaultVariants: {
          color: 'neutral',
          size: 'sm'
        }
      }
    })
  ]
})
```

### `theme.prefix` badge{label="4.2+" class="align-text-top"}

`theme.prefix`オプションを使用して、Tailwind CSSインポート時に設定したプレフィックスと同じプレフィックスを設定します。これにより、Nuxt UIコンポーネントが正しいプレフィックス付きユーティリティクラスとCSS変数を使用するようになります。

::code-group

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        prefix: 'tw'
      }
    })
  ]
})
```

```css [src/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

これはNuxt UIコンポーネントテーマのすべてのTailwindユーティリティクラスとCSS変数の前に自動的に表示されます。

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
接頭辞の使用については、Tailwind CSSドキュメントを参照してください。
::

### `prose`

`prose`オプションを使用して、Nuxt UI [`Prose`コンポーネント](/docs/typography)とそのテーマを有効にします。

- デフォルト`false`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```

### `autoImport`

`autoImport`オプションを使用して、構成可能な自動インポートを無効にするか、[`unplugin-auto-import`](https://github.com/unplugin/unplugin-auto-import)オプションをカスタマイズします。

- デフォルト`{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      autoImport: false
    })
  ]
})
```

::note
無効にしても、`@nuxt/ui/composables`から明示的にコンポジブルをインポートできます。
::

### `components`

コンポーネントの自動インポートを無効にするか、[`unplugin-vue-components`](https://github.com/unplugin/unplugin-vue-components)オプションをカスタマイズするには、`components`オプションを使用します。

- デフォルト`{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      components: false
    })
  ]
})
```

::note
無効にしても、`import Button from '@nuxt/ui/components/Button.vue'`や`import ProseCode from '@nuxt/ui/components/prose/Code.vue'`などのコンポーネントを明示的にインポートできます。
::

### `router` badge{label="4.3+" class="align-text-top"}

ルーティング統合を構成するには、`router`オプションを使用します。これは、Electronアプリケーション、MPA、[Inertia.js](https://inertiajs.com/)や[Hybridly](xph74xxph75xのようなフレームワークなど、`vue-router`を使用しないアプリケーションに便利です。

- デフォルト`true`{lang="ts-type"}

| 値|説明|
| ----- | ----------- |
| `true`{lang="ts-type"}| `RouterLink`コンポーネントでのナビゲーションに`vue-router`を使用。|
| `false`{lang="ts-type"}|ルーティング統合を無効にし、リンクをプレーン`<a>`タグとしてレンダリング。|
| `'inertia'`{lang="ts-type"}| `Link`コンポーネントのナビゲーションにInertia.jsを使用します。|

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      router: false
    })
  ]
})
```

::tip
**Hybridly**のようなフレームワークにカスタムナビゲーションロジックを提供するには、Vite設定で`router: false`を設定し、Vueプラグインをインストールするときに関数を渡すことができます。

```ts [src/main.ts]
import ui from '@nuxt/ui/vue-plugin'
import { router } from 'hybridly'

app.use(ui, {
  router: (event, { href, external }) => {
    if (external) {
      return
    }

    event.preventDefault()

    router.navigate({ url: href })
  }
})
```
::

::note
`false`または`'inertia'`に設定すると、`vue-router`は依存関係として必要ありません。
::

### `scanPackages` badge{label="4.3+" class="align-text-top"}

`scanPackages`オプションを使用して、Nuxt UIを使用してコンポーネントをスキャンする追加のnpmパッケージを指定します。これは、Nuxt UIコンポーネントを内部で使用する共有コンポーネントライブラリがある場合に便利です。

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      scanPackages: ['@my-org/ui-components']
    })
  ]
})
```

::note
デフォルトでは`@nuxt/ui`のみがスキャンされます。外部パッケージにNuxt UIを使用するVueコンポーネントが含まれている場合にこのオプションを使用します。
::

### `root` badge{label="4.9+" class="align-text-top"}

Nuxt UIが`.nuxt-ui`ディレクトリを生成するディレクトリをオーバーライドするには、`root`オプションを使用します。デフォルトではViteの`root`を使用しますが、[`electron-vite`](https://electron-vite.org/)のようなセットアップでは、レンダラーの`root`はサブディレクトリを指します。（例：`src/renderer`）のため、Tailwindがスキャンしない`src/renderer/node_modules/.nuxt-ui`にテンプレートが表示され、`bg-default`、`ring-default`、`divide-default`などのテーマクラスが欠落します。

```ts [electron.vite.config.ts] {12}
import { defineConfig } from 'electron-vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  renderer: {
    root: 'src/renderer',
    plugins: [
      vue(),
      ui({
        root: __dirname
      })
    ]
  }
})
```

::note
`root`をプロジェクトルートにポイントすると、生成された`.nuxt-ui`ディレクトリがTailwindがスキャンする`node_modules`になります。
::

### `experimental.componentDetection` badge{label="4.11+" class="align-text-top"}

`experimental.componentDetection`オプションを使用して、ツリーシェイクの自動コンポーネント検出を有効にします。この機能はソースコードをスキャンして、実際に使用されているコンポーネントを検出し、それらのコンポーネントに必要なCSSのみを生成します。（依存関係を含む）。これがなければ、ViteプラグインはすべてのコンポーネントのテーマCSSを生成します。検出はViteルートをカバーし、[`scanPackages`](#scanpackages)にリストされているパッケージとルート外にある[`components`](#components)オプションの`dirs`

- デフォルト`false`{lang="ts-type"}
- タイプ`boolean | string[]`{lang="ts-type"}

**自動検出を有効にする：**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: true
      }
    })
  ]
})
```

**動的使用のための追加コンポーネントを含める：**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: ['Modal', 'DropdownMenu', 'Popover']
      }
    })
  ]
})
```

::note
コンポーネント名の配列を指定する場合、自動検出が有効になり、これらのコンポーネント依存関係が含まれることが保証されます。これは`<component :is="..." />`のように静的に解析できない動的コンポーネントに便利です。
::

::warning
新しく使用したコンポーネントは、次の開発サーバ起動時にピックアップされます。コンポーネントを追加してスタイルがない場合は、開発サーバを再起動してください。
::

## 連続リリース

Nuxt UIは継続的なプレビューリリースに[pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)を使用し、開発者は公式リリースを待たずに最新の機能やバグ修正に即座にアクセスできます。

`v4`ブランチへのすべてのコミットとPRに対して自動プレビューリリースが作成されます。パッケージバージョンを特定のコミットハッシュまたはPR番号に置き換えて使用してください。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**はインストールURLをPRに自動的にコメントし、変更を簡単にテストできます。
::
