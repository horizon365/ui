#### `vite.config.ts`{lang="ts-type"}に Nuxt UI Vite プラグイン を 追加 し ます 。

::code-group{sync="vite"}

```ts [vite.config.ts (Vite)]{3,8}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui()
  ]
})
```

```ts [vite.config.ts (Laravel Inertia)]{3,20-22}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import laravel from 'laravel-vite-plugin'

export default defineConfig({
  plugins: [
    laravel({
      input: ['resources/js/app.ts'],
      refresh: true
    }),
    vue({
      template: {
        transformAssetUrls: {
          base: null,
          includeAbsolute: false
        }
      }
    }),
    ui({
      router: 'inertia'
    })
  ]
})
```

```ts [vite.config.ts (AdonisJS Inertia)]{3,15-17}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import adonisjs from '@adonisjs/vite/client'
import inertia from '@adonisjs/inertia/client'

export default defineConfig({
  plugins: [
    adonisjs({
      entrypoints: ['inertia/app/app.ts'],
      reload: ['resources/views/**/*.edge']
    }),
    inertia(),
    vue(),
    ui({
      router: 'inertia'
    })
  ]
})
```

::

::tip
Nuxt UI は`unplugin-auto-import`と`unplugin-vue-components`を 登録 し ます 。 これ に より`auto-imports.d.ts`と`components.d.ts`型 宣言 ファイル が 生成 さ れ ます 。 おそらく これら を 追加 し て 、`tsconfig`に 追加 し たい でしょ う 。

```json [tsconfig.app.json]
{
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue", "auto-imports.d.ts", "components.d.ts"]
}
```

```bash [.gitignore]
# Auto-generated type declarations
auto-imports.d.ts
components.d.ts
```

::

::warning
これら の 宣言 ファイル は Vite が 実行 さ れ た とき に のみ 書き込ま れ ます 。 デフォルト の`create-vue``build`スクリプト は`vite build``run-p type-check "build-only {@}"`と 並列 に 実行 さ れ ます 。 し た がっ て 、 クリーン チェック アウト で は ファイル が 存在 する 前 に タイプチェック が 開始 さ れ 、`Cannot find name 'useToast'`の よう な エラー で 失敗 する こと が あり ます 。 代わり に ビルド 後 に タイプチェック を 実行 し て 宣言 が 最初 に 生成 さ れる よう に し ます 。

```json [package.json]
{
  "scripts": {
    "build": "run-s build-only type-check"
  }
}
```

::

::tip
内部 的 に は 、 Nuxt UI は テーマ タイプ を 解決 する ため に カスタムエイリアス に 依存 し て い ます 。 TypeScript を 使用 し て いる 場合 は 、 これら の エイリアス を`tsconfig`ファイル に 追加 し て 、`vite.config.ts`で 自動 補完 を 有効 に し て ください 。

```json [tsconfig.node.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui": [
        "./node_modules/.nuxt-ui/ui"
      ]
    }
  }
}
```

```json [tsconfig.app.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui/*": [
        "./node_modules/.nuxt-ui/ui/*"
      ]
    }
  }
}
```

#### Nuxt UI Vue プラグイン を 使用 する

::code-group{sync="vite"}

```ts [src/main.ts (Vite)]{3,14}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

app.use(router)
app.use(ui)

app.mount('#app')
```

```ts [resources/js/app.ts (Laravel Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import ui from '@nuxt/ui/vue-plugin'
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers'
import { createApp, h } from 'vue'

const appName = import.meta.env.VITE_APP_NAME || 'Laravel x Nuxt UI'

createInertiaApp({
  title: title => (title ? `${title} - ${appName}` : appName),
  resolve: name =>
    resolvePageComponent(
      `./pages/${name}.vue`,
      import.meta.glob<DefineComponent>('./pages/**/*.vue')
    ),
  setup({ el, App, props, plugin }) {
    createApp({ render: () => h(App, props) })
      .use(plugin)
      .use(ui)
      .mount(el)
  }
})
```

## オプション

`vite.config.ts`に オプション を 指定 する こと で 、 Nuxt UI を カスタマイズ でき ます 。

### `prefix`

コンポーネント の プレフィックス を 変更 する に は 、`prefix`オプション を 使用 し ます 。

- デフォルト`U`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prefix: 'Nuxt'
    })
  ]
})
```

### `ui`

Nuxt UI の 設定 を 提供 する に は`ui`オプション を 使用 し て ください 。 これ は Nuxt の`app.config.ts`の`ui`キー に 相当 する Vue です 。

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'green',
          neutral: 'slate'
        }
      }
    })
  ]
})
```

### `dts`

`dts`オプション を 使用 し て 、 自動 インポート さ れ た コンポーネント と コンポジブル の 宣言 ファイル の 生成 を 有効 また は 無効 に し ます 。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      dts: false
    })
  ]
})
```

### `icon`

`icon`オプション を 使用 し て 、[Icon](/docs/components/icon)コンポーネント の デフォルト プロップ を 設定 し ます 。`size``customize`と 、`clientBundle`を 使っ て ビルド 時 の アイコン の バンドル を 設定 し ます 。 Nuxt UI 独自 の アイコン の バンドル は 、 コレクション が インストール さ れ た とき に デフォルト で 有効 に なり ます 。@@を 設定 し ます 。`clientBundle: false`を オプト アウト し ます 。

- デフォルト`{}`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      icon: {
        mode: 'svg',
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

::note{to="/docs/getting-started/integrations/icons/vue#collections"}
アイコンコレクション と クライアント バンドル について の 詳細 は 、**Icons**ドキュメント を 参照 し て ください 。
::

### `colorMode`

`colorMode`オプション を 使用 し て 、`@vueuse/core`から カラー モード の 統合 を 有効 また は 無効 に し ます 。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```

### `theme.colors`

`theme.colors`オプション を 使用 し て 、 コンポーネント テーマ の 生成 に 使用 さ れる 動的 カラーエイリアス を 定義 し ます 。

- デフォルト`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: ['primary', 'error']
      }
    })
  ]
})
```

::note
各 エイリアス は 、 アプリケーション が 使用 し て いる か どう か に かかわら ず 、 色 バリアント を 持つ コンポーネント テーマ 内 の`--ui-color-*`シェード と バリアント の 完全 な セット を 生成 し ます 。 リスト を 実際 に 使用 する エイリアス に トリミング し 、 フォーム を 使用 する 場合 は`error`を 保持 し ます 。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
色 の カスタマイズ と テーマ の 詳細 について は 、 テーマ セクション を ご覧 ください 。
::

### `theme.transitions`

`theme.transitions`オプション を 使用 し て 、 コンポーネント の トランジション を 有効 また は 無効 に し ます 。

- デフォルト`true`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        transitions: false
      }
    })
  ]
})
```

::note
この オプション は 、 ホバー また は アクティブ 状態 の コンポーネント に`transition-colors`クラス を 追加 し ます 。
::

### `theme.unstyled`badge{label="4.9+" class="align-text-top"}

`theme.unstyled`オプション を 使用 し て 、 コンポーネント から すべて の デフォルト の テーマクラス を 削除 し 、 その 構造 と`class`、`ui`、 また は`app.config.ui`で 提供 し た クラス のみ を 保持 し ます 。

- デフォルト`false`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        unstyled: true
      }
    })
  ]
})
```

::warning
これ は**structural**クラス （ ポジショニング 、 トランジション 、 フレックス/グリッド ） も 削除 し ます 。`Modal``Drawer``Calendar`の よう な レイアウト 重い コンポーネント は 、 PrimeVue の スタイル なし モード と 同様 に レイアウト を 再 供給 する 必要 が あり ます 。
::

### `theme.defaultVariants`

`theme.defaultVariants`オプション を 使用 し て 、 コンポーネント の デフォルト の`color`および`size`バリアント を 上書き し ます 。

デフォルトは`primary`または`md`のみ置き換えられるため、Avatarは`color: 'neutral'`を保持し、Separatorは`size: 'xs'`を保持します。

- デフォルト`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        defaultVariants: {
          color: 'neutral',
          size: 'sm'
        }
      }
    })
  ]
})
```

### `theme.prefix` badge {label="4.2+" class="align-text-top"}

`theme.prefix`オプションを使用して、Tailwind CSSインポートで設定したのと同じプレフィックスを設定します。これにより、Nuxt UIコンポーネントが正しいプレフィックス付きユーティリティクラスとCSS変数を使用することが保証されます。

::code-group

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        prefix: 'tw'
      }
    })
  ]
})
```

```css [src/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

これはNuxt UIコンポーネントテーマのすべてのTailwindユーティリティクラスとCSS変数の前に自動的に表示されます。

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
接頭辞の使用については、Tailwind CSSドキュメントを参照してください。
::

import { defineConfig } from 'vite'

### `router` badge {label="4.3+" class="align-text-top"}

ルーティング統合を構成するには、`router`オプションを使用します。これは、`vue-router`を使用しないアプリケーション（Electronアプリケーション、MPA、または[ Inertia.js ](https://inertiajs.com/)または[ Hybridly ](https://hybridly.dev/)など）に便利です。

- デフォルト`true`{lang="ts-type"}

| 値|説明|
| ----- | ----------- |
| `true`{lang="ts-type"}| `RouterLink`コンポーネントを使用したナビゲーションに`vue-router`を使用します。|
| `false`{lang="ts-type"}|ルーティング統合を無効にし、リンクがプレーン`<a>`タグとしてレンダリングされます。|
| `'inertia'`{lang="ts-type"}|ナビゲーションには、`Link`コンポーネントを使用してInertia.jsを使用します。|

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      router: false
    })
  ]
})
```

::tip
** Hybridly **のようなフレームワーク用のカスタムナビゲーションロジックを提供するには、Vite設定で`router: false`を設定し、Vueプラグインをインストールするときに関数を渡します。

```ts [src/main.ts]
import ui from '@nuxt/ui/vue-plugin'
import { router } from 'hybridly'

app.use(ui, {
  router: (event, { href, external }) => {
    if (external) {
      return
    }

    event.preventDefault()

    router.navigate({ url: href })
  }
})
```
::

::note
`false`または`'inertia'`に設定した場合、`vue-router`は依存関係として必要ありません。
::

### `scanPackages` badge {label="4.3+" class="align-text-top"}

`scanPackages`オプションを使用して、Nuxt UIを使用してコンポーネントをスキャンする追加のnpmパッケージを指定します。これは、Nuxt UIコンポーネントを内部で使用する共有コンポーネントライブラリがある場合に便利です。

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      scanPackages: ['@my-org/ui-components']
    })
  ]
})
```

::note
デフォルトでは`@nuxt/ui`のみがスキャンされます。Nuxt UIを使用するVueコンポーネントを外部パッケージに含む場合にこのオプションを使用してください。
::

### `root` badge {label="4.9+" class="align-text-top"}

Nuxt UIが`.nuxt-ui`ディレクトリを生成するディレクトリをオーバーライドするには、`root`オプションを使用します。テーマテンプレートを含む[`electron-vite`](https://electron-vite.org/)のような設定では、レンダラーの`root`はサブディレクトリを指します。例

```ts [electron.vite.config.ts] {12}
import { defineConfig } from 'electron-vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  renderer: {
    root: 'src/renderer',
    plugins: [
      vue(),
      ui({
        root: __dirname
      })
    ]
  }
})
```

::note
プロジェクトルートに`root`をポイントすると、生成された`.nuxt-ui`ディレクトリがTailwindがスキャンする`node_modules`になります。
::

### `experimental.componentDetection` badge {label="4.11+" class="align-text-top"}

`experimental.componentDetection`オプションを使用して、ツリーシェイクの自動コンポーネント検出を有効にします。この機能はソースコードをスキャンして、実際に使用されているコンポーネントを検出し、それらのコンポーネントに必要なCSSのみを生成します。（依存関係を含む）。これがなければ、ViteプラグインはすべてのコンポーネントのテーマCSSを生成します。検出はViteルートをカバーし、[`scanPackages`](#scanpackages)にリストされているパッケージと[`components`](#components)からの任意の`dirs`にあるパッケージ。

- デフォルト`false`{lang="ts-type"}
- タイプ`boolean | string[]`{lang="ts-type"}

**自動検出を有効にする：**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: true
      }
    })
  ]
})
```

**動的使用のために追加のコンポーネントを含める**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: ['Modal', 'DropdownMenu', 'Popover']
      }
    })
  ]
})
```

::note
コンポーネント名の配列を指定する場合、自動検出が有効になり、これらのコンポーネントおよびその依存関係が含まれることが保証されます。これは`<component :is="..." />`のように静的に解析できない動的コンポーネントに便利です。
::

::warning
新しく使用したコンポーネントは、次の開発サーバ起動時にピックアップされます。コンポーネントを追加してスタイルがない場合は、開発サーバを再起動してください。
::

## 継続 的 リリース

Nuxt UI は[を 使用 し ますpkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)は 継続 的 な プレビュー リリース 用 で 、 開発 者 は 公式 リリース を 待た ず に 最新 の 機能 や バグ 修正 に 即座 に アクセス でき ます 。

自動 プレビュー リリース は 、`v4`ブランチ へ の すべて の コミット と PR に対して 作成 さ れ ます 。 パッケージバージョン を 特定 の コミット ハッシュ また は PR 番号 に 置き換え て 使用 し て ください 。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**は 、 インストール URL とともに PR に 自動的 に コメント し 、 変更 を 簡単 に テスト でき ます 。
::
