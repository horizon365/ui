## Setup

### Nuxtプロジェクトへの追加

::steps{level="4"}

#### Nuxt UIパッケージをインストールする

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

####  `nuxt.config.ts`{lang="ts-type"}にNuxt UIモジュールを追加します。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Nuxt UIが自動的に登録するため、`@nuxt/icon`、`@nuxt/fonts`、`@nuxtjs/color-mode`を`modules`配列に追加する必要はありません。`icon`、`fonts`、`colorMode`キーを使用して、`nuxt.config.ts`でこれらのモジュールを設定することができます。
::

#### Tailwind CSSとNuxt UIをCSSにインポート

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
[Nuxt Layers](https://nuxt.com/docs/getting-started/layers)を使用すると、モジュールは各レイヤーディレクトリに対して[`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive)ディレクティブを自動的に生成します。
::

::callout{icon="i-simple-icons-visualstudiocode"}
VSCode用の[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)拡張機能をインストールし、以下の設定を追加することをお勧めします。

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

####  Appコンポーネントでアプリをラップ

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
`App`コンポーネントはグローバル設定を設定し、**Toast**、**Tooltip**、**promaticオーバーレイ**に必要です。
::

::

## Options

`nuxt.config.ts`でオプションを提供することで、Nuxt UIをカスタマイズできます。

### `prefix`

コンポーネントのプレフィックスを変更するには、`prefix`オプションを使用します。

- デフォルト`U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

`fonts`オプションを使用して、[`@nuxt/fonts`](https://github.com/nuxt/fonts)モジュールを有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### `colorMode`

`colorMode`オプションを使用して、[`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode)モジュールを有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### `theme.colors`

`theme.colors`オプションを使用して、コンポーネントテーマの生成に使用される動的カラーエイリアスを定義します。

- デフォルト`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
各エイリアスは、アプリケーションが使用しているかどうかにかかわらず、色バリアントを持つコンポーネントテーマ内の`--ui-color-*`シェードとバリアントの完全なセットを生成します。リストを実際に使用するエイリアスにトリミングし、フォームを使用する場合は`error`を保持します。バリデーションスタイルは`error`に依存します。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
色のカスタマイズとテーマの詳細については、テーマセクションをご覧ください。
::

### `theme.transitions`

`theme.transitions`オプションを使用して、コンポーネントのトランジションを有効または無効にします。

- デフォルト：`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
このオプションは、ホバーまたはアクティブ状態のコンポーネントに`transition-colors`クラスを追加します。
::

### `theme.unstyled` badge{label="4.9+" class="align-text-top"}

`theme.unstyled`オプションを使用して、コンポーネントからすべてのデフォルトのテーマクラスを削除し、その構造と`class`、`ui`、または`app.config.ui`を通じて提供するクラスのみを保持します。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
これにより**structural**クラス位置決め、トランジション、フレックス/グリッドも削除されます。`Modal`、`Drawer`、`Calendar`のようなレイアウトが重いコンポーネントは、PrimeVueのスタイルなしモードと同様にレイアウトを再供給する必要があります。
::

### `theme.defaultVariants`

`theme.defaultVariants`オプションを使用して、コンポーネントのデフォルトの`color`および`size`バリアントをオーバーライドします。

デフォルトは`primary`または`md`のみ置き換えられるため、Avatarは`color: 'neutral'`を保持し、Separatorは`size: 'xs'`を保持します。

- デフォルト`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix` badge{label="4.2+" class="align-text-top"}

`theme.prefix`オプションを使用して、Tailwind CSSインポートで設定したプレフィックスと同じプレフィックスを設定します。これにより、Nuxt UIコンポーネントが正しいプレフィックス付きユーティリティクラスとCSS変数を使用することが保証されます。

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
`@nuxt/fonts`モジュールでprefixオプションを使用するために`fonts.processCSSVariables`を有効にする必要があるかもしれません。

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

これはNuxt UIコンポーネントテーマのすべてのTailwindユーティリティクラスとCSS変数の前に自動的に表示されます。

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
接頭辞の使用については、Tailwind CSSドキュメントを参照してください。
::

### `prose`

`@nuxtjs/mdc` `@nuxt/content` `@comark/nuxt`がインストールされていなくても、Nuxt UI [`Prose`コンポーネント](/docs/typography)を強制的にインポートするには、`prose`オプションを使用します。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc` badge{label="Deprecated" color="warning" class="align-text-top"}

代わりに[`prose`](#prose)オプションを使用してください。

### `content`

`content`オプションを使用して、`@nuxt/content`がインストールされていない場合でも、Nuxt UI散文およびコンテンツコンポーネントを強制的にインポートします。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection` badge{label="4.1+" class="align-text-top"}

`experimental.componentDetection`オプションを使用して、ツリーシェイクの自動コンポーネント検出を有効にします。この機能はソースコードをスキャンして、実際に使用されているコンポーネントを検出し、それらのコンポーネント（依存関係を含む）に必要なCSSのみを生成します。

- デフォルト`false`{lang="ts-type"}
- タイプ`boolean | string[]`{lang="ts-type"}

**自動検出を有効にする：**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**動的使用のための追加コンポーネントを含める：**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
コンポーネント名の配列を指定する場合、自動検出が有効になり、これらのコンポーネント依存関係が含まれることが保証されます。これは`<component :is="..." />`のように静的に解析できない動的コンポーネントに便利です。
::

## 継続的リリース

Nuxt UIは継続的なプレビューリリースに[pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)を使用し、開発者は公式リリースを待たずに最新の機能やバグ修正に即座にアクセスできます。

`v4`ブランチへのすべてのコミットとPRに対して自動プレビューリリースが作成されます。パッケージバージョンを特定のコミットハッシュまたはPR番号に置き換えて使用してください。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**はインストールURLをPRに自動的にコメントし、変更を簡単にテストできます。
::
