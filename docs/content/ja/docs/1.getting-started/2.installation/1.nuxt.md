## セット アップ

### Nuxt プロジェクト に 追加

::steps{level="4"}

#### Nuxt UI パッケージ を インストール する

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### `nuxt.config.ts`{lang="ts-type"}に Nuxt UI モジュール を 追加 し ます 。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Nuxt UI が 自動的 に 登録 する の で 、`@nuxt/icon``@nuxt/fonts``@nuxtjs/color-mode`を`modules`配列 に 追加 する 必要 は あり ませ ん 。`icon``fonts``colorMode`キー を 使っ て 、`nuxt.config.ts`で これら の モジュール を 設定 する こと が でき ます 。
::

#### Tailwind CSS と Nuxt UI を CSS に インポート

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
[Nuxt Layers](https://nuxt.com/docs/getting-started/layers)を 使用 する と 、 モジュール は 自動的 に[`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive)ディレクティブ を 各 レイヤー ディレクトリ に 生成 し ます 。 これ に より 、 Tailwind CSS は すべて の レイヤー ソース ファイル を スキャン し て ユーティリティ クラス を 検出 し ます 。
::

::callout{icon="i-simple-icons-visualstudiocode"}
VSCode 用 の[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)拡張 子 を インストール し 、 次 の 設定 を 追加 する こと を お 勧め し ます 。

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### App コンポーネント で アプリ を ラップ

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
`App`コンポーネント は グローバル 設定 を 設定 し 、**Toast**、**Tooltip**、 および**programatic overlays**に 必要 です 。
::

::

## オプション

`nuxt.config.ts`に オプション を 指定 する こと で 、 Nuxt UI を カスタマイズ でき ます 。

### `prefix`

コンポーネント の プレフィックス を 変更 する に は 、`prefix`オプション を 使用 し ます 。

- デフォルト`U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

`fonts`オプション を 使用 し て 、[`@nuxt/fonts`](https://github.com/nuxt/fonts)モジュール を 有効 また は 無効 に し ます 。

- デフォルト`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### `colorMode`

`colorMode`オプションを使用して、[`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode)モジュールを有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### `theme.colors`

`theme.colors`オプションを使用して、コンポーネントテーマの生成に使用される動的カラーエイリアスを定義します。

- デフォルト`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
各エイリアスは、アプリケーションが使用しているかどうかにかかわらず、色バリアントを持つコンポーネントテーマ内の`--ui-color-*`シェードとバリアントの完全なセットを生成します。リストを実際に使用するエイリアスにトリミングし、フォームを使用する場合は`error`を保持してください。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
カラーカスタマイズとテーマの詳細については、テーマセクションをご覧ください。
::

### `theme.transitions`

`theme.transitions`オプションを使用して、コンポーネントのトランジションを有効または無効にします。

- デフォルト`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
このオプションは、ホバーまたはアクティブ状態のコンポーネントに`transition-colors`クラスを追加します。
::

### `theme.unstyled` badge {label="4.9+" class="align-text-top"}

`theme.unstyled`オプションを使用して、コンポーネントからすべてのデフォルトのテーマクラスを削除し、その構造と`class`、`ui`、または`app.config.ui`で提供したクラスのみを保持します。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
これは** structural **クラス（ポジショニング、トランジション、フレックス/グリッド）も削除します。`Modal`、`Drawer`、`Calendar`などのレイアウトが重いコンポーネントは、PrimeVueのスタイルなしモードと同様にレイアウトを再供給する必要があります。
::

### `theme.defaultVariants`

コンポーネントのデフォルトの`color`および`size`バリアントを上書きするには、`theme.defaultVariants`オプションを使用します。

デフォルトは`primary`または`md`のみ置き換えられるので、Avatarは`color: 'neutral'`を保持し、Separatorは`size: 'xs'`を保持します。

- デフォルト`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix` badge {label="4.2+" class="align-text-top"}

`theme.prefix`オプションを使用して、Tailwind CSSインポートで設定したのと同じプレフィックスを設定します。これにより、Nuxt UIコンポーネントが正しいプレフィックス付きユーティリティクラスとCSS変数を使用することが保証されます。

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
`@nuxt/fonts`モジュールでprefixオプションを使用するには、`fonts.processCSSVariables`を有効にする必要があるかもしれません。

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

これはNuxt UIコンポーネントテーマのすべてのTailwindユーティリティクラスとCSS変数の前に自動的に表示されます。

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
接頭辞の使用については、Tailwind CSSドキュメントを参照してください。
::

### `prose`

`prose`オプションを使用して、`@nuxtjs/mdc``@nuxt/content``@comark/nuxt`がインストールされていない場合でも、Nuxt UI [`Prose` components ](/docs/typography)を強制的にインポートします。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc` badge {label="Deprecated" color="warning" class="align-text-top"}

代わりに[`prose`](#prose)オプションを使用します。

### `content`

`@nuxt/content`がインストールされていない場合でも、Nuxt UI散文およびコンテンツコンポーネントを強制的にインポートするには、`content`オプションを使用します。

- デフォルト`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection` badge {label="4.1+" class="align-text-top"}

`experimental.componentDetection`オプションを使用して、ツリーシェイクの自動コンポーネント検出を有効にします。この機能は、ソースコードをスキャンして、実際に使用されているコンポーネントを検出し、それらのコンポーネント（依存関係を含む）に必要なCSSのみを生成します。

- デフォルト`false`{lang="ts-type"}
- タイプ`boolean | string[]`{lang="ts-type"}

**自動検出を有効にする：**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**動的使用のための追加コンポーネントを含める**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
コンポーネント 名 の 配列 を 指定 する 場合 、 自動 検出 が 有効 に なり 、 これら の コンポーネント （ および その 依存 関係 ） が 含ま れる こと が 保証 さ れ ます 。 これ は`<component :is="..." />`の よう に 静 的 に 解析 でき ない 動的 コンポーネント に 便利 です 。
::

## 継続 的 リリース

Nuxt UI は[を 使用 し ますpkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)は 継続 的 な プレビュー リリース 用 で 、 開発 者 は 公式 リリース を 待た ず に 最新 の 機能 や バグ 修正 に 即座 に アクセス でき ます 。

自動 プレビュー リリース は 、`v4`ブランチ へ の すべて の コミット と PR に対して 作成 さ れ ます 。 パッケージバージョン を 特定 の コミット ハッシュ また は PR 番号 に 置き換え て 使用 し て ください 。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**は 、 インストール URL とともに PR に 自動的 に コメント し 、 変更 を 簡単 に テスト でき ます 。
::
