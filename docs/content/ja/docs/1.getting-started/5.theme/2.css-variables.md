## 色

Nuxt UIでは、定義した[ semantic color ](/docs/getting-started/theme/design-system#semantic-colors)にTailwind CSSユーティリティクラスが提供されますので、`text-error`や`bg-success`のようなクラス名を使用できます。

::code-preview
[プライマリー]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[セカンダリー]{class="text-secondary text-sm px-4 py-1.5 inline-block"}
[成功]{class="text-success text-sm px-4 py-1.5 inline-block"}
[情報]{class="text-info text-sm px-4 py-1.5 inline-block"}
[警告]{class="text-warning text-sm px-4 py-1.5 inline-block"}
[エラー]{class="text-error text-sm px-4 py-1.5 inline-block"}

#コード
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

各ユーティリティクラスはCSS変数を使用して明暗モードの色を設定します。

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
各ユーティリティクラスがライトモードとダークモードに使用するシェードは、`main.css`ファイルで調整できます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
[** config **](/docs/getting-started/theme/design-system#runtime-configuration)`black`には複数の色合いがないため、`primary: 'black'`を使用することはできません。無地の黒または白を主な色として使用するには、`main.css`ファイルに直接設定します。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

::

## テキスト

Nuxt UIではテキストの色のためのTailwind CSSユーティリティクラスを提供しています。そのため、`text-dimmed`や`text-muted`のようなクラス名を使用できます。

::code-preview
[調光]{class="text-dimmed text-sm px-4 py-1.5 inline-block rounded-md"}
[ミュート]{class="text-muted text-sm px-4 py-1.5 inline-block rounded-md"}
[トーン]{class="text-toned text-sm px-4 py-1.5 inline-block rounded-md"}
[本文]{class="text-default text-sm px-4 py-1.5 inline-block rounded-md"}
[ハイライト]{class="text-highlighted text-sm px-4 py-1.5 inline-block rounded-md"}
[反転]{class="text-inverted bg-inverted text-sm px-4 py-1.5 inline-block rounded-md"}

#コード
```vue
<template>
  <span class="text-dimmed">Dimmed</span>
  <span class="text-muted">Muted</span>
  <span class="text-toned">Toned</span>
  <span class="text-default">Text</span>
  <span class="text-highlighted">Highlighted</span>
  <span class="text-inverted bg-inverted">Inverted</span>
</template>
```
::

各ユーティリティクラスはCSS変数を使用して明暗モードの色を設定します。

::code-group

```css [Light]
:root {
  --ui-text-dimmed: var(--ui-color-neutral-400);
  --ui-text-muted: var(--ui-color-neutral-500);
  --ui-text-toned: var(--ui-color-neutral-600);
  --ui-text: var(--ui-color-neutral-700);
  --ui-text-highlighted: var(--ui-color-neutral-900);
  --ui-text-inverted: white;
}
```

```css [Dark]
.dark {
  --ui-text-dimmed: var(--ui-color-neutral-500);
  --ui-text-muted: var(--ui-color-neutral-400);
  --ui-text-toned: var(--ui-color-neutral-300);
  --ui-text: var(--ui-color-neutral-200);
  --ui-text-highlighted: white;
  --ui-text-inverted: var(--ui-color-neutral-900);
}
```

::

::tip
これらのCSS変数は`main.css`ファイルでカスタマイズできます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-text: var(--ui-color-neutral-900);
}

.dark {
  --ui-text: white;
}
```

これらの変数の複数を一度に変更するには、[](/docs/getting-started/theme/design-system#runtime-configuration)に別の色を割り当てます。
::

## フォーカス：バッジ{label="4.9+" class="align-text-top"}

Nuxt UIは、すべてのインタラクティブ要素に`focus-visible`アウトラインを適用し、コンポーネントの`color` propで色付けします。例えば、`color="primary"`の場合、`color="neutral"`の場合、`outline-inverted/25`の場合などです。

コンポーネントの色に関係なく、アプリケーション全体で単一のアウトライン色を使用する場合は、`main.css`ファイルにグローバルルールを追加できます。

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

1つ目のルールは、各コンポーネントのフォーカスアウトラインを着色し、2つ目のルールは、`outline`や`subtle`のような目に見える境界線を持つバリアントによってフォーカスに適用されるリングの色を整列させます。

::note
これらのルールは、コンポーネントテーマによって設定された色よりも優先されるように、`@layer`の外で宣言してください。最初のルールは、独自の要素のネイティブフォーカスアウトラインも色付けすることに注意してください。[ FileUpload ](/docs/components/file-upload)または[ ContentSurround ](/docs/components/content-surround)のようにフォーカスして`border`](/docs/components/file-uploadコンポーネント`color`に従ってください。
::

##  Radius

Nuxt UIはTailwind CSSのデフォルトの`rounded-*`ユーティリティを統一された境界半径システムでオーバーライドします。そのため、通常の[ border半径ユーティリティ](https://tailwindcss.com/docs/border-radius)`rounded-xs`や`rounded-2xl`のように使用できます。

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xs"}
[sm]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-sm"}
[md]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-md"}
[lg]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-lg"}
[xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xl"}
[2xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-2xl"}
[3xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-3xl"}

#コード
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

これらのユーティリティクラスは、一貫した外観のためにすべてのコンポーネントに適用される基本半径値を定義するグローバルCSS変数`--ui-radius`に基づいて計算されます。

```css
:root {
  --ui-radius: 0.25rem;
}
```

各ユーティリティはこの基本値を掛けます：

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
`main.css`ファイルでベース半径の値をカスタマイズできます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
`--ui-radius`を変更すると、Nuxt UIコンポーネントだけでなく、独自のマークアップやサードパーティコンポーネントの`rounded-xs`から`rounded-3xl`クラスにも影響します。
::

::note
上のヘッダーにある：prose—icon {name="i-lucide-palette" class="text-primary"}テーマメニューを試して、ベース半径の値を変更してください。
::

## コンテナ

Nuxt UIは[ Container ](/docs/components/container)コンポーネントの最大幅を制御するCSS変数`--ui-container`を提供します。

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
`main.css`ファイルでこの値をカスタマイズして、アプリケーション全体で一貫してコンテナ幅を調整できます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

## ヘッダー

Nuxt UIは[ Header ](/docs/components/header)コンポーネントの高さを制御するCSS変数`--ui-header-height`を提供します。

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
`main.css`でこの値をカスタマイズして、アプリケーション全体で一貫してヘッダーの高さを調整できます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
::

## ボディ

Nuxt UIは、ライトモードとダークモードで一貫したテーマ設定を行うために、アプリの`<body>`{lang="html"}要素にデフォルトクラスを適用します。

```css
body {
  @apply antialiased text-default bg-default scheme-light dark:scheme-dark;
}
```
