## Tailwindバリアント

Nuxt UIコンポーネントは[Tailwind Variants](https://www.tailwind-variants.org/) APIを使用してスタイリングされます。

### スロット

コンポーネントは複数の`slots`を持つことができ、それぞれがコンポーネント内の個別のHTML要素またはセクションを表します。これらのスロットは柔軟なコンテンツの挿入とスタイルを可能にします。

複数のスロットを持つ例として[Card](/docs/components/card)コンポーネントを見てみましょう：

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
上記のスニペットは要約されています。実際のコンポーネントも各スロットに`v-if`ガードを搭載し、テーマはスロットの上に`variant`スタイルを定義します。
::

一部のコンポーネントはスロットを持たず、単一のルート要素で構成されています。この場合、テーマは[Container](/docs/components/container)コンポーネントのように`base`スロットのみを定義します。

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
スロットを持たないコンポーネントは[`ui` prop](#ui-prop)を持ちます。これはスロットごとに1つのキーではなく、1つの`base`キーを公開します。[Link](/docs/components/link)と[Icon](/docs/components/icon)は例外です`ui`プロパティを持たないので、[`class` prop](]()を使用してスタイルをオーバーライドします。
::

### バリアント

コンポーネントは、コンポーネントのプロップに基づいて異なる`slots`のスタイルを動的に調整する`variants`をサポートします。

例えば、[Avatar](/docs/components/avatar)コンポーネントは`size`バリアントを使用して外観を制御します。

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

このようにして、`size`プロパティは対応するスタイルを`root`スロットに適用します：

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/nuxt.png'
  size: lg
---
::

### デフォルトバリアント

`defaultVariants`プロパティは、プロパティが渡されない場合の各バリアントのデフォルト値を設定します。

例えば、[Avatar](/docs/components/avatar)コンポーネントのデフォルトサイズは`md`に設定されています。

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
`nuxt.config.ts`の`theme.defaultVariants`オプションを使用すると、`md`と`primary`を使用するすべてのコンポーネントのデフォルトの`size`と`color`をオーバーライドできます。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
`vite.config.ts`の`theme.defaultVariants`オプションを使用すると、`md`と`primary`を使用するすべてのコンポーネントのデフォルトの`size`と`color`をオーバーライドできます。
:::
::

###  Compoundバリアント

一部のコンポーネントは`compoundVariants`プロパティを使用して、複数のバリアント条件が同時に満たされた場合にクラスを適用します。

たとえば、[Button](/docs/components/button)コンポーネントは`compoundVariants`プロパティを使用して、特定の`color`と`variant`の組み合わせにクラスを適用します。

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## カスタマイズテーマ

Nuxt UIコンポーネントの外観をカスタマイズするには複数の方法があり、すべてのコンポーネントに対して一度に、またはコンポーネントごとにカスタマイズすることができます。

::note
Tailwind Variantsはクラスをマージするために[`tailwind-merge`](https://github.com/dcastil/tailwind-merge)を内部で使用するため、競合するクラスを心配する必要はありません。
::

::tip
各コンポーネントのテーマは、2つの方法で調べることができます。

- 各コンポーネントのドキュメントの`Theme`セクションを確認してください。
-  GitHubリポジトリの[`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme)でソースコードを直接参照してください。
::

### Global設定

::framework-only
#nuxt
テーマオブジェクトとまったく同じ構造を使用することで、`app.config.ts`内のコンポーネントのテーマをグローバルにオーバーライドすることができます。
#vue
テーマオブジェクトとまったく同じ構造を使用することで、`vite.config.ts`内のコンポーネントのテーマをグローバルにオーバーライドすることができます。
::

コンポーネントの[`slots`](#slots)、[`variants`](#variants)、[`compoundVariants`](#compound-variants)、xph2444x`defaultVariants`](#default-variants)をカスタマイズして、コンポーネントのデフォルトテーマを変更できます。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
この例では、`font-bold`はすべてのボタンで`font-medium`をオーバーライドします。`size="md"`と`ring-default hover:bg-accented`が`color="neutral"`と`variant="outline"`をオーバーライドすると、`size-4`は先頭のアイコンの`size-5`クラスをオーバーライドします。ボタンのデフォルトは`color="neutral"`と`variant="outline"`です。
::

デフォルトでは、これらのクラスはコンポーネントのデフォルトにマージされます。代わりにそれらを置き換える関数にスロットを設定することもできます。スロットはスロットのデフォルトクラスを引数として受け取るので、その一部を再利用できます。`variants`と`compoundVariants`のクラスは文字列を渡すときとまったく同じように、上に適用されます。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt
:::warning
関数にスロットを1箇所だけに設定します。Nuxtは[layer](https://nuxt.com/docs/getting-started/layers)の`app.config.ts`を`defuFn`とマージします。`defuFn`は、キーが既に持っている値を使って関数を呼び出し、結果のみを保持します。Nuxt UIはプレーン文字列を読み込むので、クラスはそれらを置き換えるのではなく、デフォルトにマージされます。
:::
::

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
すべてのコンポーネントからデフォルトのクラスを一度に削除するには、`nuxt.config.ts`の`theme.unstyled`オプションを使用します。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
すべてのコンポーネントからデフォルトのクラスを一度に削除するには、`vite.config.ts`の`theme.unstyled`オプションを使用します。
:::
::

### Themeコンポーネント

[Theme](/docs/components/theme)コンポーネントは、アプリの残りの部分に影響を与えることなく、すべての子孫のスロットとプロパティのデフォルトをオーバーライドします。これはグローバル設定よりも優先されます。しかし、`ui`と`class`のプロップはまだそれに勝っています。スロットはマージの代わりにクラスを置き換えるために同じ関数形式を受け入れます。[`ui`と同じ時点で解決されます。prop](#ui-prop)なので同じように振る舞います

### `ui`プロップ

`ui` propを使用してコンポーネントの**slots**をオーバーライドすることもできます。これはグローバル設定と解決済みの`variants`の両方よりも優先されます。

::component-code{slug="button"}
---
prettier: true
ignore:
  - ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  trailingIcon: i-lucide-chevron-right
  size: md
  color: neutral
  variant: outline
  ui:
    trailingIcon: 'rotate-90 size-3'
slots:
  default: |

    Button
---
::

::note
この例では、`md`サイズバリアントが`size-5`クラスを適用するにもかかわらず、`trailingIcon`スロットは`size-3`で上書きされます。
::

スロット値はクラスをマージする代わりに置き換える関数でもあります：

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
`ui`プロパティは`variants`の後で解決されます。そのため、グローバル設定とは異なり、ここでは関数がスロットの**resolved**クラスを置き換えます。その引数には`variants`と`compoundVariants`がマッチしたものが含まれます。同じスロットの`class`プロパティは、返されたクラスの上にマージされます。
::

### `class`プロップ

`class`プロパティを使用して、`root`または`base`スロットのクラスをオーバーライドします。これはグローバル設定と解決済みの`variants`の両方より優先されます。

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
この例では、`font-bold`クラスはこのボタンのデフォルトの`font-medium`クラスをオーバーライドします。
::
