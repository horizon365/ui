##  Tailwindバリアント

Nuxt UIコンポーネントは[ Tailwind Variants ](https://www.tailwind-variants.org/) APIを使用してスタイリングされます。これはバリアントを作成し、コンポーネントスタイルを管理する強力な方法を提供します。

### スロット

コンポーネントは複数の`slots`を持つことができ、それぞれがコンポーネント内の個別のHTML要素またはセクションを表します。これらのスロットにより、柔軟なコンテンツの挿入とスタイリングが可能です。

[ Card ](/docs/components/card)コンポーネントを複数のスロットを持つ例として見てみましょう。

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
上記のスニペットは要約されています。実際のコンポーネントはまた、各スロットに`v-if`ガードを持ち、テーマはスロットの上に`variant`スタイルを定義します。
::

一部のコンポーネントはスロットを持たず、単一のルート要素で構成されています。この場合、テーマは[ Container ](/docs/components/container)コンポーネントのように`base`スロットのみを定義します。

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
スロットを持たないコンポーネントは、[`ui` prop ](#ui-prop)を持ちます。スロットごとに1つのキーではなく、1つの`base`](/docs/components/link)[ Icon ](/docs/components/icon/docs/components/icon)例外です`ui` propがないので、[`class` prop ](#class-prop)を使用してスタイルを上書きします。
::

### バリアント

コンポーネントは`variants`をサポートしており、コンポーネントのプロップに基づいて異なる`slots`のスタイルを動的に調整します。

たとえば、[ Avatar ](/docs/components/avatar)コンポーネントは、`size`バリアントを使用して外観を制御します。

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

このようにして、`size` propは対応するスタイルを`root`スロットに適用します。

### デフォルトバリアント

`defaultVariants`プロパティは、プロパティが渡されなかった場合の各バリアントのデフォルト値を設定します。

たとえば、[ Avatar ](/docs/components/avatar)コンポーネントのデフォルトサイズは`md`に設定されています。

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
`nuxt.config.ts`の`theme.defaultVariants`オプションを使用すると、`md`と`primary`を使用するすべてのコンポーネントのデフォルトの`size`と`color`を上書きできます。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
`vite.config.ts`内の`theme.defaultVariants`オプションを使用すると、`md`と`primary`を使用するすべてのコンポーネントのデフォルトの`size`と`color`を上書きできます。
:::
::

### 複合バリアント

一部のコンポーネントでは、複数のバリアント条件が同時に満たされた場合にクラスを適用するために`compoundVariants`プロパティを使用します。

たとえば、[ Button ](/docs/components/button)コンポーネントは、`compoundVariants`プロパティを使用して、特定の`color`と`variant`の組み合わせにクラスを適用します。

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## カスタマイズテーマ

Nuxt UIコンポーネントの外観をカスタマイズするには複数の方法があり、すべてのコンポーネントに対して一度に、またはコンポーネントごとにカスタマイズすることができます。

::note
Tailwind Variantsは[`tailwind-merge`](https://github.com/dcastil/tailwind-merge)を使用してクラスをマージするので、競合するクラスを心配する必要はありません。
::

::tip
各コンポーネントのテーマは、2つの方法で調べることができます。

- 各コンポーネントのドキュメントの`Theme`セクションを確認してください。
- [`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme)でソースコードを参照してください。
::

### グローバル設定

::framework-only
#nuxt
`app.config.ts`内のコンポーネントのテーマは、テーマオブジェクトとまったく同じ構造を使用してオーバーライドできます。
#vue
`vite.config.ts`内のコンポーネントのテーマは、テーマオブジェクトとまったく同じ構造を使用してオーバーライドできます。
::

[`slots`](#slots)、[`variants`](#variants)、コンポーネントの`compoundVariants`](#compound-variants)[`defaultVariants`](#default-variants)を使用して、コンポーネントのデフォルトテーマを変更します。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
この例では、`font-bold`はすべてのボタンで`font-medium`を上書きします。`size="md"`と`ring-default hover:bg-accented`が`ring-accented hover:bg-elevated`を上書きした場合、`size-4`は先頭のアイコンの`size-5`クラスを上書きします。ボタンのデフォルトは`color="neutral"`と`variant="outline"`になります。
::

デフォルトでは、これらのクラスはコンポーネントのデフォルトにマージされます。代わりにそれらを置き換える関数にスロットを設定することもできます。スロットはスロットのデフォルトクラスを引数として受け取るので、それらの一部を再利用できます。`variants`と`compoundVariants`のクラスは文字列を渡すときとまったく同じように上に適用されます。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt
:::warning
関数にスロットを1箇所だけに設定します。Nuxtはすべての[ layer ](https://nuxt.com/docs/getting-started/layers)を`defuFn`とマージします。この関数は、キーがすでに下に持っている値を使って関数を呼び出し、結果のみを保持します。Nuxt UIはプレーン文字列を読み込むので、クラスを置き換えるのではなく、デフォルトにマージします。
:::
::

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
すべてのコンポーネントからデフォルトクラスを一度に削除するには、`nuxt.config.ts`の`theme.unstyled`オプションを使用します。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
すべてのコンポーネントからデフォルトクラスを一度に削除するには、`vite.config.ts`の`theme.unstyled`オプションを使用します。
:::
::

### テーマコンポーネント

[ Theme ](/docs/components/theme)コンポーネントは、アプリの残りの部分に影響を与えることなく、すべての子孫のスロットとプロップのデフォルトをオーバーライドします。これはグローバル設定よりも優先されます。`ui`と`class`propsはまだそれに勝ちます。スロットはマージの代わりにクラスを置き換えるために同じ関数形式を受け入れます。これは[`ui` prop @と同じ時点で解決されます。](#ui-prop)なので、同じように動作します。

名前'theme—ui—example'
---
::

### `ui` prop

また、`ui` propを使用して、コンポーネントの** slots **をオーバーライドすることもできます。これは、グローバル設定とresolved `variants`の両方より優先されます。

::component-code{slug="button"}
---
きれい真
無視
  -  ui.trailingIcon
  - カラー
  - バリアント
  - サイズ
  - アイコン
小道具
  trailingIcon i—lucide—chevron—right
  サイズMD
  色ニュートラル
  variantアウトライン
  UI
    trailingIcon 'rotate—90サイズ—3'
スロット
  デフォルト|

    ボタン
---
::

::note
この例では、`md`サイズバリアントが`size-5`クラスを適用するにもかかわらず、`trailingIcon`スロットは`size-3`で上書きされます。
::

スロット値はクラスをマージする代わりに置き換える関数でもあります：

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
`ui` propは`variants`の後で解決されるので、グローバルコンフィグとは異なり、ここでは関数がスロットの** resolved **クラスを置き換えます。その引数には`variants`と`compoundVariants`がマッチしたものが含まれます。同じスロットの`class` propは、返されたクラスの上にマージされます。
::

### `class` prop

`class` propを使用して、`root`または`base`スロットのクラスをオーバーライドします。これは、グローバル設定と解決済み`variants`の両方より優先されます。

::component-code{slug="button"}
---
小道具
  クラス'font—bold rounded—full'
スロット
  デフォルトボタン
---
::

::note
この例では、`font-bold`クラスは、このボタンのデフォルトの`font-medium`クラスを上書きします。
::
