##  Tailwind CSS

Tailwind CSSはCSSファーストの設定を使用しており、[`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive)

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
利用可能なテーマ変数のカスタマイズオプションについては、Tailwind CSSドキュメントを参照してください。
::

::tip
Tailwind CSS v4は[ Preflight ](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor)を変更し、ブラウザのデフォルトに合わせてボタンが`cursor: pointer`の代わりに`cursor: default`を使用するようにしました。カーソルポインタをグローバルに復元したい場合は、以下の基本スタイルをCSSに追加します。

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### フォント

`--font-*`テーマ変数を使用して、[](https://tailwindcss.com/docs/font-family#customizing-your-theme)をプロジェクトでカスタマイズします。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

::framework-only
#nuxt
:::note{to="/docs/getting-started/integrations/fonts"}
ここで定義されたフォントは`@nuxt/fonts`モジュールによって自動的にロードされ最適化されます。
:::
::

### 色

`--color-*`テーマ変数を使用して、[](https://tailwindcss.com/docs/colors#customizing-your-colors)または[](https://tailwindcss.com/docs/colors#overriding-default-colors)を上書きします。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme static {
  /* Override default green color */
  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;

  /* Define new custom color */
  --color-brand-50: #fef2f2;
  --color-brand-100: #fee2e2;
  --color-brand-200: #fecaca;
  --color-brand-300: #fca5a5;
  --color-brand-400: #f87171;
  --color-brand-500: #ef4444;
  --color-brand-600: #dc2626;
  --color-brand-700: #b91c1c;
  --color-brand-800: #991b1b;
  --color-brand-900: #7f1d1d;
  --color-brand-950: #450a0a;
}
```

::warning
カスタムカラーを追加する場合は、色ごとに`50`から`950`までのすべての色合いを定義してください。
::

### ブレークポイント

`--breakpoint-*`テーマ変数を使用して、[ブレークポイントをカスタマイズします。](https://tailwindcss.com/docs/responsive-design#customizing-your-theme)。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

### モーション

`--ease-*`テーマ変数を使用して、[](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme)をカスタマイズします。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

アニメーションの入力と終了は`--ease-out`で実行され、アニメーションの読み込みは`--ease-in-out`で実行されます。

::note
`prefers-reduced-motion`を設定すると、オーバーレイはスケーリングやスライドの代わりにフェードアウトされ、移動遷移は無効になります。
::

## カラーシステム

Nuxt UIのカラーシステムは、特定のカラー値ではなく** semantic naming **を中心に設計されています。このアプローチにより、UIのメンテナンス性が向上し、テーマの切り替えが容易になります。

### セマンティックカラー

Nuxt UIは、色の** purpose **を記述するセマンティックカラーエイリアスを提供します。各エイリアスは、`@theme`設定の色に基づいて定義されます。これは、[デフォルトのTailwind CSS palette https://tailwindcss.com/docs/colors)に加えて、定義した任意の色です。

| 色|デフォルト|説明|
| --- | --- | --- |
| `primary`{color="primary"}| `green`|主なCTA、アクティブナビゲーション、ブランド要素、重要なリンク|
| `secondary`{color="secondary"}| `blue`|セカンダリボタン、代替アクション、補完的なUI要素|
| `success`{color="success"}| `green`|成功メッセージ、完了状態、肯定的な確認|
| `info`{color="info"}|`blue`|情報アラート、ツールチップ、ヘルプテキスト、中立通知|
| `warning`{color="warning"}| `yellow`|警告メッセージ、保留中の状態、注意が必要な項目|
| `error`{color="error"}| `red`|エラーメッセージ、検証エラー、破壊的なアクション|
| `neutral`| `slate`|テキスト、ボーダー、背景、無効状態|

これらのセマンティックカラーは、Nuxt UIコンポーネントの`color` propで使用できます。

::component-code{slug="button"}
---
小道具
  色プライマリ
スロット
  default変更を保存
---
::

::note
ヘッダーのprose—icon {name="i-lucide-palette" class="text-primary"}テーマメニューを試してみて、異なる配色がUI全体にどのように影響するかを即座に確認してください。または、[ theme editor ](/theme)を開いて、すべてを一度にカスタマイズしてください！
::

### ランタイム設定

::framework-only
#nuxt
:::div
実行時に[`app.config.ts`](https://nuxt.com/docs/4.x/directory-structure/app/app-config)ファイルの`ui.colors`で設定でき、サーバーを再起動せずに動的なテーマのカスタマイズを可能にします。

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#vue
:::div
これらの色は、実行時に`vite.config.ts`ファイルの`ui.colors`キーで設定でき、動的なテーマのカスタマイズが可能です。

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
テーマに存在する色のみを使用できます。どちらか：
- [ Tailwindのデフォルト色](https://tailwindcss.com/docs/colors)`blue`、`green`、`zinc`などを使用します。
- `@theme`ディレクティブを使用してカスタムカラーを定義します（上の例の`brand`のように）
::

### 色を拡張

`tertiary`色を追加するなど、デフォルト以外のセマンティックカラーを定義することもできます。

::framework-only
#nuxt
:::div
まず、`nuxt.config.ts`に新しい色を`ui.theme.colors`キーの下に登録します。

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

次に、`app.config.ts`に`ui.colors`キーを割り当てます。

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#vue
:::div
`vite.config.ts`ファイルに新しい色を登録して割り当てます。

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

最後に、この新しい色を`color` propまたは[をクラス](/docs/getting-started/theme/css-variables)としてサポートするコンポーネントで使用します。

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
