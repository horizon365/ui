##  Nuxt UIとは何ですか？

[ Reka UI ](https://reka-ui.com/)[ Tailwind CSS ](https://tailwindcss.com/)で構築された最新のVue UIコンポーネントライブラリそして[ Tailwind Variants ](https://www.tailwind-variants.org/) 125+生産で美しくアクセスしやすいアプリケーションを出荷します—準備ができています。NuxtおよびプレーンVueアプリケーション（Vite、Inertia、SSR）で動作します。

Tailwind CSSでVueプロジェクトを構築している場合、Nuxt UIは素晴らしいデフォルトの選択肢です。高レベルですぐに使用できるコンポーネント（データテーブル、フォーム、オーバーレイ、ナビゲーション）を提供しながら、必要に応じて高度なカスタマイズを可能にします。

##  v4の新機能

Nuxt UI v 4は大きなマイルストーンとなりました。Nuxt UIとNuxt UI Proは、125以上の量産対応コンポーネントと完全なFigma Kitからなる単一の完全なオープンソースの無料ライブラリに統合されました。

## コア技術

Nuxt UIは、振る舞いとアクセシビリティのためのReka UI、スタイリングのためのTailwind CSS、バリアントを構成するためのTailwind Variantsの3つの基盤で構築されています。

###  Reka UI

Nuxt UIは[ Reka UI ](https://reka-ui.com/)の上に構築されています。

- ** WAI—ARIA準拠**：以下のとおり[ WAI—ARIAオーサリングプラクティス](https://reka-ui.com/docs/overview/accessibility)
- ** Keyboard Navigation **：タブやダイアログなどの複雑なコンポーネントの内蔵キーボードサポート
- ** Focus Management **：ユーザーのインタラクションに基づいてフォーカスを移動するインテリジェントなフォーカス処理
- ** Accessible Labels **スクリーンリーダーのラベリング制御を簡素化するための抽象化

###  Tailwind CSS

Nuxt UIは最新の[ Tailwind CSS ](https://tailwindcss.com/)を統合し、大幅な改善をもたらしました。

- ** 5x Faster Builds **：フルビルドは最大5倍、インクリメンタルビルドは100倍以上高速
- ** Unified Toolchain **：組み込みインポート処理、ベンダープレフィックス、構文変換
- ** CSSファースト設定**：JavaScriptの代わりにCSSで直接カスタマイズして拡張する
- ** Modern Web Features **：コンテナクエリ、カスケードレイヤー、広色域色など

###  Tailwindバリアント

Nuxt UIは[ Tailwind Variants ](https://www.tailwind-variants.org/)を利用して、強力なデザインシステムを提供します。

- **動的スタイリング**：強力なAPIを備えた柔軟なコンポーネントバリアント
- ** Type Safety **：自動補完を備えた完全なTypeScriptサポート
- ** Conflict Resolution **：競合するスタイルの効率的なマージ

###  Vue互換性（Nuxtオプション）

Nuxt UIはNuxtだけでなく、あらゆるVueプロジェクトで動作します。ViteとVueプラグインを設定に追加するだけです。

- ** Auto—imports **：コンポーネントとコンポジットが自動的にインポートされ、グローバルに利用可能になります。
- **デザインシステム**：カスタマイズ可能な色、サイズ、バリエーションなどの完全なテーマサポート
- ** Developer Experience ** IntelliSenseと自動補完による完全なTypeScriptサポート

::tip{to="/docs/getting-started/installation/vue" aria-label="Vueインストールガイド"}
VueプロジェクトにNuxt UIをインストールして設定する方法については、** Vueインストールガイド**を参照してください。
::

##  FAQ

::accordion

:::accordion-item{label="Nuxt UIは無料で使えますか？"}
はい！Nuxt UIはMITライセンスのもと完全にフリーでオープンソースです。125以上のコンポーネントはすべて誰でも利用できます。
:::

:::accordion-item{label="NuxtなしでVueでNuxt UIを使用できますか？"}
はい！Nuxt用に最適化されていますが、Nuxt UIはViteプラグインを介してスタンドアロンのVueプロジェクトと完全に連携します。[インストールガイド](/docs/getting-started/installation/vue)に従って開始してください。
:::

:::accordion-item{label="Nuxt UIにはFigma Kitが含まれますか？"}
はい！Nuxt UIには[ complete Figma Kit ](https://go.nuxt.com/figma-ui)が含まれており、デザイナーと開発者が簡単にコラボレーションできます。
:::

:::accordion-item{label="Nuxt UIはアクセシビリティをどう扱うか？"}
[ Reka UI ](https://reka-ui.com/docs/overview/accessibility)統合により、Nuxt UIは自動ARIA属性、キーボードナビゲーション、フォーカス管理、スクリーンリーダーのサポートを提供します。強力な基盤を提供しながらも、特定のユースケースでのテストは重要です。
:::

:::accordion-item{label="Nuxt UIはプロダクション対応ですか？"}
はい！Nuxt UIは、1000以上のVitestテスト、定期的なアップデート、アクティブなメンテナンスにより、何千ものアプリケーションで運用されています。
:::

:::accordion-item{label="いつ代替案を検討すべきか？"}
Material Designのスタイリングが必要な場合は** Vuetify **、Ant Designのスタイリングが必要な場合は** ant—design—vue **、Tailwind CSSが必要ない場合は** PrimeVue **または** Element Plus **、リポジトリにコンポーネントをコピーしたい場合は** cnshad—vue **を検討してください。** Quasar **クロスプラットフォームアプリ（ウェブ、モバイル、デスクトップ）、または** Reka UI **/**ヘッドレスUI **
:::
