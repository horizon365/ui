##  Nuxt UIとは？

[Reka UI](https://reka-ui.com/)、[Tailwind CSS](https://tailwindcss.com/)、[Tailwind Variants](https://www.tailwind-variants.org/)上に構築された最新のVue UIコンポーネントライブラリで、125以上のプロダクション対応コンポーネントを備えた美しくアクセスしやすいアプリケーションを提供します。NuxtおよびプレーンなVueアプリケーション（Vite、Inertia、SSR）で動作します。

Tailwind CSSでVueプロジェクトを構築している場合、Nuxt UIは素晴らしいデフォルトの選択肢です。高レベルですぐに使用できるコンポーネント（データテーブル、フォーム、オーバーレイ、ナビゲーション）を提供しながら、必要に応じて高度なカスタマイズを可能にします。

##  v 4の新機能は？

Nuxt UI v 4は大きなマイルストーンとなりました。Nuxt UIとNuxt UI Proは、125以上の量産対応コンポーネントと完全なFigma Kitからなる単一の完全なオープンソースの無料ライブラリに統合されました。

v3からv4への移行はv2からv3への移行よりもはるかにスムーズです。詳細は[migrationガイド](/docs/getting-started/migration)をご覧ください。

## コア技術

Nuxt UIは、振る舞いとアクセシビリティのためのReka UI、スタイリングのためのTailwind CSS、バリアントを構成するためのTailwind Variantsの3つの基盤で構築されています。

### Reka UI

Nuxt UIはコンポーネントの基盤として[Reka UI](https://reka-ui.com/)の上に構築されています。

- **WAI—ARIA Compliance** [WAI—ARIAオーサリングプラクティスに従います](https://reka-ui.com/docs/overview/accessibility)に適切なセマンティクスとロールを使用
- **キーボードナビゲーション**：タブやダイアログなどの複雑なコンポーネントを内蔵キーボードサポート
- **Focus Management**ユーザーの操作に基づいてフォーカスを移動するインテリジェントなフォーカス処理
- **アクセシブルなラベル**：スクリーンリーダーのラベル制御を簡素化する抽象化

### Tailwind CSS

Nuxt UIは最新の[Tailwind CSS](https://tailwindcss.com/)を統合し、大幅な改善をもたらしました。

- **5x高速ビルド**：フルビルドは最大5倍、インクリメンタルビルドは100倍以上高速
- **Unified Toolchain**組み込みのインポート処理、ベンダープレフィックス、構文変換
- **CSSファーストの設定** JavaScriptの代わりにCSSで直接カスタマイズして拡張する
- **モダンウェブ機能**：コンテナクエリ、カスケードレイヤー、広域色など

### Tailwindバリアント

Nuxt UIは[Tailwind Variants](https://www.tailwind-variants.org/)を利用して、強力なデザインシステムを提供します。

- ** Dynamic Styling**：強力なAPIを備えた柔軟なコンポーネントバリアント
- **Type Safety**完全なTypeScriptサポートと自動補完
- **競合解決**競合するスタイルの効率的なマージ

### Vue互換性Nuxtオプション

Nuxt UIはNuxtだけでなく、あらゆるVueプロジェクトで動作します。ViteとVueプラグインを設定に追加するだけです。

- **Auto—imports**コンポーネントとコンポジブルが自動的にインポートされ、グローバルに利用可能になります
- ** Design System**：カスタマイズ可能な色、サイズ、バリエーションなどによる完全なテーマサポート
- ** Developer Experience**：IntelliSenseと自動補完による完全なTypeScriptサポート

::tip{to="/docs/getting-started/installation/vue" aria-label="Vue導入ガイド"}
VueプロジェクトにNuxt UIをインストールして設定する方法は、**Vueインストールガイド**を参照してください。
::

### TypeScriptのサポート

Nuxt UIは、優れた開発者エクスペリエンスのための包括的なTypeScript統合を提供する。

- **自動補完**すべてのコンポーネントプロップ、スロット、イベント
- **Generic Components** [Vue Generics](https://vuejs.org/api/sfc-script-setup.html#generics)の使用
- **タイプセーフテーマ** In `app.config.ts`
- **IntelliSense**：コードベース全体

## FAQ

::accordion

:::accordion-item{label="Nuxt UIは無料で使えますか？"}
はい！Nuxt UIはMITライセンスのもと、完全にフリーでオープンソースです。125以上のコンポーネントはすべて誰でも利用できます。
:::

:::accordion-item{label="NuxtなしでVueでNuxt UIを使用できますか？"}
はい！Nuxt用に最適化されていますが、Nuxt UIはViteプラグインを介してスタンドアロンのVueプロジェクトと完全に連携します。[installation guide](/docs/getting-started/installation/vue)に従って開始できます。
:::

:::accordion-item{label="Nuxt UIにはFigma Kitが含まれますか？"}
はい！Nuxt UIには[ complete Figma Kit](https://go.nuxt.com/figma-ui)が含まれており、デザイナーと開発者が簡単にコラボレーションできます。
:::

:::accordion-item{label="Nuxt UIはアクセシビリティをどう扱うか？"}
[Reka UI](https://reka-ui.com/docs/overview/accessibility)との統合により、Nuxt UIは自動ARIA属性、キーボードナビゲーション、フォーカス管理、スクリーンリーダーのサポートを提供します。強固な基盤を提供しながらも、特定のユースケースでのテストは重要です。
:::

:::accordion-item{label="Nuxt UIはプロダクション対応ですか？"}
はい！Nuxt UIは、1000以上のVitestテスト、定期的なアップデート、アクティブなメンテナンスにより、何千ものアプリケーションで運用されています。
:::

:::accordion-item{label="いつ代替案を検討すべきか？"}
Material Designのスタイリングが必要な場合は**Vuetify**、Ant Designのスタイリングが必要な場合は**ant—design—vue**、Tailwind CSSが不要な場合は**PrimeVue**または**Element Plus**、リポジトリにコンポーネントをコピーしたい場合は**shadcn—vue**、クロスプラットフォームアプリの場合は**Quasar**をご検討ください。web、モバイル、デスクトップ
