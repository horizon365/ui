## スキル と は ？

スキル は 、 AI コーディング エージェント に ライブラリ 、 フレームワーク 、 または コードベース に関する コンテキスト を 与える 構造 化 さ れ た 知識 ファイル です 。 リアルタイム の ツール アクセス を 提供 する MCP サーバー と は 異なり 、 スキル は エージェント の コンテキスト に 直接 ロード さ れる ため 、 会話 中 に それら を 参照 でき ます 。

Nuxt UI は**usage skill**を 提供 し 、 Nuxt UI を 使っ て UI を 構築 する 方法 を AI エージェント に 教える 。

## 使用 法

使用 スキル により 、 AI エージェント は Nuxt UI v4 を 使用 し た ビルド に関する 包括 的 な 知識 を 得る こと が でき ます 。

- Nuxt 、 Vue 、 Laravel 、 AdonisJS へ の インストール
- セマンティック カラー と CSS 変数 による テーマ と ブランディング
- すべて の 125 以上 の コンポーネント と 小道具 と 使用 パターン
- Composables`useToast``useOverlay``defineShortcuts`
- 標準 スキーマ による フォーム 検証
- レイアウト 作成 （ ダッシュ ボード 、 ドキュメント 、 チャット 、 エディタ ）
- 公式 スターター テンプレート

この スキル に は 、 AI エージェント が タスク に 基づい て オンデ マンド で ロード する 追加 の 参照 が 含ま れ 、 応答 に 焦点 を 当て 、 コンテキスト 効率 を 維持 し ます 。

::note
インストール が 完了 し たら 、 エージェント の チャット で`/nuxt-ui`と 入力 し て スキル を 起動 でき ます 。
::

### Skills CLI

[`skills`](https://skills.sh)CLI は Nuxt UI スキル を インストール する 最も 簡単 な 方法 です 。 Cursor 、 Claude Code 、 Codex 、 Windsurf 、 Cline など を 含む 35 以上 の エージェント を サポート し て い ます 。

```bash
npx skills add nuxt/ui
```

`--agent`フラグ で 特定 の エージェント を ターゲット に でき ます 。

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

また は 、 グローバル に インストール し て 、 スキル を すべて の プロジェクト で 利用 でき ます 。

```bash
npx skills add nuxt/ui --global
```

GitHub から の クローン 作成 が ネットワーク 上 で 遅い 場合 は 、 代わり に Web サイト から 直接 インストール でき ます 。

```bash
npx skills add https://ui.nuxt.com
```

::tip
[に アクセスskills.sh](https://skills.sh)で スキル エコシステム の 詳細 を 学び 、 利用 可能 な スキル を 閲覧 し て ください 。
::

### カーソル

#### クイックインストール

下 の ボタン を クリック し て Nuxt UI スキル を カーソル に 直接 インストール し ます 。

::u-button
---
to " カーソル//anysphere.cursor-deeplink/install-skill?url=https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui"
ラベル スキル を インストール
色 ニュートラル
アイコン i-simple-icons - カーソル
---
::

#### 手動 設定

1. カーソル を 開き 、 “ 設定 ” > “ スキル ” に 移動 し ます 。
2. “ スキル を 追加 ” を クリック し 、 以下 の URL を 入力 し ます 。

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```

### クロード コード

::note{icon="i-lucide-info"}
**Claude Code が インストール さ れ て いる こと を 確認 し て ください 。**[Anthropic の ドキュメント](https://docs.anthropic.com/en/docs/claude-code/quickstart)を ご覧 ください 。
::

CLI コマンド を 使用 し て スキル を 追加 し ます 。

```bash
claude skill add https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
