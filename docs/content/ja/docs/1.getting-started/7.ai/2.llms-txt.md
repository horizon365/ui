## LMs.txt と は 何 です か ？

LLMs.txt は 、 大 規模 言語 モデル （ LLM ） 用 に 特別 に 設計 さ れ た 構造 化 さ れ た ドキュメント 形式 です 。 Nuxt UI は 、 コンポーネントライブラリ に関する 包括 的 な 情報 を 含む LLMs.txt ファイル を 提供 し 、 AI ツール が Nuxt UI 開発 を 容易 に 理解 し 支援 できる よう に し ます 。

これら の ファイル は AI の 使用 に 最適 化 さ れ 、 コンポーネント 、 API 、 使用 パターン 、 ベスト プラクティス に関する 構造 化 情報 が 含ま れ ます 。

## 利用 可能 ルート

AI ツール が ドキュメント に アクセス できる よう に LLMs.txt ルート を 提供 し ます 。

- **`/llms.txt`**- すべて の コンポーネント の 構造 化 さ れ た 概要 と ドキュメントリンク が 含ま れ て い ます （~5K トーク ン ）
- **`/llms-full.txt`**- 実装 の 詳細 、 例 、 テーマ 、 合成 可能 、 移行 ガイダンス を 含む 包括 的 な ドキュメント を 提供 し ます （ 約 100 万 トーク ン ）

## 正しい ファイル の 選択

::note{icon="i-lucide-info"}
**ほとんど の ユーザー は`/llms.txt`**から 始める べき です 。 これ に は すべて の 重要 な 情報 が 含ま れ て おり 、 標準 的 な LLM コンテキストウィンドウ で 動作 し ます 。 包括 的 な 実装 例 が 必要 で 、 AI ツール が 大 規模 な コンテキスト （ 200K 以上 ） を サポート する 場合 に のみ`/llms-full.txt`を 使用 し て ください 。
::

## 重要 な ご 利用 上 の 注意

::warning{icon="i-lucide-alert-triangle"}
**- シンボル は 手動 で 入力 する 必要 が あり ます**- Cursor や Windsurf など の ツール を 使用 する 場合 、`@`シンボル は チャット インター フェイス で 手動 で 入力 する 必要 が あり ます 。 コピー 貼り 付け は 、 ツール が コンテキスト 参照 として 認識 する 能力 を 損ない ます 。
::

## AI ツール の 使い方

### カーソル

Nuxt UI は 、 コンポーネント 開発 で AI を より 良く 支援 する ため に カーソル で 参照 できる 特殊 な LLMs.txt ファイル を 提供 し ます 。

#### 使い方 ：

1. **直接 参照**： 質問 する とき に LLMs.txt の URL を 言及 し て ください 。
2. `@docs`を 使用 し て 、 特定 の URL を プロジェクトコンテキスト に 追加 し ます 。

[Cursor`@`の メンション について もっと 読む](https://cursor.com/docs/agent/prompting)

### ウィンド サーフィン

Windsurf は Nuxt UI LLMs.txt ファイル に 直接 アクセス し 、 コンポーネント の 使用 状況 や ベスト プラクティス を 理解 でき ます 。

#### Windsurf で LLMs.txt を 使用 する ：

- を 使用 し て 特定 の LLMs.txt URL を 参照 し ます 。
- ワーク スペース で これら の URL を 参照 する 永続 ルール を 作成

[Windsurf Web と Docs Search](https://docs.windsurf.com/windsurf/cascade/web-search)

### その他 の AI ツール

LLMs.txt を サポート する AI ツール は 、 これら の ルート を 使用 し て Nuxt UI を より よく 理解 でき ます 。

#### ChatGPT 、 Claude 、 または 他 の LLM の 例 ：

- " Nuxt UI ドキュメント を 使用 し てhttps://ui.nuxt.com/llms.txt"
- " Nuxt UI ガイドライン に 従っ て くださいhttps://ui.nuxt.com/llms-full.txt"
