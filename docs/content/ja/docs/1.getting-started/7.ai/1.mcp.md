##  MCPとは？

MCP Model Context Protocolは、AIアシスタントが外部のデータソースやツールにアクセスできるようにする標準化されたプロトコルです。Nuxt UIは、Claude Code、Cursor、WindsurfなどのAIアシスタントがコンポーネント情報、ソースコード、使用例に直接アクセスできるMCPサーバを提供します。

MCPサーバーは、当社のコンポーネントライブラリへの構造化されたアクセスを提供し、AIツールがNuxt UI開発を容易に理解し支援できるようにします。

## 利用可能なリソース

Nuxt UI MCPサーバーは、ディスカバリのために以下のリソースを提供します。

- **`resource://nuxt-ui/components`**カテゴリで利用可能なすべてのコンポーネントを閲覧します。
- **`resource://nuxt-ui/composables`**カテゴリ付きのすべての利用可能なコンポジットを閲覧します。
- **`resource://nuxt-ui/examples`**利用可能なすべてのコード例を参照
- **`resource://nuxt-ui/templates`**利用可能なすべてのプロジェクトテンプレートを参照します。
- **`resource://nuxt-ui/documentation-pages`**利用可能なすべてのドキュメントページを参照してください。

これらのリソースには、`@`を使用してClaude Codeなどのツールを使用してアクセスできます。

## 利用可能なツール

Nuxt UI MCPサーバーは、カテゴリごとに以下のツールを提供します。

### 検索ツール

- **`search-components`**：名前、カテゴリ、または意図でコンポーネントを検索します。`"segmented control"`や`"combobox"`などの代替名がマッチし、結果は関連性によってランク付けされます。パラメータがない場合、すべてのコンポーネントが表示されます。
- **`search-composables`名前または説明でコンポジットを検索します。パラメータなしで、すべてのコンポジットをリストします。
- **`search-icons`** Iconifyコレクション全体のアイコンを検索しますデフォルトは`lucide`。Nuxt UIで使用される`i-{prefix}-{name}`形式のアイコン名を返します。

### コンポーネントツール

- **`get-component`**コンポーネントのドキュメントと詳細を取得します。特定の部品のみを取得し、応答サイズを縮小するために`sections``usage``examples``api``theme``changelog`をサポートします。
- **`get-component-metadata`** props、slots、イベントを含むコンポーネントのメタデータを取得します軽量で、ドキュメントコンテンツはありません。Propsはデフォルトでコンパクトです。生の再帰的プロップスキーマには`full: true`を渡します。

### ドキュメンテーションツール

- **`search-documentation`**：ドキュメントページをタイトル、説明、またはセクションで検索します。パラメータなしで、すべてのページを一覧表示します。フィルタには`section`を使用します（例：`"getting-started"`、`"components"`）
- **`get-documentation-page`** URLパスでドキュメントページコンテンツを取得します。`headings`パラメータをサポートして、特定のh2セクション（例：`["Usage", "API"]`）のみを取得し、応答サイズを縮小します。

### テンプレートツール

- **`list-templates`**：利用可能なすべてのNuxt UIテンプレートをリストします。
- **`get-template`**テンプレートの説明、機能、リンクを取得します。

### サンプルツール

- **`list-examples`**利用可能なすべてのUI例の名前を一覧表示します。
- **`get-example`** UIサンプルのソースコードを取得します。

### 移行ツール

- **`get-migration-guide`** Nuxt UIの移行ガイドとアップグレード手順を取得します。

## 利用可能なツールを制限

オプションの`X-MCP-Tools` HTTPヘッダーをカンマ区切りのツール名リストに設定して、アシスタントが必要とするツールのみを公開します。これにより、アシスタントで定義されたコンテキストを減らすことができます。

正確なケバブケースのMCPツール名を使用します。

```json
{
  "X-MCP-Tools": "search-components,get-component"
}
```

ヘッダーがないとすべてのツールが公開されず、空のヘッダーがあるとツールが公開されません。

## 利用可能なプロンプト

Nuxt UI MCPサーバーは、一般的なワークフローのガイドプロンプトを提供します。

- **`find-component-for-usecase`**：特定のユースケースに最適なコンポーネントを見つける
- **`implement-component-with-props`**適切なプロパティを持つ完全なコンポーネント実装を生成する
- **`setup-project-with-template`**：プロジェクトテンプレートのセットアップ手順を入手する

これらのリソースには、`/`を使用してClaude Codeなどのツールを使用してアクセスできます。

## 設定

Nuxt UI MCPサーバーはHTTPトランスポートを使用し、さまざまなAIアシスタントで構成できます。

###  ChatGPT

::note{icon="i-lucide-info"}
** MCPを使用したカスタムコネクタは、ChatGPT for ProおよびPlusアカウントで利用できます。** Web上でアクセス可能です。
::

以下の手順に従って、ChatGPT内のコネクタとしてNuxt UIを設定します。

1. **開発者モードを有効にする：**
   -  Go to "Settings">"Connectors">"Advanced Settings">"Developer mode"

2. **オープンチャットGPT設定**

3. **[コネクタ]タブで、新しいコネクタを作成します。**
   - 名前を付けてください：`Nuxt UI`
   -  MCPサーバURL `https://ui.nuxt.com/mcp`
   - 認証`None`

4. **クリック作成**

Nuxt UIコネクタは、後で会話中にコンポーザーの「開発者モード」ツールに表示されます。

### クロードコード

::note{icon="i-lucide-info"}
** Claude Codeがインストールされていることを確認してください。**[ Anthropicのドキュメント](https://docs.anthropic.com/en/docs/claude-code/quickstart)をご覧ください。
::

CLIコマンドを使用してサーバーを追加します。

```bash
claude mcp add --transport http nuxt-ui https://ui.nuxt.com/mcp
```

###  Claudeデスクトップ

#### セットアップ手順：

1.  Claude Desktopを開き、「設定」>「開発者」に移動します。
2. 「Edit Config」をクリックします。ローカルのClaudeディレクトリが開きます。
3. `claude_desktop_config.json`ファイルをカスタムMCPサーバー構成で変更します。

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://ui.nuxt.com/mcp"
      ]
    }
  }
}
```

4.  Claude Desktopアプリを再起動します。Nuxt UI MCPサーバーが登録されています。

###  Gemini CLI

#### セットアップ手順：

1.  Gemini CLI設定ファイル通常は～/. gemini/settings.jsonまたは環境で指定されているを探します。
2.  mcpServersオブジェクトに次の構成を追加します。

###  GitHub Copilotエージェント

::note{icon="i-lucide-info"}
** Repository administrator access required.** GitHub CopilotコーディングエージェントのMCPサーバを設定するために必要です。
::

[ Visual Studio Code ](#visual-studio-code)でMCPサーバーを既に構成している場合は、`servers`キーを`mcpServers`に置き換え、Copilotで使用できるツールを指定する`tools`キーを追加します。

#### セットアップ手順：

1.  GitHubリポジトリに移動
2.  Go to **設定**>**コード&自動化**>** Copilot **>**コーディングエージェント**
3. ** MCP構成**セクションで、次の構成を追加します。
  ```json
  {
    "mcpServers": {
      "nuxt-ui": {
        "type": "http",
        "url": "https://ui.nuxt.com/mcp",
        "tools": ["*"]
      }
    }
  }
  ```
4. クリック保存

#### 設定の検証

MCPサーバが正しく設定されていることを確認する。

1. リポジトリに問題を作成し、Copilotに割り当てます。
2.  Copilotがプルリクエストを作成するのを待ちます
3. プルリクエストで、「Copilot started work」タイムラインイベントの[セッションを表示]をクリックします。
4. 右上の省略記号ボタン...をクリックし、サイドバーのCopilotをクリックします。
5.  Start MCP Serversステップを展開して、構成されているNuxtツールを確認します。

GitHub CopilotコーディングエージェントとMCPを使用する方法の詳細は、[ Extend coding agent with MCP ](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp)を参照してください。

###  GitHub Copilot CLI

#### セットアップ手順：

1.  GitHub Copilot CLIをインタラクティブモードで起動します。
2.  Run `/mcp add`。
3. 設定フォームに入力します。
   - **サーバー名**`nuxt-ui`
   - **サーバタイプ**`HTTP`
   - ** URL **`https://ui.nuxt.com/mcp`
   - ** HTTPヘッダ**空のまま
   - ** Tools **`*`
4.  Press <kbd> Ctrl </kbd>+<kbd> S </kbd>保存します。CLIを再起動することなく、MCPサーバーをすぐに利用できます。

または、サーバーを`~/.copilot/mcp-config.json`に直接追加します。

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "tools": ["*"]
    }
  }
}
```

`/mcp show`を使用して、サーバーが設定され、使用可能であることを確認します。

詳細は、[ GitHub Copilot CLI用MCPサーバの追加](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)を参照してください。

###  Google Antiggravity

#### セットアップ手順：

1. エディタのエージェントパネルの上部にある「...」ドロップダウンからMCPストアを開きます。
2. 「MCPサーバーの管理」をクリックします。
3. 「View raw config」をクリックします。
4. `mcp_config.json`をカスタムMCPサーバー構成で変更します。

```json [mcp_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "serverUrl": "https://ui.nuxt.com/mcp"
    }
  }
}
```

5. [MCPサーバーの管理]タブに戻り、[更新]をクリックします。Nuxt UI MCPサーバーが表示されます。

###  OpenCode

#### セットアップ手順：

1. プロジェクトのルートに`opencode.json`を作成します。
2. 以下の設定を追加します。

```json [opencode.json]
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "nuxt-ui": {
      "type": "remote",
      "url": "https://ui.nuxt.com/mcp",
      "enabled": true
    }
  }
}
```

###  Visual Studio Code

::note{icon="i-lucide-info"}
**必要な拡張子をインストールします。**[ GitHub Copilot ](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)[ GitHub Copilot Chat ](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat)がインストールされていることを確認してください。
::

#### セットアップ手順：

1.  VS Codeを開き、コマンドパレットにアクセスします（Ctrl/Cmd + Shift + P）
2. 「環境設定Open Workspace Settings JSON」と入力して選択します。
3. プロジェクトの`.vscode`フォルダに移動するか、存在しない場合は作成します。
4. 以下の構成で`mcp.json`ファイルを作成または編集します。

```json [.vscode/mcp.json]
{
  "servers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "headers": {
        "X-MCP-Tools": "search-components,get-component"
      }
    }
  }
}
```

`headers`エントリを削除して、すべてのNuxt UI MCPツールを利用できるようにします。

## 使用例

設定が完了すると、AIアシスタントに次のような質問をすることができます。

- "すべての利用可能なNuxt UIコンポーネントの一覧"
- "Get Buttonコンポーネントドキュメント"
- 「ボタンの使い方例だけ見せてください」
- "入力はどのような小道具を受け入れますか"
- "フォーム関連コンポーネントを検索"
- "lucideで矢印アイコンを検索"
- "ダッシュボードテンプレート一覧"
- "テンプレート設定手順を取得"
- 「インストールガイドを表示」
- "移行ガイドを入手"
- "すべての例をリスト"
- "ContactFormサンプルコードを取得"

AIアシスタントはMCPサーバーを使用して構造化JSONデータをフェッチし、開発中にNuxt UIのガイド付き支援を提供します。

::tip
コンポーネントドキュメントの場合、AIは`sections`パラメータ（`usage`、`examples`、`api`、`theme`、`changelog`）を使用して、関連する部分のみを取得できます。その他のページの場合は、`headings`パラメータをh2タイトルで使用します（例：`["Usage", "API"]`）。
::
