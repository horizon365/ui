## 使用法

::note{to="/docs/components/app"}
Nuxt UIは**App**コンポーネントを提供し、アプリケーションをラップして`locale` propを含むグローバル設定を提供します。
::

### Locale

`@nuxt/ui/locale`から使用したいロケールで`locale`プロパティを使用します：

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
各ロケールには`code`プロパティ（例：`en`、`en-GB`、`fr`）があり、[Calendar](/docs/components/calendar)、[InputDate](/docs/components/input-date)、[InputTime](/docs/components/input-time)のようなコンポーネントの日付/時刻形式を決定します。
::

### カスタムロケール

[defineLocale](/docs/composables/define-locale)ユーティリティを使用して独自のロケールを作成できます。

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
`code`パラメータを見て、そこに言語のisoコードを渡す必要があります。例：

* `hi`ヒンディー語（言語）
* `de-AT`：オーストリア（地域）で使用されているドイツ語（言語）

::

### Extendロケール

既存のロケールをカスタマイズするには、[extendLocale](/docs/composables/extend-locale)ユーティリティを使用して`messages`または`code`をオーバーライドします。

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### 動的ロケール

言語を動的に切り替えるには、[Vue I 18 n](https://vue-i18n.intlify.dev/)プラグインを使用します。

::steps{level="4"}

####  Vue I18nパッケージをインストールする

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### x`main.ts`でVue I18nプラグインを使用する

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

####  `useI18n`を使用して`locale`プロパティを設定する

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

::

### 動的方向

各ロケールには`dir`プロパティがあり、`App`コンポーネントがすべてのコンポーネントの方向性を設定するために使用します。

多言語アプリケーションでは、`<html>`要素の`lang`属性と`dir`属性をユーザのロケールに基づいて動的に設定したいかもしれません。これは[useHead](https://unhead.unjs.io/docs/head/api/composables/use-head)コンポーザブルで行うことができます：

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
