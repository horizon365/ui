## 使用法

::note{to="/docs/components/app"}
Nuxt UIは** App **コンポーネントを提供し、`locale` propを含むグローバル設定を提供します。
::

###  Locale

`@nuxt/ui/locale`から使用するロケールで`locale`プロパティを使用します。

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
各ロケールには`code`プロパティがあります例[入力日](/docs/components/input-date)と[入力時間](/docs/components/input-time)
::

### カスタムロケール

[ defineLocale ](/docs/composables/define-locale)ユーティリティを使用して、独自のロケールを作成できます。

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
`code`パラメータを見てください。そこに言語のisoコードを渡す必要があります。例：

* `hi`ヒンディー語言語
* `de-AT`：オーストリア（地域）で使用されているドイツ語

::

### ロケールを拡張

既存のロケールをカスタマイズするには、[ extendLocale ](/docs/composables/extend-locale)ユーティリティを使用して`messages`または`code`をオーバーライドします。

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### 動的ロケール

言語を動的に切り替えるには、[ Nuxt I18n ](https://i18n.nuxtjs.org/)モジュールを使用できます。

::steps{level="4"}

####  Nuxt I18nパッケージをインストールする

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### `nuxt.config.ts`{lang="ts-type"}にNuxt I18nモジュールを追加します。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### `useI18n`を使って`locale` propを設定します。

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### 自動リンクローカライズ：badge {label="4.7+" class="align-text-top"}

`@nuxtjs/i18n`がインストールされている場合、[ Link ](/docs/components/link)コンポーネントは、`$localePath`ヘルパーを使用して内部リンクを自動的にローカライズします。つまり、リンクを`localePath()`または`localeRoute()`でラップする必要はありません。

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
外部リンクと絶対URLは自動的に検出され、ローカライズはスキップされます。必要に応じて、`localePath()`または`localeRoute()`を手動で使用できます。
::

::

### 動的方向

各ロケールには`dir`プロパティがあり、これは`App`コンポーネントがすべてのコンポーネントの方向性を設定するために使用されます。

多言語アプリケーションでは、`lang`と`dir`属性をユーザーのロケールに基づいて動的に`<html>`要素に設定したい場合があります。これは[ useHead ](https://nuxt.com/docs/api/composables/use-head)で構成できます。

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
