## インストール

開始するには、公式の[ guide ](https://content.nuxt.com/docs/getting-started/installation)または要約に従うことができます：

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/content
```

```bash [yarn]
yarn add @nuxt/content
```

```bash [npm]
npm install @nuxt/content
```

```bash [bun]
bun add @nuxt/content
```

::

次に、`@nuxt/content`モジュールを`nuxt.config.ts`に追加します。

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxt/content'
  ],
  css: ['~/assets/css/main.css']
})
```

::caution
`modules`配列の`@nuxt/ui`の後に`@nuxt/content`を登録する必要があります。そうしないと散文コンポーネントは利用できません。
::

## 設定

MarkdownコンテンツファイルでTailwind CSSクラスを使用する場合、Tailwindが必要なユーティリティクラスを検出して生成できるようにする必要があります。デフォルトでは、Tailwindの自動コンテンツ検出はmarkdownファイルに記述されたクラスを検出しない場合があります。

これを修正するには、CSSファイルで[`@source` directive ](https://tailwindcss.com/docs/functions-and-directives#source-directive)を使用して、コンテンツディレクトリを明示的に含めます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@source "../../../content/**/*";
```

これにより
-  Tailwindはコンテンツディレクトリ内のすべてのマークダウンファイルをスキャンします
-  markdownで使用されるユーティリティクラス（`text-primary`など）は、最終CSSに含まれます。
-  MDCコンポーネントまたはコンテンツ内のカスタムVueコンポーネント内の動的クラスは正しく動作します

::tip
globパターンを使用して、スキャンするファイルをより具体的に指定することもできます。
- `@source "../../../content/docs/**/*.md"`—docsフォルダ内のmarkdownのみスキャン
- `@source "../../../content/**/*.{md,yml}"`—マークダウンファイルとYAMLファイルの両方を含める
::

::note{to="https://tailwindcss.com/docs/detecting-classes-in-source-files" target="_blank"}
Tailwindの自動コンテンツ検出とビルドパフォーマンス最適化のベストプラクティスの詳細をご覧ください。
::

## コンポーネント

`@nuxt/content`を使ってドキュメントを作成しているかもしれません。それを助けるために、ページで使用できるコンポーネントをいくつか作成しました。

- [ ContentSearch ](/docs/components/content-search)を含む組み込みフルテキスト検索コマンドパレットAlgolia DocSearchの必要性を置き換えます
- [ ContentNavigation ](/docs/components/content-navigation)コンポーネントを持つナビゲーションツリー
- [ ContentToc ](/docs/components/content-toc)コンポーネントを持つ粘着性のある目次
- [ ContentSurround ](/docs/components/content-surround)コンポーネントを使用した前/次のナビゲーション

## タイポグラフィ

Nuxt UIはすべての散文コンポーネントの独自の実装を提供しているので、`@nuxt/content`でレンダリングされたmarkdownは他のコンポーネントと同じテーマをピックアップします。

::note{to="/docs/typography"}
完全な** Typography **システムを発見し、リッチで一貫性のあるコンテンツプレゼンテーションのために利用可能なすべての散文コンポーネントを探索します。
::

##  Utils

Nuxt UIは、`@nuxt/content`が返すデータをコンポーネントが期待する形式に再形成するヘルパーを提供します。

### `mapContentNavigation`

このユーティリティは`queryCollectionNavigation`からナビゲーションをマップし、さまざまなコンポーネントで使用できるオブジェクトの配列に再帰的に変換します。

`mapContentNavigation(navigation, options?)`
- `navigation`ナビゲーションツリー ContentNavigationItemの配列。
- `options`（オプション）：
  - `labelAttribute`文字列ラベルとして使用するフィールドデフォルトでは`title`
  - `deep`数値または未定義ナビゲーションのレベルの数を制御します`undefined`はデフォルトで、すべてのレベルを含みます

**例**以下のブレッドクラムの例に示すように、ナビゲーションデータを正しい形式に変換するためによく使われます。

```vue [app.vue]
<script setup lang="ts">
import { mapContentNavigation } from '@nuxt/ui/utils/content'
import { findPageBreadcrumb } from '@nuxt/content/utils'

const route = useRoute()

const { data: navigation } = await useAsyncData('navigation', () => queryCollectionNavigation('content'))
const { data: page } = await useAsyncData(route.path, () => queryCollection('content').path(route.path).first())

const breadcrumb = computed(() => mapContentNavigation(
  findPageBreadcrumb(navigation.value, page.value?.path, { indexAsChild: true }),
  { deep: 0 }
).map(({ icon, ...link }) => link))
</script>

<template>
  <UPage>
    <UPageHeader v-bind="page">
      <template #headline>
        <UBreadcrumb :items="breadcrumb" />
      </template>
    </UPageHeader>
  </UPage>
</template>
```
