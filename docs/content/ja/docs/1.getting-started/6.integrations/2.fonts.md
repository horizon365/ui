## 使用法

Nuxt UIは自動的に[`@nuxt/fonts`](https://github.com/nuxt/fonts)モジュールを登録しますので、追加のセットアップは必要ありません。

### 宣言

Nuxt UIアプリケーションでフォントを使用するには、CSSでフォントを宣言するだけです。自動的に読み込まれ、最適化されます。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

### 設定

`nuxt.config.ts`の`ui.fonts`オプションを使用して、`@nuxt/fonts`モジュールを無効にできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
