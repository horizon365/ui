## 使用法

Nuxt UIは`Icon`コンポーネントを[`@iconify/vue`](https://iconify.design/docs/icon-components/vue/)でバックアップして出荷しますので、追加のセットアップは必要ありません。

### アイコンコンポーネント

[ Icon ](/docs/components/icon)コンポーネントと`name` propを使用してアイコンを表示できます。

::component-code{slug="icon"}
---
小道具
  名前'i—lucide電球'
  クラス'サイズ—5'
---
::

::note
<https://iconify.design>コレクションから任意の名前を使用できます。<https://icones.js.org>で簡単に閲覧するか、[`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCPツールを使用してAIアシスタントから直接検索します。
::

::warning
ダッシュ`-`でコレクションを使用する場合、`@iconify/vue`は`@nuxt/icon`のようにこのケースを処理しないため、アイコン名とコレクション名をコロン`:`で区切る必要があります。例えば、`i-simple-icons-github`の代わりに`i-simple-icons:github`や`simple-icons:github`と書く必要があります。

[ Iconify命名規約](https://iconify.design/docs/icon-components/vue/#icon)の詳細をご覧ください。
::

### コンポーネントプロップ

一部のコンポーネントには、[ Button ](/docs/components/button)のように、アイコンを表示するための`icon` propがあります。

::component-code{slug="button"}
---
無視
  - カラー
  - バリアント
小道具
  アイコンi—lucide太陽
  バリアント：微妙
スロット
  デフォルトボタン
---
::

## コレクション

###  Iconifyデータセット

アイコンデータをローカルにインストールすることを強くお勧めします。

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

たとえば、`i-lucide-lightbulb`アイコンを使用するには、`@iconify-json/lucide`でコレクションをインストールします。

コレクションをインストールすると、Nuxt UIが使用するアイコンをビルドに埋め込むことができます。そのため、SSR中にすぐにレンダリングされ、実行時にIconify APIからフェッチされるのではなく、完全にオフラインで動作します。これは、デフォルトで`lucide`コレクションからNuxt UI自身のアイコンに対して自動的に行われます。

アプリの他の場所で上書きしたり使用したりするアイコンなど、他のアイコンをバンドルするには、`vite.config.ts`の`icon.clientBundle.icons`オプションに追加します。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
`i-{collection}-{name}`または`{collection}:{name}`フォームのいずれかを使用できます。例：`i-lucide-heart`または`lucide:heart`、および`i-material-symbols-menu`または`material-symbols:menu`。`@iconify-json/{collection_name}`で参照する各コレクションをインストールします。
::

使用するアイコンを1つずつリストしないでバンドルするには、代わりに`scan`を有効にします。インストールされたコレクションからアイコンの使用状況をソースでスキャンしてバンドルします。`@nuxt/icon`の`clientBundle.scan`の動作と同じ方法です。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

スキャンは`.vue``.jsx``.tsx``.md``.mdc``.mdx``.yml``.yaml`ファイルのみを読み込み、文字列として書かれたアイコン名のみにマッチします。`.ts`または`.js`ファイルで定義されたアイコンは、ナビゲーションリンクのリストのように見逃されます。`i-lucide-${name}`のように動的に構築された名前も同様です。これらのファイルもスキャンするために`globInclude`を設定します。デフォルトのリストを置き換えるので、まだ必要な拡張子を残してください。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

ビルド時にセット全体がわかっている場合でも、`clientBundle.icons`にリストすることで、動的な名前をバンドルすることができます。APIからのアイコンなど、実行時にのみ存在する名前はまったくバンドルできず、Iconify APIからオンデマンドでロードされます。

コレクションがインストールされていないアイコンは、実行時にIconify APIからロードされるため、`@iconify-json/{collection_name}`で使用する各コレクションをインストールします。バンドルを完全にオプトアウトするには、`icon.clientBundle`を`false`に設定します。
