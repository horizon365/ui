## 使用法

Nuxt UIは[`@iconify/vue`](https://iconify.design/docs/icon-components/vue/)をバックアップした`Icon`コンポーネントを出荷しますので、追加のセットアップは必要ありません。

### Iconコンポーネント

[Icon](/docs/components/icon)コンポーネントと`name`プロパティを使用してアイコンを表示できます。

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
<https://iconify.design>コレクションから任意の名前を使用できます。<https://icones.js.org>で簡単に参照するか、[`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCPツールを使用してAIアシスタントから直接検索してください。
::

::warning
ダッシュ`-`でコレクションを使用する場合、`@iconify/vue`は`@nuxt/icon`のようにこのケースを処理しないため、アイコン名とコレクション名をコロン`:`で区切る必要があります。例えば`i-simple-icons-github`の代わりに`i-simple-icons:github`や`simple-icons:github`と書く必要があります。

[Iconify命名規約](https://iconify.design/docs/icon-components/vue/#icon)の詳細をご覧ください。
::

### コンポーネント小道具

一部のコンポーネントには、アイコンを表示するための`icon`プロパティもあります。例えば、[Button](/docs/components/button)です。

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## コレクション

### Iconifyデータセット

アイコンデータをローカルにインストールすることを強くお勧めします。

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

たとえば、`i-lucide-lightbulb`アイコンを使用するには、`@iconify-json/lucide`でコレクションをインストールします。

コレクションをインストールすると、Nuxt UIが使用するアイコンをビルドに埋め込むことができます。そのため、SSR中にすぐにレンダリングされ、実行時にIconify APIからフェッチされるのではなく、完全にオフラインで動作します。これは、デフォルトで`lucide`コレクションからNuxt UI自身のアイコンに対して自動的に行われます。

アプリの他の場所でオーバーライドしたり使用したりするアイコンなど、他のアイコンをバンドルするには、`vite.config.ts`の`icon.clientBundle.icons`オプションに追加します。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
`i-{collection}-{name}`または`{collection}:{name}`形式のいずれかを使用できます。例えば、`i-lucide-heart`または`lucide:heart`、`i-material-symbols-menu`または`material-symbols:menu`です。`@iconify-json/{collection_name}`で参照する各コレクションをインストールします。
::

アイコンを1つずつリストしないでバンドルするには、代わりに`scan`を有効にします。`@nuxt/icon`の`clientBundle.scan`と同じように、インストールされたコレクションからアイコンの使用状況をソースからスキャンしてバンドルします。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

スキャンは`.vue` `.jsx` `.tsx` `.md` `.mdc` `.mdx` `.yml` `.yaml`ファイルのみを読み込み、文字列として書かれたアイコン名のみにマッチします。ナビゲーションリンクのリストのような`.ts`または`.js`ファイルで定義されたアイコンは見逃されます。`i-lucide-${name}`のように動的にビルドされた名前も同様です。これらのファイルもスキャンするように`globInclude`を設定してください。デフォルトのリストを置き換えるので、まだ必要な拡張子を残してください。

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

ビルド時にセット全体がわかっている場合でも、`clientBundle.icons`にリストすることで動的な名前をバンドルすることができます。APIからのアイコンのように、実行時にのみ存在する名前はバンドルすることができず、Iconify APIからオンデマンドでロードされます。

コレクションがインストールされていないアイコンは、実行時にIconify APIからロードされるため、`@iconify-json/{collection_name}`で使用する各コレクションをインストールします。バンドルを完全にオプトアウトするには、`icon.clientBundle`を`false`に設定します。
