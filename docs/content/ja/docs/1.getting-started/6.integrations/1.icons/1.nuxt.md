## 使用法

Nuxt UIは自動的に[`@nuxt/icon`](https://github.com/nuxt/icon)モジュールを登録しますので、追加のセットアップは必要ありません。

### Iconコンポーネント

[Icon](/docs/components/icon)コンポーネントと`name`プロパティを使用してアイコンを表示できます。

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
<https://iconify.design>コレクションから任意の名前を使用できます。<https://icones.js.org>で簡単に参照するか、[`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCPツールを使用してAIアシスタントから直接検索してください。
::

### コンポーネント小道具

一部のコンポーネントにはアイコンを表示するための`icon`プロパティもあります。[Button](/docs/components/button)のように：

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## コレクション

### Iconifyデータセット

アイコンデータをローカルにインストールすることを強くお勧めします。

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

例えば、`i-uil-github`アイコンを使用するには、`@iconify-json/uil`を使用してコレクションをインストールします。この方法でアイコンをローカルまたはサーバレス関数から提供することができ、SSRとクライアント側の両方でより高速で信頼性が高くなります。

コレクションをインストールすることで、Nuxt UIはビルド時に使用するアイコンをクライアントバンドルに埋め込むことができます。そのため、実行時にオンデマンドでロードされるのではなく、最初のレンダリングで利用できます。これは、デフォルトで`lucide`コレクションからNuxt UI自身のアイコンに対して自動的に行われます。アプリの他の場所でオーバーライドしたり使用したりするアイコンなど、他のアイコンをバンドルするには、`nuxt.config.ts`の`@nuxt/icon`の[`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle)オプションに追加してください

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

または、`clientBundle.scan`を有効にして、ソースをスキャンしてアプリ全体で使用されるすべてのアイコンをバンドルします。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

スキャンは`.vue` `.jsx` `.tsx` `.md` `.mdc` `.mdx` `.yml` `.yaml`ファイルのみを読み込み、文字列として書かれたアイコン名のみにマッチします。ナビゲーションリンクのリストのような`.ts`または`.js`ファイルで定義されたアイコンは見逃されます。`i-lucide-${name}`のように動的にビルドされた名前も同様です。これらのファイルもスキャンするように`globInclude`を設定します。デフォルトのリストを置き換えるので、まだ必要な拡張子を残してください。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

ビルド時にセット全体がわかっている場合でも、`clientBundle.icons`にリストすることで動的な名前をバンドルすることができます。APIからのアイコンなど、実行時にのみ存在する名前はまったくバンドルすることはできません。アプリケーションがサーバーレンダリングされるときに`/api/_nuxt_icon`ルートからオンデマンドでロードされ、Iconify APIをフォールバックとして使用され、`nuxt generate`または`ssr: false`を使用するときにIconify APIから直接ロードされます。

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
詳細は`@nuxt/icon`のドキュメントをご覧ください。
::

### カスタムローカルコレクション

ローカルSVGファイルを使用して、カスタムIconifyコレクションを作成できます。

たとえば、アイコンのSVGファイルを任意のフォルダ（`./app/assets/icons`）の下に配置します。

```bash
assets/icons
├── add.svg
└── remove.svg
```

`nuxt.config.ts`で、`icon.customCollections`に項目を追加します。

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

次に、次のようにアイコンを使用できます：

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
詳細は`@nuxt/icon`のドキュメントをご覧ください。
::

## Theme

`app.config.ts`のコンポーネントが使用するデフォルトのアイコンを変更できます。

:icons-theme-select

:icons-theme

::note
`app.config.ts`でオーバーライドするアイコンは、クライアントバンドルに埋め込まれるのではなく、実行時にオンデマンドでロードされます。それらもバンドルするには、`nuxt.config.ts`の`@nuxt/icon`の[`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle)に)形式例えば`lucide:rocket`で追加してください。
::
