## 使用法

Nuxt UIは自動的に[`@nuxtjs/color-mode`](https://github.com/nuxt-modules/color-mode)モジュールを登録しますので、追加のセットアップは必要ありません。

### コンポーネント

組み込みの[ ColorModeAvatar ](/docs/components/color-mode-avatar)または[ ColorModeImage ](/docs/components/color-mode-image)コンポーネントを使用して、明暗モードと暗モードで異なる画像を表示し、[ ColorModeButton ](/docs/components/color-mode-button)[ ColorModeSwitch ](/docs/components/color-mode-switch)または[ ColorMode](/docs/components/color-mode-select)コンポーネントを選択して、ライトモードとダークモードを切り替えます。

また、[ useColorMode ](https://color-mode.nuxtjs.org/usage/basic)を使用して、独自のカスタムコンポーネントを構築することもできます。

```vue [ColorModeButton.vue]
<script setup lang="ts">
const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark) {
    colorMode.preference = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <ClientOnly v-if="!colorMode?.forced">
    <UButton
      :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
      color="neutral"
      variant="ghost"
      :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
      @click="isDark = !isDark"
    />

    <template #fallback>
      <div class="size-8" />
    </template>
  </ClientOnly>
</template>
```

### 設定

`nuxt.config.ts`の`ui.colorMode`オプションを使用して、`@nuxtjs/color-mode`モジュールを無効にできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```
