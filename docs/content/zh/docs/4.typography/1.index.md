Nuxt UI为您的markdown内容提供了精美的样式**Prose组件**。无论您是使用库渲染markdown还是直接使用prose组件，Nuxt UI都会应用其设计系统，因此您的内容会自动适应应用程序的主题。

::framework-only
#nuxt
:::div

::::note
使用[`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc)、[`@nuxt/content`](https://github.com/nuxt/content)或[`@comark/nuxt`](https://comark.dev/rendering/nuxt)时，自动启用散文组件。<br><br>否则，请启用`nuxt.config.ts`中的[`prose`](/docs/getting-started/installation/nuxt#prose)选项：

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
有关Nuxt Content的安装和设置，请查看**Content integration**指南。
::::

:::

#vue
:::note
要在Vue中使用prose组件，您需要在`vite.config.ts`中启用[`prose`](/docs/getting-started/installation/vue#prose)选项：

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::
::

## 用法

::framework-only
#nuxt
:::div
有多种方法可以渲染样式化内容：

1. **Markdown rendering**：使用ContentRenderer、MDC、Markdown或MarkdownDocument以自动散文样式呈现markdown
2. **Direct Vue usage**：直接在Vue模板中导入和使用prose组件
:::

#vue
:::div
有多种方法可以渲染样式化内容：

1. **Markdown rendering**：使用Markdown或MarkdownDocument以自动散文样式呈现markdown
2. **Direct Vue usage**：直接在Vue模板中导入和使用prose组件
:::

::

### 使用ContentRenderer：badge{label="Nuxt only" color="warning" class="align-text-top"}

使用[`@nuxt/content`](https://github.com/nuxt/content)时，使用[`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer)组件呈现您的收藏页面：

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### 带有MDC组件：badge{label="Nuxt only" color="warning" class="align-text-top"}

使用[`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc)或[`@nuxt/content`](https://github.com/nuxt/content)时，请使用[`<MDC>`](https://github.com/nuxt-content/mdc)组件来呈现markdown字符串：

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc`已被弃用，转而支持[Comark](https://comark.dev)。您现有的markdown文件是兼容的，无需更改内容。
::

### 带Markdown组件

[Comark](https://comark.dev)呈现markdown，内置流媒体支持。它在令牌到达时递增呈现令牌，使其成为AI聊天响应和任何其他动态markdown内容的理想选择。

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
`shiki`插件为代码块添加了语法高亮。当呈现增量到达的内容时使用`:streaming`属性，例如AI响应。

要支持暗模式，请将以下CSS添加到样式表中：

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
请参阅**Chat**组件，了解使用Comark渲染AI聊天消息的完整示例。
::

### 使用MarkdownDocument

使用[`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code)组件来呈现预解析的`MarkdownDocument`，而无需将任何解析器或插件代码发送到浏览器。当解析发生在服务器上、在构建步骤中或通过API时，这很有用。

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### 带有散文组件

直接在Vue模板中使用prose组件以实现最大控制：

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## MDC芯片

Markdown元素会自动映射到prose组件：`# Heading`变成`<ProseH1>`，`**bold**`变成`<ProseStrong>`，`` `code` ``变成`<ProseCode>`，等等。

[MDC Syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax)更进一步，允许您直接在markdown中使用Vue组件。它由Nuxt Content，Nuxt MDC和Comark支持。

## Theme

在您的应用配置中删除任何散列组件样式：

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
