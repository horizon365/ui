### 语言

高亮显示可用于数十种编程语言。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <UButton @click="updateMessage">
      Click me
    </UButton>
  </div>
</template>
```

#code

````html
```vue
<script setup lang="ts">
const message = ref（'Hello World！'）

public void run（）{
  message.value = '按钮已点击！'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <UButton @click="updateMessage">
      单击我
    </UButton>
  </div>
</template>
```
````

::

::tip
默认情况下，`material-theme-lighter`和`material-theme-palenight` Shiki主题分别用于亮和暗模式。使用`@nuxt/content`时，您可以通过`nuxt.config.ts`中的[`content.build.markdown.highlight`](https://content.nuxt.com/docs/getting-started/configuration#highlight)键进行更改。使用独立`@nuxtjs/mdc`时，通过[`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations)键配置主题。使用[Comark](https://comark.dev)时，通过`shiki`插件选项配置主题。

要使用Comark支持暗模式，请将以下CSS添加到样式表中：

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

::

::tip
文件名图标由`ProseCodeIcon`组件呈现，包含一组预定义的图标，您可以在应用配置中自定义这些图标：

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
这些文件名图标来自[`vscode-icons`](https://icones.js.org/collection/vscode-icons)集合，该集合与其他组件使用的`lucide`图标分开，并根据需要从文件扩展名解析。安装`@iconify-json/vscode-icons`以在本地和离线提供它们，就像任何其他集合一样。
::

### 复制按钮

每个代码块都有一个内置的复制按钮，可以将代码复制到剪贴板。

将`copy` prop设置为`false`以隐藏按钮，或传递[Button](/docs/components/button) prop以自定义按钮。

::tip
您可以通过应用配置中的`ui.icons.copy`和`ui.icons.copyCheck`键更改图标：

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

### Line高亮显示

突出显示特定线条以引起对重要部分的注意。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
defineNuxtConfig（{
  modules：'@ nuxt/ui']，//这一行高亮显示
  css：文件'assets/css/main.css']
})
```
````

### Code diff

使用`diff`语言显示代码版本之间的更改。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
defineNuxtConfig（{
  模块：[
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```
````
