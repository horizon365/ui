## 列表

Markdown支持无序、有序和嵌套列表，以满足各种内容需求。

### 无序列表

对没有特定顺序的项目使用无序列表。每个项目以`-`符号开头。

::tabs{class="gap-0"}

::code-preview{label="预览" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- 我是一个列表项。
- 我是另一个列表项。
- 我是最后一个列表项。

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### 有序列表

当项目顺序很重要时使用有序列表，比如流程中的步骤。

::tabs{class="gap-0"}

::code-preview{label="预览" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. 我是一个列表项。
2. 我是另一个列表项。
3. 我是最后一个列表项。

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### 嵌套列表

为复杂结构创建包含子项的层次列表。子项缩进四个空格以进行嵌套。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- 我是一个列表项。
  - 我是一个嵌套的列表项。
  - 我是另一个嵌套列表项。
- 我是另一个列表项。
  - 另一个嵌套项
    - 深度嵌套项
    - 另一个深嵌套项
  - 回到第二层

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### 混合列表

您可以为复杂的层次结构组合联合收割机有序和无序列表。

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. 第一个主要步骤
   - 子要求A
   - 子要求B
2. 第二个主要步骤
   - 另一个子项
   - 最终分项
3. 最终步骤

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## 表格

以行和列清晰地呈现结构化数据。表格是比较数据或列出属性的理想选择。

::tabs{class="gap-0"}

::code-preview{label="预览" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| 道具    |默认   |类型                     |
|---------|-----------|--------------------------|
| `name`|           | `string`{lang="ts-type"}|
| `size`| `md`      | `string`{lang="ts-type"}|
| `color`| `neutral`| `string`{lang="ts-type"}|

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
