## Headings

使用标题来组织你的内容，使其更容易阅读。

当标题有一个`id`时，可以用一个锚链接包装，在`H2`和`H3`（在大屏幕上）的悬停上显示一个哈希图标，这样读者就可以直接链接到一个部分。

使用`@nuxt/content`时，默认为`H2`至`H4`启用锚链接，否则禁用，包括[Comark](https://comark.dev)。将[`Theme`](/docs/components/theme)组件与`anchor`一起使用prop用于在应用的某个部分切换它们：

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt（无文本）
:::div

::::note
使用`@nuxt/content`时，默认为`H2`、`H3`和`H4`启用锚链接，您可以控制它们的生成[]()（例如，禁用AI聊天界面）以及`nuxt.config.ts`中的[toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc)：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::

## Links

要创建链接，请将链接文本括在括号中，然后将URL括在括号中。适用于外部链接和内部链接。

::tabs{class="gap-0"}

::code-preview{label="预览" class="[&>div]:*:my-0"}
[Nuxt文档](https://nuxt.com)

#代码

```mdc
[Nuxt documentation](https://nuxt.com)
```
