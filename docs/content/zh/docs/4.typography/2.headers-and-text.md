## 标题

使用标题来组织你的内容，使其更容易阅读。

当标题有一个`id`时，标题可以被包装在一个锚链接中，`H2`和`H3`（在大屏幕上）的hover上会显示一个哈希图标，这样读者就可以直接链接到一个部分。

当使用`@nuxt/content`时，`H2`到`H4`的锚链接默认为启用，否则为禁用，包括[Comark](https://comark.dev)。使用`anchor`道具的[`Theme`](/docs/components/theme)组件可以在应用的某个部分切换它们：

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
使用`@nuxt/content`时，`H2`、`H3`和`H4`默认开启锚链接。您可以控制它们的[generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)（例如，在AI聊天界面中禁用它们），也可以控制您的`nuxt.config.ts`中的[toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc)：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::

## 链接

要创建链接，请将链接文本括在括号中，然后将URL括在括号中。适用于外部链接和内部链接。

::tabs{class="gap-0"}

::code-preview{label="预览" class="[&>div]:*:my-0"}
[Nuxt文档](https://nuxt.com)

#code

```mdc
[Nuxt documentation](https://nuxt.com)
```
