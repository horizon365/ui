## 用法

PageGrid组件提供了一个响应式网格布局，用于显示[PageCard](/docs/components/page-card)组件或任何其他元素，根据屏幕大小自动调整1到3列。

::component-example
---
name: 'page-grid-example'
class: 'p-8'
---
::

您还可以使用`col-span-*`和`row-span-*`实用程序类来使用它以便当样式布局显示卡片列表。

::component-example
---
collapse: true
name: 'page-grid-bento-example'
class: 'p-8'
---
::
