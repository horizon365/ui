## Layout

核心结构组件，用于组织应用程序的布局并为UI建立一致的基础。

:components-list{category="layout"}

## Element

基本的UI构建块，包括按钮、徽章、头像、图标和其他基本界面元素，用于打造直观和一致的用户体验。

:components-list{category="element"}

## Form

用于构建交互式用户输入体验的全面表单组件，包括文本输入、选择、复选框、单选框组、开关、滑块和完整的表单验证。

:components-list{category="form"}

## Data

用于显示和组织数据的组件，包括表格、折叠、旋转木马、时间线、树和用户配置文件。

:components-list{category="data"}

## 导航

用于用户导航和寻路的组件，包括菜单、面包屑、分页、选项卡、步进器、链接和命令选项板。

:components-list{category="navigation"}

## 叠加

出现在主内容上方的浮动UI元素，包括模态、弹出框、工具提示、抽屉、幻灯片和上下文菜单。

:components-list{category="overlay"}

## Page

预建的营销和内容部分，用于创建登录页面，博客，定价页面和其他营销材料。

:components-list{category="page"}

::note{to="https://github.com/nuxt-ui-templates/saas" target="_blank"}
查看GitHub上的**SaaS template**以获取真实示例。
::

## 仪表板

用于构建具有可调整大小的面板、可折叠的侧边栏、浏览器和搜索功能的动态仪表板的专用组件。

:components-list{category="dashboard"}

::note{icon="i-simple-icons-github"}
查看GitHub上的[`Nuxt`](https://github.com/nuxt-ui-templates/dashboard)和[`Vue`](https://github.com/nuxt-ui-templates/dashboard-vue)仪表板模板以获得真实示例。
::

## AI聊天

用于构建会话界面和聊天机器人的组件，由[Vercel AI SDK ](https://ai-sdk.dev/)提供支持。

:components-list{category="chat"}

::note{icon="i-simple-icons-github"}
查看GitHub上的[`Nuxt`](https://github.com/nuxt-ui-templates/chat)和[`Vue`](https://github.com/nuxt-ui-templates/chat-vue) AI Chat模板以获得真实示例。
::

## 编辑器：badge{label="4.3+" class="align-text-top"}

:components-list{category="editor"}

::note{to="https://github.com/nuxt-ui-templates/editor" target="_blank"}

## 内容

与文档站点的[Content](/docs/getting-started/integrations/content)集成的组件，包括目录、搜索、导航树和周围的页面链接。

:components-list{category="content"}

::note{to="https://github.com/nuxt-ui-templates/docs" target="_blank"}

::
