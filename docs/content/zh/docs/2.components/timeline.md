### 控制活动项目

您可以使用`default-value`属性或`v-model`指示词搭配项目的`value`来控制使用中的项目。如果未提供`value`，则会预设为索引。

：组件示例{name="timeline-model-value-example" prettier}

::tip
当提供`v-model`或`default-value`时，使用`value-key`属性更改用于匹配项目的密钥。
::

使用select事件

您可以添加`@select`侦听器以使项目可单击。

::note
行程常式函式会分别接收`Event`和`TimelineItem`做为第一个和第二个参数。
::
