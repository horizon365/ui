## 用法

使用默认插槽居中并限制内容的宽度。

::tip{to="/docs/getting-started/theme/css-variables#container"}
它的最大宽度由`--ui-container` CSS变量控制。
::

::component-example
---
name: 'container-example'
props:
  class: 'w-full'
---
::
