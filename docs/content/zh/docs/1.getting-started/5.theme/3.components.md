## Tailwind变体

Nuxt UI组件使用[Tailwind Variants](https://www.tailwind-variants.org/)API进行样式设置，该API提供了一种强大的方法来创建变体和管理组件样式。

### Slots

组件可以有多个`slots`，每个代表组件中一个不同的HTML元素或部分。这些插槽允许灵活的内容插入和样式。

以[Card](/docs/components/card)组件为例，该组件具有多个插槽：

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
上面的片段是经过删节的。真实的组件在每个插槽上也带有`v-if`保护，主题在插槽顶部定义了`variant`样式。
::

有些组件没有插槽，它们只是由单个根元素组成。在这种情况下，主题只定义了`base`插槽，就像[Container](/docs/components/container)组件一样，例如：

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
没有插槽的组件仍然有一个[`ui`prop](#ui-prop)。它公开一个`base`密钥，而不是每个插槽一个密钥。[Link](/docs/components/link)和[Icon](/docs/components/icon)例外：它们没有`ui`prop，因此使用[`class`prop](#class-prop)来覆盖它们的样式。
::

### Variants

组件支持`variants`，可根据组件道具动态调整不同`slots`的样式。

例如，[Avatar](/docs/components/avatar)组件使用`size`变体来控制其外观：

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

这样，`size`道具将对`root`插槽应用相应的样式：

### Default Variants

当没有传递prop时，`defaultVariants`属性为每个变量设置默认值。

例如，[Avatar](/docs/components/avatar)组件的默认大小设置为`md`：

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

### Compound Variants

某些组件使用`compoundVariants`属性在同时满足多个变量条件时应用类。

例如，[Button](/docs/components/button)组件使用`compoundVariants`属性为特定的`color`和`variant`组合应用类：

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## 自定义主题

您有多种方式来自定义Nuxt UI组件的外观，您可以一次为所有组件或每个组件进行自定义。

::note
Tailwind Variants使用[`tailwind-merge`](https://github.com/dcastil/tailwind-merge)来合并类，因此您不必担心类冲突。
::

::tip
您可以通过两种方式探索每个组件的主题：

- 检查每个组件文档中的`Theme`部分。
- 直接在GitHub仓库中浏览源代码，地址为[`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme)。
::

### 全局配置

::framework-only

您可以自定义[`slots`](#slots)，[`variants`](#variants)，[`compoundVariants`](#compound-variants)和[`defaultVariants`](#default-variants)更改组件的默认主题：

::framework-only
#nuxt（无文本）
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

版本号
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
在此范例中，`font-bold`会覆写所有按钮上的`font-medium`，当`size="md"`和`ring-default hover:bg-accented`覆写`ring-accented hover:bg-elevated`而`color="neutral"`和`variant="outline"`覆写`ring-accented hover:bg-elevated`时，`size-4`会覆写前置图标上的`size-5`类别。按钮现在预设为`color="neutral"`和`variant="outline"`。
::

默认情况下，这些类合并到组件的默认值中。您也可以将插槽设置为函数来替换它们。它接收插槽的默认类作为其参数，因此您可以重用其中的一部分。`variants`和`compoundVariants`中的类仍然应用于顶部，就像您传递字符串时一样。

::framework-only
#nuxt（无文本）
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

版本号
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::

:::

### 主题组件

[Theme](/docs/components/theme)组件将覆盖其所有后代的插槽和属性默认值，而不会影响应用程序的其余部分。这将优先于全局配置，但`ui`和`class`props仍然胜过它。插槽接受相同的函数形式来替换它们的类，而不是合并。它与[`ui`prop @在同一点上解析。](#ui-prop)，因此它的行为方式相同。

在此示例中，`trailingIcon`插槽将被`size-3`覆盖，即使`md`大小变量会将`size-5`类应用于它。

槽值也可以是替换其类而不是合并它们的函数：

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
`ui`属性是在`variants`之后解析的，因此与全域组态不同，这里的函数会取代插槽的**resolved**类别。它的参数包含`variants`和`compoundVariants`相符的项目。相同插槽上的`class`属性仍会合并在传回类别的顶端。
::
