##  Tailwind变体

Nuxt UI组件使用[Tailwind Variants](https://www.tailwind-variants.org/) API进行样式化，该API提供了一种强大的方法来创建变体和管理组件样式。

### 老虎机

组件可以有多个`slots`，每个`slots`代表组件中不同的HTML元素或部分。这些插槽允许灵活的内容插入和样式。

我们以[Card](/docs/components/card)组件为例，它有多个插槽：

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
上面的片段是经过删节的。真实的组件在每个插槽上也带有`v-if`保护，主题在插槽顶部定义了`variant`样式。
::

有些组件没有插槽，它们只是由一个根元素组成。在这种情况下，主题只定义了`base`插槽，例如[Container](/docs/components/container)组件：

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
没有插槽的组件仍然有一个[`ui` prop](#ui-prop)。它公开了一个`base`键，而不是每个插槽一个键。[Link](/docs/components/link)和[Icon](/docs/components/icon)是例外：它们没有`ui` prop，所以使用[`class` prop](#class-prop)来覆盖它们的样式。
::

### 变体

组件支持`variants`，可以根据组件的props动态调整不同`slots`的样式。

例如，[Avatar](/docs/components/avatar)组件使用`size`变体来控制其外观：

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

这样，`size` prop会将相应的样式应用到`root`插槽：

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/nuxt.png'
  size: lg
---
::

### 默认变体

`defaultVariants`属性在没有传递prop时为每个变量设置默认值。

例如，[Avatar](/docs/components/avatar)组件的默认大小设置为`md`：

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
您可以在`nuxt.config.ts`中使用`theme.defaultVariants`选项来覆盖使用`md`和`primary`的每个组件的默认`size`和`color`。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
您可以在`vite.config.ts`中使用`theme.defaultVariants`选项来覆盖使用`md`和`primary`的每个组件的默认`size`和`color`。
:::
::

### 复合变体

某些组件使用`compoundVariants`属性在同时满足多个变量条件时应用类。

例如，[Button](/docs/components/button)组件使用`compoundVariants`属性为特定的`color`和`variant`组合应用类：

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## 自定义主题

您有多种方式来自定义Nuxt UI组件的外观，您可以一次为所有组件或每个组件进行自定义。

::note
Tailwind Variants在后台使用[`tailwind-merge`](https://github.com/dcastil/tailwind-merge)来合并类，因此您不必担心类冲突。
::

::tip
您可以通过两种方式探索每个组件的主题：

- 检查每个组件文档中的`Theme`部分。
- 直接在GitHub存储库[`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme)中浏览源代码。
::

### 全局配置

::framework-only
#nuxt
您可以使用与主题对象完全相同的结构，在`app.config.ts`中全局覆盖组件的主题。
#vue
您可以使用与主题对象完全相同的结构，在`vite.config.ts`中全局覆盖组件的主题。
::

您可以自定义组件的[`slots`](#slots)、[`variants`](#variants)、[`compoundVariants`](#compound-variants)和[`defaultVariants`](#default-variants)，以更改组件的默认主题：

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
在本例中，`font-bold`覆盖所有按钮上的`font-medium`，`size-4`覆盖`size-5`类（当`size="md"`时），`ring-default hover:bg-accented`覆盖`ring-accented hover:bg-elevated`（当`color="neutral"`和`variant="outline"`时）。按钮现在默认为`color="neutral"`和`variant="outline"`。
::

默认情况下，这些类合并到组件的默认值中。您也可以将插槽设置为函数来替换它们。它将插槽的默认类作为其参数接收，因此您可以重用其中的一部分。来自`variants`和`compoundVariants`的类仍然在顶部应用，就像您传递字符串时一样。

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt
:::warning
只在一个地方设置一个slot到一个函数。Nuxt将每个[layer](https://nuxt.com/docs/getting-started/layers)的`app.config.ts`与`defuFn`合并，这将使用该键已经具有的任何值调用您的函数，并且只保留结果。Nuxt UI然后读取一个普通字符串，因此其类将合并到默认值中，而不是替换它们。
:::
::

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
要一次性从所有组件中删除默认类，请在`nuxt.config.ts`中使用`theme.unstyled`选项。
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
要一次性从所有组件中删除默认类，请在`vite.config.ts`中使用`theme.unstyled`选项。
:::
::

### Theme组件

[Theme](/docs/components/theme)组件覆盖所有子组件的插槽和属性默认值，而不影响应用的其余部分。这优先于全局配置，但是`ui`和`class`仍然战胜了它。插槽接受相同的函数形式来替换它们的类而不是合并。它在与[`ui`相同的点上解析prop](#ui-prop)，所以它的行为相同。

### `ui`道具

您也可以使用`ui`属性覆盖组件的**slots**。这优先于全局配置和解析的`variants`。

::component-code{slug="button"}
---
prettier: true
ignore:
  - ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  trailingIcon: i-lucide-chevron-right
  size: md
  color: neutral
  variant: outline
  ui:
    trailingIcon: 'rotate-90 size-3'
slots:
  default: |

    Button
---
::

::note
在本例中，`trailingIcon`插槽被`size-3`覆盖，即使`md`大小变体将向其应用`size-5`类。
::

槽值也可以是替换其类而不是合并它们的函数：

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
`ui` prop在`variants`之后解析，因此与全局配置不同，这里的函数替换了插槽的**resolved**类。其参数包含`variants`和`compoundVariants`匹配的内容。同一插槽上的`class` prop仍然合并在返回的类之上。
::

### `class`道具

使用`class`属性覆盖`root`或`base`插槽的类。这优先于全局配置和解析的`variants`。

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
在本例中，`font-bold`类将覆盖此按钮上的默认`font-medium`类。
::
