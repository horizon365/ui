## Colors

Nuxt UI为您定义的每个[semantic color](/docs/getting-started/theme/design-system#semantic-colors)提供Tailwind CSS实用程序类，因此您可以使用类名称，如`text-error`或`bg-success`：

::code-preview
[初级]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[中学]{class="text-secondary text-sm px-4 py-1.5 inline-block"}
[成功]{class="text-success text-sm px-4 py-1.5 inline-block"}
[详细信息]{class="text-info text-sm px-4 py-1.5 inline-block"}
[警告]{class="text-warning text-sm px-4 py-1.5 inline-block"}
[错误]{class="text-error text-sm px-4 py-1.5 inline-block"}

#代码
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

每个实用程序类都使用一个CSS变量来设置其亮和暗模式的颜色：

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
您可以在`main.css`文件中调整每个工具类用于明暗模式的阴影：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
不能在[****](/docs/getting-started/theme/design-system#runtime-configuration)中使用`primary: 'black'`，因为`black`没有多个阴影。要使用纯黑色或白色作为主色，请直接在`main.css`文件中设置：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

::

::code-preview

[静音]{class="text-muted text-sm px-4 py-1.5 inline-block rounded-md"}
[色调]{class="text-toned text-sm px-4 py-1.5 inline-block rounded-md"}
[正文]{class="text-default text-sm px-4 py-1.5 inline-block rounded-md"}
[高亮显示]{class="text-highlighted text-sm px-4 py-1.5 inline-block rounded-md"}

#代码
```vue
<template>
  <span class="text-dimmed">Dimmed</span>
  <span class="text-muted">Muted</span>

</template>
```
::

每个实用程序类都使用一个CSS变量来设置其亮和暗模式的颜色：

::code-group

```css [Light]
:root {
  --ui-text-dimmed: var(--ui-color-neutral-400);
  --ui-text-muted: var(--ui-color-neutral-500);
  --ui-text-toned: var(--ui-color-neutral-600);
  --ui-text: var(--ui-color-neutral-700);
  --ui-text-highlighted: var(--ui-color-neutral-900);
  --ui-text-inverted: white;
}
```

```css [Dark]
.dark {
  --ui-text-dimmed: var(--ui-color-neutral-500);
  --ui-text-muted: var(--ui-color-neutral-400);
  --ui-text-toned: var(--ui-color-neutral-300);
  --ui-text: var(--ui-color-neutral-200);
  --ui-text-highlighted: white;
  --ui-text-inverted: var(--ui-color-neutral-900);
}
```

::

::tip
您可以在`main.css`文件中自定义这些CSS变量：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-text: var(--ui-color-neutral-900);
}

.dark {
  --ui-text: white;
}
```

要同时更改其中的多个变量，请在配置中为`neutral`](/docs/getting-started/theme/design-system#runtime-configuration)指定不同的颜色。
::

## Focus：badge{label="4.9+" class="align-text-top"}

Nuxt UI在每个交互元素上应用`focus-visible`轮廓，并使用组件的`color`道具进行着色，例如`color="primary"`时为`outline-primary/25`或`color="neutral"`时为`outline-inverted/25`。

如果您希望在整个应用中使用单一轮廓颜色，而不考虑组件颜色，则可以在`main.css`文件中添加全局规则：

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

第一个规则为每个组件的焦点轮廓着色，第二个规则通过具有可见边框的变体（如`outline`或`subtle`）对齐应用于焦点的环形重新着色，包括在其链接聚焦时突出显示的卡片。

::note
请确保在任何`@layer`之外声明这些规则，以便它们优先于组件主题设置的颜色。请记住，第一个规则也会为您自己的元素的本地焦点轮廓着色，以及在焦点上包含`border`的变体，如[FileSurround](/docs/components/file-upload)或[ContentSurround](/docs/components/content-surround继续遵循组件`color`。
::

## Radius

Nuxt UI使用统一的边界半径系统覆盖Tailwind CSS默认的`rounded-*`实用程序，因此您可以使用常规的[border radius实用程序](https://tailwindcss.com/docs/border-radius)，如`rounded-xs`或`rounded-2xl`：

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xs"}
[sm]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-sm"}
[md]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-md"}
[lg]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-lg"}
[xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xl"}
[2xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-2xl"}
[3xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-3xl"}

#代码
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

这些实用程序类是基于全局`--ui-radius`CSS变量计算的，该变量定义了应用于所有组件的基本半径值，以实现一致的外观。

```css
:root {
  --ui-radius: 0.25rem;
}
```

每个实用程序都将此基础值相乘：

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
您可以在`main.css`文件中自定义基半径值：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
更改`--ui-radius`还会影响您自己的标记和第三方组件上的`rounded-xs`到`rounded-3xl`类，而不仅仅是Nuxt UI组件。
::

::note
尝试上面标题中的：prose-icon{name="i-lucide-palette" class="text-primary"}主题菜单来更改底部半径值。
::

## Container

Nuxt UI提供了一个`--ui-container`CSS变量，用于控制[Container](/docs/components/container)组件的最大宽度。

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
您可以在`main.css`文件中自定义此值，以便在整个应用程序中一致地调整容器宽度：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

## Header

Nuxt UI提供了一个`--ui-header-height`CSS变量，用于控制[Header](/docs/components/header)组件的高度。

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
您可以在`main.css`中自定义此值，以便在整个应用程序中一致地调整标题高度：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
::

## Body

Nuxt UI在您的应用的`<body>`{lang="html"}元素上应用默认类，以便在明暗模式下保持一致的主题：

```css
body {
  @apply antialiased text-default bg-default scheme-light dark:scheme-dark;
}
```
