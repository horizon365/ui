## 用法

Nuxt UI会自动为您注册[`@nuxt/icon`](https://github.com/nuxt/icon)模块，因此无需额外设置。

### Icon组件

您可以将[Icon](/docs/components/icon)组件与`name`道具一起使用，以显示图标：

::component-code{slug="icon"}
---
道具：
  名称：'i-lucide-lightbulb'
  class：'size-5'
---
::

::note
您可以使用<https://iconify.design>集合中的任何名称。在<https://icones.js.org>上轻松浏览它们，或使用[`search-icons`](/docs/getting-started/ai/mcp#available-tools)MCP工具直接从AI助手搜索。
::

### Component props

某些组件还具有用于显示图标的`icon`道具，例如[Button](/docs/components/button)：

::component-code{slug="button"}
---
忽略：
  - color
  - variant
道具：
  图标：i-lucide-sun
  变体：细微
插槽：
  默认：按钮
---
::

## Collection

### Iconify数据集

强烈建议使用以下命令在本地安装图标数据：

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

例如，要使用`i-uil-github`图标，请使用`@iconify-json/uil`安装其集合。这样，图标可以在本地或从您的无服务器功能中提供，这在SSR和客户端上都更快，更可靠。

安装该集合还可以让Nuxt UI在构建时将其使用的图标嵌入到客户端包中，因此它们在第一次渲染时可用，而不是在运行时按需加载。默认情况下，Nuxt UI自己的图标会自动从`lucide`集合中加载。要捆绑其他图标，例如您在应用中覆盖或使用的图标，请执行以下操作：将它们添加到`@nuxt/icon`的[`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle)选项中的`nuxt.config.ts`：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

或者启用`clientBundle.scan`，通过扫描您的源代码来捆绑应用中使用的每个图标，这样您就不必逐个列出它们：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

扫描只读取`.vue`、`.jsx`、`.tsx`、`.md`、`.mdc`、`.mdx`、`.yml`和`.yaml`文件，并且只匹配以文字字符串形式写入的图标名称。在`.ts`或`.js`文件中定义的图标（如导航链接列表）将丢失，像`i-lucide-${name}`这样的动态生成的名称也是如此。设置`globInclude`也可以扫描这些文件。它将替换默认列表，所以保留您仍然需要的扩展名：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

当您在构建时知道整个集合时，仍然可以通过在`clientBundle.icons`中列出动态名称来绑定动态名称。仅在运行时存在的名称（例如来自API的图标）根本无法绑定。当您的应用服务器呈现时，它们将按需从`/api/_nuxt_icon`路由加载，并使用Iconify API作为后备，以及在使用`nuxt generate`或`ssr: false`时直接从Iconify API获取。

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
请在`@nuxt/icon`文档中了解更多信息。
::

### Custom本地集合

您可以使用本地SVG文件创建自定义Iconify集合。

例如，将图标的SVG文件放在您选择的文件夹下，例如`./app/assets/icons`：

```bash
assets/icons
├── add.svg
└── remove.svg
```

在`nuxt.config.ts`中，在`icon.customCollections`中添加一个项目：

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

然后你可以像这样使用图标：

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
在`@nuxt/icon`文档中了解更多信息。
::
