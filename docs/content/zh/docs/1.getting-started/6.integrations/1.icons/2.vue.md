## 用法

Nuxt UI提供了一个由[`@iconify/vue`](https://iconify.design/docs/icon-components/vue/)支持的`Icon`组件，因此无需额外的设置。

### Icon组件

您可以使用[Icon](/docs/components/icon)组件和`name`道具来显示图标：

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
您可以使用<https://iconify.design>集合中的任何名称。在<https://icones.js.org>上轻松浏览它们，或使用[`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP工具直接从AI助手进行搜索。
::

::warning
当使用带破折号的集合（`-`）时，您需要用冒号（`:`）将图标名称与集合名称分开，因为`@iconify/vue`不像`@nuxt/icon`那样处理这种情况。例如，您需要编写`i-simple-icons:github`或`simple-icons:github`。

了解有关[Iconify命名约定](https://iconify.design/docs/icon-components/vue/#icon)的更多信息。
::

### 组件道具

一些组件也有一个`icon`道具来显示图标，例如[Button](/docs/components/button)：

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## 系列

### Iconify数据集

强烈建议使用以下命令在本地安装图标数据：

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

例如，要使用`i-lucide-lightbulb`图标，请使用`@iconify-json/lucide`安装其集合。

安装该集合可以让Nuxt UI将其使用的图标嵌入到您的构建中，因此它们在SSR期间直接呈现并完全离线工作，而不是在运行时从Iconify API获取。这会自动为Nuxt UI自己的图标进行，默认情况下来自`lucide`集合。

要捆绑其他图标，例如您在应用中覆盖或在其他地方使用的图标，请将它们添加到`vite.config.ts`中的`icon.clientBundle.icons`选项：

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
您可以使用`i-{collection}-{name}`或`{collection}:{name}`表单，例如`i-lucide-heart`或`lucide:heart`，以及`i-material-symbols-menu`或`material-symbols:menu`。使用`@iconify-json/{collection_name}`安装您引用的每个集合。
::

要捆绑你使用的图标而不逐个列出它们，请启用`scan`。它会扫描你的源代码，从你安装的集合中查找图标使用情况并捆绑它们，与`@nuxt/icon`的`clientBundle.scan`的工作方式相同：

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

扫描只能读取`.vue`、`.jsx`、`.tsx`、`.md`、`.mdc`、`.mdx`、`.yml`和`.yaml`文件，并且它只匹配以文字字符串形式写入的图标名称。在`.ts`或`.js`文件中定义的图标，如导航链接列表，将丢失，像`i-lucide-${name}`这样的动态生成的名称。设置`globInclude`也扫描这些文件。它取代了默认列表，所以保留你仍然需要的扩展名：

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

当您在构建时知道整个集合时，仍然可以通过在`clientBundle.icons`中列出动态名称来绑定它们。仅在运行时存在的名称（例如来自API的图标）根本不能绑定，而是根据需要从Iconify API加载。

未安装集合的图标在运行时仍从Iconify API加载，因此请安装与`@iconify-json/{collection_name}`一起使用的每个集合。要选择完全退出捆绑，请将`icon.clientBundle`设置为`false`。
