## 用法

Nuxt UI 会自动为你注册 [`@nuxt/fonts`](https://github.com/nuxt/fonts) 模块，因此无需额外设置。

### 声明

要在 Nuxt UI 应用中使用字体，你可以直接在 CSS 中声明它。它会自动加载并为你优化。

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

### 配置

你可以通过 `nuxt.config.ts` 中的 `ui.fonts` 选项来禁用 `@nuxt/fonts` 模块：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
