## 安装

开始使用，你可以按照官方 [指南](https://content.nuxt.com/docs/getting-started/installation) 操作，或简要如下：

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/content
```

```bash [yarn]
yarn add @nuxt/content
```

```bash [npm]
npm install @nuxt/content
```

```bash [bun]
bun add @nuxt/content
```

::

然后，在你的 `nuxt.config.ts` 中添加 `@nuxt/content` 模块：

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxt/content'
  ],
  css: ['~/assets/css/main.css']
})
```

::caution
你需要在 `modules` 数组中将 `@nuxt/content` 注册在 `@nuxt/ui` 之后，否则 prose 组件将不可用。
::

## 配置

当你在 markdown 内容文件中使用 Tailwind CSS 类时，需要确保 Tailwind 能够检测并生成必要的实用类。默认情况下，Tailwind 的自动内容检测可能不会识别 markdown 文件中编写的类。

要解决此问题，请在 CSS 文件中使用 [`@source` 指令](https://tailwindcss.com/docs/functions-and-directives#source-directive) 显式包含你的内容目录：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@source "../../../content/**/*";
```

这可确保：
- Tailwind 会扫描你的内容目录中的所有 markdown 文件
- 你在 markdown 中使用的任何实用类（如 `text-primary`）都会包含在最终 CSS 中
- MDC 组件或内容中的自定义 Vue 组件里的动态类也能正常工作

::tip
你还可以使用 glob 模式来更具体地指定要扫描的文件：
- `@source "../../../content/docs/**/*.md"` - 仅扫描 docs 文件夹中的 markdown
- `@source "../../../content/**/*.{md,yml}"` - 同时包含 markdown 和 YAML 文件
::

::note{to="https://tailwindcss.com/docs/detecting-classes-in-source-files" target="_blank"}
进一步了解 Tailwind 的自动内容检测以及优化构建性能的最佳实践。
::

## 组件

你可能正在使用 `@nuxt/content` 构建文档站点。为了帮助你完成这项工作，我们构建了一些组件，你可以在页面中使用：

- 内置的全文搜索命令面板，使用 [ContentSearch](/docs/components/content-search)，无需再使用 Algolia DocSearch
- 使用 [ContentNavigation](/docs/components/content-navigation) 组件的导航树
- 使用 [ContentToc](/docs/components/content-toc) 组件的粘性目录
- 使用 [ContentSurround](/docs/components/content-surround) 组件的上一页 / 下一页导航

## 排版

Nuxt UI 提供了所有 prose 组件的自有实现，因此由 `@nuxt/content` 渲染的 markdown 会与你的其他组件保持一致的主题。

::note{to="/docs/typography"}
探索完整的 **Typography** 系统，并查看所有可用的 prose 组件，以实现丰富且一致的内容呈现。
::

## 工具

Nuxt UI 提供了一些辅助函数，用于将 `@nuxt/content` 返回的数据重塑为其组件期望的格式。

### `mapContentNavigation`

此工具会映射来自 `queryCollectionNavigation` 的导航，并将其递归转换为可由各种组件使用的对象数组。

`mapContentNavigation(navigation, options?)`
- `navigation`：导航树（ContentNavigationItem 数组）。
- `options`（可选）：
  - `labelAttribute`：（string）用作标签的字段（默认为 `title`）
  - `deep`：（number 或 undefined）控制包含多少层导航（默认为 `undefined`，包含所有层级）

**示例：** 如下面的面包屑示例所示，它通常用于将导航数据转换为正确格式。

```vue [app.vue]
<script setup lang="ts">
import { mapContentNavigation } from '@nuxt/content'
</script>

<template>
  <UBreadcrumb :items="mapContentNavigation(navigation)" />
</template>
```
