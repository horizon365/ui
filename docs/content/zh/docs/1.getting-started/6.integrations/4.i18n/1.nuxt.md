## 用法

::note{to="/docs/components/app"}
Nuxt UI提供了一个**App**组件，该组件包装您的应用以提供全局配置，包括`locale`属性。
::

### Locale

使用`locale` prop和你想从`@nuxt/ui/locale`使用的locale：

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
每个区域设置都有一个`code`属性（例如`en`、`en-GB`、`fr`），用于确定[Calendar](/docs/components/calendar)、[InputDate](/docs/components/input-date)和[InputTime](/docs/components/input-time)等组件中的日期/时间格式。
::

### 自定义区域设置

您可以使用[defineLocale](/docs/composables/define-locale)实用程序创建自己的区域设置：

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
看看`code`参数，在那里你需要传递语言的iso代码。示例：

* `hi`印地语（语言）
* `de-AT`：德语（语言），用于奥地利（地区）

::

### Extend语言环境

您可以通过使用[extendLocale](/docs/composables/extend-locale)实用程序覆盖现有区域设置的`messages`或`code`来自定义该区域设置：

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### 动态语言环境

要在语言之间动态切换，您可以使用[Nuxt I18 n](https://i18n.nuxtjs.org/)模块。

::steps{level="4"}

#### 安装Nuxt I18 n软件包

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### 在您的`nuxt.config.ts`{lang="ts-type"}中添加Nuxt I18 n模块

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### 使用`useI18n`设置`locale`属性

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### 自动链接本地化：badge{label="4.7+" class="align-text-top"}

当安装`@nuxtjs/i18n`时，[Link](/docs/components/link)组件会使用`$localePath`帮助程序自动本地化内部链接。这意味着您不需要手动使用`localePath()`或`localeRoute()`包装链接。

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
外部链接和绝对URL会自动检测并跳过本地化。如果需要，您仍然可以手动使用`localePath()`或`localeRoute()`。
::

::

### 动态方向

每个区域设置都有一个`dir`属性，`App`组件将使用该属性设置所有组件的方向性。

在多语言应用程序中，您可能希望根据用户的区域设置动态设置`<html>`元素上的`lang`和`dir`属性，您可以使用[useHead](https://nuxt.com/docs/api/composables/use-head)组合：

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
