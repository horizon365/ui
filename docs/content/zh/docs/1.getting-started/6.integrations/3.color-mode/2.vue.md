## 用法

Nuxt UI 会自动将 [useDark](https://vueuse.org/core/useDark) 组合式函数注册为 Vue 插件，因此无需额外配置。

### 组件

你可以使用内置的 [ColorModeAvatar](/docs/components/color-mode-avatar) 或 [ColorModeImage](/docs/components/color-mode-image) 组件来显示浅色和深色模式下的不同图片，也可以使用 [ColorModeButton](/docs/components/color-mode-button)、[ColorModeSwitch](/docs/components/color-mode-switch) 或 [ColorModeSelect](/docs/components/color-mode-select) 组件在浅色和深色模式之间切换。

你还可以使用 [useColorMode](https://vueuse.org/core/useColorMode) 组合式函数来构建自己的自定义组件：

```vue [ColorModeButton.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useColorMode } from '@vueuse/core'

const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark: boolean) {
    colorMode.value = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <UButton
    :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
    color="neutral"
    variant="ghost"
    :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
    @click="isDark = !isDark"
  />
</template>
```

### 配置

你可以通过 `vite.config.ts` 中的 `colorMode` 选项来禁用此插件：

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```
