## MCP是什么？

MCP（Model Context Protocol）是一个标准化的协议，它使AI助手能够访问外部数据源和工具。Nuxt UI提供了一个MCP服务器，允许Claude Code，Cursor和Windsurf等AI助手直接访问组件信息，源代码和使用示例。

MCP服务器提供对我们组件库的结构化访问，使AI工具能够轻松理解和协助Nuxt UI开发。

## Available Resources

Nuxt UI MCP服务器提供以下资源用于发现：

- **`resource://nuxt-ui/components`**：按类别浏览所有可用组件
- **`resource://nuxt-ui/composables`**：按类别浏览所有可用的合成
- **`resource://nuxt-ui/examples`**：浏览所有可用的代码示例
- **`resource://nuxt-ui/templates`**：浏览所有可用的项目模板
- **`resource://nuxt-ui/documentation-pages`**：浏览所有可用文档页面

您可以使用`@`通过Claude Code等工具访问这些资源。

## Available Tools

Nuxt UI MCP服务器提供以下按类别组织的工具：

### Search Tools

- **`search-components`**：按名称、类别或意图搜索组件。匹配替代名称（如`"segmented control"`或`"combobox"`），并按相关性对结果进行排序。如果没有参数，则列出所有组件
- **`search-composables`**：按名称或描述搜索可组合项。如果没有参数，则列出所有可组合项
- **`search-icons`**：在Iconify集合中搜索图标（默认为`lucide`）。以Nuxt UI使用的`i-{prefix}-{name}`格式返回图标名称

### Component Tools

- **`get-component`**：检索组件文档和详细信息。支持`sections`参数（`usage`、`examples`、`api`、`theme`、`changelog`）以仅提取特定部分并减小响应大小
- **`get-component-metadata`**：检索组件的元数据，包括prop、插槽和事件（轻量级，无文档内容）。默认情况下，prop是紧凑的，传递`full: true`以获取原始递归prop架构

### Documentation Tools

- **`search-documentation`**：按标题、描述或章节搜索文档页面。如果没有参数，则列出所有页面。使用`section`进行筛选（例如`"getting-started"`、`"components"`）
- **`get-documentation-page`**：通过URL路径检索文档页面内容。支持`headings`参数，仅获取特定的h2部分（例如`["Usage", "API"]`）并减少响应大小

### Template Tools

- **`list-templates`**：列出所有可用的Nuxt UI模板，带有可选的框架过滤
- **`get-template`**：检索模板的描述、功能和链接

### 示例工具

- **`list-examples`**：列出所有可用UI示例的名称
- **`get-example`**：检索UI示例的源代码

### Migration Tools

- **`get-migration-guide`**：检索此版本Nuxt UI的迁移指南和升级说明

## Limit可用工具

将可选的`X-MCP-Tools`HTTP标头设置为逗号分隔的工具名称列表，以仅显示助手需要的工具。这有助于减少助手中定义的上下文。

使用确切的kebab案例MCP工具名称，例如：

```json
{
  "X-MCP-Tools": "search-components,get-component"
}
```

没有标头会公开所有工具，空标头不会公开任何工具，未知的工具名称会返回配置错误。

## Available

Nuxt UI MCP服务器为常见工作流提供引导提示：

- **`find-component-for-usecase`**：查找最适合您特定用例的组件
- **`implement-component-with-props`**：使用适当的道具生成完整的组件实现
- **`setup-project-with-template`**：获取项目模板的引导设置说明

您可以使用`/`通过Claude Code等工具访问这些资源。

## Configuration

Nuxt UI MCP服务器使用HTTP传输，可以在不同的AI助手中配置。

### ChatGPT

::note{icon="i-lucide-info"}
**使用MCP的自定义连接器可在ChatGPT上为Pro和Plus帐户提供。**可在Web上查看。
::

按照以下步骤将Nuxt UI设置为ChatGPT中的连接器：

1. **Enable Developer mode：**
   - Go to“Settings”>“Connectors”>“Advanced settings”>“Developer mode”

2. **Open ChatGPT设置**

3. **在“连接器”选项卡中，创建新连接器：**
   - 给它起个名字：`Nuxt UI`
   - MCP服务器URL：`https://ui.nuxt.com/mcp`
   - Authentication：`None`

4. **Click button**

稍后在对话期间，Nuxt UI连接器将出现在作曲家的“开发者模式”工具中。

### Claude Code

::note{icon="i-lucide-info"}
**确保安装了Claude代码。**有关安装说明，请访问[Anthropic的文档](https://docs.anthropic.com/en/docs/claude-code/quickstart)。
::

使用CLI命令添加服务器：

```bash
claude mcp add --transport http nuxt-ui https://ui.nuxt.com/mcp
```

### Claude桌面

#### Setup Instructions：

1. 打开Claude桌面并导航到“设置”>“开发人员”。
2. 点击“编辑配置”。这将打开本地Claude目录。
3. 使用自定义MCP服务器配置修改`claude_desktop_config.json`文件。

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://ui.nuxt.com/mcp"
      ]
    }
  }
}
```

4. 重新启动Claude桌面应用程序。Nuxt UI MCP服务器现在应该已注册。

#### Setup Instructions：

1. Locate your Gemini CLI configuration file（通常是配置文件/. gemini/settings.json或在您的环境中指定的配置文件）。

### GitHub Copilot代理

::note{icon="i-lucide-info"}
需要**Repository管理员访问权限。**这是为GitHub Copilot编码代理配置MCP服务器所需的。
::

如果您已经在[Visual Studio Code](#visual-studio-code)中配置了MCP服务器，请将`servers`键替换为`mcpServers`，并添加一个`tools`键，指定Copilot可以使用哪些工具。

#### Setup Instructions：

1. Navigate to your GitHub repository
2. Go to**Settings** > **Code & automation** > **Copilot** > **Coding agent**
3. 在**MCP配置**部分中，添加以下配置：
  ```json
  {
    "mcpServers": {
      "nuxt-ui": {
        "type": "http",
        "url": "https://ui.nuxt.com/mcp",
        "tools": ["*"]
      }
    }
  }
  ```
4. Click Save

#### 正在验证配置：

要验证MCP服务器是否配置正确，请执行以下操作：

1. 在存储库中创建问题并将其分配给Copilot
2. Wait for Copilot to create a pull request
3. 在拉取请求中，单击“Copilot started work”时间轴事件中的View session
4. 单击右上角的省略号按钮（.），然后单击侧边栏中的Copilot
5. 展开“启动MCP服务器”步骤以查看已配置的Nuxt工具

有关将MCP与GitHub Copilot编码代理配合使用的更多信息，请参阅[Extend coding agent with MCP](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp。

### GitHub Copilot CLI

#### Setup Instructions：

1. 在交互模式下启动GitHub Copilot CLI。
2. Run`/mcp add`.
3. 填写配置表：
   - **Server Name**：`nuxt-ui`
   - **Server Type**：`HTTP`
   - **URL**：`https://ui.nuxt.com/mcp`
   - **HTTP Headers**：留空
   - **Tools**：`*`
4. Press<kbd>Ctrl</kbd>+<kbd>S</kbd>保存。MCP服务器立即可用，无需重新启动CLI。

或者直接将服务器添加到`~/.copilot/mcp-config.json`：

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "tools": ["*"]
    }
  }
}
```

使用`/mcp show`确认服务器已配置且可用。

有关详细信息，请参阅[Adding MCP servers for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)。

### Visual Studio代码

::note{icon="i-lucide-info"}
**安装所需的扩展。**确保您已安装[GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)和[GitHub Copilot聊天室](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat)扩展。
::

#### Setup Instructions：

1. Open VS Code并访问命令行（Ctrl/Cmd + Shift + P）
2. 键入“首选项：打开工作区设置（JSON）”并选择它
3. 导航到项目的`.vscode`文件夹，如果不存在，则创建一个文件夹
4. 使用以下配置创建或编辑`mcp.json`文件：

```json [.vscode/mcp.json]
{
  "servers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "headers": {
        "X-MCP-Tools": "search-components,get-component"
      }
    }
  }
}
```

删除`headers`条目以使所有Nuxt UI MCP工具可用。

## 用法示例

配置完成后，您可以向AI助手询问以下问题：

- “列出所有可用的Nuxt UI组件”
- “获取按钮组件文档”
- “仅显示按钮用法示例”
- “Input接受什么道具？”
- “查找表单相关组件”
- “在lucide中搜索箭头图标”
- “列出仪表板模板”
- “获取模板设置说明”
- “显示安装指南”
- “获取迁移指南”
- “列出所有示例”
- “获取ContactForm示例代码”

AI助手将使用MCP服务器获取结构化JSON数据，并在开发过程中为Nuxt UI提供指导帮助。

::tip
对于组件文档，人工智能可以使用`sections`参数（`usage`、`examples`、`api`、`theme`、`changelog`），只取相关部分;对于其他页面，可以使用带有h2标题的`headings`参数（如`["Usage", "API"]`）。
::
