## 什么是技能？

技能是结构化的知识文件，为AI编码代理提供有关库，框架或代码库的上下文。与提供实时工具访问的MCP服务器不同，技能直接加载到代理的上下文中，因此它可以在整个对话中引用它们。

Nuxt UI提供了一个**usage skill**，可以教AI代理如何使用Nuxt UI构建UI：安装，主题化，组件，可组合，表单，覆盖和布局。

## 用法

使用技巧为AI代理提供了有关使用Nuxt UI v4构建的全面知识。它包括：

- 安装Nuxt、Vue、Laravel和AdonisJS
- 使用语义颜色和CSS变量进行主题化和品牌化
- 所有125+组件与道具和使用模式
- 可组合（`useToast`，`useOverlay`，`defineShortcuts`）
- Form验证与标准模式
- 布局合成（仪表板，聊天，编辑器）
- 官方入门模板

该技能包括AI代理根据任务按需加载的其他引用，保持响应集中和上下文高效。

::note
安装后，您可以通过在代理的聊天中输入`/nuxt-ui`来调用该技能。
::

### Skills CLI

[`skills`](https://skills.sh) CLI是安装Nuxt UI技能的最简单方法。它支持35+代理，包括Cursor，Claude Code，Codex，Windsurf，Cline等。

```bash
npx skills add nuxt/ui
```

您可以使用`--agent`标志来定位特定的代理：

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

或者全局安装，以便在所有项目中使用该技能：

```bash
npx skills add nuxt/ui --global
```

如果从GitHub克隆在您的网络上很慢，您可以直接从网站安装：

```bash
npx skills add https://ui.nuxt.com
```

::tip
请访问[skills.sh](https://skills.sh)，了解有关技能生态系统的更多信息，并浏览可用技能。
::

### 光标

#### 快速安装

点击下面的按钮，直接在Cursor中安装Nuxt UI技能：

::u-button

label: Install Skill
color: neutral
icon: i-simple-icons-cursor

::

#### 手动设置

1. 打开光标并转到“设置”>“技能”
2. 点击“添加技能”，输入以下URL：

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
