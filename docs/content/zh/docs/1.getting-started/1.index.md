## Nuxt UI 是什么？

一个基于 [Reka UI](https://reka-ui.com/)、[Tailwind CSS](https://tailwindcss.com/) 和 [Tailwind Variants](https://www.tailwind-variants.org/) 构建的现代 Vue UI 组件库，用于交付美观且无障碍的应用，包含 125+ 个生产就绪组件。适用于 Nuxt 和普通 Vue 应用（Vite、Inertia、SSR）。

如果你正在构建一个使用 Tailwind CSS 的 Vue 项目，Nuxt UI 是一个很好的默认选择。它提供高层、开箱即用的组件（数据表格、表单、覆盖层、导航），同时在需要时仍允许高级自定义。

## v4 有什么新变化？

Nuxt UI v4 标志着一个重要里程碑：Nuxt UI 和 Nuxt UI Pro 现已统一为一个单一、完全开源且免费的库，包含 125+ 个生产就绪组件和完整的 Figma Kit。

从 v3 迁移到 v4 将比从 v2 迁移到 v3 顺畅得多。请阅读[迁移指南](/docs/getting-started/migration)了解更多。

## 核心技术

Nuxt UI 建立在三个基础之上：Reka UI 负责行为和可访问性，Tailwind CSS 负责样式，Tailwind Variants 负责组合变体。

### Reka UI

Nuxt UI 基于 [Reka UI](https://reka-ui.com/) 构建，作为组件的基础：

- **WAI-ARIA 合规**：遵循 [WAI-ARIA 编写实践](https://reka-ui.com/docs/overview/accessibility)，具有正确的语义和角色
- **键盘导航**：为标签页和对话框等复杂组件内置键盘支持
- **焦点管理**：智能焦点处理，根据用户交互移动焦点
- **无障碍标签**：抽象层，简化屏幕阅读器控件的标注

### Tailwind CSS

Nuxt UI 集成了最新的 [Tailwind CSS](https://tailwindcss.com/)，带来显著改进：

- **构建速度提升 5 倍**：完整构建速度最多提升 5 倍，增量构建速度提升超过 100 倍
- **统一工具链**：内置导入处理、厂商前缀和语法转换
- **CSS 优先配置**：直接在 CSS 中自定义和扩展，而不是 JavaScript
- **现代 Web 特性**：容器查询、层叠层、广色域颜色等

### Tailwind Variants

Nuxt UI 利用 [Tailwind Variants](https://www.tailwind-variants.org/) 提供强大的设计系统：

- **动态样式**：通过强大 API 提供灵活的组件变体
- **类型安全**：完整的 TypeScript 支持和自动补全
- **冲突解析**：高效合并冲突样式

### Vue 兼容性（Nuxt 可选）

Nuxt UI 适用于任何 Vue 项目，而不仅仅是 Nuxt。只需在配置中添加 Vite 和 Vue 插件即可：

- **自动导入**：组件和组合式函数会自动导入并全局可用
- **设计系统**：完整的主题支持，可自定义颜色、尺寸、变体等
- **开发者体验**：完整的 TypeScript 支持，包含 IntelliSense 和自动补全

::tip{to="/docs/getting-started/installation/vue" aria-label="Vue installation guide"}
在 **Vue 安装指南** 中了解如何在 Vue 项目中安装和配置 Nuxt UI。
::

### TypeScript 支持

Nuxt UI 提供全面的 TypeScript 集成，带来更出色的开发者体验：

- **自动补全**：适用于所有组件 props、插槽和事件
- **泛型组件**：使用 [Vue Generics](https://vuejs.org/api/sfc-script-setup.html#generics)
- **类型安全的主题**：在 `app.config.ts` 中
- **IntelliSense**：贯穿整个代码库

## 常见问题

::accordion

:::accordion-item{label="Nuxt UI 可以免费使用吗？"}
是的！Nuxt UI 完全免费，并在 MIT 许可证下开源。所有 125+ 组件都向所有人开放。
:::

:::accordion-item{label="我可以在不使用 Nuxt 的情况下将 Nuxt UI 用于 Vue 吗？"}
是的！虽然针对 Nuxt 进行了优化，但 Nuxt UI 通过我们的 Vite 插件可与独立 Vue 项目完美配合。你可以按照[安装指南](/docs/getting-started/installation/vue)开始使用。
:::

:::accordion-item{label="Nuxt UI 是否包含 Figma Kit？"}
是的！Nuxt UI 包含一个[完整的 Figma Kit](https://go.nuxt.com/figma-ui)，涵盖所有组件，方便设计师和开发者协作。
:::

:::accordion-item{label="Nuxt UI 如何处理无障碍？"}
通过 [Reka UI](https://reka-ui.com/docs/overview/accessibility) 集成，Nuxt UI 提供自动 ARIA 属性、键盘导航、焦点管理和屏幕阅读器支持。虽然提供了强大基础，但在你的具体使用场景中进行测试仍然很重要。
:::

:::accordion-item{label="Nuxt UI 是否已准备好用于生产环境？"}
是的！Nuxt UI 已被数千个应用用于生产环境，拥有 1000+ Vitest 测试、定期更新和积极维护。
:::

:::accordion-item{label="什么时候应考虑替代方案？"}
如果你想要 Material Design 样式，可以考虑 **Vuetify**；如果想要 Ant Design 样式，可以考虑 **ant-design-vue**；如果你不想使用 Tailwind CSS，可以考虑 **PrimeVue** 或 **Element Plus**；如果你更喜欢将组件复制到仓库中，可以考虑 **shadcn-vue**；如果你需要跨平台应用（Web、移动端、桌面端），可以考虑 **Quasar**；如果你只需要无样式基础组件，可以考虑 **Reka UI** / **Headless UI**。
:::

可以在 [GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a) 提问并获得帮助，在 [Discord](https://go.nuxt.com/discord) 与社区交流，或在 [GitHub](https://github.com/nuxt/ui/issues) 报告 bug。
