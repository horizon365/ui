## 什么是Nuxt UI？

基于[Reka UI](https://reka-ui.com/)、[Tailwind CSS](https://tailwindcss.com/)和[Tailwind Variants](https://www.tailwind-variants.org/)构建的现代化Vue UI组件库，可提供125个以上生产就绪组件的美观且可访问的应用程序。适用于Nuxt和普通Vue应用程序（Vite、Inertia、SSR）。

如果您正在使用Tailwind CSS构建Vue项目，Nuxt UI是一个很好的默认选择。它提供了高级，即用型组件（数据表，表单，覆盖，导航），同时还允许在需要时进行高级自定义。

##  v4有什么新功能？

Nuxt UI v4标志着一个重要的里程碑：Nuxt UI和Nuxt UI Pro现在统一为一个单一的、完全开源的免费库，其中包含125多个生产就绪的组件和一个完整的Figma Kit。

从v3到v4的迁移将比从v2到v3更顺利。请参阅[迁移指南](/docs/getting-started/migration)了解更多信息。

## 核心技术

Nuxt UI建立在三个基础上：Reka UI用于行为和可访问性，Tailwind CSS用于样式化，Tailwind Variants用于组合变体。

### Reka UI

Nuxt UI构建在[Reka UI](https://reka-ui.com/)之上，作为组件的基础：

- **WAI-ARIA合规性**：遵循[WAI-ARIA创作实践](https://reka-ui.com/docs/overview/accessibility)，并具有适当的语义和角色
- **键盘导航**：内置键盘支持复杂组件，如选项卡和对话框
- **焦点管理**：智能焦点处理，根据用户交互移动焦点
- **sible Labels**：用于简化屏幕阅读器标签控件的抽象

### Tailwind CSS

Nuxt UI集成了最新的[Tailwind CSS](https://tailwindcss.com/)，带来了显著的改进：

- **5 x更快的构建速度**：完整构建速度最高可达5倍，增量构建速度超过100倍
- **统一工具链**：内置导入处理、供应商前缀和语法转换
- **CSS优先**：直接在CSS中而不是JavaScript中自定义和扩展
- **现代Web浏览器**：容器查询、层叠层、宽色域色彩等

###  Tailwind变体

Nuxt UI利用[Tailwind Variants](https://www.tailwind-variants.org/)提供强大的设计系统：

- **动态样式**：具有强大API的灵活组件变体
- **Type Safety**：完整的TypeScript支持和自动完成
- **冲突解决**：高效合并冲突样式

### Vue兼容性（Nuxt可选）

Nuxt UI适用于任何Vue项目，而不仅仅是Nuxt。只需将Vite和Vue插件添加到您的配置中：

- **Auto-imports**：组件和可组合组件自动导入并全局可用
- **设计系统**：全面的主题支持，可定制颜色、大小、变体等
- **开发人员体验e**：完整的TypeScript支持，具有智能感知和自动完成功能

::tip{to="/docs/getting-started/installation/vue" aria-label="Vue安装指南"}
在**安装指南中了解如何在Vue项目中安装和配置Nuxt UI。
::

### TypeScript支持

Nuxt UI提供全面的TypeScript集成，以获得上级开发人员体验：

- **自动完成**：用于所有组件道具、插槽和事件
- **泛型**：使用[Vue泛型](https://vuejs.org/api/sfc-script-setup.html#generics)
- **类型安全主题**：在`app.config.ts`中
- **IntelliSense**：在整个代码库中

## 常见问题

::accordion

:::accordion-item{label="Nuxt UI可以免费使用吗？"}
是的！Nuxt UI在MIT许可下完全免费开源。所有125+组件都可供任何人使用。
:::

:::accordion-item{label="我可以在没有Nuxt的情况下使用Vue的Nuxt UI吗？"}
是的，我会的虽然针对Nuxt进行了优化，但Nuxt UI通过我们的Vite插件与独立Vue项目完美兼容。您可以按照[安装指南](/docs/getting-started/installation/vue)开始使用。
:::

:::accordion-item{label="Nuxt UI是否包含Figma Kit？"}
是的，我会的Nuxt UI包括一个[complete Figma Kit](https://go.nuxt.com/figma-ui)，包含所有组件，使设计师和开发人员可以轻松协作。
:::

:::accordion-item{label="Nuxt UI如何处理可访问性？"}
通过[Reka UI](https://reka-ui.com/docs/overview/accessibility)集成，Nuxt UI提供自动ARIA属性、键盘导航、焦点管理和屏幕阅读器支持。在提供强大基础的同时，在特定用例中进行测试仍然很重要。
:::

:::accordion-item{label="Nuxt UI是否已准备好生产？"}
是的！Nuxt UI被数千个应用程序用于生产，具有1000+ Vitest测试，定期更新和主动维护。
:::

:::accordion-item{label="我什么时候应该考虑替代方案？"}
如果你想要Material Design样式，可以考虑**Vuetify**;如果你想要Ant Design样式，可以考虑**ant-design-vue**;如果你不想要Tailwind CSS，可以考虑**PrimeVue**或**Element Plus**;如果你喜欢将组件复制到repo中，可以考虑**shadcn-vue**;如果你喜欢跨平台应用，可以考虑**Quasar**（web、移动的、桌面）或**Reka UI**/** Headless UI**（如果您只需要无样式的基元）。
:::

:::accordion-item{label="我在哪里可以获得帮助？"}
在[GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a)中提出问题并获得帮助，在[Discord](https://go.nuxt.com/discord)上与社区聊天，或在[GitHub](https://github.com/nuxt/ui/issues)上报告错误。
