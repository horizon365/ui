Nuxt UI v4 标志着一个重要里程碑：**Nuxt UI 和 Nuxt UI Pro 现已统一为一个单一、完全开源且免费的库**。你现在可以使用 125+ 个生产就绪组件，全部位于 `@nuxt/ui` 包中。

::note
由于某些依赖项，Nuxt UI v4 需要 **Nuxt 4.1 或更高版本**。请确保在迁移到 Nuxt UI v4 之前升级。
::

本指南提供将应用从 v3 迁移到 v4 的分步说明。

## 迁移项目

### 从 Nuxt UI Pro 迁移

1. 在 `package.json` 中将 `@nuxt/ui-pro` 替换为 `@nuxt/ui`：

::code-group{sync="pm"}

```bash [pnpm]
pnpm remove @nuxt/ui-pro
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn remove @nuxt/ui-pro
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm uninstall @nuxt/ui-pro
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun remove @nuxt/ui-pro
bun add @nuxt/ui tailwindcss
```

::

-   '@nuxt/ui-pro',
+   '@nuxt/ui'

## 来自 v3 的变更

升级到 Nuxt UI v4 后，请注意以下重要变更：

### ButtonGroup 已重命名

`ButtonGroup` 组件已重命名为 [`FieldGroup`](/docs/components/field-group)：

```diff
<template>
- <UButtonGroup>
+ <UFieldGroup>
    <UButton label="Button" />
    <UButton icon="i-lucide-chevron-down" />
+ </UFieldGroup>
- </UButtonGroup>
</template>
```

### PageMarquee 已重命名

`PageMarquee` 组件已重命名为 [`Marquee`](/docs/components/marquee)：

```diff
<template>
- <UPageMarquee :items="items" />
+ <UMarquee :items="items" />
</template>
```

### PageAccordion 已移除

`PageAccordion` 组件已被移除，改用 [`Accordion`](/docs/components/accordion)：

```diff
<template>
- <UPageAccordion
+ <UAccordion
    :items="items"
+   :unmount-on-hide="false"
+   :ui="{ trigger: 'text-base', body: 'text-base text-muted' }"
  />
</template>
```

::note
`PageAccordion` 组件是一个包装器，它将 `unmount-on-hide` 设置为 `false` 并自定义了 `ui` prop。
::

### 模型修饰符已重命名

[`Input`](/docs/components/input)、[`InputNumber`](/docs/components/input-number) 和 [`Textarea`](/docs/components/textarea) 使用的 `modelModifiers` 形状在 v4 中发生了变化：

1. `nullify` 修饰符已重命名为 `nullable`（它将空/空白值转换为 `null`）。
2. 新增了一个 `optional` 修饰符（它将空/空白值转换为 `undefined`）。

```diff
- <UInput v-model.nullify="value" />
+ <UInput v-model.nullable="value" />
```

```diff
- <UTextarea v-model="value" :model-modifiers="{ nullify: true }" />
+ <UTextarea v-model="value" :model-modifiers="{ nullable: true }" />
```

当你希望空值为 `null` 时使用 `nullable`，当你更倾向于将缺失值设为 `undefined` 时使用 `optional`。

### Form 组件变更

`Form` 组件在 v4 中得到了改进，具有更好的状态管理和嵌套表单处理。以下是你需要了解的关键变更：

1. Schema **转换将仅**应用于 **`@submit` 数据**，不再会改变表单状态。这提供了更好的可预测性，并防止意外的状态变更。
2. **嵌套表单必须显式启用**，使用 `nested` prop。这使组件行为更明确，并防止意外创建嵌套表单。
3. **嵌套表单现在应提供 `name`** prop（类似于 `UFormField`），并会自动从父表单继承状态。

```diff
<template>
  <UForm :state="state" :schema="schema" @submit="onSubmit">
    <UFormField label="Customer" name="customer">
      <UInput v-model="state.customer" placeholder="Wonka Industries" />
    </UFormField>

    <div v-for="(item, index) in state.items" :key="index">
      <UForm
-       :state="item"
+       :name="`items.${index}`"
        :schema="itemSchema"
+       nested
      >
        <UFormField :label="!index ? 'Description' : undefined" name="description">
          <UInput v-model="item.description" />
        </UFormField>
        <UFormField :label="!index ? 'Price' : undefined" name="price">
          <UInput v-model="item.price" type="number" />
        </UFormField>
      </UForm>
    </div>
  </UForm>
</template>
```

### 已移除的弃用工具

一些此前在 Nuxt UI Pro 中可用的 **Nuxt Content 工具**已在 v4 中**移除**：

- `findPageBreadcrumb`
- `findPageHeadline`

这些现在完全由 Nuxt Content 提供。请确保相应地更新导入和用法。

```diff
- import { findPageHeadline } from '@nuxt/ui-pro/utils/content'
+ import { findPageHeadline } from '@nuxt/content/utils'

- import { findPageBreadcrumb } from '@nuxt/ui-pro/utils/content'
+ import { findPageBreadcrumb } from '@nuxt/content/utils'
```

### AI SDK 迁移（可选）

本节仅适用于你正在使用 AI SDK 和聊天组件（`ChatMessage`、`ChatMessages`、`ChatPrompt`、`ChatPromptSubmit`、`ChatPalette`）。如果你没有使用 AI 功能，可以跳过本节。

1. 在 `package.json` 中更新 `@ai-sdk/vue` 和 `ai` 依赖，并添加 [Comark](https://comark.dev)（替代 `@nuxtjs/mdc`，用于将 AI 响应渲染为流式 Markdown）：

::framework-only
#nuxt
:::div
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/nuxt": "latest"
  }
}
```

将 `@comark/nuxt` 添加到你的模块：

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
+   '@comark/nuxt'
  ]
})
```
:::

#vue
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/vue": "latest"
  }
}
```
::

2. `useChat` 组合式 API 已更改：`input` 和 `handleSubmit` 已被移除，改用 `sendMessage`，并且 `messages` 现在是一个你可以直接设置的 ref：

```diff
<script setup lang="ts">
  import { useChat } from '@ai-sdk/vue'

- const { messages, input, handleSubmit, status, error, reload, setMessages } = useChat()
+ const { messages, status, error, sendMessage, regenerate, stop } = useChat()
+ const input = ref('')
+
+ function handleSubmit() {
+   sendMessage({ text: input.value })
+   input.value = ''
+ }
</script>
```

3. 消息现在使用 `parts` 而不是 `content`：

```diff
// When manually creating messages
- setMessages([{
+ messages.value = [{
  id: '1',
  role: 'user',
- content: 'Hello world'
+ parts: [{ type: 'text', text: 'Hello world' }]
- }])
+ }]

// In templates
<template>
- <UChatMessage :content="message.content" />
+ <UChatMessage :parts="message.parts" />
</template>
```

4. 一些方法已重命名：

```diff
// Regenerate the last message
- reload()
+ regenerate()
```

5. 对于基于 parts 的渲染，请将 `<MDC>` 替换为 `<Markdown>`。`Markdown` 组件专为流式 Markdown 构建，它会在 AI 返回 token 时增量渲染。使用 AI SDK 辅助函数和来自 `@nuxt/ui/utils/ai` 的 `isPartStreaming` 工具。

::note
使用 `shiki` 插件时，请将以下 CSS 添加到样式表中以支持深色模式：

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::framework-only
#nuxt
```vue
<script setup lang="ts">
import { isReasoningUIPart, isTextUIPart } from 'ai'
import { isPartStreaming } from '@nuxt/ui/utils/ai'
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]
</script>

<template>
  <UChatMessages :messages="messages" :status="status">
    <template #content="{ message }">
      <template v-for="(part, index) in message.parts" :key="`${message.id}-${part.type}-${index}`">
        <UChatReasoning
          v-if="isReasoningUIPart(part)"
          :text="part.text"
          :streaming="isPartStreaming(part)"
        >
          <Markdown
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
        </UChatReasoning>

        <template v-else-if="isTextUIPart(part)">
          <Markdown
            v-if="message.role === 'assistant'"
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
          <p v-else-if="message.role === 'user'" class="whitespace-pre-wrap">
            {{ part.text }}
          </p>
        </template>
      </template>
    </template>
  </UChatMessages>
</template>
```
