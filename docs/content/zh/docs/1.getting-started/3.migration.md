Nuxt UI v4标志着一个重要的里程碑：**Nuxt UI和Nuxt UI Pro现在统一为一个完全开源的免费库**。您现在可以访问125个以上的生产就绪组件，所有组件都在`@nuxt/ui`包中提供。

::note
Nuxt UI v4需要**Nuxt 4.1或更高版本的**，因为存在一些依赖关系。请确保在迁移到Nuxt UI v4之前进行升级。
::

本指南提供了将应用程序从v3迁移到v4的分步说明。

## 迁移您的项目

### 来自Nuxt UI Pro

1. 将`package.json`中的`@nuxt/ui-pro`替换为`@nuxt/ui`：

::code-group{sync="pm"}

```bash [pnpm]
pnpm remove @nuxt/ui-pro
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn remove @nuxt/ui-pro
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm uninstall @nuxt/ui-pro
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun remove @nuxt/ui-pro
bun add @nuxt/ui tailwindcss
```

::

::framework-only
#nuxt
:::div

2. 在`nuxt.config.ts`中将`@nuxt/ui-pro`替换为`@nuxt/ui`：

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro',
+   '@nuxt/ui'
  ]
})
```
:::

#vue
:::div

- import uiPro from '@nuxt/ui-pro/vite'

##  v3的更改

升级到Nuxt UI v4后，请注意以下重要更改：

### 重命名的按钮组

`ButtonGroup`组件已重命名为[`FieldGroup`](/docs/components/field-group)：

```diff
<template>
- <UButtonGroup>
+ <UFieldGroup>
    <UButton label="Button" />
    <UButton icon="i-lucide-chevron-down" />
+ </UFieldGroup>
- </UButtonGroup>
</template>
```

### 重命名的PageMarquee

`PageMarquee`组件已重命名为[`Marquee`](/docs/components/marquee)：

```diff
<template>
- <UPageMarquee :items="items" />
+ <UMarquee :items="items" />
</template>
```

### 删除PageAccordion

`PageAccordion`组件已被删除，以支持[`Accordion`](/docs/components/accordion)：

```diff
<template>
- <UPageAccordion
+ <UAccordion
    :items="items"
+   :unmount-on-hide="false"
+   :ui="{ trigger: 'text-base', body: 'text-base text-muted' }"
  />
</template>
```

::note
`PageAccordion`组件是一个包装器，它将`unmount-on-hide`设置为`false`并自定义`ui`属性。
::

### 重命名模型修改器

[`Input`](/docs/components/input)、[`InputNumber`](/docs/components/input-number)和[`Textarea`](/docs/components/textarea)使用的`modelModifiers`形状在v4中发生了变化：

1.  `nullify`修饰符被重命名为`nullable`（它将空值转换为`null`）。
2. 添加了一个新的`optional`修饰符（它将空值转换为`undefined`）。

```diff
- <UInput v-model.nullify="value" />
+ <UInput v-model.nullable="value" />
```

```diff
- <UTextarea v-model="value" :model-modifiers="{ nullify: true }" />
+ <UTextarea v-model="value" :model-modifiers="{ nullable: true }" />
```

当你想要空值时使用`nullable`作为`null`，当你喜欢`undefined`作为缺失值时使用`optional`。

### 表单组件的更改

`Form`组件在v4中得到了改进，具有更好的状态管理和嵌套表单处理。以下是您需要注意的关键更改：

1. 模式**转换将仅应用于**`@submit` data**，并且不再改变表单的状态。这提供了更好的可预测性，并防止意外的状态变化。
2. **嵌套表单必须使用`nested` prop显式启用**。这使组件行为更加显式，并防止意外创建嵌套表单。
3. **嵌套窗体现在应该提供`name`**属性（类似于`UFormField`），并将自动从父窗体继承其状态。

```diff
<template>
  <UForm :state="state" :schema="schema" @submit="onSubmit">
    <UFormField label="Customer" name="customer">
      <UInput v-model="state.customer" placeholder="Wonka Industries" />
    </UFormField>

    <div v-for="(item, index) in state.items" :key="index">
      <UForm
-       :state="item"
+       :name="`items.${index}`"
        :schema="itemSchema"
+       nested
      >
        <UFormField :label="!index ? 'Description' : undefined" name="description">
          <UInput v-model="item.description" />
        </UFormField>
        <UFormField :label="!index ? 'Price' : undefined" name="price">
          <UInput v-model="item.price" type="number" />
        </UFormField>
      </UForm>
    </div>
  </UForm>
</template>
```

### 已删除弃用的实用程序

一些以前在Nuxt UI Pro中可用的**Nuxt内容实用程序**在v4中已被**removed**：

- `findPageBreadcrumb`
- `findPageHeadline`

这些现在完全由Nuxt Content提供。请确保相应地更新您的导入和使用。

```diff
- import { findPageHeadline } from '@nuxt/ui-pro/utils/content'
+ import { findPageHeadline } from '@nuxt/content/utils'

- import { findPageBreadcrumb } from '@nuxt/ui-pro/utils/content'
+ import { findPageBreadcrumb } from '@nuxt/content/utils'
```

### AI SDK迁移（可选）

本节仅适用于使用AI SDK和聊天组件（`ChatMessage`，`ChatMessages`，`ChatPrompt`，`ChatPromptSubmit`，`ChatPalette`）的情况。如果您不使用AI功能，可以跳过本节。

1. 更新`package.json`中的`@ai-sdk/vue`和`ai`依赖项，并添加[Comark](https://comark.dev)（替换`@nuxtjs/mdc`以将AI响应渲染为流式Markdown）：

::framework-only
#nuxt
:::div
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/nuxt": "latest"
  }
}
```

将`@comark/nuxt`添加到您的模块：

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
+   '@comark/nuxt'
  ]
})
```
:::

#vue
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/vue": "latest"
  }
}
```
::

2.  `useChat`可组合API已更改：`input`和`handleSubmit`已被删除，以支持`sendMessage`，`messages`现在是您直接设置的引用：

```diff
<script setup lang="ts">
  import { useChat } from '@ai-sdk/vue'

- const { messages, input, handleSubmit, status, error, reload, setMessages } = useChat()
+ const { messages, status, error, sendMessage, regenerate, stop } = useChat()
+ const input = ref('')
+
+ function handleSubmit() {
+   sendMessage({ text: input.value })
+   input.value = ''
+ }
</script>
```

3. Messages现在使用`parts`而不是`content`：

```diff
// When manually creating messages
- setMessages([{
+ messages.value = [{
  id: '1',
  role: 'user',
- content: 'Hello world'
+ parts: [{ type: 'text', text: 'Hello world' }]
- }])
+ }]

// In templates
<template>
- <UChatMessage :content="message.content" />
+ <UChatMessage :parts="message.parts" />
</template>
```

4. 某些方法已被重命名：

```diff
// Regenerate the last message
- reload()
+ regenerate()
```

5. 将`<MDC>`替换为`<Markdown>`以实现基于部件的渲染。`Markdown`组件专为流式Markdown而构建，它会在令牌从AI到达时增量渲染令牌。使用AI SDK帮助程序和`@nuxt/ui/utils/ai`中的`isPartStreaming`实用程序。

::note
使用`shiki`插件时，将以下CSS添加到样式表以支持暗模式：

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::framework-only
#nuxt
```vue
<script setup lang="ts">
import { isReasoningUIPart, isTextUIPart } from 'ai'
import { isPartStreaming } from '@nuxt/ui/utils/ai'
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]
</script>

<template>
  <UChatMessages :messages="messages" :status="status">
    <template #content="{ message }">
      <template v-for="(part, index) in message.parts" :key="`${message.id}-${part.type}-${index}`">
        <UChatReasoning
          v-if="isReasoningUIPart(part)"
          :text="part.text"
          :streaming="isPartStreaming(part)"
        >
          <Markdown
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
        </UChatReasoning>

        <template v-else-if="isTextUIPart(part)">
          <Markdown
            v-if="message.role === 'assistant'"
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
          <p v-else-if="message.role === 'user'" class="whitespace-pre-wrap">
            {{ part.text }}
          </p>
        </template>
      </template>
    </template>
  </UChatMessages>
</template>
```
