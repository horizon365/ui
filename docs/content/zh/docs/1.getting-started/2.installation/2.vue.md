## Setup

### Add to a Vue project

::steps{level="4"}

#### 安装Nuxt UI包

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### 在您的`vite.config.ts`{lang="ts-type"}中添加Nuxt UI Vite插件

::code-group{sync="vite"}

```ts [vite.config.ts (Vite)]{3,8}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui()
  ]
})
```

```ts [vite.config.ts (Laravel Inertia)]{3,20-22}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import laravel from 'laravel-vite-plugin'

export default defineConfig({
  plugins: [
    laravel({
      input: ['resources/js/app.ts'],
      refresh: true
    }),
    vue({
      template: {
        transformAssetUrls: {
          base: null,
          includeAbsolute: false
        }
      }
    }),
    ui({
      router: 'inertia'
    })
  ]
})
```

```ts [vite.config.ts (AdonisJS Inertia)]{3,15-17}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'
import adonisjs from '@adonisjs/vite/client'
import inertia from '@adonisjs/inertia/client'

export default defineConfig({
  plugins: [
    adonisjs({
      entrypoints: ['inertia/app/app.ts'],
      reload: ['resources/views/**/*.edge']
    }),
    inertia(),
    vue(),
    ui({
      router: 'inertia'
    })
  ]
})
```

::

::tip
Nuxt UI注册了`unplugin-auto-import`和`unplugin-vue-components`，这将生成`auto-imports.d.ts`和`components.d.ts`类型声明文件。您可能希望gitignore这些文件，并将它们添加到您的`tsconfig`中。

```json [tsconfig.app.json]
{
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue", "auto-imports.d.ts", "components.d.ts"]
}
```

```bash [.gitignore]
# Auto-generated type declarations
auto-imports.d.ts
components.d.ts
```

::

::warning
这些声明文件仅在Vite运行时写入。默认的`create-vue``build`脚本与`vite build`（`run-p type-check "build-only {@}"`）并行运行`vue-tsc`，因此在清理签出时，类型检查可能会在文件存在之前启动，并因错误（如`Cannot find name 'useToast'`）而失败。请在构建后运行类型检查，以便首先生成声明。

```json [package.json]
{
  "scripts": {
    "build": "run-s build-only type-check"
  }
}
```

::

::tip
在内部，Nuxt UI依赖于自定义别名来解析主题类型。如果您使用的是TypeScript，请将这些别名添加到您的`tsconfig`文件中，以便在`vite.config.ts`中启用自动完成。

```json [tsconfig.node.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui": [
        "./node_modules/.nuxt-ui/ui"
      ]
    }
  }
}
```

```json [tsconfig.app.json]
{
  "compilerOptions": {
    "paths": {
      "#build/ui/*": [
        "./node_modules/.nuxt-ui/ui/*"
      ]
    }
  }
}
```
::

#### 使用Nuxt UI Vue插件

::code-group{sync="vite"}

```ts [src/main.ts (Vite)]{3,14}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

app.use(router)
app.use(ui)

app.mount('#app')
```

```ts [resources/js/app.ts (Laravel Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import ui from '@nuxt/ui/vue-plugin'
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers'
import { createApp, h } from 'vue'

const appName = import.meta.env.VITE_APP_NAME || 'Laravel x Nuxt UI'

createInertiaApp({
  title: title => (title ? `${title} - ${appName}` : appName),
  resolve: name =>
    resolvePageComponent(
      `./pages/${name}.vue`,
      import.meta.glob<DefineComponent>('./pages/**/*.vue')
    ),
  setup({ el, App, props, plugin }) {
    createApp({ render: () => h(App, props) })
      .use(plugin)
      .use(ui)
      .mount(el)
  }
})
```

```ts [inertia/app/app.ts (AdonisJS Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import ui from '@nuxt/ui/vue-plugin'
```

::code-group{sync="vite"}

```html [index.html (Vite)]{9}
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Nuxt UI</title>
  </head>
  <body>
    <div id="app" class="isolate"></div>

```

```blade [resources/views/app.blade.php (Laravel Inertia)]{10}
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1">
    @inertiaHead
    @vite('resources/js/app.ts')
  </head>
  <body>
    <div class="isolate">
        @inertia
    </div>
  </body>
</html>
```

```edge [resources/views/inertia_layout.edge (AdonisJS Inertia)]{10}
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1">
    @inertiaHead()

  </head>
```

## Options

您可以通过在`vite.config.ts`中提供选项来自定义Nuxt UI。

### `prefix`

使用`prefix`选项更改组件的前缀。

- Default：`U`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prefix: 'Nuxt'
    })
  ]
})
```

### `ui`

使用`ui`选项为Nuxt UI提供配置。这是Nuxt的`app.config.ts`中的`ui`键的Vue等效项。

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'green',
          neutral: 'slate'
        }
      }
    })
  ]
})
```

### `dts`

使用`dts`选项可以启用或禁用为自动导入的组件和可组合项生成声明文件。

- Default：`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      dts: false
    })
  ]
})
```

### `icon`

使用`icon`选项为[Icon](/docs/components/icon)组件设置默认道具（`size`，`mode`，`customize`），并通过`clientBundle`配置构建时图标绑定。Nuxt UI自身图标的绑定在安装其集合时默认启用。设置`clientBundle: false`选择退出。

- 默认：`{}`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      icon: {
        mode: 'svg',
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

::note{to="/docs/getting-started/integrations/icons/vue#collections"}
在**Icons**文档中了解有关图标集合和客户端捆绑的更多信息。
::

### `colorMode`

使用`colorMode`选项启用或禁用来自`@vueuse/core`的颜色模式集成。

- Default：`true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```

### `theme.colors`

使用`theme.colors`选项定义用于生成组件主题的动态颜色别名。

- Default：`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: ['primary', 'error']
      }
    })
  ]
})
```

::note
每个别名都会在具有颜色变体的组件主题中生成一整套`--ui-color-*`阴影和变体，无论您的应用是否使用它。将列表修剪为您实际使用的别名，如果您使用表单，则保留`error`，因为验证样式依赖于它。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
在“主题”部分了解有关颜色自定义和主题化的更多信息。
::

### `theme.transitions`

使用`theme.transitions`选项启用或禁用组件上的转换。

- Default：`true`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        transitions: false
      }
    })
  ]
})
```

::note
此选项在具有悬停或活动状态的组件上添加`transition-colors`类。
::

### `theme.unstyled`：徽章{label="4.9+" class="align-text-top"}

使用`theme.unstyled`选项可从组件中删除所有默认主题类，仅保留其结构和通过`class`、`ui`或`app.config.ui`提供的类。

- Default：`false`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        unstyled: true
      }
    })
  ]
})
```

::warning
这也剥离了**structural**类（定位、过渡、flex/grid），而不仅仅是修饰类。像`Modal`、`Drawer`或`Calendar`这样的布局重的组件需要你重新提供它们的布局，类似于PrimeVue的无样式模式。
::

### `theme.defaultVariants`

使用`theme.defaultVariants`选项可替代元件的默认`color`和`size`变体。

仅替换恰好为`primary`或`md`的默认值，因此头像保留`color: 'neutral'`，分隔符保留`size: 'xs'`。

- Default：`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [vite.config.ts] {9-14}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        defaultVariants: {
          color: 'neutral',
          size: 'sm'
        }
      }
    })
  ]
})
```

### `theme.prefix`：badge{label="4.2+" class="align-text-top"}

使用`theme.prefix`选项来配置您在Tailwind CSS导入中设置的相同前缀。这可以确保Nuxt UI组件使用正确的前缀实用程序类和CSS变量。

::code-group

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        prefix: 'tw'
      }
    })
  ]
})
```

```css [src/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

这将自动为Nuxt UI组件主题中的所有Tailwind实用程序类和CSS变量添加前缀：

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
在Tailwind CSS文档中了解有关使用前缀的更多信息。
::

### `prose`

使用`prose`选项启用Nuxt UI[`Prose`components](/docs/typography)及其主题。

- Default：`false`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```

### `autoImport`

使用`autoImport`选项禁用可组合的自动导入或自定义[`unplugin-auto-import`](https://github.com/unplugin/unplugin-auto-import)选项。

- Default：`{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      autoImport: false
    })
  ]
})
```

::note
禁用后，您仍然可以从`@nuxt/ui/composables`显式导入可组合对象。
::

### `components`

使用`components`选项禁用组件自动导入或自定义[`unplugin-vue-components`](https://github.com/unplugin/unplugin-vue-components)选项。

- Default：`{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      components: false
    })
  ]
})
```

::note
禁用后，您仍然可以显式导入组件，例如`import Button from '@nuxt/ui/components/Button.vue'`或`import ProseCode from '@nuxt/ui/components/prose/Code.vue'`。
::

### `router`：徽章{label="4.3+" class="align-text-top"}

使用`router`选项配置路由集成。这对于不使用`vue-router`的应用程序（如Electron应用程序、MPA或诸如](https://inertiajs.com/)或[Hybridly](https://hybridly.dev/)等框架）非常有用。

- Default：`true`{lang="ts-type"}

| 值|描述|
| ----- | ----------- |
| `true`{lang="ts-type"}|将`vue-router`用于带`RouterLink`组件的导航。|
| `false`{lang="ts-type"}|禁用路由集成，链接呈现为普通的`<a>`标记。|
| `'inertia'`{lang="ts-type"}|使用Inertia.js及其`Link`组件进行导航。|

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      router: false
    })
  ]
})
```

::tip
您可以通过在Vite配置中设置`router: false`，并在安装Vue插件时传递一个函数，为**Hybridly**等框架提供自定义导航逻辑：

```ts [src/main.ts]
import ui from '@nuxt/ui/vue-plugin'
import { router } from 'hybridly'

app.use(ui, {
  router: (event, { href, external }) => {
    if (external) {
      return
    }

    event.preventDefault()

    router.navigate({ url: href })
  }
})
```
::

::note
当设置为`false`或`'inertia'`时，不需要将`vue-router`作为依赖项。
::

### `scanPackages`：徽章{label="4.3+" class="align-text-top"}

使用`scanPackages`选项指定应使用Nuxt UI扫描组件的其他npm包。当您拥有内部使用Nuxt UI组件的共享组件库时，这很有用。

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      scanPackages: ['@my-org/ui-components']
    })
  ]
})
```

::note
默认情况下，只扫描`@nuxt/ui`。当您的外部包包含使用Nuxt UI的Vue组件时，请使用此选项。
::

### `root`：徽章{label="4.9+" class="align-text-top"}

使用`root`选项覆盖Nuxt UI生成其`.nuxt-ui`目录的目录（包含主题模板），默认使用Vite的`root`，但在像[`electron-vite`](https://electron-vite.org/)这样的设置中，渲染器的`root`指向子目录（例如`src/renderer`），所以模板落在`src/renderer/node_modules/.nuxt-ui`中，Tailwind不会扫描它们，导致像`bg-default`、`ring-default`和`divide-default`这样的主题类丢失。

```ts [electron.vite.config.ts] {12}
import { defineConfig } from 'electron-vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  renderer: {
    root: 'src/renderer',
    plugins: [
      vue(),
      ui({
        root: __dirname
      })
    ]
  }
})
```

::note
将`root`指向您的项目根目录，以便生成的`.nuxt-ui`目录最终位于Tailwind扫描的`node_modules`中。
::

### `experimental.componentDetection`：徽章{label="4.11+" class="align-text-top"}

使用`experimental.componentDetection`选项为树抖动启用自动组件检测。此功能扫描您的源代码以检测实际使用的组件，并仅为这些组件生成必要的CSS（包括它们的依赖项）。如果没有它，Vite插件会为每个组件生成主题CSS。检测覆盖Vite根，在[`scanPackages`](#scanpackages)中列出的软件包以及位于根目录外部的[`components`](#components)选项中的任何`dirs`。

- Default：`false`{lang="ts-type"}
- Type：`boolean | string[]`{lang="ts-type"}

**启用自动检测：**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: true
      }
    })
  ]
})
```

**包括用于动态使用的附加组件：**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      experimental: {
        componentDetection: ['Modal', 'DropdownMenu', 'Popover']
      }
    })
  ]
})
```

::note
当提供组件名称数组时，将启用自动检测，并保证包含这些组件（沿着及其依赖项）。这对于无法静态分析的动态组件（如`<component :is="..." />`）非常有用。
::

::warning
新使用的组件会在下次启动开发服务器时被拾取。如果你添加了一个组件，但它的样式丢失了，请重新启动开发服务器。
::

## Continuous releases

Nuxt UI使用pkg.pr.new @@进行持续预览发布，为开发者提供即时访问最新功能和bug修复的机会，而无需等待官方发布。

自动预览版本是为`v4`分支的所有提交和PR创建的。通过将您的包版本替换为特定的提交哈希或PR编号来使用它们。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
pkg.pr.new @@将自动对带有安装URL的PR进行注释，从而可以轻松测试更改。
::
