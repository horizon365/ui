## 设置

### 添加到Nuxt项目

::steps{level="4"}

#### 安装Nuxt UI包

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### 在您的`nuxt.config.ts`{lang="ts-type"}中添加Nuxt UI模块

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
无需将`@nuxt/icon`、`@nuxt/fonts`或`@nuxtjs/color-mode`添加到`modules`阵列中，因为Nuxt UI会自动注册它们。您仍然可以使用`icon`、`fonts`和`colorMode`键在`nuxt.config.ts`中配置这些模块。
::

#### 在CSS中导入Tailwind CSS和Nuxt UI

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
当使用[Nuxt Layers](https://nuxt.com/docs/getting-started/layers)时，模块会自动为每个层目录生成[`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive)指令，确保Tailwind CSS扫描所有层源文件以查找实用程序类。
::

::callout{icon="i-simple-icons-visualstudiocode"}
建议为VSCode安装[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)扩展，并添加以下设置：

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### 使用App组件包装您的应用

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
`App`组件设置全局配置，**Toast**、**Tooltip**和**编程覆盖**需要该组件。
::

::

## 选项

您可以通过在`nuxt.config.ts`中提供选项来自定义Nuxt UI。

### `prefix`

使用`prefix`选项更改组件的前缀。

- 默认值：`U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

使用`fonts`选项启用或禁用[`@nuxt/fonts`](https://github.com/nuxt/fonts)模块。

- 默认值：`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### `colorMode`

使用`colorMode`选项启用或禁用[`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode)模块。

- 默认值：`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### `theme.colors`

使用`theme.colors`选项定义用于生成组件主题的动态颜色别名。

- 默认值：`['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
每个别名都会在具有颜色变体的组件主题中生成一整套`--ui-color-*`阴影和变体，无论您的应用是否使用它。将列表修剪为您实际使用的别名，如果您使用表单，请保留`error`，因为验证样式依赖于它。
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
在“主题”部分了解有关颜色自定义和主题化的更多信息。
::

### `theme.transitions`

使用`theme.transitions`选项启用或禁用组件上的转换。

- 默认值：`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
此选项将`transition-colors`类添加到具有悬停或活动状态的组件上。
::

### `theme.unstyled`：badge{label="4.9+" class="align-text-top"}

使用`theme.unstyled`选项从组件中删除所有默认主题类，只保留它们的结构和通过`class`、`ui`或`app.config.ui`提供的类。

- 默认值：`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
这也剥离了**structural**类（定位，过渡，flex/grid），而不仅仅是装饰性的。像`Modal`，`Drawer`或`Calendar`这样的布局重的组件需要你重新提供它们的布局，类似于PrimeVue的无样式模式。
::

### `theme.defaultVariants`

使用`theme.defaultVariants`选项覆盖组件的默认`color`和`size`变体。

只有完全为`primary`或`md`的默认值才会被替换，因此Avatar保留`color: 'neutral'`，Separator保留`size: 'xs'`。

- 默认值：`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix`：badge{label="4.2+" class="align-text-top"}

使用`theme.prefix`选项来配置您在Tailwind CSS导入中设置的相同前缀。这可以确保Nuxt UI组件使用正确的前缀实用程序类和CSS变量。

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
您可能需要启用`fonts.processCSSVariables`才能对`@nuxt/fonts`模块使用prefix选项：

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

这将自动为Nuxt UI组件主题中的所有Tailwind实用程序类和CSS变量添加前缀：

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
在Tailwind CSS文档中了解有关使用前缀的更多信息。
::

### `prose`

使用`prose`选项强制导入Nuxt UI [`Prose`组件](/docs/typography)，即使未安装`@nuxtjs/mdc`、`@nuxt/content`或`@comark/nuxt`。

- 默认值：`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc`：badge{label="Deprecated" color="warning" class="align-text-top"}

请改用[`prose`](#prose)选项。

### `content`

使用`content`选项强制导入Nuxt UI散文和内容组件，即使未安装`@nuxt/content`。

- 默认值：`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection`：badge{label="4.1+" class="align-text-top"}

使用`experimental.componentDetection`选项启用自动组件检测以进行树抖动。此功能扫描您的源代码以检测实际使用的组件，并仅为这些组件（包括其依赖项）生成必要的CSS。

- 默认值：`false`{lang="ts-type"}
- 类型：`boolean | string[]`{lang="ts-type"}

**启用自动检测：**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**包含用于动态使用的附加组件：**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
当提供一个组件名数组时，会启用自动检测，并保证这些组件（沿着它们的依赖项）被包含在内。这对于像`<component :is="..." />`这样不能静态分析的动态组件很有用。
::

## 连续发布

Nuxt UI使用[pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)进行持续预览发布，为开发人员提供即时访问最新功能和错误修复，而无需等待官方发布。

自动预览版本是为`v4`分支的所有提交和PR创建的。使用它们时，请将您的包版本替换为特定的提交哈希或PR编号。

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**会自动对带有安装URL的PR进行注释，从而可以轻松测试更改。
::
