##  사용

PageGrid 구성 요소는 [PageCard](/docs/components/page-card) 구성 요소 또는 다른 요소를 표시하는 응답형 그리드 레이아웃을 제공하며 화면 크기에 따라 1-3열을 자동으로 조정합니다.

::component-example
---
이름: "page-grid-example"
클래스: P-8
---
::

또한 `col-span-*` 및 `row-span-*` 유틸리티 클래스를 사용하여 bento 스타일 레이아웃에 카드 목록을 표시하는 데 사용할 수도 있습니다.

::component-example
---
축소: true
이름: 'page-grid-bento-example'
클래스: P-8
---
::
