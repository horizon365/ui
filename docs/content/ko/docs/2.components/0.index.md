##  Layout

응용 프로그램의 레이아웃을 구성하고 UI에 대한 일관된 기반을 설정하기 위한 핵심 구조 구성 요소입니다.Core structural components for organizing your application's layout and establishing a consistent foundation for your UI.

: components-list {category="layout"}

##  요소

직관적이고 일관된 사용자 환경을 만들기 위한 버튼, 배지, 아바타, 아이콘 및 기타 기본 인터페이스 요소를 포함하는 필수 UI 구성 요소입니다.

:components-list {category="element"}

##  양식

텍스트 입력, 선택, 확인란, 라디오 그룹, 스위치, 슬라이더 및 전체 양식 유효성 검사를 포함하여 대화형 사용자 입력 환경을 구축하기 위한 포괄적인 양식 구성 요소

:components-list {category="form"}

##  데이터

테이블, 아코디언, 캐로셸, 타임라인, 트리 및 사용자 프로파일을 포함하여 데이터를 표시하고 구성하는 구성요소입니다.

:components-list {category="data"}

##  내비게이션

메뉴, 빵 부스러기, 페이지 매김, 탭, 스텝퍼, 링크 및 명령 팔레트를 포함하여 사용자 탐색 및 경로 찾기를 위한 구성요소

:components-list {category="navigation"}

##  오버레이

기본 컨텐트 위에 표시되는 부동 UI 요소로 모달, 팝업, 도구 설명, 드로어, 슬라이드오버 및 컨텍스트 메뉴가 있습니다.

:components-list {category="overlay"}

##  페이지

소개 페이지, 블로그, 가격 페이지 및 기타 마케팅 자료를 작성하기 위한 사전 구축된 마케팅 및 컨텐츠 섹션입니다.

:components-list {category="page"}

::note{to="https://github.com/nuxt-ui-templates/saas" target="_blank"}
GitHub에서 **SaaS 템플릿**를 확인하여 실제 예제를 확인하십시오.
::

##  대시보드

크기 조정 가능한 패널, 축소 가능한 사이드바, 도구 모음 및 검색 기능을 사용하여 동적 대시보드를 구축하기 위한 특수 구성 요소입니다.

:components-list {category="dashboard"}

::note{icon="i-simple-icons-github"}
GitHub에서 [`Nuxt`](https://github.com/nuxt-ui-templates/dashboard) 및 [`Vue`](https://github.com/nuxt-ui-templates/dashboard-vue 대시보드 템플릿을 확인하여 실제 예제를 보십시오.
::
