##  사용

PageList 구성 요소는 컨텐츠를 세로 목록 레이아웃으로 표시하는 유연한 방법을 제공합니다. [PageCard](/docs/components/page-card) 구성 요소 또는 항목 간에 선택적으로 구분할 수 있는 다른 요소의 스택 목록을 만드는 데 적합합니다.

::component-example
---
축소: true
이름: 'page-list-example'
소품 :
  클래스 : 'w-full'
---
::

###  Divide

`divide`prop 을 사용하여 각 자식 요소 사이에 구분자를 추가합니다.

::component-example
---
축소: true
이름: 'page-list-divide-example'
소품 :
  클래스: 'w-full'
---
::
