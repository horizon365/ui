## List 목록

Markdown은 다양한 콘텐츠 요구에 맞게 정렬되지 않은, 정렬된, 중첩된 목록을 지원합니다.Markdown supports unordered, ordered, and nested list for various content needs.

### 순서가 지정되지 않은 목록

특정 순서가 없는 항목에는 순서가 없는 목록을 사용합니다. `-` 기호로 각 항목을 시작합니다.

::tabs{class="gap-0"}

::code-preview{label="미리보기" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I는 목록 항목입니다.
- I는 다른 목록 항목입니다.
- I는 마지막 목록 항목입니다.

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### 순서 리스트

프로세스의 단계와 같이 품목 주문이 중요할 때 순서 목록을 사용합니다. 각 항목을 숫자로 시작합니다.

::tabs{class="gap-0"}

::code-preview{label="미리보기" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. I는 목록 항목입니다.
2. I는 또 다른 목록 항목입니다.
3. I는 마지막 목록 항목입니다.

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### 중첩된 목록

복잡한 구조에 대한 하위 항목이 있는 계층 목록을 만듭니다. 중첩할 하위 항목을 네 개의 공백으로 들여씁니다.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I는 리스트 항목입니다.
  - I는 중첩된 목록 항목입니다.
  - I는 또 다른 중첩된 목록 항목입니다.
- I는 또 다른 목록 항목입니다.
  - 다른 중첩된 항목
    - 깊은 중첩 항목
    - 다른 깊은 중첩 항목
  - 두 번째 레벨로 돌아가기

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### 혼합 목록

복잡한 계층에 대해 정렬된 목록과 정렬되지 않은 목록을 결합할 수 있습니다.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. 첫 번째 주 단계
   - 하위 요구 사항 A
   - 하위 요구 사항 B
2. 두 번째 주요 단계
   - 다른 하위 항목
   - Final 하위 항목
3. 최종 단계

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## 테이블

행과 열에 구조화된 데이터를 명확하게 표시합니다. 테이블은 데이터를 비교하거나 등록 정보를 나열하는 데 적합합니다.

::tabs{class="gap-0"}

::code-preview{label="미리보기" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| 프로프 (Prop)    | 기본 값 (Default)   | 유형 (Type)                     |
|---------|-----------|--------------------------|
| `name`|           | `string`{lang="ts-type"}|
| `size` 이미지| `md`      | `string`{lang="ts-type"}|
| `color`| `neutral` 이미지| `string`{lang="ts-type"}|

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
