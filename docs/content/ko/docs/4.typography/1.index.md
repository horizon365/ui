Nuxt UI는 markdown 콘텐츠에 대해 **Prose components** 스타일을 아름답게 지정합니다. markdown을 라이브러리로 렌더링하든 산문 구성 요소를 직접 사용하든 Nuxt UI는 디자인 시스템을 적용하여 컨텐츠가 응용 프로그램의 테마에 맞게 자동으로 적응할 수 있습니다.

::framework-only
#nuxt 코드
:::div

::::note
Prose 구성 요소는 [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc)[`@nuxt/content`](](https://github.com/nuxt/contenthttps://github.com/nuxt/contenthttps://github.com/nuxt/content)또는))https://github.com/nuxt/contenthttps://github.com/nuxt/content 또는 사용할 때 사용할 때 경우 자동으로 활성화됩니다.[`prose`](/docs/getting-started/installation/nuxt#prose) 옵션을 사용하도록 설정합니다.

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
Nuxt Content 설치 및 설정에 대해서는 **Content integration**guide를 참조하십시오.
::::

#vue #vue
:::note
Vue에서 산문 구성 요소를 사용하려면 [`prose`](/docs/getting-started/installation/vue#prose) 옵션을 사용하도록 설정해야 합니다.

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```

##  사용

::framework-only
#nuxt 코드
:::div
스타일이 지정된 컨텐츠를 렌더하는 방법은 다음과 같습니다.

1. **Markdown rendering**: ContentRenderer, MDC, Markdown 또는 MarkdownDocument를 사용하여 자동 산문 스타일을 사용하여 Markdown을 렌더링합니다.
2. **Direct Vue use**: Vue 템플릿에서 직접 산문 구성 요소를 가져오고 사용하십시오.
:::

#vue #vue
:::div
스타일이 지정된 컨텐츠를 렌더링하는 방법은 다음과 같습니다.

1. **Markdown rendering**: Markdown 또는 MarkdownDocument를 사용하여 자동 산문 스타일 지정을 사용하여 Markdown 렌더링
2. **Direct Vue use**: Vue 템플릿에서 직접 산문 구성 요소를 가져오고 사용하십시오.

###  ContentRenderer와 함께: badge{label="Nuxt only" color="warning" class="align-text-top"}

[`@nuxt/content`](https://github.com/nuxt/content)를 사용하는 경우 [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer) 구성요소로 수집 페이지를 렌더링합니다.

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### MDC 구성요소 포함: badge{label="Nuxt only" color="warning" class="align-text-top"}

[`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) 또는 [](https://github.com/nuxt/content) 을 사용하는 경우 [`@nuxtjs/mdc`]( 태그를 사용하여 ]( 태그를 렌더링하는 데 사용할 때 [PH04`@nuxtjs/mdc`]( 태그 문자열을 사용하여 @PH05@ 태그를 사용하여 렌더링하십시오.

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc`은(는) 더 이상 사용되지 않습니다. [Comark](https://comark.dev)를 위해 사용자의 기존 마크다운 파일은 호환되며 콘텐츠 변경이 필요하지 않습니다.

###  Markdown 구성요소 포함

[Comark](https://comark.dev)는 스트리밍 지원을 통해 마크다운을 렌더링합니다. 토큰이 도착하면 토큰을 점진적으로 렌더링하여 AI 채팅 응답과 기타 동적 마크다운 콘텐츠에 이상적입니다.

::framework-only
#nuxt 코드
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue #vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
`shiki` 플러그인은 코드 블록에 구문 강조 표시를 추가합니다. AI 응답과 같이 점진적으로 도착하는 컨텐츠를 렌더링할 때는 `:streaming`prop을 사용하십시오.

다크 모드를 지원하려면 스타일시트에 다음 CSS를 추가합니다.

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
Comark를 사용하여 AI 채팅 메시지를 렌더링하는 전체 예는 **Chat** 구성 요소를 참조하십시오.

###  MarkdownDocument 사용

[`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code) 구성 요소를 사용하여 구문 분석 `MarkdownDocument` 구성 요소를 브라우저에 전달하지 않고 렌더링합니다. 이는 서버에서, 빌드 단계에서 또는 API를 통해 구문 분석이 수행될 때 유용합니다.

::framework-only
#nuxt #nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue #vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### Prose 구성 요소 포함

최대 제어를 위해 Vue 템플릿에서 직접 산문 구성 요소를 사용합니다.Use prose components directly in Vue templates for maximum control:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

##  테마

앱 구성에서 산문 구성 요소 스타일 지정을 재정의합니다.Override any prose component styling in your app configuration:

::framework-only
#nuxt 코드
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue #vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
