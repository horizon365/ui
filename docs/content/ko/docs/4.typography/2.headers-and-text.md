##  헤더

제목을 사용하여 내용을 구성하고 쉽게 읽을 수 있습니다.

제목은 `id`가 있을 때 앵커 링크로 래핑될 수 있으며, 해시 아이콘은 `H2` 및 `H3` (큰 화면에서)에 대한 해시 아이콘으로 표시되므로 독자가 섹션에 직접 연결할 수 있습니다.

앵커 링크는 기본적으로 `H2`에서 `H4`에 대해 활성화되며, 그렇지 않으면 비활성화됩니다.[Comark](https://comark.dev) 포함. [`Theme`](/docs/components/theme 구성 요소를 사용하여 ) 구성 요소를 `anchor`prop 앱의 섹션에 대해 토글 합니다.prop to toggle them for a section of your app:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt #nuxt
:::div

::::note
`@nuxt/content`를 사용할 때, 앵커 링크는 `H2`, `H3` 및 `H4` 에 대해 기본적으로 활성화됩니다. 이들의 [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)를 제어할 수 있습니다.(예를 들어, AI 채팅 인터페이스에 대해 비활성화하려면) 및 [toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc) @ @ @ `nuxt.config.ts` :

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
