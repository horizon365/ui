## Headings 파일

제목을 사용하여 내용을 구성하고 쉽게 읽을 수 있습니다.

제목은 `id`가 있을 때 앵커 링크로 래핑될 수 있으며, `H2` 및 `H3`에 대한 해시 아이콘이 hover에 표시되어 있으므로 독자가 섹션에 직접 연결할 수 있습니다.

앵커 링크는 `@nuxt/content`를 사용하는 경우 `H2`에서 `H4`까지 기본적으로 활성화되고, 다른 경우에는 [Comark](https://comark.dev)가 포함되어 있습니다. [`Theme`](/docs/components/theme) 구성 요소를 `anchor` 섹션과 함께 사용하여 응용 프로그램의 prop 섹션을 전환합니다.

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
`@nuxt/content`를 사용하는 경우 `H2`, `H3` 및 `H4`에 대한 앵커 링크가 기본적으로 활성화됩니다. [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)(예: AI 채팅 인터페이스에 대해 비활성화) 및 [toc generation](xph03032x를 제어할 수 있습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
