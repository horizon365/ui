###  언어

구문 강조 표시는 수십 개의 프로그래밍 언어에서 사용할 수 있습니다.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <UButton @click="updateMessage">
      Click me
    </UButton>
  </div>
</template>
```

# 코드

````html
```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = '버튼을 클릭했습니다!'
}
</script>

<template>
  <div>
    <h1> {{ message }} </h1>
    <UButton @click="updateMessage">
      나를 클릭하십시오.
    </UButton>
  </div>
</template>
```
````

::tip
기본적으로 `material-theme-lighter` 및 `material-theme-palenight`Shiki 테마는 밝은 모드와 어두운 모드에 각각 사용됩니다. `@nuxt/content`를 사용하면 [`content.build.markdown.highlight`](https://content.nuxt.com/docs/getting-started/configuration#highlight) 키를 통해 변경할 수 있습니다. `nuxt.config.ts` 독립형 모드에서 `nuxt.config.ts` ) 키를 사용할 때.[`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations)key.[Comark](https://comark.dev) 플러그인 옵션을 사용하여 테마를 구성합니다.

Comark를 사용하여 어두운 모드를 지원하려면 스타일시트에 다음 CSS를 추가합니다.

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

###  파일 이름

코드 블록은 자동 아이콘 검색을 통해 파일 이름 표시를 지원합니다.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

# 코드

````mdc
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```
````

::

::tip
파일 이름 아이콘은 `ProseCodeIcon` 구성 요소에 의해 렌더링되며 앱 구성에서 사용자 지정할 수 있는 미리 정의된 아이콘 집합을 포함합니다.The filename icon is rendered by the `ProseCodeIcon` component and contains a set of predefined icons which you can customize in your app configuration:

::framework-only
#nuxt 코드
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue #vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
이러한 파일 이름 아이콘은 [`vscode-icons`](https://icones.js.org/collection/vscode-icons) 모음에서 가져온 것이며, 나머지 구성 요소가 사용하는 `lucide` 아이콘과는 별도로 파일 확장자에서 필요에 따라 해결됩니다. 다른 모음과 마찬가지로 `@iconify-json/vscode-icons`을 설치하여 로컬 및 오프라인으로 서비스를 제공합니다.
::

### 복사 단추

모든 코드 블록에는 코드를 클립보드에 복사하는 기본 제공 복사 단추가 있습니다.

`copy`prop을 `false`로 설정하여 버튼을 숨기거나 [Button](/docs/components/button)props를 전달하여 사용자 정의합니다.

::tip
앱 구성에서 `ui.icons.copy` 및 `ui.icons.copyCheck` 키를 사용하여 아이콘을 변경할 수 있습니다.

::framework-only
#nuxt 코드
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue #vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

### 코드 diff

`diff` 언어를 사용하여 코드 버전 간의 변경 사항을 표시합니다.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

# 코드

````mdc
```diff [nuxt.config.ts]
export default defineNuxtConfig({
  모듈 : [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```
````
