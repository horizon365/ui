##  사용

`badge` 구성 요소의 기본 슬롯에 markdown을 사용하여 콘텐츠에 [Badge](/docs/components/badge)를 표시합니다.

::code-preview

:::badge
** v 4. 0. 0 **
:::

# 코드

```mdc
::badge
**v4.0.0**
::
```
