### Zoom 이미지

기본적으로 이미지는 대화식 확대/축소를 지원합니다. 이미지를 클릭하면 부드러운 전환이 있는 모달 오버레이에서 이미지가 열리므로 사용자가 세부 정보를 보다 자세히 검토할 수 있습니다.

특정 이미지에서 확대되지 않도록 하려면 `:zoom="false"` 특성을 추가합니다.

::code-preview{class="[&>div>p]:my-0"}
![ zoom 없는 이미지 ](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}

# 코드

```mdc
![Image without zoom](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}
```
