Nuxt UI v4는 중요한 이정표를 표시합니다. **Nuxt UI와 Nuxt UI Pro는 이제 완전히 오픈 소스 및 무료 라이브러리 **로 통합되었습니다. 이제 125개 이상의 프로덕션 준비 구성 요소에 액세스할 수 있으며 모두 `@nuxt/ui` 패키지로 제공됩니다.

::note
Nuxt UI v4에는 특정 종속성으로 인해 **Nuxt 4.1 이상의 **가 필요합니다. Nuxt UI v4로 마이그레이션하기 전에 업그레이드하십시오.
::

이 가이드에서는 애플리케이션을 v3에서 v4로 마이그레이션하는 단계별 지침을 제공합니다.

## 프로젝트 마이그레이션

###  Nuxt UI Pro에서

1.  @ `@nuxt/ui-pro` 을 `@nuxt/ui` 로 바꾸기 @@ @ `package.json` :

::code-group{sync="pm"}

```bash [pnpm]
pnpm remove @nuxt/ui-pro
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn remove @nuxt/ui-pro
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm uninstall @nuxt/ui-pro
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun remove @nuxt/ui-pro
bun add @nuxt/ui tailwindcss
```

::

::framework-only
#nuxt #nuxt
:::div

2.  @ `@nuxt/ui-pro` 을 `@nuxt/ui` 로 바꾸기 @@ @ `nuxt.config.ts` :

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro',
+   '@nuxt/ui'
  ]
})
```
:::

#vue #vue
:::div

2.  @ `@nuxt/ui-pro` 을 `vite.config.ts` 로 바꾸기 @@ `@nuxt/ui` 로 바꾸기 @@ `vite.config.ts`:

```diff [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
- import uiPro from '@nuxt/ui-pro/vite'
+ import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
-   uiPro({
+   ui({
      ui: {
        colors: {
          primary: 'green',
          neutral: 'slate'
        }
      }
    })
  ]
})
```
:::

#nuxt #nuxt
:::div

4. CSS에서 `@nuxt/ui-pro`를 `@nuxt/ui`로 바꿉니다.

```diff [app/assets/css/main.css]
- @import "@nuxt/ui-pro";
```

```diff [app/assets/css/main.css]
- @source "../../content/**/*";
+ @source "../../../content/**/*";
```
::::

## v3에서의 변경사항

Nuxt UI v4로 업그레이드한 후에는 다음과 같은 중요한 변경 사항에 유의하십시오.

### 이름이 ButtonGroup으로 변경됨

`ButtonGroup` 구성 요소의 이름이 [`FieldGroup`](/docs/components/field-group)로 변경되었습니다.

```diff
<template>
- <UButtonGroup>
+ <UFieldGroup>
    <UButton label="Button" />
    <UButton icon="i-lucide-chevron-down" />
+ </UFieldGroup>
- </UButtonGroup>
</template>
```

### PageMarquee로 이름 변경

`PageMarquee` 구성 요소의 이름이 [`Marquee`](/docs/components/marquee)로 변경되었습니다.

```diff
<template>
- <UPageMarquee :items="items" />
+ <UMarquee :items="items" />
</template>
```

### 삭제 PageAccordion

`PageAccordion` 구성 요소는 [`Accordion`](/docs/components/accordion)를 위해 제거되었습니다.

```diff
<template>
- <UPageAccordion
+ <UAccordion
    :items="items"
+   :unmount-on-hide="false"
+   :ui="{ trigger: 'text-base', body: 'text-base text-muted' }"
  />
</template>
```

::note
`PageAccordion` 구성요소는 `unmount-on-hide`를 `false`로 설정하고 `ui`prop을 사용자 정의하는 래퍼입니다.
::

###  이름 변경된 모델 수정자

[`modelModifiers` 쉐이프는 ](/docs/components/input)[`InputNumber` ]( /docs/components/input-number 및 ) [ @ 에 의해 사용되었습니다.

1.  `nullify` 수정자의 이름이 `nullable`로 변경되었습니다(비어 있거나 빈 값을 `null`로 변환).
2.  새 `optional` 수정자가 추가되었습니다 (비어 있거나 빈 값을 `undefined`로 변환).

```diff
- <UInput v-model.nullify="value" />
+ <UInput v-model.nullable="value" />
```

```diff
- <UTextarea v-model="value" :model-modifiers="{ nullify: true }" />
+ <UTextarea v-model="value" :model-modifiers="{ nullable: true }" />
```

빈 값을 `null`로 만들려면 `nullable`를 사용하고, 부재한 값에 `undefined`를 선호할 때는 `optional`를 사용합니다.

### 양식 구성요소 변경

`Form` 구성 요소는 v4에서 향상된 상태 관리 및 중첩된 양식 처리 기능을 제공합니다. 다음은 주의해야 할 주요 변경 사항입니다.

1. 스키마**변환은 **data**에만 적용되며 양식의 상태를 더 이상 변경하지 않습니다. 이것은 예측 가능성을 제공하고 예기치 않은 상태 돌연변이를 방지합니다.
2. **중첩된 양식은 `nested`prop을 사용하여 명시적으로 활성화되어야 합니다. 이는 구성 요소 동작을 보다 명확하게 만들고 실수로 중첩된 양식을 만들지 않도록 합니다.
3. **Nested 양식은 `name`**prop (`UFormField`와 유사)를 제공하고 부모 양식에서 자동으로 상태를 상속합니다.

```diff
<template>
  <UForm :state="state" :schema="schema" @submit="onSubmit">
    <UFormField label="Customer" name="customer">
      <UInput v-model="state.customer" placeholder="Wonka Industries" />
    </UFormField>

    <div v-for="(item, index) in state.items" :key="index">
      <UForm
-       :state="item"
+       :name="`items.${index}`"
        :schema="itemSchema"
+       nested
      >
        <UFormField :label="!index ? 'Description' : undefined" name="description">
          <UInput v-model="item.description" />
        </UFormField>
        <UFormField :label="!index ? 'Price' : undefined" name="price">
          <UInput v-model="item.price" type="number" />
        </UFormField>
      </UForm>
    </div>
  </UForm>
</template>
```

###  사용되지 않는 유틸리티 제거

이전에 Nuxt UI Pro에서 사용할 수 있었던 **Nuxt Content utilities** 는 v4에서 **removed** 이었습니다.

- `findPageBreadcrumb`
- `findPageHeadline`

이제 Nuxt Content에 의해 완전히 제공됩니다. 가져오기 및 사용 방법을 적절히 업데이트하십시오.

```diff
- import { findPageHeadline } from '@nuxt/ui-pro/utils/content'
+ import { findPageHeadline } from '@nuxt/content/utils'

- import { findPageBreadcrumb } from '@nuxt/ui-pro/utils/content'
+ import { findPageBreadcrumb } from '@nuxt/content/utils'
```

### AI SDK 마이그레이션 (선택 사항)

이 섹션은 AI SDK 및 채팅 구성 요소(`ChatMessage`, `ChatMessages`, `ChatPrompt``ChatPromptSubmit`, `ChatPalette`)를 사용하는 경우에만 적용됩니다. AI 기능을 사용하지 않는 경우에는 이 섹션을 건너뛸 수 있습니다.

1. 업데이트`@ai-sdk/vue` 및 `ai` 의존성을 `package.json` 추가하고 [Comark](https://comark.dev) (AI 응답을 스트리밍 Markdown으로 렌더링하기 위해 `@nuxtjs/mdc` 대체):

::framework-only
#nuxt 코드
:::div
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/nuxt": "latest"
  }
}
```

모듈에 `@comark/nuxt`를 추가하십시오:

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
+   '@comark/nuxt'
  ]
})
```
:::

#vue #vue
```diff
{
  "dependencies": {
-   "@ai-sdk/vue": "^1.2.x",
+   "@ai-sdk/vue": "^4.0.x",
-   "ai": "^4.3.x",
+   "ai": "^7.0.x",
+   "@comark/vue": "latest"
  }
}
```
::

2.  `useChat` 컴포블 API가 변경되었습니다: `input` 및 `handleSubmit`는 `sendMessage` 대신 삭제되었으며 `messages`는 이제 직접 설정한 참조입니다:

```diff
<script setup lang="ts">
  import { useChat } from '@ai-sdk/vue'

- const { messages, input, handleSubmit, status, error, reload, setMessages } = useChat()
+ const { messages, status, error, sendMessage, regenerate, stop } = useChat()
+ const input = ref('')
+
+ function handleSubmit() {
+   sendMessage({ text: input.value })
+   input.value = ''
+ }
</script>
```

3.  메시지는 `content` 대신 `parts`를 사용합니다.

```diff
// When manually creating messages
- setMessages([{
+ messages.value = [{
  id: '1',
  role: 'user',
- content: 'Hello world'
+ parts: [{ type: 'text', text: 'Hello world' }]
- }])
+ }]

// In templates
<template>
- <UChatMessage :content="message.content" />
+ <UChatMessage :parts="message.parts" />
</template>
```

4.  일부 메서드의 이름이 변경되었습니다:

```diff
// Regenerate the last message
- reload()
+ regenerate()
```

5. 파트 기반 렌더링을 위해 `<MDC>`를 `<Markdown>`로 바꿉니다. `Markdown` 구성 요소는 Markdown 스트리밍을 위해 특별히 제작되었으며, AI에서 토큰이 도착할 때 토큰을 점진적으로 렌더링합니다. AI SDK 도우미와 `@nuxt/ui/utils/ai`의 @@ 유틸리티를 사용하십시오.

::note
`shiki` 플러그인을 사용할 때, 다크 모드 지원을 위해 스타일시트에 다음 CSS를 추가합니다.

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::framework-only
#nuxt 코드
```vue
<script setup lang="ts">
import { isReasoningUIPart, isTextUIPart } from 'ai'
import { isPartStreaming } from '@nuxt/ui/utils/ai'
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]
</script>

<template>
  <UChatMessages :messages="messages" :status="status">
    <template #content="{ message }">
      <template v-for="(part, index) in message.parts" :key="`${message.id}-${part.type}-${index}`">
        <UChatReasoning
          v-if="isReasoningUIPart(part)"
          :text="part.text"
          :streaming="isPartStreaming(part)"
        >
          <Markdown
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
        </UChatReasoning>

        <template v-else-if="isTextUIPart(part)">
          <Markdown
            v-if="message.role === 'assistant'"
            :value="part.text"
            :streaming="isPartStreaming(part)"
            :plugins="plugins"
            class="*:first:mt-0 *:last:mb-0"
          />
          <p v-else-if="message.role === 'user'" class="whitespace-pre-wrap">
            {{ part.text }}
          </p>
        </template>
      </template>
    </template>
  </UChatMessages>
</template>
```
