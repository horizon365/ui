## Setup 설정

### Nuxt 프로젝트에 추가

::steps{level="4"}

#### Nuxt UI 패키지 설치하기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### xx`nuxt.config.ts`{lang="ts-type"}에 Nuxt UI 모듈 추가

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Nuxt UI가 자동으로 등록하므로 `@nuxt/icon`, `@nuxt/fonts` 또는 `@nuxtjs/color-mode`를 `modules` 어레이에 추가할 필요가 없습니다. `icon`, `fonts` 및 `colorMode` 키를 사용하여 `nuxt.config.ts`에서 이러한 모듈을 구성할 수 있습니다.
::

#### Import Tailwind CSS 및 Nuxt UI CSS CSS에서

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
[Nuxt Layers](https://nuxt.com/docs/getting-started/layers)를 사용하는 경우 모듈은 각 레이어 디렉토리에 대해 [`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive) 지시어를 자동으로 생성하여 Tailwind CSS가 모든 레이어 소스 파일에서 유틸리티 클래스를 검색합니다.
::

::callout{icon="i-simple-icons-visualstudiocode"}
VSCode에 대한 [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) 확장을 설치하고 다음 설정을 추가하는 것이 좋습니다.

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### App 구성 요소를 사용하여 앱 래핑

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
`App` 구성 요소는 전역 구성을 설정하고 **Toast**, **Tooltip** 및 **programmatic overlays**에 필요합니다.
::

::

## Options 옵션

`nuxt.config.ts`에서 옵션을 제공하여 Nuxt UI를 사용자 정의할 수 있습니다.

### `prefix` (### `prefix`)의 발음을 ### `prefix`

`prefix` 옵션을 사용하여 구성 요소의 접두어를 변경합니다.

- 기본값: `U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

`fonts` 옵션을 사용하여 [`@nuxt/fonts`](https://github.com/nuxt/fonts) 모듈을 활성화 또는 비활성화합니다.

- Default: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### `colorMode` 파일

`colorMode` 옵션을 사용하여 [`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode) 모듈을 활성화 또는 비활성화합니다.

- 기본값: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### `theme.colors`

`theme.colors` 옵션을 사용하여 구성요소 주제를 생성하는 데 사용되는 동적 색상 앨리어스를 정의합니다.

- Default: `['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
각 별칭은 구성 요소 테마에 `--ui-color-*` 음영 및 변형의 전체 집합을 생성하며, 응용 프로그램에서 사용하는지 여부에 관계없이 색상 변형이 있습니다. 목록을 실제 사용하는 별칭으로 잘라내고, 유효성 검사 스타일이 의존하므로 양식을 사용하는 경우에는 `error`를 유지합니다.
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
테마 섹션에서 색상 사용자 정의 및 주제 지정에 대해 자세히 알아보십시오.
::

### `theme.transitions`

`theme.transitions` 옵션을 사용하여 구성요소의 전환을 활성화하거나 비활성화합니다.

- Default: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
이 옵션은 커서 또는 활성 상태가 있는 구성 요소에 `transition-colors` 클래스를 추가합니다.
::

### `theme.unstyled` : badge{label="4.9+" class="align-text-top"}

`theme.unstyled` 옵션을 사용하여 구성 요소에서 모든 기본 테마 클래스를 제거하고 해당 구조와 `class`, `ui` 또는 `app.config.ui`를 통해 제공한 클래스만 유지합니다.

- 기본값: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
이것은 **structural** 클래스 (포지셔닝, 전환, 플렉스 / 그리드)를 제거하고, 단지 코스메틱 것이 아닙니다. `Modal`, `Drawer` 또는 `Calendar`와 같은 레이아웃이 무거운 구성 요소는 PrimeVue의 스타일이 지정되지 않은 모드와 유사하게 레이아웃을 다시 공급해야합니다.
::

### `theme.defaultVariants` 파일

`theme.defaultVariants` 옵션을 사용하여 구성 요소의 기본 `color` 및 `size` 변형을 재지정합니다.

정확히 `primary` 또는 `md`인 기본값만 대체되므로 아바타는 `color: 'neutral'`를 유지하고 분리기는 `size: 'xs'`를 유지합니다.

- Default: `{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix` : badge{label="4.2+" class="align-text-top"}

`theme.prefix` 옵션을 사용하여 Tailwind CSS 가져오기에서 설정한 것과 동일한 접두사를 구성합니다. 이렇게 하면 Nuxt UI 구성 요소가 올바른 접두사 유틸리티 클래스 및 CSS 변수를 사용할 수 있습니다.

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
`@nuxt/fonts` 모듈에서 접두사 옵션을 사용하려면 `fonts.processCSSVariables`를 활성화해야 할 수도 있습니다.You might need to enable `fonts.processCSSVariables` to use the prefix option with the `@nuxt/fonts` module:

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

이것은 Nuxt UI 컴포넌트 테마의 모든 Tailwind 유틸리티 클래스와 CSS 변수에 자동으로 접두어를 추가합니다.

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Tailwind CSS 설명서에서 접두사 사용에 대해 자세히 알아보십시오.
::

### `prose` 파일

`prose` 옵션을 사용하여 `@nuxtjs/mdc`, `@nuxt/content` 또는 `@comark/nuxt`가 설치되어 있지 않은 경우에도 Nuxt UI [`Prose` components](/docs/typography) 임포트를 강제로 수행합니다.

- Default: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc` : badge{label="Deprecated" color="warning" class="align-text-top"}

대신 [`prose`](#prose) 옵션을 사용합니다.

### `content` 사용자

`content` 옵션을 사용하여 `@nuxt/content`가 설치되지 않은 경우에도 Nuxt UI 산문 및 내용 구성 요소를 강제로 가져옵니다.

- 기본값: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection`: badge{label="4.1+" class="align-text-top"}

`experimental.componentDetection` 옵션을 사용하여 트리 셰이킹을 위한 자동 구성 요소 감지를 활성화합니다. 이 기능은 소스 코드를 스캔하여 실제로 사용되는 구성 요소를 감지하고 해당 구성 요소에 필요한 CSS만 생성합니다(종속성 포함).

- 기본값: `false`{lang="ts-type"}
- Type : `boolean | string[]`{lang="ts-type"}

**자동 감지 기능 활성화: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**동적 사용을 위한 추가 구성요소 포함: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
구성 요소 이름의 배열을 제공하면 자동 탐지가 활성화되고 이러한 구성 요소는 종속성과 함께 포함됩니다. 정적 분석이 불가능한 `<component :is="..." />`와 같은 동적 구성 요소에 유용합니다.
::

## Continuous 버전

Nuxt UI는 [pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)를 사용하여 지속적인 미리 보기 릴리스를 제공하므로 개발자가 공식 릴리스를 기다리지 않고도 최신 기능과 버그 수정에 즉시 액세스할 수 있습니다.

`v4` 분기의 모든 커밋 및 PR에 대해 자동 미리 보기 릴리스가 생성됩니다. 패키지 버전을 특정 커밋 해시 또는 PR 번호로 대체하여 사용합니다.

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new**는 설치 URL을 사용하여 PR에 자동으로 주석을 추가하여 변경 사항을 쉽게 테스트할 수 있습니다.
::
