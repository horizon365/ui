## 설정

### Nuxt   프로젝트 에   추가

::steps{level="4"}

#### Nuxt   UI   패키지   설치 하 기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

####   Nuxt   UI   모듈 을   추가  `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Nuxt   UI 가   자동 으로   등록 하 기   때문 에  `@nuxt/icon`,  `@nuxt/fonts`  또는  `@nuxtjs/color-mode`  을 (를)  `modules`  스토리지 에   추가 할   필요 가   없 습니다 .  `icon`,  `fonts`  및  `colorMode`  키 를   사용 하 여   이러 한   모듈 을   구성 할   수   있 습니다 .
::

####   당신 의   CSS 에서   Tailwind   CSS 와   Nuxt   UI   가져오 기

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
[Nuxt   Layers](https://nuxt.com/docs/getting-started/layers)를   사용 하 면   모듈 은   각   레이어   디렉 토리 에   대해  [`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive)Tailwind   명령 을   자동 으로   생성 하 여   CSS   유틸리티   클래스 에   대한   모든   레이어   소스   파일 을   스캔 합니다 .
::

::callout{icon="i-simple-icons-visualstudiocode"}
VSCode 에   대해  [Tailwind   CSS   IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)확장 을   설치 하 고   다음   설정 을   추가 하 는   것 이   좋 습니다 .

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### App   구성   요소 로   앱   래핑

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
`App`  구성   요소 는   글로벌   구성 을   설정 하 고  **Toast**Tooltip**  및  **programmatic   overlays**  에   필요 합니다 .
::

##   옵션

`nuxt.config.ts`에   옵션 을   제공 하 여   Nuxt   UI 를   사용자   정의 할   수   있 습니다 .

###  `prefix`

`prefix` 옵션을 사용하여 구성요소의 접두사를 변경합니다.

- 기본값: `U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

`fonts` 옵션을 사용하여 [`@nuxt/fonts`](https://github.com/nuxt/fonts) 모듈을 활성화 또는 비활성화합니다.

- 기본값: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

###  @ `colorMode` @

`colorMode` 옵션을 사용하여 [`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode) 모듈을 활성화 또는 비활성화합니다.

- 기본값: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

###  @ `theme.colors` @

`theme.colors` 옵션을 사용하여 구성요소 주제를 생성하는 데 사용할 동적 색상 별칭을 정의합니다.

- 기본값: `['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
각 별칭은 구성 요소 테마에서 사용 여부에 관계없이 `--ui-color-*`shades와 변형의 전체 집합을 생성합니다. 실제 사용 중인 별칭으로 목록을 잘라내고 유효성 검사 스타일에 의존하기 때문에 양식을 사용하는 경우 `error`를 유지합니다.
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
테마 섹션에서 색상 사용자 정의 및 주제 지정에 대해 자세히 알아보십시오.
::

### `theme.transitions`

`theme.transitions` 옵션을 사용하여 구성 요소의 전환을 활성화하거나 비활성화합니다.

- 기본값: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
이 옵션은 커서 또는 활성 상태가 있는 구성 요소에 `transition-colors` 클래스를 추가합니다.
::

### `theme.unstyled` badge {label="4.9+" class="align-text-top"}

`theme.unstyled` 옵션을 사용하여 구성 요소에서 모든 기본 테마 클래스를 제거하고 해당 구조와 `class`, `ui` 또는 `app.config.ui`를 통해 제공한 클래스만 유지합니다.

- 기본값: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
이것은 **structural**클래스 또한 (위치, 전환, flex/grid), 단지 화장용 것이 아닙니다.`Modal`, `Drawer` 또는 `Calendar` 같은 레이아웃을 재공급해야 합니다.
::

### `theme.defaultVariants` @ `theme.defaultVariants` @

`theme.defaultVariants` 옵션을 사용하여 구성 요소의 기본 `color` 및 `size` 변형을 재정의합니다.

정확히 `primary` 또는 `md`인 기본값만 대체되므로 Avatar는 `color: 'neutral'`을 유지하고 Separator는 `size: 'xs'`을 유지합니다.

- 기본 값 :  `{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix` `theme.prefix` @  badge{label="4.2+" class="align-text-top"}

`theme.prefix`  옵션 을   사용 하 여   Tailwind   CSS   가져오 기 에서   설정 한   것 과   동일 한   접두사 를   구성 합니다 .   이렇게   하 면   Nuxt   UI   구성   요소 가   올바른   접두사   유틸리티   클래스 와   CSS   변수 를   사용 할   수   있 습니다 .

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
`fonts.processCSSVariables`  모듈 과   함께   접두사   옵션 을   사용 하 려면  `@nuxt/fonts`  을   사용 하 도록   설정 해야   할   수도   있 습니다 .

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

이것 은   Nuxt   UI   컴포넌트   테마 의   모든   Tailwind   유틸리티   클래스 와   CSS   변수 에   자동 으로   접두어 를   추가 합니다 .

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Tailwind   CSS   문서 에서   접두사   사용 에   대해   자세히   알아보 십시오 .
::

### `prose`

`prose`  옵션 을   사용 하 여   Nuxt   UI[`Prose`components](/docs/typography)  이 (가)   설치 되 어   있 지   않 은   경우 에 도  `@nuxt/content`  임 포트 를   강제 로   수행 합니다 .

- 기본 값 :  `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc` @ `mdc` @  badge{label="Deprecated" color="warning" class="align-text-top"}

대신  [`prose`](#prose)  옵션 을   사용 하 십시오 .

###  @ `content` @

`content`  옵션 을   사용 하 여  `@nuxt/content`  가   설치 되 어   있 지   않 더라도   Nuxt   UI   산문   및   컨텐츠   구성   요소 를   강제 로   가져오 십시오 .

- 기본 값 :  `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection` @ `experimental.componentDetection` @  badge{label="4.1+" class="align-text-top"}

`experimental.componentDetection`  옵션 을   사용 하 여   트리   셰이킹 을   위한   자동   구성   요소   감지 를   활성 화 합니다 .   이   기능 은   소스   코드 를   스캔 하 여   실제로   사용 되 는   구성   요소 를   감지 하 고   해당   구성   요소 에   필요 한   CSS 만   생성 합니다 (종속 성   포함) .

- 기본 값 :  `false`{lang="ts-type"}
- 유형 :  `boolean | string[]`{lang="ts-type"}

**자동   감지   사용 :  **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**동적   사용 을 위한   추가   구성   요소   포함 :  **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
구성   요소   이름 의   배열 을   제공 할   때   자동   탐지 가   활성 화 되 고   이러 한   구성   요소 는   종속 성 과   함께   포함 됩니다 .   정적 으로   분석 할   수   없 는  `<component :is="..." />`와   같 은   동적   구성   요소 에   유용 합니다 .
::

##   지속 적 인   발표

Nuxt   UI 는  [  을   사용 합니다 .pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)  지속 적 인   미리 보 기   릴리스 를   제공 하 여   개발자 가   공식   릴리스 를   기다리 지   않 고 도   최신   기능 과   버그   수정 을   즉시   액세스 할   수   있 습니다 .

모든   커밋   및   PR 에   대해   자동   미리   보 기   릴리스 가  `v4`분기 에   생성 됩니다 .   패키지   버전 을   특정   커밋   해시   또는   PR   번호 로   대체 하 여   사용 합니다 .

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
** @pkg.pr.new**는   자동 으로   PR 에   주석 을   달 아   설치   URL 을   사용 하 여   변경   사항 을   쉽 게   테스트   할   수   있 습니다 .
::
