## MCP 란 무엇입니까?

MCP(Model Context Protocol)는 AI 도우미가 외부 데이터 소스 및 도구에 액세스할 수 있도록 해주는 표준화된 프로토콜입니다. Nuxt UI는 Claude Code, Cursor, Windsurf와 같은 AI 도우미가 구성 요소 정보, 소스 코드 및 사용 예제에 직접 액세스할 수 있도록 해주는 MCP 서버를 제공합니다.

MCP 서버는 컴포넌트 라이브러리에 대한 구조적 액세스를 제공하여 AI 도구가 Nuxt UI 개발을 쉽게 이해하고 지원할 수 있도록 합니다.

## 사용 가능한 리소스

Nuxt UI MCP 서버는 검색을 위해 다음과 같은 리소스를 제공합니다.

- **`resource://nuxt-ui/components`** : 범주를 가진 사용 가능한 모든 구성 요소 찾아보기
- **`resource://nuxt-ui/composables`PH09@: 카테고리를 가진 사용 가능한 모든 합성 파일 보기
- **`resource://nuxt-ui/examples`** : 사용 가능한 코드 예제 모두 보기
- **`resource://nuxt-ui/templates`** : 사용 가능한 모든 프로젝트 템플릿 보기
- **`resource://nuxt-ui/documentation-pages`** : 사용 가능한 모든 문서 페이지 보기

Claude Code와 같은 도구를 사용하여 `@`를 사용하여 이러한 리소스에 액세스 할 수 있습니다.

## 사용 가능한 도구

Nuxt UI MCP 서버는 범주별로 구성된 다음과 같은 도구를 제공합니다.

###  검색 도구

- **`search-components`** : 이름, 범주 또는 의도별로 구성 요소를 검색합니다. `"segmented control"` 또는 `"combobox"` 같은 대체 이름은 관련성별로 검색됩니다. params가 없는 모든 구성 요소를 나열합니다.
- **`search-composables`** : 이름이나 설명으로 합성 파일을 검색합니다. params가 없으면 모든 합성 파일이 나열됩니다.
- **`search-icons`**: Iconify 컬렉션에서 아이콘을 검색합니다(기본값은 `lucide`). Nuxt UI에서 사용하는 `i-{prefix}-{name}` 형식으로 아이콘 이름을 반환합니다.

###  구성 요소 도구

- **`get-component`** : 구성 요소 문서 및 세부 정보를 검색합니다. `sections` 매개변수(`usage`, `examples`, `api`, `theme`, `changelog`)를 지원하여 특정 부품만 검색하고 응답 크기를 줄일 수 있도록 합니다.
- **`get-component-metadata`** : props, slots, 이벤트(경량, 문서 내용 없음)를 포함하는 구성요소에 대한 메타데이터를 검색합니다. props는 기본적으로 컴팩트하며 원시 재귀 스키마의 경우 `full: true`를 전달합니다.

###  문서화 툴

- **`search-documentation`** : 문서 페이지를 제목, 설명 또는 섹션별로 검색합니다. params가 없으면 모든 페이지가 나열됩니다. `section` 를 사용하여 필터링합니다(예: `"getting-started"`, `"components"`).
- **`get-documentation-page`** : URL 경로로 문서 페이지 내용을 검색합니다. `headings` 매개변수를 사용하여 특정 h2 섹션만 검색하고 응답 크기를 줄일 수 있습니다.

### 템플릿 툴

- **`list-templates`** : 프레임워크 필터링 옵션을 사용하여 사용 가능한 모든 Nuxt UI 템플릿을 나열합니다.
- **`get-template`**템플릿에 대한 설명, 기능 및 링크 검색

###  도구 예제

- **`list-examples`** : 사용 가능한 모든 UI 예제의 이름을 나열합니다.
- **`get-example`**UI 예제의 소스 코드 검색

### 마이그레이션 도구

- **`get-migration-guide`** : Nuxt UI 버전에 대한 마이그레이션 가이드 및 업그레이드 지침 검색

##  사용 가능한 도구 제한

옵션 `X-MCP-Tools`HTTP 헤더를 쉼표로 구분된 도구 이름 목록으로 설정하여 도우미가 필요로 하는 도구만 표시합니다. 이렇게 하면 도우미에 정의된 컨텍스트를 줄일 수 있습니다.

정확한 케밥 케이스 MCP 도구 이름을 사용하십시오. 예를 들면 다음과 같습니다.

```json
{
  "X-MCP-Tools": "search-components,get-component"
}
```

헤더는 모든 도구를 노출하지 않고, 빈 헤더는 도구를 노출하지 않으며, 알 수 없는 도구 이름은 구성 오류를 반환합니다.

##  사용 가능한 프롬프트

Nuxt UI MCP 서버는 일반적인 작업 흐름에 대한 안내 프롬프트를 제공합니다.

- **`find-component-for-usecase`** : 특정 사용 사례에 가장 적합한 구성 요소 찾기
- **`implement-component-with-props`** : 적절한 소품으로 구성 요소 구현을 생성합니다.
- **`setup-project-with-template`** : 프로젝트 템플릿에 대한 지침 얻기

Claude Code와 같은 도구를 사용하여 `/`를 사용하여 이러한 리소스에 액세스 할 수 있습니다.

##  설정

Nuxt UI MCP 서버는 HTTP 전송을 사용하며 다른 AI 도우미에서 구성할 수 있습니다.

###  ChatGPT

::note{icon="i-lucide-info"}
**MCP를 사용하는 맞춤형 커넥터는 ChatGPT for Pro and Plus 계정에서 사용할 수 있습니다. ** 웹에서 액세스할 수 있습니다.
::

다음 단계에 따라 Nuxt UI를 ChatGPT 내에서 커넥터로 설정합니다.Follow these steps to set up Nuxt UI as a connector within ChatGPT:

1. **개발자 모드 사용: **
   -  설정 > 커넥터 > 고급 설정 > 개발자 모드로 이동

2. **ChatGPT 설정 열기**

3. **커넥터 탭에서 새 커넥터를 만듭니다.**
   -  이름을 지정하십시오 `Nuxt UI`
   - MCP 서버 URL: `https://ui.nuxt.com/mcp`
   - 인증: `None`

4. **Create**를 클릭합니다.

Nuxt UI 커넥터는 나중에 대화하는 동안 작곡가의 "개발자 모드" 도구에 나타납니다.

### 클로드 코드

::note{icon="i-lucide-info"}
**Claude Code가 설치되어 있는지 확인하십시오.** 방문 [Anthropic의 documentation](https://docs.anthropic.com/en/docs/claude-code/quickstart) 설치 지침.
::

CLI 명령을 사용하여 서버를 추가합니다.

```bash
claude mcp add --transport http nuxt-ui https://ui.nuxt.com/mcp
```

### Claude 데스크탑

#### 설정 지침:

1. Claude Desktop을 열고 설정 > 개발자로 이동합니다.
2. Edit Config를 클릭하면 로컬 Claude 디렉토리가 열립니다.
3. 사용자 지정 MCP 서버 구성을 사용하여 `claude_desktop_config.json` 파일을 수정합니다.

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://ui.nuxt.com/mcp"
      ]
    }
  }
}
```

4. Claude Desktop 앱을 다시 시작합니다.Nuxt UI MCP 서버가 등록되어 있어야 합니다.

### GitHub Copilot 에이전트

::note{icon="i-lucide-info"}
**저장소 관리자 액세스가 필요합니다.** GitHub Copilot 코딩 에이전트에 대한 MCP 서버를 구성하는 데 필요합니다.
::

MCP 서버를 [Visual Studio Code](#visual-studio-code)에 이미 구성한 경우 `servers`키를 `mcpServers`로 바꾸고 Copilot에서 사용할 수 있는 도구를 지정하는 `tools`키를 추가합니다.

#### 설정 지침:

1. GitHub 저장소로 이동
2. 로 이동 **Settings****Code & automation**Copilot**Coding agent**
3. MCP configuration**** 섹션에서 다음 설정을 추가합니다.
  ```json
  {
    "mcpServers": {
      "nuxt-ui": {
        "type": "http",
        "url": "https://ui.nuxt.com/mcp",
        "tools": ["*"]
      }
    }
  }
  ```
4. 저장을 클릭합니다.

####  구성 확인:

MCP 서버가 올바르게 구성되었는지 확인하려면 다음을 수행합니다.

1.  저장소에 문제를 만들고 Copilot에 할당
2. Copilot이 pull request를 생성할 때까지 대기
3.  pull request에서 Copilot started work 타임라인 이벤트의 세션 보기를 클릭합니다.
4. 오른쪽 위에 있는 줄임표 버튼(...)을 클릭한 다음 사이드바에서 Copilot 을 클릭합니다.
5. MCP 서버 시작 단계를 확장하여 구성된 Nuxt 도구를 확인합니다.

GitHub Copilot 코딩 에이전트와 MCP를 사용하는 방법에 대한 자세한 내용은 [MCP를 사용하여 코딩 에이전트 확장](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp)을 참조하십시오.

### GitHub Copilot CLI 사용

#### 설정 지침:

1. 대화형 모드에서 GitHub Copilot CLI 시작.
2.  실행 `/mcp add`
3.  구성 양식을 다음과 같이 입력합니다.
   - **서버 이름** :`nuxt-ui`
   - **서버 유형** :`HTTP`
   - **URL** `https://ui.nuxt.com/mcp`
   - **HTTP 헤더** : 비어 있음
   - ** 도구 **`*`
4. Press<kbd>Ctrl</kbd><kbd>S</kbd>저장하려면 MCP 서버를 즉시 사용할 수 있습니다. CLI를 다시 시작하지 않고도 즉시 사용할 수 있습니다.

또는 서버를 `~/.copilot/mcp-config.json`에 직접 추가하십시오.

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "tools": ["*"]
    }
  }
}
```

`/mcp show`를 사용하여 서버가 구성되어 있고 사용 가능한지 확인합니다.

자세한 내용은 [GitHub Copilot CLI에 대한 MCP 서버 추가](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)를 참조하십시오.

### Google 안티중력

#### 설정 지침:

1. 편집기의 에이전트 패널 상단에 있는 "..." 드롭다운을 통해 MCP 스토어를 엽니다.
2. MCP 서버 관리 클릭
3.  "View raw config"를 클릭하십시오.
4.  사용자 지정 MCP 서버 구성으로 `mcp_config.json` 수정:

```json [mcp_config.json]
{
  "mcpServers": {
    "nuxt-ui": {
      "serverUrl": "https://ui.nuxt.com/mcp"
    }
  }
}
```

5. MCP 서버 관리 탭으로 돌아가서 새로 고침을 클릭합니다. 이제 Nuxt UI MCP 서버가 나타납니다.

### Le Chat Mistral 이미지

#### 설정 지침:

1. 인텔리전스 > 커넥터로 이동
2.  커넥터 추가 버튼을 클릭한 다음 "Custom MCP Connector"를 선택합니다.
3. 사용자 지정 MCP 커넥터 만들기:
    - 커넥터 이름:`NuxtUI`
    - 서버 URL: `https://ui.nuxt.com/mcp`

### OpenCode @ 오픈코드

####  설정 지침:

1.  프로젝트 루트에서 `opencode.json`을 만듭니다.
2.  다음 설정을 추가합니다.

```json [opencode.json]
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "nuxt-ui": {
      "type": "remote",
      "url": "https://ui.nuxt.com/mcp",
      "enabled": true
    }
  }
}
```

### Visual Studio 코드

::note{icon="i-lucide-info"}
**필요한 확장 프로그램을 설치하십시오.**GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) 및 [GitHub Copilot Chat]( https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat 확장 프로그램이 설치되어 있는지 확인하십시오.
::

####  설정 지침:

1.  VS 코드를 열고 명령 팔레트에 액세스 (Ctrl / Cmd + Shift + P)
2. Preferences:Open Workspace Settings (JSON)를 입력한 다음 선택합니다.
3.  프로젝트의 `.vscode` 폴더로 이동하거나 존재하지 않는 경우 하나를 만듭니다.
4.  다음 구성으로 `mcp.json` 파일을 만들거나 편집합니다.

```json [.vscode/mcp.json]
{
  "servers": {
    "nuxt-ui": {
      "type": "http",
      "url": "https://ui.nuxt.com/mcp",
      "headers": {
        "X-MCP-Tools": "search-components,get-component"
      }
    }
  }
}
```

`headers` 항목을 제거하여 모든 Nuxt UI MCP 도구를 사용할 수 있도록 합니다.

3.  MCP 설정에 다음 구성을 추가합니다.
