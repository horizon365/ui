## LLM.txt 란 무엇입니까?

LLM.txt는 LLM(대형 언어 모델)을 위해 특별히 설계된 구조화된 문서 형식입니다. Nuxt UI는 컴포넌트 라이브러리에 대한 포괄적인 정보가 포함된 LLM.txt 파일을 제공하므로 AI 도구가 Nuxt UI 개발을 쉽게 이해하고 지원할 수 있습니다.

이러한 파일은 AI 사용을 위해 최적화되어 있으며 구성요소, API, 사용 패턴 및 모범 사례에 대한 구조화된 정보를 포함합니다.

##  사용 가능한 경로

우리는 AI 도구가 우리의 문서에 액세스하는 데 도움이되는 LLMs.txt 경로를 제공합니다.

- **`/llms.txt`** - 모든 구성 요소와 해당 문서 링크(~5K 토큰)의 구조적인 개요가 포함되어 있습니다.
- **`/llms-full.txt`** - 구현 세부 정보, 예제, 테마, 작성 가능 파일 및 마이그레이션 지침(~1M+토큰)을 포함한 포괄적인 문서 제공

## 올바른 파일 선택

::note{icon="i-lucide-info"}
**대부분의 사용자는 `/llms.txt`**로 시작해야 합니다. 모든 필수 정보를 포함하고 표준 LLM 컨텍스트 창에서 작동합니다. 포괄적 인 구현 예제가 필요하고 AI 도구가 대규모 컨텍스트 (200K + 토큰)를 지원하는 경우에만 `/llms-full.txt`를 사용하십시오.
::

## 중요한 사용법 노트

::warning{icon="i-lucide-alert-triangle"}
** - 기호는 수동으로 입력해야 합니다.** - 커서나 Windsurf와 같은 도구를 사용할 때는 채팅 인터페이스에서 `@` 기호를 직접 입력해야 합니다. 복사 붙여넣기는 도구가 컨텍스트 참조로 인식하는 능력을 손상시킵니다.
::

## AI 도구와 함께 사용

###  커서

Nuxt UI는 구성요소 개발에 대한 AI 지원을 위해 커서에서 참조할 수 있는 특수 LLMs.txt 파일을 제공합니다.

####  사용 방법:

1. **직접 참조** : 질문할 때 LLMs.txt URL 언급
2.  @ `@docs` 을 사용하여 프로젝트 컨텍스트에 이러한 특정 URL을 추가합니다.

[ 프롬프트 및 `@` Cursor ](https://cursor.com/docs/agent/prompting)

###  Windsurf

Windsurf는 Nuxt UI LLMs.txt 파일에 직접 액세스하여 구성요소 사용 및 모범 사례를 이해할 수 있습니다.

#### Windsurf와 함께 LLMs.txt 사용:

- 특정 LLMs.txt URL을 참조하려면 `@docs`를 사용합니다.
- 작업 영역에서 이러한 URL을 참조하는 영구 규칙을 만듭니다.

[Windsurf Web and Docs Search에 대해 자세히 읽어보세요](https://docs.windsurf.com/windsurf/cascade/web-search)

###  다른 AI 도구

#### ChatGPT ,   Claude   또는   기타   LLM 의   예 :
