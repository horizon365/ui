##   기술 이란   무엇 입니까 ?

기술 은   AI   코딩   에이전트 에게   라이브러리 ,   프레임워크   또는   코드 베이스 에   대한   컨텍스트 를   제공 하 는   구조 화 된   지식   파일 입니다 .   실시간   도구   액세스 를   제공 하 는   MCP   서버 와 는   달리   기술 은   에이전트 의   컨텍스트 에   직접   로드 되 어   대화   중 에   기술 을   참조 할   수   있 습니다 .

Nuxt   UI 는  **usage   skills**를   제공 하 여   AI   에이전트 에게   Nuxt   UI 를   사용 하 여   UI 를   구축 하 는   방법 을   가르쳐 줍니다 :   설치 ,   테마 ,   구성   요소 ,   합성   가능   파일 ,   양식 ,   오버레이   및   레이아웃 .

## 사용

사용   기술 은   AI   에이전트 에게   Nuxt   UI   v 4 를   사용 하 여   구축 하 는   것 에   대한   포괄 적 인   지식 을   제공 합니다 .   이   기술 은   다음 과   같 은   내용 을   다룹니다 .

- Nuxt ,   Vue ,   Laravel   및   AdonisJS   설치
- 의미   색상   및   CSS   변수 를   사용 한   테마   및   브 랜딩
-   소품 과   사용   패턴 이   있 는   125 개   이상 의   구성 요소
- 합성   가능   (`useToast``useOverlay``defineShortcuts`)
- 표준   스키마 를   사용 한   양식   유효성   검사
- 레이아웃   구성   (대시보드 ,   문서 ,   채팅 ,   편집기)
-   공식   시작   템플 릿

이   기술 에 는   AI   에이전트 가   작업 에   따라   요청 에   따라   로드 하 는   추가   참조 가   포함 되 어   있 어   응답 에   초점 을   맞추 고   상황 에   맞 게   효율 적 으로   유지 됩니다 .

::note
설치 가   완료 되 면   에이전트 의   채팅 에서  `/nuxt-ui`를   입력 하 여   스킬 을   호출 할   수   있 습니다 .
::

### 스킬   CLI

[`skills`](https://skills.sh)CLI 는   Nuxt   UI   기술 을   설치 하 는   가장   쉬운   방법 으로 ,   Cursor ,   Claude   Code ,   Codex ,   Windsurf ,   Cline   등 을   포함 한   35 개   이상 의   에이전트 를   지원 합니다 .

```bash
npx skills add nuxt/ui
```

`--agent`  플래그 를   사용 하 여   특정   에이전트 를   대상 으로   할   수   있 습니다 .

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

또는   전   세계 적 으로   설치 하 여   모든   프로젝트 에서   기술 을   사용 할   수   있 도록   합니다 .

```bash
npx skills add nuxt/ui --global
```

GitHub 에서   복제 하 는   것 이   네트워크 에서   느린   경우 ,   웹   사이트 에서   직접   설치 할   수   있 습니다 :

```bash
npx skills add https://ui.nuxt.com
```

::tip
방문  [skills.sh](https://skills.sh)  기술   생태 계 에   대해   자세히   알아보 고   사용   가능 한   기술 을   찾아보 십시오 .
::

### 커서

#### 빠른   설치

아래   단추 를   클릭 하 여   커서 에   직접   Nuxt   UI   기술 을   설치 합니다 . Click   the   button   below   to   install   the   Nuxt   UI   skill   directly   in   Cursor :

::u-button
---
커서 :  //  cursor :anysphere.cursor-deeplink/install-skill?url=https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui"
라벨 :   Install   Skill
색상: 중립
아이콘: i-simple-icons-cursor
---
::

####  수동 설정

1. 커서를 열고 "설정" > "기술"으로 이동
2.  "스킬 추가"를 클릭하고 다음 URL을 입력합니다.

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```

### 클로드 코드

::note{icon="i-lucide-info"}
**Claude Code가 설치되어 있는지 확인하십시오.** 방문 [Anthropic의 documentation](https://docs.anthropic.com/en/docs/claude-code/quickstart) 설치 지침.
::

CLI 명령을 사용하여 기술을 추가합니다.

```bash
claude skill add https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
