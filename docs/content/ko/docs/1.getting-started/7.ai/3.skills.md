##  기술이란 무엇입니까?

기술은 AI 코딩 에이전트에게 라이브러리, 프레임워크 또는 코드베이스에 대한 컨텍스트를 제공하는 구조화된 지식 파일입니다. 실시간 도구 액세스를 제공하는 MCP 서버와는 달리 기술은 에이전트의 컨텍스트에 직접 로드되어 대화 중에 기술을 참조할 수 있습니다.

Nuxt UI는 AI 에이전트가 Nuxt UI를 사용하여 UI를 구축하는 방법을 가르치는 **usage skill**를 제공합니다(설치, 테마, 구성 요소, 합성 가능 파일, 양식, 오버레이 및 레이아웃).

## 사용법

사용 기술은 AI 에이전트에게 Nuxt UI v4를 사용하여 구축하는 것에 대한 포괄적인 지식을 제공합니다. 이 기술은 다음과 같은 내용을 다룹니다.

- Nuxt, Vue, Laravel 및 AdonisJS 설치
- Theming and branding with semantic colors and CSS variables 의미 색상 및 CSS 변수를 사용한 테마 및 브랜딩
- All 125+ 소품 및 사용 패턴이 있는 구성요소
- 합성 가능 파일 (`useToast`, `useOverlay`, `defineShortcuts`)
- Form 검증을 위한 표준 스키마
- Layout 구성 (대시보드, 문서, 채팅, 편집기)
- 공식 스타터 템플릿

이 기술에는 AI 에이전트가 작업에 따라 요청에 따라 로드하는 추가 참조가 포함되어 있어 응답에 초점을 맞추고 상황에 맞게 효율적으로 유지됩니다.

::note
설치가 완료되면 에이전트의 채팅에서 `/nuxt-ui`를 입력하여 기술을 호출할 수 있습니다.
::

### Skills CLI 지원

[`skills`](https://skills.sh) CLI는 Cursor, Claude Code, Codex, Windsurf, Cline 등을 포함한 35개 이상의 에이전트를 지원하는 Nuxt UI 기술을 설치하는 가장 쉬운 방법입니다.

```bash
npx skills add nuxt/ui
```

`--agent` 플래그를 사용하여 특정 에이전트를 대상으로 지정할 수 있습니다.

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

또는 전 세계적으로 설치하여 모든 프로젝트에서 기술을 사용할 수 있도록 합니다.

```bash
npx skills add nuxt/ui --global
```

GitHub에서 복제하는 것이 네트워크에서 느린 경우, 웹 사이트에서 직접 설치할 수 있습니다:

```bash
npx skills add https://ui.nuxt.com
```

::tip
[skills.sh](https://skills.sh)를 방문하여 기술 생태계에 대해 자세히 알아보고 사용 가능한 기술을 찾아보십시오.
::

### Cursor

#### 빠른 설치

아래 단추를 클릭하여 커서에 직접 Nuxt UI 기술을 설치합니다.Click the button below to install the Nuxt UI skill directly in Cursor:

::u-button
---
to: "cursor://anysphere.cursor-deeplink/install-skill?url=https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui"
label: Install Skill
color: neutral
icon: i-simple-icons-cursor
---
::

#### 수동 설정

1. 커서를 열고 "설정" > "기술"으로 이동합니다.
2. "Add skill"을 클릭하고 다음 URL을 입력합니다.

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```

### 클로드 코드

::note{icon="i-lucide-info"}
**Ensure Claude Code is installed.** 설치 지침은 [Anthropic의 documentation](https://docs.anthropic.com/en/docs/claude-code/quickstart) 를 방문하십시오.
::

CLI 명령을 사용하여 기술을 추가하려면:

```bash
claude skill add https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
