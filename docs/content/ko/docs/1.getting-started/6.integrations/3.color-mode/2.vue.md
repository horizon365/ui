##  사용법

Nuxt UI는 자동으로 [useDark](https://vueuse.org/core/useDark)컴포블을 Vue 플러그인으로 등록하므로 추가 설정이 필요하지 않습니다.

###  구성 요소

내장형 [ColorModeAvatar](/docs/components/color-mode-avatar)또는 [ColorModeImage](/docs/components/color-mode-image) 구성 요소를 사용하여 밝은 모드와 어두운 모드에 대해 다른 이미지를 표시할 수 있습니다.[Color ModeImage)) 구성 요소를 사용하여 밝은 모드와 어두운 모드에 대해 다른 이미지를 표시할 수 있습니다.[ColorModeSwitch](/docs/components/color-mode-switch) 또는 [ColorModeSelect](/docs/components/color-mode-select) 구성 요소를 사용하여 조명 모드와 어두운 모드 간에 전환합니다.

또한 [useColorMode](https://vueuse.org/core/useColorMode)composable을 사용하여 사용자 정의 구성 요소를 만들 수 있습니다.

```vue [ColorModeButton.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useColorMode } from '@vueuse/core'

const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark: boolean) {
    colorMode.value = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <UButton
    :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
    color="neutral"
    variant="ghost"
    :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
    @click="isDark = !isDark"
  />
</template>
```

###  구성

이 플러그인을 비활성화할 수 있습니다 `colorMode` 옵션을 `vite.config.ts` 에서:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```
