##  사용

Nuxt UI는 자동으로 [`@nuxt/fonts`](https://github.com/nuxt/fonts)모듈을 등록하므로 추가 설정이 필요하지 않습니다.

###  선언문

Nuxt UI 응용 프로그램에서 글꼴을 사용하려면 CSS에서 선언하면 됩니다. 자동으로 로드되고 최적화됩니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

###  구성

`nuxt.config.ts`에서 `ui.fonts` 옵션으로 `@nuxt/fonts` 모듈을 비활성화할 수 있습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
