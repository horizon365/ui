##  사용법

::note{to="/docs/components/app"}
Nuxt UI는 **App** 구성 요소를 제공하여 앱을 래핑하여 `locale`prop을 포함한 글로벌 구성을 제공합니다.
::

###  로케일

`locale`prop을 `@nuxt/ui/locale`에서 사용할 로케일과 함께 사용하십시오.

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
각 로케일에는 `code` 속성이 있음 (예: `en``en-GB`Calendar](/docs/components/calendar)), 같은 구성 요소의 날짜/시간 형식을 결정하는 데 사용됩니다. `en``en-GB`Calendar](/docs/components/calendar),[InputDate](/docs/components/input-date) 및 [InputTime](/docs/components/input-time) .
::

###  사용자 지정 로케일

[defineLocale](/docs/composables/define-locale)유틸리티를 사용하여 사용자 고유의 로케일을 만들 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
`code` 매개변수를 보면 언어의 ISO 코드를 전달해야합니다. 예를 들어 :

* `hi`힌디어 (언어)
* `de-AT``de-AT`: 오스트리아 (지역)에서 사용되는 독일어 (언어)

::

###  로케일 확장

[extendLocal](/docs/composables/extend-locale) 유틸리티를 사용하여 `messages` 또는 `code`를 재지정하여 기존 로케일을 사용자 정의할 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### 동적 로케일

언어 간에 동적으로 전환하려면 [Nuxt I18n](https://i18n.nuxtjs.org/) 모듈을 사용하십시오.

::steps{level="4"}

#### Nuxt I18n 패키지 설치하기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

####  Nuxt I18n 모듈을 추가 `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

####  설정 `locale`prop @ `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### 자동 링크 로컬라이제이션: badge{label="4.7+" class="align-text-top"}

`@nuxtjs/i18n` 을(를) 설치하면 [Link](/docs/components/link) 구성 요소가 `$localePath`helper를 사용하여 내부 링크를 자동으로 현지화합니다. 이는 링크를 `localePath()` 또는 `localeRoute()`로 수동으로 래핑할 필요가 없음을 의미합니다.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
외부 링크 및 절대 URL은 자동으로 감지되며 로컬라이제이션을 건너뜁니다. 필요한 경우 `localePath()` 또는 `localeRoute()` 를 수동으로 사용할 수 있습니다
::

::

### 동적 방향

각 로케일에는 `dir` 속성이 있으며 `App` 구성요소가 모든 구성요소의 방향성을 설정하기 위해 사용됩니다.

다국어 응용 프로그램에서는 `lang` 및 `dir` 속성을 사용자의 로케일에 따라 동적으로 설정할 수 있습니다. [useHead](https://nuxt.com/docs/api/composables/use-head 컴포지블로 수행할 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
