## 사용법

::note{to="/docs/components/app"}
Nuxt UI는 `locale` prop를 포함한 전역 구성을 제공하기 위해 앱을 래핑하는 **Appxph05x 구성 요소를 제공합니다.Nuxt UI prop prop prop including global configurations.
::

### 로케 일

`@nuxt/ui/locale`에서 사용할 로케일과 함께 `locale` prop을 사용합니다.

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
각 로케일에는 `code` 속성(예: `en`, `en-GB`, `fr`)이 있으며, [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) 및 xputTimph3031x와 같은 구성 요소의 날짜/시간 형식을 결정합니다.
::

### 사용자 지정 로케일

[defineLocale](/docs/composables/define-locale) 유틸리티를 사용하여 사용자 고유의 로케일을 만들 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
`code` 매개 변수를 보면 언어의 ISO 코드를 전달해야합니다. 예를 들어 다음과 같습니다.

* `hi` 힌디어 (언어)
* `de-AT`: 오스트리아 (지역)에서 사용되는 독일어 (언어)

::

### Extend 로캘

[extendLocale](/docs/composables/extend-locale) 유틸리티를 사용하여 `messages` 또는 `code`를 재지정하여 기존 로케일을 사용자 정의할 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Dynamic 로케일

언어 간에 동적으로 전환하려면 [Nuxt I18n](https://i18n.nuxtjs.org/) 모듈을 사용할 수 있습니다.

::steps{level="4"}

#### Nuxt I18n 패키지 설치하기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### xx`nuxt.config.ts`xph13x에 Nuxt I18n 모듈을 추가합니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### x`useI18n`를 사용하여 `locale` Prop 설정

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### 자동 링크 지역화: badge{label="4.7+" class="align-text-top"}

`@nuxtjs/i18n`를 설치하면 [Link](/docs/components/link) 구성 요소가 `$localePath` 도우미를 사용하여 내부 링크를 자동으로 현지화합니다. 즉, `localePath()` 또는 `localeRoute()`로 링크를 수동으로 래핑할 필요가 없습니다.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
외부 링크 및 절대 URL은 자동으로 감지되고 지역화를 건너뜁니다. 필요한 경우 `localePath()` 또는 `localeRoute()`를 수동으로 사용할 수 있습니다.
::

::

### Dynamic 방향

각 로케일에는 `dir` 속성이 있으며 `App` 구성 요소가 모든 구성 요소의 방향성을 설정하는 데 사용됩니다.

다국어 응용 프로그램에서는 [useHead](https://nuxt.com/docs/api/composables/use-head) 컴포지션을 사용하여 사용자의 로케일을 기반으로 `<html>` 요소의 `lang` 및 `dir` 속성을 동적으로 설정할 수 있습니다.

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
