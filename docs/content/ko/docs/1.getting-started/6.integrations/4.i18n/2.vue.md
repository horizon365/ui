##  사용법

::note{to="/docs/components/app"}
Nuxt UI는 **App** 구성 요소를 제공하여 앱을 래핑하여 `locale`prop을 포함한 글로벌 구성을 제공합니다.
::

###  로 캘

`locale`prop을 `@nuxt/ui/locale`에서 사용할 로케일과 함께 사용하십시오.

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
각 로케일은 `code` 속성을 가집니다.(예: `en``en-GB`Calendar](/docs/components/calendar)), 같은 구성 요소의 날짜/시간 형식을 결정하는 데 사용됩니다. `en``en-GB`Calendar](/docs/components/calendar),[InputDate](/docs/components/input-date) 및 [InputTime]( /docs/components/input-time) .
::

###  사용자 지정 로케일

[defineLocale](/docs/composables/define-locale)유틸리티를 사용하여 사용자 고유의 로케일을 만들 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
`code` 매개변수를 보면 언어의 ISO 코드를 전달해야합니다. 예를 들어 다음과 같습니다.

* `hi`힌디어 (언어)
* `de-AT``de-AT`: 오스트리아 (지역)에서 사용되는 독일어 (언어)

::

###  로케일 연장

[extendLocal](/docs/composables/extend-locale) 유틸리티를 사용하여 `messages` 또는 `code`를 재지정하여 기존 로케일을 사용자 정의할 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### 동적 로케일

언어 간에 동적으로 전환하려면 [Vue I18n](https://vue-i18n.intlify.dev/)플러그인을 사용하십시오.

::steps{level="4"}

#### Vue I18n 패키지 설치하기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

####  Vue I18n 플러그인 사용`main.ts`

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

####  설정 `locale` prop @ `useI18n`

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

### 동적 방향

각 로케일에는 `dir` 속성이 있으며 `App` 컴포넌트가 모든 컴포넌트의 방향성을 설정하기 위해 사용됩니다.

다국어 응용 프로그램에서는 `lang` 및 `dir` 속성을 사용자의 로케일에 따라 동적으로 설정할 수 있습니다. [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head)composable로 할 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
