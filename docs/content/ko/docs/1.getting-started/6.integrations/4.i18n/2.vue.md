## 사용법

::note{to="/docs/components/app"}
Nuxt UI는 `locale` prop를 포함한 전역 구성을 제공하기 위해 앱을 래핑하는 **Appxph05x 구성 요소를 제공합니다.Nuxt UI prop prop prop including global configurations.
::

### 로케 일

`@nuxt/ui/locale`에서 사용하려는 로케일과 함께 `locale` prop을 사용합니다.

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
각 로케일에는 `code` 속성(예: `en`, `en-GB`, `fr`)이 있으며, [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) 및 xputTimph3031x와 같은 구성 요소의 날짜/시간 형식을 결정합니다.
::

### 사용자 지정 로케일

[defineLocale](/docs/composables/define-locale) 유틸리티를 사용하여 사용자 고유의 로케일을 만들 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
`code` 매개 변수를 보면 언어의 ISO 코드를 전달해야합니다. 예를 들어 다음과 같습니다.

* `hi` 힌디어(언어)
* `de-AT`: 오스트리아 (지역)에서 사용되는 독일어 (언어)

::

### Extend 로케일

[extendLocale](/docs/composables/extend-locale) 유틸리티를 사용하여 `messages` 또는 `code`를 재지정하여 기존 로케일을 사용자 정의할 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### Dynamic 로케일

언어 간에 동적으로 전환하려면 [Vue I18n](https://vue-i18n.intlify.dev/) 플러그인을 사용할 수 있습니다.

::steps{level="4"}

#### Vue I18n 패키지 설치하기

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### x`main.ts`에서 Vue I18n 플러그인 사용

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

#### x`useI18n`를 사용하여 `locale` Prop 설정

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

### Dynamic 방향

각 로케일에는 `dir` 속성이 있으며, `App` 구성 요소에서 모든 구성 요소의 방향성을 설정하는 데 사용됩니다.

다국어 응용 프로그램에서는 [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head) 컴포지션을 사용하여 사용자의 로케일을 기반으로 `<html>` 요소의 `lang` 및 `dir` 속성을 동적으로 설정할 수 있습니다.

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
