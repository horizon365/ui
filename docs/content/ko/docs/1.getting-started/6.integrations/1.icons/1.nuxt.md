##  사용법

Nuxt UI는 자동으로 [`@nuxt/icon`](https://github.com/nuxt/icon)모듈을 등록하므로 추가 설정이 필요하지 않습니다.

### 아이콘 구성 요소

[Icon](/docs/components/icon) 구성 요소를 `name`prop으로 사용하여 아이콘을 표시할 수 있습니다.

::component-code{slug="icon"}
---
소품 :
  모델 번호:i-lucide-lightbulb
  클래스 : 'size-5'
---
::

::note
<https://iconify.design>collection에서 임의의 이름을 사용할 수 있습니다.<https://icones.js.org>에서 쉽게 찾아보거나 `search-icons`](/docs/getting-started/ai/mcp#available-tools)MCP 도구를 사용하여 AI 비서로부터 직접 검색할 수 있습니다.
::

###  구성요소 소품

일부 구성 요소에는 `icon`prop이 있어 [Button](/docs/components/button)처럼 아이콘을 표시합니다.

::component-code{slug="button"}
---
무시하기:
  -  color
  - variant @ 변수
소품 :
  아이콘 : i-lucide-sun
  변형: 미묘함
슬롯 :
  기본값: 단추
---
::

##  컬렉션

### Iconify 데이터 세트

다음과 같이 아이콘 데이터를 로컬에 설치하는 것이 좋습니다.

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

예를 들어, `i-uil-github` 아이콘을 사용하려면 `@iconify-json/uil`를 사용하여 컬렉션을 설치합니다. 이 방법으로 아이콘을 로컬로 제공하거나 서버가 없는 기능에서 제공할 수 있으며 SSR 및 클라이언트측 모두에서 더 빠르고 안정적입니다.

또한 모음을 설치하면 Nuxt UI가 빌드 시 클라이언트 번들에 사용하는 아이콘을 포함할 수 있으므로 런타임 시 필요할 때 로드되는 대신 첫 번째 렌더링 시 사용할 수 있습니다. 이 작업은 기본적으로 `lucide` 모음에서 Nuxt UI의 고유 아이콘에 대해 자동으로 발생합니다. 재정의하거나 응용 프로그램의 다른 곳에서 사용하는 아이콘과 같은 다른 아이콘을 번들로 만들려면 추가 `@nuxt/icon`s[`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle 옵션에 `nuxt.config.ts` 옵션에 `nuxt.config.ts` :

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

또는 `clientBundle.scan`를 활성화하여 소스를 스캔하여 앱 전체에서 사용되는 모든 아이콘을 번들로 묶어 하나씩 나열할 필요가 없습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

스캔은 `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` 및 `.yaml` 파일만 읽으며 문자 문자열로 작성된 아이콘 이름만 일치합니다. `.ts`에 정의된 아이콘은 링크 또는`.js`파일 목록에서 누락된 것과 같습니다. as are names built dynamically like `i-lucide-${name}` . `globInclude` 를 설정하여 파일을 스캔합니다. 기본 목록을 대체하므로 여전히 필요한 확장자를 유지합니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

동적 이름은 빌드 시 전체 집합을 알고 있는 경우에도 번들로 사용할 수 있습니다. API에서 오는 아이콘처럼 런타임에만 존재하는 이름은 번들로 제공할 수 없습니다. 앱이 서버 렌더링될 때 `/api/_nuxt_icon` 라우트에서 요청에 따라 로드되며 Iconify API를 대체 기능으로그리고 `nuxt generate` 또는 `ssr: false`를 사용하는 경우 Iconify API에서 직접 사용할 수 있습니다.

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
이에 대한 자세한 내용은 `@nuxt/icon` 문서에서 확인하십시오.
::

### 사용자 정의 로컬 컬렉션

로컬 SVG 파일을 사용하여 사용자 정의 Iconify 컬렉션을 만들 수 있습니다.

예를 들어, 아이콘의 SVG 파일을 선택한 폴더 아래에 배치합니다(예: `./app/assets/icons` :

```bash
assets/icons
├── add.svg
└── remove.svg
```

`nuxt.config.ts`에 `icon.customCollections`에 항목을 추가합니다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

다음과 같이 아이콘을 사용할 수 있습니다.You can use the icons like this:

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
이에 대한 자세한 내용은 `@nuxt/icon` 문서에서 확인하십시오.
::

##  테마

`app.config.ts`에서 구성 요소에 사용되는 기본 아이콘을 변경할 수 있습니다.

:icons-theme-select 아이콘 테마 선택

: 아이콘 테마

::note
`app.config.ts` 에서 덮어쓰는 아이콘은 클라이언트 번들에 포함되지 않고 런타임 시 요청 시 로드됩니다. 번들로 묶으려면 `{collection}:{name}` 형식(예: `lucide:rocket`)에 추가하십시오.
::
