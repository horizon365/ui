## 사용법

Nuxt UI는 자동으로 [xph03x](xph06x) 모듈을 등록하므로 추가 설정이 필요하지 않습니다.

### icon 구성 요소

[Icon](/docs/components/icon) 구성 요소를 `name` prop과 함께 사용하여 아이콘을 표시할 수 있습니다.

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
<https://iconify.design> 컬렉션에 있는 모든 이름을 사용할 수 있습니다. <https://icones.js.org>에서 쉽게 찾아보거나 [`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP 도구를 사용하여 AI 어시스턴트에서 직접 검색할 수 있습니다.
::

### Component 소품

일부 컴포넌트에는 `icon` prop이 있어 아이콘을 표시할 수 있습니다. 예를 들어 [Button](/docs/components/button)와 같이 다음과 같습니다.

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## Collections 파일

### Iconify 데이터 집합

다음과 같이 아이콘 데이터를 로컬에 설치하는 것이 좋습니다.

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

예를 들어, `i-uil-github` 아이콘을 사용하려면 `@iconify-json/uil`를 사용하여 컬렉션을 설치합니다. 이렇게 하면 로컬로 또는 서버가 없는 기능에서 아이콘을 제공할 수 있습니다. SSR 및 클라이언트측 모두에서 더 빠르고 안정적입니다.

또한 모음을 설치하면 Nuxt UI가 빌드 시 클라이언트 번들에 사용하는 아이콘을 포함할 수 있으므로 런타임 시 필요에 따라 로드되지 않고 첫 번째 렌더링 시 사용할 수 있습니다. 이 작업은 기본적으로 `lucide` 모음에서 Nuxt UI의 고유 아이콘에 대해 자동으로 발생합니다. 재정의하거나 응용 프로그램의 다른 곳에서 사용하는 아이콘과 같은 다른 아이콘을 번들로 만들려면 `nuxt.config.ts`의 [`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle) 옵션에 추가합니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

또는 `clientBundle.scan`를 활성화하여 소스를 스캔하여 앱 전체에서 사용되는 모든 아이콘을 번들로 묶어 하나씩 나열할 필요가 없습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

스캔은 오직 `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` 및 `.yaml` 파일만을 읽으며, 문자 문자열로 쓰여진 아이콘 이름만 일치합니다. `.ts` 또는 `.js` 파일에 정의된 아이콘은 탐색 링크 목록처럼 누락되고, 누락됩니다. 은 `i-lucide-${name}`와 같이 동적으로 빌드된 이름입니다. `globInclude`를 설정하여 파일도 스캔합니다. 기본 목록을 대체하므로 필요한 확장자를 그대로 유지합니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

동적 이름은 빌드 시 전체 집합을 알고 있는 경우에도 `clientBundle.icons`에 나열하여 번들로 사용할 수 있습니다. API에서 오는 아이콘처럼 런타임에만 존재하는 이름은 번들로 제공되지 않습니다. 이러한 이름은 앱이 서버 렌더링될 때 `/api/_nuxt_icon` 경로에서 로드되고 Iconify API를 대체 기능으로 사용하며 `nuxt generate` 또는 x14x를 사용할 때 직접 Iconify API에서 로드됩니다.

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
이에 대한 자세한 내용은 `@nuxt/icon` 문서에서 참조하십시오.
::

### 사용자 정의 로컬 모음

로컬 SVG 파일을 사용하여 사용자 정의 Iconify 컬렉션을 만들 수 있습니다.

예를 들어, 아이콘의 SVG 파일을 선택한 폴더 아래에 놓습니다(예: `./app/assets/icons`:

```bash
assets/icons
├── add.svg
└── remove.svg
```

`nuxt.config.ts`에서 `icon.customCollections`의 항목을 추가합니다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

다음과 같이 아이콘을 사용할 수 있습니다.You can use the icons like this:

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
이에 대한 자세한 내용은 `@nuxt/icon` 문서에서 참조하십시오.
::

::note
`app.config.ts`에서 재정의한 아이콘은 클라이언트 번들에 포함되지 않고 런타임 시 요청에 따라 로드됩니다. 번들로 만들려면 `{collection}:{name}` 형식(예: `lucide:rocket`)으로 `nuxt.config.ts`의 [](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle)에 추가합니다.
::
