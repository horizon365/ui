## 사용법

Nuxt UI는 [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/xph08x로 지원되는 `Icon` 구성 요소를 제공하므로 추가 설정이 필요하지 않습니다.

### Icon 구성요소

[Icon](/docs/components/icon) 구성 요소를 `name` prop과 함께 사용하여 아이콘을 표시할 수 있습니다.

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
<https://iconify.design> 컬렉션에 있는 모든 이름을 사용할 수 있습니다. <https://icones.js.org>에서 쉽게 찾아보거나 [`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP 도구를 사용하여 AI 어시스턴트에서 직접 검색할 수 있습니다.
::

::warning
대시(`-`)가 있는 컬렉션을 사용할 때는 아이콘 이름과 콜론(`:`)을 사용하여 컬렉션 이름을 구분해야 합니다. `@iconify/vue`는 `@nuxt/icon`와 같이 이 경우를 처리하지 않습니다. 예를 들어 `i-simple-icons-github` 대신 `i-simple-icons:github` 또는 `simple-icons:github`를 작성해야 합니다.

[Iconify 명명 규칙 ](https://iconify.design/docs/icon-components/vue/#icon)에 대해 자세히 알아보십시오.
::

### Component 소품

일부 컴포넌트에는 `icon` prop이 있어 아이콘을 표시할 수 있습니다. 예를 들어 [Button](/docs/components/button)와 같이 다음과 같습니다.

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## Collections 파일 목록

### Iconify 데이터세트

다음과 같이 아이콘 데이터를 로컬에 설치하는 것이 좋습니다.

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

예를 들어, `i-lucide-lightbulb` 아이콘을 사용하려면 `@iconify-json/lucide`를 사용하여 컬렉션을 설치합니다.

모음을 설치하면 Nuxt UI가 사용하는 아이콘을 빌드에 포함할 수 있으므로 SSR 중에 즉시 렌더링하고 런타임 시 Iconify API에서 가져오는 대신 완전히 오프라인으로 작동합니다. 기본적으로 `lucide` 모음에서 Nuxt UI 자체 아이콘에 대해 자동으로 발생합니다.

재정의하거나 앱의 다른 곳에서 사용하는 아이콘과 같은 다른 아이콘을 번들로 만들려면 `vite.config.ts`의 `icon.clientBundle.icons` 옵션에 추가합니다.To bundle other icons, such as one you override or use elsewhere in your app, add them to the `icon.clientBundle.icons` option in your `vite.config.ts`:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
`i-{collection}-{name}` 또는 `{collection}:{name}` 양식(예: `i-lucide-heart` 또는 `lucide:heart`) 및 `i-material-symbols-menu` 또는 `material-symbols:menu`)을 사용할 수 있습니다. `@iconify-json/{collection_name}`로 참조하는 각 컬렉션을 설치합니다.
::

사용하는 아이콘을 하나씩 나열하지 않고 번들로 사용하려면 `scan`를 사용하도록 설정합니다. `@nuxt/icon`의 `clientBundle.scan`와 같은 방식으로 설치된 모음에서 아이콘 사용을 소스에서 검색하여 번들로 만듭니다.

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

스캔은 오직 `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` 및 `.yaml` 파일만 읽으며 문자 문자열로 작성된 아이콘 이름과 일치합니다. `.ts` 또는 `.js` 파일에 정의된 아이콘은 탐색 링크 목록처럼 누락되고 누락됩니다. 은 `i-lucide-${name}`와 같이 동적으로 빌드된 이름입니다. `globInclude`를 설정하여 파일을 스캔합니다. 기본 목록을 대체하므로 필요한 확장 기능을 유지합니다.

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

동적 이름은 빌드 시 전체 집합을 알고 있는 경우에도 `clientBundle.icons`에 나열하여 번들로 사용할 수 있습니다. API에서 제공되는 아이콘처럼 런타임에만 존재하는 이름은 전혀 번들로 제공되지 않으며 필요에 따라 Iconify API에서 로드됩니다.

모음이 설치되지 않은 아이콘은 실행 시 Iconify API에서 로드되므로 `@iconify-json/{collection_name}`와 함께 사용하는 각 모음을 설치합니다. 번들링을 완전히 해제하려면 `icon.clientBundle`를 `false`로 설정하십시오.
