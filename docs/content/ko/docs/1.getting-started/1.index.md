## Nuxt UI 란 무엇입니까?

[Reka UI](https://reka-ui.com/)Tailwind CSS](https://tailwindcss.com/), 에 구축된 최신 Vue UI 컴포넌트 라이브러리그리고 [Tailwind Variants](https://www.tailwind-variants.org/)를 통해 125개 이상의 생산 환경을 갖춘 아름답고 접근 가능한 애플리케이션을 제공합니다. Nuxt 및 일반 Vue 앱 (Vite, Inertia, SSR)과 함께 사용할 수 있습니다.

Tailwind CSS를 사용하여 Vue 프로젝트를 구축하는 경우 Nuxt UI는 기본적으로 사용할 수 있는 높은 수준의 구성요소(데이터 테이블, 양식, 오버레이, 탐색)를 제공하며 필요할 때 고급 사용자 정의를 허용합니다.

## v4의 새로운 기능은 무엇입니까?

Nuxt UI v4는 주요 이정표를 표시합니다 : Nuxt UI와 Nuxt UI Pro는 이제 125 + 프로덕션 준비 구성 요소와 완전한 Figma 키트로 구성된 단일 완전한 오픈 소스 및 무료 라이브러리로 통합되었습니다.

v3에서 v4로의 마이그레이션은 v2에서 v3으로의 마이그레이션보다 훨씬 원활합니다. 자세한 내용은 [마이그레이션 가이드](/docs/getting-started/migration)에서 확인하십시오.

## 핵심 기술

Nuxt UI는 세 가지 기초 위에 구축되었습니다: 행동과 접근성을 위한 Reka UI, 스타일을 위한 Tailwind CSS, 그리고 변형을 작성하기 위한 Tailwind Variants

### Reka UI 사용자

Nuxt UI는 [Reka UI](https://reka-ui.com/) 위에 구성 요소의 기초로 구축되었습니다.

- **WAI-ARIA 준수**: 후속 [WAI-ARIA 저작 실습 ](https://reka-ui.com/docs/overview/accessibility) 적절한 의미 체계와 역할
- **Keyboard Navigation**: 탭 및 대화 상자와 같은 복잡한 구성 요소를 위한 키보드 지원 내장
- **Focus Management** : 사용자 상호 작용에 따라 초점을 이동하는 지능적인 초점 처리
- **액세스 가능한 레이블**: 화면 판독기의 레이블 제어를 단순화하기 위한 추상화

### Tailwind CSS

Nuxt UI는 최신 [Tailwind CSS](https://tailwindcss.com/)를 통합하여 크게 개선되었습니다.

- **@5배 빠른 빌드**: 전체 빌드 속도 최대 5배, 증분 빌드 속도 100배 이상 향상
- **통합 도구 체인**: 내장 가져오기 처리, 공급업체 사전 수정 및 구문 변환
- **CSS-first configuration**: JavaScript 대신 CSS로 직접 사용자 정의 및 확장
- **Modern Web Features**: 컨테이너 쿼리, 계단식 레이어, 넓은 영역 색상 등

### Tailwind Variants (Tailwind Variants)의 지도

Nuxt UI는 [Tailwind Variants](https://www.tailwind-variants.org/)를 활용하여 강력한 설계 시스템을 제공합니다.

- **Dynamic Styling** : 강력한 API를 사용한 유연한 컴포넌트 변형
- **Type Safety** : 자동 완성을 위한 TypeScript 지원
- **충돌 해결** : 충돌 스타일의 효율적인 병합

### Vue 호환성 (Nuxt 선택 사항)

Nuxt UI는 Nuxt 뿐만 아니라 Vue 프로젝트에서도 작동합니다. Vite와 Vue 플러그인을 구성에 추가하기만 하면 됩니다.

- **Auto-imports** : 컴포넌트와 합성 파일이 자동으로 임포트되어 전 세계적으로 사용 가능합니다.
- **Design System** : 사용자 정의 색상, 크기, 변형 등을 갖춘 전체 테마 지원
- **Developer Experience**: IntelliSense를 통한 TypeScript 지원 완료 및 자동 완성

##  FAQ

::accordion

:::accordion-item{label="Nuxt UI는 무료로 사용할 수 있습니까?"}
Nuxt UI는 MIT 라이센스에 따라 완전히 무료이며 오픈 소스이며 모든 125 개 이상의 구성 요소는 모두가 사용할 수 있습니다..
:::

:::accordion-item{label="Nuxt 없이 Vue와 Nuxt UI를 사용할 수 있습니까?"}
- 그래! Nuxt에 최적화되어 있지만 Nuxt UI는 Vite 플러그인을 통해 독립형 Vue 프로젝트와 완벽하게 작동합니다. [설치 가이드](/docs/getting-started/installation/vue)를 따라 시작할 수 있습니다.
:::

:::accordion-item{label="Nuxt UI에는 Figma 키트가 포함되어 있습니까?"}
- 그래! Nuxt UI에는 [complete Figma Kit](https://go.nuxt.com/figma-ui)가 포함되어 있어 디자이너와 개발자가 쉽게 공동 작업할 수 있습니다.
:::

:::accordion-item{label="Nuxt UI는 액세스 가능성을 어떻게 처리합니까?"}
Nuxt UI는 [Reka UI](https://reka-ui.com/docs/overview/accessibility)통합을 통해 자동화된 ARIA 속성, 키보드 탐색, 포커스 관리 및 화면 판독기 지원을 제공하며, 강력한 기반을 제공하면서도 특정 사용 사례에 대한 테스트가 중요합니다.
:::

:::accordion-item{label="Nuxt UI 프로덕션 준비가 되었습니까?"}
Nuxt UI는 1000개 이상의 Vitest 테스트, 정기적인 업데이트 및 활성 유지 관리를 통해 수천 개의 응용 프로그램에서 프로덕션에 사용됩니다.
:::

:::accordion-item{label="언제 대안을 고려해야 합니까?"}
