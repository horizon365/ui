##  색상

Nuxt UI는 각각의 [semantic color](/docs/getting-started/theme/design-system#semantic-colors)에 대해 Tailwind CSS 유틸리티 클래스 클래스를 제공하므로 `text-error` 또는 `bg-success`와 같은 클래스 이름을 사용할 수 있습니다.

::code-preview
[1월 1일]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[중고] {class="text-secondary text-sm px-4 py-1.5 inline-block"}
[성공] {class="text-success text-sm px-4 py-1.5 inline-block"}
[정보] {class="text-info text-sm px-4 py-1.5 inline-block"}
[경고] {class="text-warning text-sm px-4 py-1.5 inline-block"}
[오류]{class="text-error text-sm px-4 py-1.5 inline-block"}

# 코드
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

각 유틸리티 클래스는 CSS 변수를 사용하여 밝은 모드 및 어두운 모드의 색상을 설정합니다.

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
각 유틸리티 클래스가 밝은 모드와 어두운 모드에 사용할 음영을 `main.css` 파일에서 조정할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
[**config**](/docs/getting-started/theme/design-system#runtime-configuration)는 여러 음영이 없기 때문에 `black`에는 기본 색상으로 단색이나 흰색을 사용하려면 `main.css` 파일에 직접 설정하십시오.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

::

##  텍스트

Nuxt UI는 텍스트 색상에 대한 Tailwind CSS 유틸리티 클래스를 제공하므로 `text-dimmed` 또는 `text-muted`와 같은 클래스 이름을 사용할 수 있습니다.

::code-preview
[잡담] {class="text-dimmed text-sm px-4 py-1.5 inline-block rounded-md"}
[잡담] {class="text-muted text-sm px-4 py-1.5 inline-block rounded-md"}
[포토] [포토] {class="text-toned text-sm px-4 py-1.5 inline-block rounded-md"}
[문자] {class="text-default text-sm px-4 py-1.5 inline-block rounded-md"}
[포토] {class="text-highlighted text-sm px-4 py-1.5 inline-block rounded-md"}
[반전] {class="text-inverted bg-inverted text-sm px-4 py-1.5 inline-block rounded-md"}

# 코드
```vue
<template>
  <span class="text-dimmed">Dimmed</span>
  <span class="text-muted">Muted</span>
  <span class="text-toned">Toned</span>
  <span class="text-default">Text</span>
  <span class="text-highlighted">Highlighted</span>
  <span class="text-inverted bg-inverted">Inverted</span>
</template>
```
::

각 유틸리티 클래스는 CSS 변수를 사용하여 밝은 모드 및 어두운 모드의 색상을 설정합니다.

::code-group

```css [Light]
:root {
  --ui-text-dimmed: var(--ui-color-neutral-400);
  --ui-text-muted: var(--ui-color-neutral-500);
  --ui-text-toned: var(--ui-color-neutral-600);
  --ui-text: var(--ui-color-neutral-700);
  --ui-text-highlighted: var(--ui-color-neutral-900);
  --ui-text-inverted: white;
}
```

```css [Dark]
.dark {
  --ui-text-dimmed: var(--ui-color-neutral-500);
  --ui-text-muted: var(--ui-color-neutral-400);
  --ui-text-toned: var(--ui-color-neutral-300);
  --ui-text: var(--ui-color-neutral-200);
  --ui-text-highlighted: white;
  --ui-text-inverted: var(--ui-color-neutral-900);
}
```

::

::tip
`main.css` 파일에서 이러한 CSS 변수를 사용자 정의할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-text: var(--ui-color-neutral-900);
}

.dark {
  --ui-text: white;
}
```

이러한 변수 중 몇 가지를 한 번에 변경하려면 [ 설정에서 `neutral`](/docs/getting-started/theme/design-system#runtime-configuration) 에 다른 색상을 할당합니다.
::

##  포커스: badge{label="4.9+" class="align-text-top"}

Nuxt UI는 모든 대화형 요소에 `focus-visible` 아웃라인을 적용하고, 구성요소의 `color`prop로 착색하며, 예를 들어 `outline-primary/25` when `color="primary"` 또는 `outline-inverted/25`when`color="neutral"`

컴포넌트 색상에 관계없이 전체 앱에서 단일 윤곽선 색상을 선호하는 경우 `main.css` 파일에 전역 규칙을 추가할 수 있습니다.

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

첫 번째 규칙은 모든 구성 요소의 초점 윤곽을 착색하고, 두 번째 규칙은 변형에 의해 초점에 적용 된 링 색상을 `outline` 또는 `subtle`와 같은 보이는 테두리에 정렬합니다.

::note
이러한 규칙은 `@layer` 외부에서 선언하여 구성 요소 테마에 의해 설정된 색상보다 우선합니다. 첫 번째 규칙은 요소의 기본 포커스 아웃라인을 색조로 지정합니다.`border` on focus like [FileUpload](/docs/components/file-upload ) 또는 [ContentSurround](/docs/components/content-surround) @ @ 다음 구성 요소 `color`를 계속 따르십시오.
::

##  반지름

Nuxt UI는 Tailwind CSS의 기본값인 `rounded-*`유틸리티를 통합된 경계 반경 시스템으로 대체하므로 일반 [border radius utilities](https://tailwindcss.com/docs/border-radiuslike)like`rounded-xs` 또는 `rounded-2xl` :

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xs"}
[sm]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-sm"}
[md]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-md"}
[lg]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-lg"}
[xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-xl"}
[2xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-2xl"}
[3xl]{class="border-2 border-accented text-sm px-4 py-1.5 inline-block rounded-3xl"} @

# 코드
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

이러한 유틸리티 클래스는 전역 `--ui-radius`CSS 변수를 기반으로 계산되며, 이 변수는 일관성 있는 모양을 위해 모든 구성요소에 적용되는 기본 반지름 값을 정의합니다.

```css
:root {
  --ui-radius: 0.25rem;
}
```

각 유틸리티는 이 기본값을 곱합니다:

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
`main.css`파일에서 기준 반지름 값을 사용자화할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
`--ui-radius`를 변경하면 Nuxt UI 구성 요소뿐만 아니라 자신의 마크업 및 타사 구성 요소의 `rounded-xs` 클래스에도 영향을 미칩니다.
::

::note
위의 헤더에서 :prose-icon{name="i-lucide-palette" class="text-primary"}theme 메뉴를 사용하여 기본 반지름 값을 변경하십시오.
::

##  컨테이너

Nuxt UI는 [Container](/docs/components/container) 구성 요소의 최대 너비를 제어하는 `--ui-container`CSS 변수를 제공합니다.

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
`main.css`파일에서 이 값을 사용자 정의하여 애플리케이션 전체에서 컨테이너 너비를 일관되게 조정할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

##  헤더

Nuxt UI는 `--ui-header-height`CSS 변수를 제공하여 [Header](/docs/components/header) 구성 요소의 높이를 제어합니다.

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
`main.css`에서 이 값을 사용자 지정하여 애플리케이션 전체에서 헤더 높이를 일관되게 조정할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
::

##  바디

Nuxt UI는 앱의 `<body>`{lang="html"} 요소에 기본 클래스를 적용하여 밝은 모드와 어두운 모드 간에 일관된 테마 지정을 수행합니다.

```css
body {
  @apply antialiased text-default bg-default scheme-light dark:scheme-dark;
}
```
