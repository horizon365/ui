## TAILWIND CSS (Xph000xTailwind CSS) (영어)

Tailwind CSS는 CSS 우선 설정을 사용하여 CSS에서 [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directivexph05x 지시어로 디자인 토큰을 정의 할 수 있습니다.이 테마는 이식 가능하고 유지 가능하며 사용자 정의하기 쉽습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
사용 가능한 모든 테마 변수 사용자 정의 옵션은 Tailwind CSS 문서를 참조하십시오.
::

::tip
Tailwind CSS v4는 [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor)를 변경하여 브라우저 기본값과 일치하도록 단추가 `cursor: pointer` 대신 `cursor: default`를 사용하도록 했습니다. 포인터 커서를 전역적으로 복원하려면 CSS에 다음 기본 스타일을 추가하십시오.

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### 글꼴

`--font-*` 테마 변수를 사용하여 프로젝트에서 [utilities](https://tailwindcss.com/docs/font-family#customizing-your-theme) 글꼴 패밀리를 사용자화합니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

::framework-only
#nuxt
:::note{to="/docs/getting-started/integrations/fonts"}
여기에 정의된 글꼴은 `@nuxt/fonts` 모듈에 의해 자동으로 로드되고 최적화됩니다.
:::
::

### Color 이미지

`--color-*` 테마 변수를 사용하여 [colors](https://tailwindcss.com/docs/colors#customizing-your-colors) 또는 [override 기본 colors](https://tailwindcss.com/docs/colors#overriding-default-colors)를 사용자 정의할 수 있습니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme static {
  /* Override default green color */
  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;

  /* Define new custom color */
  --color-brand-50: #fef2f2;
  --color-brand-100: #fee2e2;
  --color-brand-200: #fecaca;
  --color-brand-300: #fca5a5;
  --color-brand-400: #f87171;
  --color-brand-500: #ef4444;
  --color-brand-600: #dc2626;
  --color-brand-700: #b91c1c;
  --color-brand-800: #991b1b;
  --color-brand-900: #7f1d1d;
  --color-brand-950: #450a0a;
}
```

::warning
사용자 정의 색상을 추가할 때는 각 색상에 대해 `50`부터 `950`까지의 모든 음영을 정의해야 합니다.
::

### 중단 점

`--breakpoint-*` 테마 변수를 사용하여 breakpoints](https://tailwindcss.com/docs/responsive-design#customizing-your-theme)를 사용자 정의합니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

### Motion (### Motion)

`--ease-*` 테마 변수를 사용하여 프로젝트의 애니메이션 및 이동 전환에 대한 easing](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme)를 사용자 정의합니다.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

`--ease-out`에서 실행되는 애니메이션 입력 및 종료는 `--ease-in-out`에서 애니메이션을 확정되지 않은 로드하므로 이 두 개의 라이브러리를 재정의합니다.

::note
`prefers-reduced-motion`를 설정하면 오버레이가 배율 조정 또는 슬라이딩 및 이동 전환 대신 제자리에서 페이드됩니다.
::

## color 시스템

Nuxt UI의 색상 시스템은 특정 색상 값이 아닌 **semantic naming**를 중심으로 설계되었습니다.이 접근 방식은 UI를보다 유지 관리 가능하게하고 테마 전환을 쉽게 만듭니다.

### 의미론적 색

Nuxt UI는 색상의 **pure**를 설명하는 의미 론적 색상 별칭을 제공합니다. 각 별칭은 `@theme` 구성의 색상을 기반으로 정의되며, [기본 Tailwind CSS palette](https://tailwindcss.com/docs/colors) 이외에 정의된 모든 색상일 수 있습니다.

| 색상 (color)| 기본 값| 설명 (Description)|
| --- | --- | --- |
| `primary`{color="primary"}| `green` 공식| 주요 CTA, 활성 탐색, 브랜드 요소, 중요 링크|
| `secondary`{color="secondary"}| `blue` 공식| 보조 단추, 대체 작업, 보완 UI 요소|
| `success`{color="success"}| `green`| 성공 메시지, 완료 상태, 긍정적인 확인|
| `info`{color="info"} (`info`{color="info"})| `blue`| 정보 경고, 툴팁, 도움말 텍스트, 중립 알림|
| `warning`{color="warning"}| `yellow`| 경고 메시지, 보류 상태, 주의가 필요한 항목|
| `error`{color="error"} 공식| `red` 공식| 오류 메시지, 유효성 검사 오류, 파괴 작업|
| `neutral`| `slate`| 텍스트, 테두리, 배경, 비활성화 상태|

이러한 의미 색상은 Nuxt UI 컴포넌트의 `color` prop에서 사용할 수 있습니다.

::component-code{slug="button"}
---
props:
  color: primary
slots:
  default: Save Changes
---
::

::note
헤더에서 :prose-icon{name="i-lucide-palette" class="text-primary"} 테마 메뉴를 사용하여 다양한 색상 구성표가 전체 UI에 어떤 영향을 미치는지 즉시 확인하거나 [theme editor](/theme)를 열어 모든 것을 한 번에 사용자 정의하십시오!
::

### Runtime 설정

::framework-only
#nuxt
:::div
`ui.colors` 키 아래의 [`app.config.ts`](https://nuxt.com/docs/4.x/directory-structure/app/app-config) 파일에서 런타임 시 이러한 색상을 구성할 수 있으므로 서버를 다시 시작하지 않고도 동적 테마 사용자 정의를 수행할 수 있습니다.

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#vue
:::div
`ui.colors` 키 아래의 `vite.config.ts` 파일에서 런타임 시 이러한 색상을 구성할 수 있으므로 동적 테마 사용자 정의를 허용합니다.

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
테마에 있는 색상만 사용할 수 있습니다. 다음 중 하나입니다.
- Tailwind의 기본 colors](https://tailwindcss.com/docs/colors) 사용 (`blue`, `green`, `zinc`와 같은)
- xx`@theme` 지시문을 사용하여 사용자 정의 색상을 정의합니다 (위의 예제에서 `brand`와 같습니다).
::

### Extend 색상

`tertiary` 색상을 추가하는 것과 같이 기본값 이외의 추가 의미 색상을 정의할 수 있습니다.You may want to define extra semantic colors beyond the default, such as adding a `tertiary` color:

::framework-only
#nuxt
:::div
먼저, `ui.theme.colors` 키 아래에 `nuxt.config.ts`의 새 색상을 등록합니다.

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

그런 다음, `app.config.ts` 키 아래에 `ui.colors`를 할당합니다.

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#vue
:::div
`vite.config.ts` 파일에 새 색상을 등록하고 할당하십시오:

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

마지막으로, `color` prop 또는 [as class](/docs/getting-started/theme/css-variables)를 지원하는 컴포넌트에 이 새로운 색상을 사용합니다.

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
