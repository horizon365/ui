### Zu einem Nuxt-Projekt hinzufügen

::steps{level="4"}

#### Install das Nuxt UI Paket installieren

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### Füge das Nuxt UI Modul in dein`nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Es ist nicht notwendig ,`@nuxt/icon`,`@nuxt/fonts`oder`@nuxtjs/color-mode`zu Ihrem`modules`Array hinzuzufügen , da Nuxt UI sie automatisch registriert .
::

#### Import Tailwind CSS und Nuxt UI in Ihrem CSS

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
Bei Verwendung von[Nuxt Layers](https://nuxt.com/docs/getting-started/layers)generiert das Modul automatisch[`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive)Direktiven für jedes Layer-Verzeichnis , um sicherzustellen , dass Tailwind CSS alle Layer-Quelldateien nach Utility-Klassen durchsucht .
::

::callout{icon="i-simple-icons-visualstudiocode"}
Es wird empfohlen , die[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)Erweiterung für VSCode zu installieren und die folgenden Einstellungen hinzuzufügen :

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### Wickeln Sie Ihre App mit App-Komponente

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
Die`App`- Komponente richtet die globale Konfiguration ein und wird für**Toast**,**Tooltip**und**programmatische Überlagerungen**benötigt .
::

::

## Optionen

Sie können die Nuxt-Benutzeroberfläche anpassen , indem Sie Optionen in Ihrem`nuxt.config.ts`angeben .

`prefix`

Verwenden Sie die Option `prefix`, um den Präfix der Komponenten zu ändern.

@@@125@@126@@@@@127@@@@@127@@@@@126@@@@@@@127@@@@@@@@126@@@@@@@@@@@127{lang="ts-type"}`U``U`

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@

Verwenden Sie die Option `fonts`, um das Modul [`@nuxt/fonts`](https://github.com/nuxt/fonts) zu aktivieren oder zu deaktivieren.

@@@145@@146@@@@@147@@@@147@@@@146@@@@@@147@@@@@@146@@@@@@@@@@@146{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

`colorMode`

Verwenden Sie die Option `colorMode`, um das Modul [`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode) zu aktivieren oder zu deaktivieren.

@@@165@@@166@@@@@167@@@@@167@@@@166@@@@@@166@@@@@@@@@@166`true`PH1667 @

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@

Verwenden Sie die Option `theme.colors`, um die dynamischen Farbaliase zu definieren, die zum Generieren des Komponentendesigns verwendet werden.

@@@180@@@181@@@@181@@@@181@@@@@181@@@@181@@@@@@181@@@@@@@181@@@@@@@@181@@@@@@@@181@@@@@@@@181@@@@@@@@18181@@

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
Jeder Alias generiert einen vollständigen Satz von `--ui-color-*` Schattierungen und Varianten in den Komponententhemen mit Farbvarianten, unabhängig davon, ob Ihre App sie verwendet oder nicht. Trimmen Sie die Liste auf die Aliase, die Sie tatsächlich verwenden, und behalten Sie `error`, wenn Sie Formulare verwenden, da Validierungsstile darauf angewiesen sind.
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
Erfahren Sie mehr über die Farbanpassung und das Thema im Themenbereich.
::

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@

Verwenden Sie die Option `theme.transitions`, um Übergänge auf Komponenten zu aktivieren oder zu deaktivieren.

- Default:`true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
Mit dieser Option wird die Klasse `transition-colors` für Komponenten mit Hover-oder aktiven Status hinzugefügt.
::

`theme.unstyled`: badge{label="4.9+" class="align-text-top"}

Verwenden Sie die Option `theme.unstyled`, um alle Standardthemenklassen aus Komponenten zu entfernen und nur deren Struktur und die Klassen beizubehalten, die Sie über `class`,`ui` oder `app.config.ui` bereitstellen.

@@@221@@@@@222@@@@@@@@222@@@@@@@@@@@@PH2222@@@@@@@@@@PH2223

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
Dies streift auch **struktural** Klassen (Positionierung, Übergänge, Flex/Grid), nicht nur kosmetische. Layout-schwere Komponenten wie `Modal`,`Drawer` oder `Calendar` müssen Sie ihr Layout ähnlich dem unstyled Modus von PrimeVue erneut liefern.
::

`theme.defaultVariants`

Verwenden Sie die Option `theme.defaultVariants`, um die Standardvarianten `color` und `size` für Komponenten außer Kraft zu setzen.

Nur Standardwerte, die genau `primary` oder `md` sind, werden ersetzt, so dass Avatar `color: 'neutral'` und Separator `size: 'xs'` behält.

- Default :`{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

`theme.prefix`: badge{label="4.2+" class="align-text-top"}

Verwenden Sie die`theme.prefix`- Option , um das gleiche Präfix zu konfigurieren , das Sie für Ihren Tailwind CSS-Import festgelegt haben . Dadurch wird sichergestellt , dass Nuxt-UI - Komponenten die richtigen vordefinierten Hilfsklassen und CSS-Variablen verwenden .

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
Möglicherweise müssen Sie`fonts.processCSSVariables`aktivieren , um die Präfixoption mit dem`@nuxt/fonts`- Modul zu verwenden :

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

Dadurch werden automatisch alle Tailwind-Utility - Klassen und CSS-Variablen in Nuxt UI-Komponententhemen vorangestellt :

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Weitere Informationen zur Verwendung eines Präfixes finden Sie in der Tailwind CSS-Dokumentation .
::

Verwenden Sie die Option`prose`, um den Import von Nuxt-Benutzeroberfläche[`Prose`components](/docs/typography)zu erzwingen , auch wenn`@nuxtjs/mdc`,`@nuxt/content`oder`@comark/nuxt`nicht installiert ist .

```ts [nuxt.config.ts] {4-6}

  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

`content`

Verwenden Sie die Option`content`, um den Import der Prosa - und Inhaltskomponenten der Nuxt-Benutzeroberfläche zu erzwingen , auch wenn`@nuxt/content`nicht installiert ist .

@@@343`false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }

```

`experimental.componentDetection`: badge{label="4.1+" class="align-text-top"}

Verwenden Sie die Option`experimental.componentDetection`, um die automatische Komponentenerkennung für das Baumschütteln zu aktivieren . Diese Funktion scannt Ihren Quellcode , um festzustellen , welche Komponenten tatsächlich verwendet werden , und generiert nur das erforderliche CSS für diese Komponenten (einschließlich ihrer Abhängigkeiten) .

- Default :`false`{lang="ts-type"}
- Typ :`boolean | string[]`{lang="ts-type"}

**Automatische Erkennung aktivieren :**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**Fügen Sie zusätzliche Komponenten für die dynamische Verwendung hinzu :**

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
Bei der Bereitstellung eines Arrays von Komponentennamen wird die automatische Erkennung aktiviert und diese Komponenten (zusammen mit ihren Abhängigkeiten) werden garantiert einbezogen . Dies ist nützlich für dynamische Komponenten wie`<component :is="..." />`, die nicht statisch analysiert werden können .
::

## Fortlaufende Veröffentlichungen

Nuxt UI verwendet[pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new)für kontinuierliche Vorschauversionen , die Entwicklern sofortigen Zugriff auf die neuesten Funktionen und Fehlerbehebungen bieten , ohne auf offizielle Veröffentlichungen zu warten .

Automatische Vorschau-Releases werden für alle Commits und PRs an den`v4`branch . Use erstellt , indem Sie Ihre Paketversion durch den spezifischen Commit-Hash oder die PR-Nummer ersetzen .

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
@@406pkg.pr.new**kommentiert PRs automatisch mit der Installations-URL , so dass Änderungen einfach getestet werden können .
::
