## Was ist Nuxt UI?.

Eine moderne Vue UI-Komponentenbibliothek, die auf [Reka UI](https://reka-ui.com/),[Tailwind CSS](https://tailwindcss.com/),[Tailwind Variants](https://www.tailwind-variants.org/), um schöne und zugängliche Anwendungen mit 125 + Produktion zu versenden-Kompatibel mit Nuxt-und einfachen Vue-Apps (Vite, Inertia, SSR).

Wenn Sie ein Vue-Projekt mit Tailwind CSS erstellen, ist die Nuxt-Benutzeroberfläche eine großartige Standardwahl. Sie bietet hochwertige, sofort einsatzbereite Komponenten (Datentabellen, Formulare, Overlays, Navigation) und ermöglicht bei Bedarf weiterhin eine erweiterte Anpassung.

## Kerntechnologien

Nuxt UI basiert auf drei Grundlagen: Reka UI für Verhalten und Zugänglichkeit, Tailwind CSS für das Styling und Tailwind Variants für das Komponieren von Varianten.

### Reka UI

Nuxt UI basiert auf [Reka UI](https://reka-ui.com/) als Grundlage für die Komponenten:

- ** WAI-ARIA Compliance**: Folgt [ WAI-ARIA-Autorenpraktiken ](https://reka-ui.com/docs/overview/accessibility) mit der richtigen Semantik und Rollen
- **Tastaturnavigation**: Integrierte Tastaturunterstützung für komplexe Komponenten wie Registerkarten und Dialoge
- **Focus-Management**: Intelligente Fokus-Handhabung, die den Fokus basierend auf Benutzerinteraktionen bewegt
- **Accessible Labels**: Abstraktionen zur Vereinfachung der Beschriftungssteuerung für Bildschirmlesegeräte

### Tailwind CSS (englisch)

Nuxt UI integriert die neueste [Tailwind CSS](https://tailwindcss.com/), was erhebliche Verbesserungen bringt:

- **@5x Faster Builds**: Vollständige Builds bis zu 5x schneller, inkrementelle Builds über 100x schneller
- **Unified Toolchain**: Eingebaute Importbehandlung, Herstellervoreinstellung und Syntaxtransformation
- ** CSS-first Configuration**: Anpassen und erweitern direkt in CSS statt JavaScript
- **Modern Web Features**: Containerabfragen, Kaskadenschichten, Farben mit großem Farbumfang und mehr

### Rückenwindvarianten

Nuxt UI nutzt [Tailwind Variants](https://www.tailwind-variants.org/), um ein leistungsfähiges Designsystem bereitzustellen:

- **Dynamisches Styling **: Flexible Komponentenvarianten mit einer leistungsstarken API
- **Type Safety**: Vollständige TypeScript-Unterstützung mit automatischer Vervollständigung
- **Konfliktlösung**: Effiziente Verschmelzung von widersprüchlichen Stilen

### Vue Kompatibilität (Nuxt optional)

Nuxt UI funktioniert mit jedem Vue-Projekt, nicht nur mit Nuxt. Fügen Sie einfach die Vite-und Vue-Plugins zu Ihrer Konfiguration hinzu:

- ** Auto-imports **: Komponenten und Compositables werden automatisch importiert und sind weltweit verfügbar
- **Design System**: Vollständige Theming-Unterstützung mit anpassbaren Farben, Größen, Varianten und mehr
- **Developer Experience**: Vollständige TypeScript-Unterstützung mit IntelliSense und automatischer Vervollständigung

:::accordion-item{label="Ist Nuxt UI kostenlos zu verwenden?"}
Ja! Nuxt UI ist völlig kostenlos und Open Source unter der MIT-Lizenz. Alle 125 + Komponenten sind für jedermann verfügbar.
:::

:::accordion-item{label="Kann ich Nuxt UI mit Vue ohne Nuxt verwenden?"}
ja! Während für Nuxt optimiert, funktioniert Nuxt UI perfekt mit Standalone-Vue-Projekten über unsere Vite plugin. You folgen können die [installation guide](/docs/getting-started/installation/vue) um loszulegen.
:::

:::accordion-item{label="Enthält Nuxt UI ein Figma Kit?"}
ja! Nuxt UI enthält ein [complete Figma Kit](https://go.nuxt.com/figma-ui) mit allen Komponenten, was es Designern und Entwicklern leicht macht, zusammenzuarbeiten.
:::

:::accordion-item{label="Wie geht Nuxt UI mit Zugänglichkeit um?"}
Durch die Integration von [Reka UI](https://reka-ui.com/docs/overview/accessibility) bietet Nuxt UI automatische ARIA-Attribute, Tastaturnavigation, Fokusmanagement und Unterstützung für Bildschirmleser.
:::

:::accordion-item{label="Ist Nuxt UI produktionsbereit?"}
Nuxt UI wird in der Produktion von Tausenden von Anwendungen mit über 1000 Vitest-Tests, regelmäßigen Updates und aktiver Wartung verwendet.
:::

:::accordion-item{label="Wann sollte ich Alternativen in Betracht ziehen?"}
Betrachten Sie **Vuetify** wenn Sie Material Design Styling wollen,** ant-design-vue** für Ant Design Styling,**PrimeVue** oder **Element Plus** wenn Sie nicht wollen, dass Tailwind,** shad-vue ** repo, wenn Sie es vorziehen, in Ihre Komponenten zu kopieren, cnCSS **Quasar** für plattformübergreifende Apps (Web, Mobile, Desktop) oder **Reka UI**/**Headless UI** wenn Sie nur unstyled Primitives benötigen.
:::
