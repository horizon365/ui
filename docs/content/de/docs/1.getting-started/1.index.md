## Was ist Nuxt UI?

Eine moderne Vue UI-Komponentenbibliothek, die auf [Reka UI](https://reka-ui.com/), [Tailwind CSS](https://tailwindcss.com/) und [Tailwind Variants](https://www.tailwind-variants.org/) basiert, um schöne und zugängliche Anwendungen mit über 125 produktionsfertigen Komponenten zu liefern.

Wenn Sie ein Vue-Projekt mit Tailwind CSS erstellen, ist die Nuxt-Benutzeroberfläche eine großartige Standardwahl. Sie bietet hochwertige, sofort einsatzbereite Komponenten (Datentabellen, Formulare, Overlays, Navigation) und ermöglicht bei Bedarf weiterhin erweiterte Anpassungen.

##  Was ist neu in v4?

Nuxt UI v4 markiert einen wichtigen Meilenstein: Nuxt UI und Nuxt UI Pro sind jetzt in einer einzigen, vollständig Open-Source-und kostenlosen Bibliothek mit über 125 produktionsreifen Komponenten und einem vollständigen Figma-Kit vereint.

Die Migration von v3 zu v4 wird viel reibungsloser sein als von v2 zu v3. Lesen Sie mehr im [migration-Leitfaden ](/docs/getting-started/migration).

## Core-Technologie

Nuxt UI basiert auf drei Grundlagen: Reka UI für Verhalten und Zugänglichkeit, Tailwind CSS für das Styling und Tailwind Variants für das Komponieren von Varianten.

### Reka UI (englisch)

Nuxt UI ist auf [Reka UI](https://reka-ui.com/) als Grundlage für die Komponenten aufgebaut:

- **WAI-ARIA Compliance**: Folgt den [WAI-ARIA-Authoring-Praktiken ](https://reka-ui.com/docs/overview/accessibility) mit der richtigen Semantik und Rollen
- **Keyboard Navigation**: Integrierte Tastaturunterstützung für komplexe Komponenten wie Registerkarten und Dialoge
- **Focus Management**: Intelligentes Fokushandling, das den Fokus basierend auf Benutzerinteraktionen verschiebt
- **Accessible Labels**: Abstractions to simplify labeling controls for screen reader (Abstraktionen zur Vereinfachung der Beschriftungssteuerung für Screenreader)

### Tailwind CSS (Englisch)

Nuxt UI integriert die neueste [Tailwind CSS](https://tailwindcss.com/), bringt erhebliche Verbesserungen:

- **5x Faster Builds**: Vollständige Builds bis zu 5x schneller, inkrementelle Builds über 100x schneller
- **Unified Toolchain**: Integrierte Importverarbeitung, Herstellerpräfixierung und Syntaxtransformationen
- **CSS-first Configuration**: Anpassen und Erweitern direkt in CSS anstelle von JavaScript
- **Modern Web Features**: Containerabfragen, Kaskadenebenen, Farben mit großem Farbraum und mehr

### Tailwind-Varianten

Nuxt UI nutzt die Vorteile der [Tailwind Variants](https://www.tailwind-variants.org/), um ein leistungsstarkes Designsystem bereitzustellen:

- **Dynamic Styling**: Flexible Bauteilvarianten mit einer leistungsstarken API
- **Type Safety**: Volle TypeScript-Unterstützung mit automatischer Vervollständigung
- **Conflict Resolution**: Effizientes Zusammenführen von widersprüchlichen Stilen

### Vue-Kompatibilität (Nuxt optional)

Nuxt UI funktioniert mit jedem Vue-Projekt, nicht nur Nuxt. Fügen Sie einfach die Vite-und Vue-Plugins zu Ihrer Konfiguration hinzu:

- **Auto-imports**: Komponenten und Compositables werden automatisch importiert und sind weltweit verfügbar
- **Design System**: Vollständige Theming-Unterstützung mit anpassbaren Farben, Größen, Varianten und mehr
- **Developer Experience**: Vollständige TypeScript-Unterstützung mit IntelliSense und automatischer Vervollständigung

### TypeScript Unterstützung.

Nuxt UI bietet eine umfassende TypeScript-Integration für eine überlegene Entwicklererfahrung:

- **Auto-completion**: Für alle Komponenten-Requisiten, Slots und Events
- **Generic Components**: Verwenden von [Vue Generics](https://vuejs.org/api/sfc-script-setup.html#generics)
- **Type-safe Theming**: In `app.config.ts` (Für Deutschland)
- **IntelliSense**: In der gesamten Codebasis

## FAQ

::accordion

:::accordion-item{label="Ist Nuxt UI kostenlos zu verwenden?"}
Ja! Nuxt UI ist völlig kostenlos und Open Source unter der MIT-Lizenz. Alle 125 + Komponenten sind für jedermann verfügbar.
:::

:::accordion-item{label="Kann ich Nuxt UI mit Vue ohne Nuxt verwenden?"}
ja! Während für Nuxt optimiert, funktioniert Nuxt UI perfekt mit Standalone-Vue-Projekten über unsere Vite plugin. You können die [installation guide](/docs/getting-started/installation/vue) folgen, um loszulegen.
:::

:::accordion-item{label="Enthält Nuxt UI ein Figma Kit?"}
ja! Nuxt UI enthält ein [complete Figma Kit](https://go.nuxt.com/figma-ui) mit allen Komponenten, was es Designern und Entwicklern leicht macht, zusammenzuarbeiten.
:::

:::accordion-item{label="Wie geht Nuxt UI mit der Zugänglichkeit um?"}
Durch die Integration von [Reka UI](https://reka-ui.com/docs/overview/accessibility) bietet die Nuxt UI automatische ARIA-Attribute, Tastaturnavigation, Fokusmanagement und Unterstützung für Bildschirmleser.
:::

:::accordion-item{label="Ist Nuxt UI produktionsreif?"}
Nuxt UI wird in der Produktion von Tausenden von Anwendungen mit über 1000 Vitest-Tests, regelmäßigen Updates und aktiver Wartung verwendet.
:::

:::accordion-item{label="Wann sollte ich Alternativen in Betracht ziehen?"}
Berücksichtigen Sie **Vuetify**, wenn Sie Material Design-Styling wünschen, **ant-design-vue** für Ant Design-Styling, **PrimeVue** oder **Element Plus**, wenn Sie kein Tailwind CSS wünschen, **shadcn-vue**, wenn Sie Komponenten lieber in Ihr Repo kopieren, **Quasar** für plattformübergreifende Apps (Web, Mobile, Desktop), oder **Reka UI**/**Headless UI**, wenn Sie nur unstyled Primitive benötigen.
:::

Stellen Sie Fragen und erhalten Sie Hilfe in [GitHub Discussions ](https://github.com/nuxt/ui/discussions/categories/q-a), chatten Sie mit der Community auf [Discord](https://go.nuxt.com/discord) oder melden Sie Fehler auf [GitHub](https://github.com/nuxt/ui/issues).
