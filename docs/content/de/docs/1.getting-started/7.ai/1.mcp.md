@@ph000@@@Was ist MCP?

MCP (Model Context Protocol) ist ein standardisiertes Protokoll, das KI-Assistenten den Zugriff auf externe Datenquellen und Tools ermöglicht. Nuxt UI bietet einen MCP-Server, der KI-Assistenten wie Claude Code, Cursor und Windsurf den direkten Zugriff auf Komponenteninformationen, Quellcode und Anwendungsbeispiele ermöglicht.

Der MCP-Server bietet einen strukturierten Zugriff auf unsere Komponentenbibliothek, sodass KI-Tools die Nuxt-UI-Entwicklung leicht verstehen und unterstützen können.

## Verfügbare Ressourcen

Der Nuxt UI MCP-Server stellt die folgenden Ressourcen für die Erkennung zur Verfügung:

- **`resource://nuxt-ui/components`**: Alle verfügbaren Komponenten mit Kategorien durchsuchen
- **`resource://nuxt-ui/composables`**: Durchsuchen Sie alle verfügbaren composables mit Kategorien
- **`resource://nuxt-ui/examples`**: Alle verfügbaren Codebeispiele durchsuchen
- **`resource://nuxt-ui/templates`**: Durchsuchen Sie alle verfügbaren Projektvorlagen
- **`resource://nuxt-ui/documentation-pages`**: Durchsuchen Sie alle verfügbaren Dokumentationsseiten

Sie können auf diese Ressourcen mit Tools wie Claude Code zugreifen, indem Sie `@`.

## Verfügbare Werkzeuge

Der Nuxt UI MCP-Server bietet die folgenden Tools, die nach Kategorien sortiert sind:

### Suchwerkzeuge

- **`search-components`**: Suche Komponenten nach Namen, Kategorie oder Absicht. Alternative Namen wie `"segmented control"` oder `"combobox"` werden abgestimmt und die Ergebnisse werden nach Relevanz geordnet. Ohne Parameter werden alle Komponenten aufgelistet
- ****: Suche nach composables nach Name oder Beschreibung. Ohne Parameter listet alle composables auf
- **`search-icons`**: Suche nach Icons in Iconify Sammlungen (standardmäßig auf `lucide`). Gibt Symbolnamen im `i-{prefix}-{name}` Format zurück, das von Nuxt UI verwendet wird

### Komponentenwerkzeuge

- **`get-component`**: Unterstützt einen `sections` Parameter (`usage`,`examples`,`api`,`theme`,`changelog`), um nur bestimmte Teile abzurufen und die Antwortgröße zu reduzieren
- ****: Retrieved metadata for a component including props, slots, and events (lightweight, no documentation content). Props sind standardmäßig kompakt, übergeben `full: true` für die rekursiven Rohproppenschemata

### Dokumentationswerkzeuge

- ****: Suche Dokumentationsseiten nach Titel, Beschreibung oder Abschnitt. Ohne Parameter, listet alle Seiten auf. Verwenden Sie `section` zum Filtern (z. B.`"getting-started"`,`"components"`).
- **`get-documentation-page`**: Zeigt den Inhalt der Dokumentationsseite über den URL-Pfad an. Unterstützt einen `headings`-Parameter, um nur bestimmte h2-Abschnitte abzurufen (z. B.`["Usage", "API"]`) und die Antwortgröße zu reduzieren

### Template-Werkzeuge

- **`list-templates`**: Listet alle verfügbaren Nuxt UI-Vorlagen mit optionaler Framework-Filterung auf
- **`get-template`**: Abruft der Beschreibung, der Funktionen und der Links einer Vorlage

### Beispielwerkzeuge

- **`list-examples`**: Listet die Namen aller verfügbaren UI-Beispiele auf
- **`get-example`**: Gibt den Quellcode eines UI-Beispiels zurück

### Migrationswerkzeuge

- **`get-migration-guide`**: Abrufen der Migrationsanleitung und Upgrade-Anweisungen für diese Version von Nuxt UI

## Limit verfügbare Tools

Setzen Sie den optionalen `X-MCP-Tools` HTTP-Header auf eine durch Kommas getrennte Liste von Werkzeugnamen, um nur die Werkzeuge anzuzeigen, die Ihr Assistent benötigt.

Verwenden Sie die genauen Namen der kebab-case MCP-Tools, zum Beispiel:

```json
{
  "X-MCP-Tools": "search-components,get-component"
}
```

Kein Header macht alle Tools verfügbar, ein leerer Header macht keine Tools verfügbar und ein unbekannter Toolname gibt einen Konfigurationsfehler zurück.

## Verfügbare Prompts

Der Nuxt UI MCP Server bietet geführte Eingabeaufforderungen für gängige Workflows:

- **`find-component-for-usecase`**: Finden Sie die beste Komponente für Ihren spezifischen Anwendungsfall
- **`implement-component-with-props`**: Erstellen Sie eine vollständige Komponentenimplementierung mit den richtigen Requisiten
- **`setup-project-with-template`**: Erhalten Sie eine Anleitung zur Einrichtung von Projektvorlagen

Sie können auf diese Ressourcen mit Tools wie Claude Code zugreifen, indem Sie `/` verwenden.

### Gemini CLI

#### Setup-Anweisungen:

1. Suchen Sie Ihre Gemini-CLI-Konfigurationsdatei (normalerweise ~/.gemini/settings.json oder wie in Ihrer Umgebung angegeben).

## Anwendungsbeispiele

Einmal konfiguriert, können Sie Ihrem KI-Assistenten Fragen stellen wie:

- "Liste aller verfügbaren Nuxt UI-Komponenten"
- "Dokumentation der Button-Komponenten abrufen"
- "Zeig mir einfach die Button-Anwendungsbeispiele"
- "Welche Requisiten akzeptiert Input?"
- "Formularbezogene Komponenten finden"
- "Suche nach Pfeil-Icons in lucide"
- "Dashboard-Vorlagen auflisten"
- "Anleitung zum Einrichten von Vorlagen abrufen"
- "Installationsanleitung anzeigen"
- "Holen Sie sich den Migrationsleitfaden"
- "Alle Beispiele auflisten"
- "Erhalten Sie ContactForm-Beispielcode"

Der KI-Assistent wird den MCP-Server verwenden, um strukturierte JSON-Daten abzurufen und während der Entwicklung eine geführte Unterstützung für die Nuxt-Benutzeroberfläche bereitzustellen.

::tip
Für Komponentendokumente kann die KI den Parameter `sections`(`usage`,`examples`,`api`,`theme`,`changelog`) verwenden, um nur relevante Teile abzurufen.
::
