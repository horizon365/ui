@@ph000@@@Was sind Fähigkeiten ?

Skills sind strukturierte Wissensdateien , die KI-Codieragenten Kontext über eine Bibliothek , ein Framework oder eine Codebasis geben . Im Gegensatz zu MCP-Servern , die Echtzeit-Tool - Zugriff bieten , werden Skills direkt in den Kontext des Agenten geladen , damit er sie während der gesamten Konversation referenzieren kann .

Nuxt UI bietet eine**usage skill**, die KI-Agenten beibringt , wie man UIs mit Nuxt UI erstellt : Installation , Theming , Komponenten , Composables , Formulare , Overlays und Layouts .

@@ph003@Verwendung

Der Usage Skill vermittelt KI-Agenten umfassende Kenntnisse über das Erstellen mit Nuxt UI v4 . Er umfasst :

- Installation für Nuxt , Vue , Laravel und AdonisJS
- Theming und Branding mit semantischen Farben und CSS-Variablen
- Alle 125 + Komponenten mit Requisiten und Nutzungsmustern
- Composables (`useToast`,`useOverlay`,`defineShortcuts`)
- Formularvalidierung mit Standardschema
- Layout-Komposition (Dashboard , Docs , Chat , Editor)
- Offizielle Startervorlagen

Der Skill enthält zusätzliche Referenzen , die der KI-Agent je nach Aufgabe bei Bedarf lädt , um die Antworten fokussiert und kontexteffizient zu halten .

::note
Nach der Installation können Sie den Skill aufrufen , indem Sie im Chat Ihres Agenten`/nuxt-ui`eingeben .
::

### Skills CLI

Die[`skills`](https://skills.sh)CLI ist der einfachste Weg , um die Nuxt UI skill . It unterstützt 35 + Agenten einschließlich Cursor , Claude Code , Codex , Windsurf , Cline und mehr zu installieren .

```bash
npx skills add nuxt/ui
```

Sie können bestimmte Agenten mit dem`--agent`- Flag ansprechen :

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

Oder installieren Sie es global , sodass der Skill in allen Ihren Projekten verfügbar ist :

```bash
npx skills add nuxt/ui --global
```

Wenn das Klonen von GitHub in Ihrem Netzwerk langsam ist , können Sie stattdessen direkt von der Website aus installieren :

```bash
npx skills add https://ui.nuxt.com
```

::tip
Siehe[skills.sh](https://skills.sh), um mehr über das Fähigkeiten - Ökosystem zu erfahren und verfügbare Fähigkeiten zu durchsuchen .
::
