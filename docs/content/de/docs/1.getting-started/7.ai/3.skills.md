## Was sind Fähigkeiten?

Skills sind strukturierte Wissensdateien, die KI-Codieragenten Kontext über eine Bibliothek, ein Framework oder eine Codebasis geben. Im Gegensatz zu MCP-Servern, die Echtzeit-Tool-Zugriff bieten, werden Skills direkt in den Kontext des Agenten geladen, so dass er sie während der gesamten Konversation referenzieren kann.

Nuxt UI bietet ein **usage skill**, das KI-Agenten beibringt, wie man UIs mit Nuxt UI erstellt: Installation, Theming, Komponenten, Composables, Formulare, Overlays und Layouts.

## Usage (gebraucht)

Der Usage Skill vermittelt KI-Agenten umfassendes Wissen über das Erstellen mit Nuxt UI v4. Er umfasst:

- Installation für Nuxt, Vue, Laravel und AdonisJS
- Theming und Branding mit semantischen Farben und CSS Variablen
- Alle 125 + Komponenten mit Props und Nutzungsmustern
- Composables (`useToast`, `useOverlay`, `defineShortcuts`)(Deutsche Übersetzung)
- Form Validierung mit Standardschema
- Layout Zusammensetzung (Dashboard, Docs, Chat, Editor)
- Offizielle Starter-Vorlagen

Der Skill enthält zusätzliche Referenzen, die der KI-Agent je nach Aufgabe bei Bedarf lädt, um die Antworten fokussiert und kontexteffizient zu halten.

::note
Nach der Installation können Sie den Skill aufrufen, indem Sie `/nuxt-ui` im Chat Ihres Agenten eingeben.
::

### Skills CLI (englisch)

Die [`skills`](https://skills.sh) CLI ist der einfachste Weg, um die Nuxt UI skill. It unterstützt 35 + Agenten einschließlich Cursor, Claude Code, Codex, Windsurf, Cline, und mehr zu installieren.

```bash
npx skills add nuxt/ui
```

Sie können bestimmte Agenten mit dem Flag `--agent` ansprechen:

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

Oder installieren Sie es global, sodass der Skill in allen Ihren Projekten verfügbar ist:

```bash
npx skills add nuxt/ui --global
```

Wenn das Klonen von GitHub in Ihrem Netzwerk langsam ist, können Sie stattdessen direkt von der Website aus installieren:

```bash
npx skills add https://ui.nuxt.com
```

::tip
Besuchen Sie [skills.sh](https://skills.sh), um mehr über das Skills-Ökosystem zu erfahren und die verfügbaren Skills zu durchsuchen.
::

### Cursor Bearbeiten

#### Quick-Installation

Klicken Sie auf die Schaltfläche unten, um den Nuxt UI-Skill direkt in Cursor zu installieren:

::u-button

::

#### Manuelle Einrichtung

1. Öffnen Sie Cursor und gehen Sie zu "Einstellungen">"Fähigkeiten"
2. Klicken Sie auf "Skill hinzufügen" und geben Sie die folgende URL ein:

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```

Der XPH053XCLAUE Code

::note{icon="i-lucide-info"}
**Ensure Claude Code is installed.** Besuchen Sie [Anthropic's documentation](https://docs.anthropic.com/en/docs/claude-code/quickstart) für Installationsanweisungen.
::

Fügen Sie den Skill mit dem Befehl CLI hinzu:

```bash
claude skill add https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
