## Tailwind CSS (englisch)

Tailwind CSS verwendet eine CSS-First-Konfiguration, mit der Sie Ihre Design-Token mit der [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive) Direktive direkt in Ihrem CSS definieren können.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
Überprüfen Sie die Tailwind CSS-Dokumentation für alle verfügbaren Optionen zur Anpassung von Theme-Variablen.
::

::tip
Tailwind CSS v4 hat sein [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) geändert, so dass die Schaltflächen `cursor: default` anstelle von `cursor: pointer` verwenden, um die Standardeinstellungen des Browsers zu erfüllen.

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### Breakpoints (siehe oben)

Verwenden Sie die `--breakpoint-*` theme-Variablen, um [customize Ihre Breakpoints ](https://tailwindcss.com/docs/responsive-design#customizing-your-theme).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

Verwenden Sie die `--ease-*` Themenvariablen, um [die easing](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme) der Animationen und Bewegungsübergänge in Ihrem Projekt anzupassen.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

Enter-und Exit-Animationen laufen auf `--ease-out`, unbestimmte Ladeanimationen auf `--ease-in-out`, so dass diese beiden Wiederholungen der Bibliothek überschrieben werden.

::note
Wenn `prefers-reduced-motion` gesetzt ist, werden Überlagerungen anstelle von Skalierung oder Schieben ausgeblendet, und Bewegungsübergänge werden deaktiviert.
::

## Farbsystem

Das Farbsystem von Nuxt UI wurde um **semantische Namensnennung ** herum entwickelt und nicht um bestimmte Farbwerte. Dieser Ansatz macht Ihre Benutzeroberfläche wartbarer und macht das Wechseln des Themas einfach.

### semantische Farben

Jedes Alias wird basierend auf einer Farbe aus Ihrer `@theme`-Konfiguration definiert, die jede Farbe sein kann, die Sie zusätzlich zu der [default Tailwind CSS-Palette ](https://tailwindcss.com/docs/colors) definieren.

| --- | --- | --- |
| {color="primary"}|@@@@133| Haupt-CTAs, aktive Navigation, Markenelemente, wichtige Links|
| @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@|@@@@136| Sekundäre Buttons, alternative Aktionen, ergänzende UI-Elemente|
| {color="success"}|@@@@139 @| Erfolgsmeldungen, abgeschlossene Zustände, positive Bestätigungen|
| {color="info"}|@@@@@@@142| Info-Benachrichtigungen, Tooltips, Hilfetexte, neutrale Benachrichtigungen|
| @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@################################################################################################################################|@@@@145| Warnmeldungen, ausstehende Zustände, Aufmerksamkeits-benötigte Elemente|

Diese semantischen Farben sind in den `color` prop der Nuxt UI-Komponenten verfügbar:

::component-code{slug="button"}
---

  Farbe: Primär
Slots auf:
  Default: Änderung speichern
---
::

::note
Probieren Sie das: prose-icon {name="i-lucide-palette" class="text-primary"} theme-Menü in der Kopfzeile aus, um sofort zu sehen, wie sich verschiedene Farbschemata auf die gesamte Benutzeroberfläche auswirken, oder öffnen Sie die [theme-editor](/theme), um alles auf einmal anzupassen!
::

### Laufzeitkonfiguration

::framework-only
#nuxt sein
:::div
Sie können diese Farben zur Laufzeit in Ihrer [`app.config.ts`]() Datei unter dem `ui.colors` Schlüssel konfigurieren, so dass eine dynamische Theme-Anpassung ohne Neustart des Servers möglich ist:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#Ansehen
:::div
Sie können diese Farben zur Laufzeit in Ihrer `vite.config.ts`-Datei unter dem `ui.colors`-Schlüssel konfigurieren, um eine dynamische Anpassung des Designs zu ermöglichen:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
Sie können nur Farben verwenden, die in Ihrem Theme vorhanden sind. Entweder:
- Verwendung [Tailwind-Standardfarben ](https://tailwindcss.com/docs/colors)(wie `blue`,`green`,`zinc`)
- Definieren Sie zuerst benutzerdefinierte Farben mit der `@theme`-Richtlinie (wie `brand` in unserem obigen Beispiel)
::

### Erweitern Farben

Sie können zusätzliche semantische Farben über die Standardwerte hinaus definieren, z. B. das Hinzufügen einer `tertiary` color:

::framework-only
#nuxt sein
:::div
Zuerst registrieren Sie die neue Farbe in Ihrem `nuxt.config.ts` unter dem `ui.theme.colors` Schlüssel:

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

Dann weisen Sie es in Ihrem `app.config.ts` unter dem `ui.colors` Schlüssel zu:

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#Ansehen
:::div
Registrieren Sie sich und weisen Sie die neue Farbe in Ihrer `vite.config.ts` Datei zu:

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

Verwenden Sie schließlich diese neue Farbe in Komponenten, die das `color` prop oder [als Klasse ](/docs/getting-started/theme/css-variables):

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
