Nuxt UI bietet Tailwind CSS Utility Classes für jede [semantic color](/docs/getting-started/theme/design-system#semantic-colors), die Sie definieren, so dass Sie Klassennamen wie `text-error` oder `bg-success` verwenden können:

::code-preview
[Bearbeiten]@ph007 @
[Bearbeiten]@@ph008
[Erfolg]@ph009
[Info]@ph010
[Warnung]@@ph011
[Fehler]@@ph012

#Der Code
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
</template>
```
::

Jede Utility-Class verwendet eine CSS-Variable, um ihre Farbe für den hellen und dunklen Modus festzulegen:

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
}
```
::

::tip
Sie können einstellen, welche Schattierung jede Dienstprogrammklasse für den Hell-und Dunkelmodus in Ihrer `main.css`-Datei verwendet:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: var(--ui-color-primary-700);
}

.dark {
  --ui-primary: var(--ui-color-primary-200);
}
```
::

::warning
Sie können `primary: 'black'` in Ihrem [**config**]() verwenden, da `black` keine mehrfachen Schattierungen hat.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary: black;
}

.dark {
  --ui-primary: white;
}
```

## Fokus: badge{label="4.9+" class="align-text-top"}

Nuxt UI wendet auf jedes interaktive Element eine `focus-visible`-Gliederung an, die mit der `color`-Prop der Komponente eingefärbt ist, z. B.`outline-primary/25` when `color="primary"` oder `outline-inverted/25` when `color="neutral"`.

Wenn Sie eine einzelne Umrissfarbe für Ihre gesamte App unabhängig von der Komponentenfarbe bevorzugen, können Sie eine globale Regel in Ihrer `main.css`Datei hinzufügen:

::code-group

```css [Primary]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-primary/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-primary);
}
```

```css [Neutral]
@import "tailwindcss";
@import "@nuxt/ui";

*,
::before,
::after {
  @apply outline-inverted/25;
}

*:focus-visible,
*:has(> a:focus-visible) {
  --tw-ring-color: var(--ui-border-inverted);
}
```

::

Die erste Regel färbt die Fokuskontur jeder Komponente, die zweite richtet die Ringfarbe aus, die auf den Fokus von Varianten mit einem sichtbaren Rahmen wie `outline` oder `subtle` angewendet wird, einschließlich Karten, die hervorheben, wenn ihre Verbindung fokussiert ist.

::note
Stellen Sie sicher, dass Sie diese Regeln außerhalb von `@layer` deklarieren, damit sie Vorrang vor den Farben haben, die von den Komponententhemen festgelegt werden. Denken Sie daran, dass die erste Regel auch die native Fokuskontur Ihrer eigenen Elemente einfärbt,`border` auf Fokus wie [FileUpload](/docs/components/file-upload) oder [ContentSurround](/docs/components/content-surround) Folgen Sie der Komponente `color`.
::

Nuxt UI überschreibt Tailwind CSS Standard `rounded-*` utilities mit einem einheitlichen Grenzradius-System, so dass Sie reguläre [border radius utilities](https://tailwindcss.com/docs/border-radius) wie `rounded-xs` oder `rounded-2xl`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]@@@@@@@@@@@@@@286
[sm]@@@@@@@@@@@@@@@@@@287
[md]@@@@@@@@@@@@@@288
[lg]@@@@@@@@@@@@@289
[xl]@@@@@@@@290
[2xl]@@@@@@@@291
[3xl]@@@@@@@@@@@@@@292

#Der Code
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

Diese Utility-Klassen werden auf Basis einer globalen `--ui-radius` CSS-Variablen berechnet, die den Basisradiuswert definiert, der für ein konsistentes Erscheinungsbild auf alle Komponenten angewendet wird.

```css
:root {
  --ui-radius: 0.25rem;
}
```

Jeder Nutzen multipliziert diesen Basiswert mit:

```css
@theme {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
Sie können den Basisradiuswert in Ihrer `main.css` Datei anpassen:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
Die Änderung von `--ui-radius` betrifft auch die Klassen `rounded-xs` zu `rounded-3xl` auf Ihrem eigenen Markup und Drittanbieterkomponenten, nicht nur Nuxt-UI-Komponenten.
::

::note
Versuchen Sie das: prose-icon {name="i-lucide-palette" class="text-primary"} theme-Menü in der Kopfzeile oben, um den Basisradiuswert zu ändern.
::

@@334@Einweg-Container

Nuxt UI stellt eine `--ui-container` CSS-Variable zur Verfügung, die die maximale Breite der Komponente [Container](/docs/components/container) steuert.

```css
:root {
  --ui-container: 80rem; /* var(--container-7xl) */
}
```

::tip
Sie können diesen Wert in Ihrer `main.css`-Datei anpassen, um die Containerbreiten in Ihrer gesamten Anwendung einheitlich anzupassen:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
