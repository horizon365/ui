## Tailwind-Varianten

Nuxt UI-Komponenten werden mit der [Tailwind Variants](https://www.tailwind-variants.org/) API gestylt, die eine leistungsstarke Möglichkeit zum Erstellen von Varianten und Verwalten von Komponentenstilen bietet.

@@ph005@gmail.de

Komponenten können mehrere `slots` haben, die jeweils ein bestimmtes HTML-Element oder einen bestimmten Abschnitt innerhalb der Komponente darstellen.

Nehmen wir als Beispiel die Komponente [Card](/docs/components/card), die mehrere Steckplätze hat:

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
Die echten Komponenten tragen auch `v-if` guards auf jedem Slot und das Thema definiert `variant` styles auf den Slots.
::

In diesem Fall definiert das Theme nur den `base` slot wie die [Container](](/docs/components/container) Komponente zum Beispiel:

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
Komponenten ohne Steckplätze haben immer noch einen [`ui` prop](#ui-prop). Es stellt einen einzigen `base` Schlüssel statt eines Schlüssels pro Steckplatz zur Verfügung.[Link](](/docs/components/link) und [Icon](]()PH07) sind die Ausnahmen: sie haben keine `ui` prop, also verwenden Sie die [`class` prop](#class-prop), um ihre Stile zu überschreiben.
::

@@@ph079@@@Varianten

Komponenten unterstützen `variants`, die die Stile verschiedener `slots` basierend auf Komponenten-Requisiten dynamisch anpassen.

Zum Beispiel verwendet die Komponente [Avatar](/docs/components/avatar) eine `size`-Variante, um ihr Aussehen zu steuern:

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

Auf diese Weise wendet der `size` prop die entsprechenden Stile auf den `root` slot an:

::component-code{slug="avatar"}
---
Ignoriert:
  @@113@src@src
Props:
  src: 'https://github.com/nuxt.png'(auf Englisch)
  Größe: lg
---
::

### Defaultvarianten

Die `defaultVariants`-Eigenschaft legt den Standardwert für jede Variante fest, wenn keine Prop übergeben wird.

Zum Beispiel hat die Komponente [Avatar](/docs/components/avatar) ihre Standardgröße auf `md` gesetzt:

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt sein
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
Sie können die Option `theme.defaultVariants` in Ihrem `nuxt.config.ts` verwenden, um die Standardeinstellungen `size` und `color` jeder Komponente zu überschreiben, die `md` und `primary` verwendet.
:::

#Ansehen
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
Sie können die Option `theme.defaultVariants` in Ihrem `vite.config.ts` verwenden, um die Standardeinstellungen `size` und `color` jeder Komponente, die `md` und `primary` verwendet, außer Kraft zu setzen.
:::
::

### zusammengesetzte Varianten

Einige Komponenten verwenden die `compoundVariants`-Eigenschaft, um Klassen anzuwenden, wenn mehrere Variantenbedingungen gleichzeitig erfüllt sind.

Beispielsweise verwendet die Komponente [Button](/docs/components/button) die `compoundVariants`-Eigenschaft, um Klassen für eine bestimmte Kombination aus `color` und `variant` anzuwenden:

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## Anpassen des Themas

Sie haben mehrere Möglichkeiten, das Erscheinungsbild von Nuxt UI-Komponenten anzupassen, Sie können dies für alle Komponenten gleichzeitig oder pro Komponente tun.

::note
Tailwind Variants verwendet [`tailwind-merge`](https://github.com/dcastil/tailwind-merge) unter der Haube, um Klassen zusammenzuführen, so dass Sie sich keine Sorgen über widersprüchliche Klassen machen müssen.
::

::tip
Sie können das Thema für jede Komponente auf zwei Arten untersuchen:

- Überprüfen Sie den Abschnitt `Theme` in der Dokumentation jeder einzelnen Komponente.
- Durchsuchen Sie den Quellcode direkt im GitHub-Repository unter [`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme).
::

### Globale Konfiguration

::framework-only
#nuxt sein
Sie können das Thema der Komponenten global in Ihrem `app.config.ts` überschreiben, indem Sie genau die gleiche Struktur wie das Theme-Objekt verwenden.
#Ansehen
Sie können das Thema der Komponenten global in Ihrem `vite.config.ts` überschreiben, indem Sie genau die gleiche Struktur wie das Theme-Objekt verwenden.
::

Bitte beachten Sie: [`slots`](#slots),[`variants`](#variants),[`compoundVariants`]() und [`defaultVariants`](#default-variants) einer Komponente ändern, um das Standarddesign einer Komponente zu ändern:

::framework-only
#nuxt sein
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#Ansehen
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
In diesem Beispiel überschreibt `font-bold` überschreibt `font-medium` auf allen Schaltflächen,`size-4` überschreibt `size-5` Klasse auf dem führenden Symbol, wenn `size="md"` und `ring-default hover:bg-accented` überschreibt `ring-accented hover:bg-elevated` wenn `color="neutral"` und `variant="outline"`.
::

Standardmäßig werden diese Klassen mit den Standardwerten der Komponente zusammengeführt. Sie können einen Slot auch auf eine Funktion setzen, um sie stattdessen zu ersetzen. Er empfängt die Standardklassen des Slots als Argument, sodass Sie einen Teil davon wiederverwenden können. Klassen von `variants` und `compoundVariants` gelten immer noch oben, genau wie beim Übergeben einer Zeichenfolge.

::framework-only
#nuxt sein
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#Ansehen
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt sein
:::warning
Setzen Sie einen Steckplatz für eine Funktion nur an einer Stelle. Nuxt führt die `app.config.ts` von jedem [layer]() mit `defuFn` zusammen, was Ihre Funktion mit dem Wert aufruft, den der Schlüssel bereits unten hat, und nur das Ergebnis behält. Nuxt UI liest dann eine einfache Zeichenkette, so dass seine Klassen mit den Standardwerten zusammengeführt werden, anstatt sie zu ersetzen.
:::
::

::framework-only
#nuxt sein
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
Um die Standardklassen aus allen Komponenten auf einmal zu entfernen, verwenden Sie die Option `theme.unstyled` in Ihrem `nuxt.config.ts`.
:::

#Ansehen
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
Um die Standardklassen aus allen Komponenten auf einmal zu entfernen, verwenden Sie die Option `theme.unstyled` in Ihrem `vite.config.ts`.
:::
::

### Theme-Komponente

Die Komponente [Theme](/docs/components/theme) überschreibt Slots und Prop-Defaults für alle ihre Nachkommen, ohne den Rest der App zu beeinflussen.`ui` und `class`requisiten immer noch gewinnen über it. Slots akzeptieren die gleiche Funktion Form, um ihre Klassen zu ersetzen, anstatt merging. It wird an der gleichen Stelle wie die [`ui` prop ](#ui-prop), so verhält es sich auf die gleiche Weise.

::component-example
---
Name: 'Theme-ui-Beispiel'
---
::

`ui` prop

Sie können auch die **slots** mit der `ui` prop.

::component-code{slug="button"}
---
Schöner: wahr
Ignoriert:
  - ui.trailingIcon (auf Englisch)
  @@@@@@@378@@color
  @@@@@@@@379@@variant
  @@ph380@@Größe
  @@@@@@@@ph381@@icon
Props:
  trailingIcon: i-lucide-chevron-rechts
  Größe: MD
  Farbe: neutral
  Variante: Übersicht
  ui: ist
    trailingIcon: 'rotate-90 size-3'(auf Englisch)
Slots auf:
  Default:|

    Der Button
---
::

::note
In diesem Beispiel wird der `trailingIcon`-Slot mit `size-3` überschrieben, obwohl die `md`-Größenvariante eine `size-5`-Klasse darauf anwenden würde.
::

Ein Slot-Wert kann auch eine Funktion sein, um seine Klassen zu ersetzen, anstatt sie zusammenzuführen:

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
Die `ui` prop wird nach der `variants` aufgelöst, so dass im Gegensatz zur globalen Konfiguration eine Funktion hier die **resolved** classes ersetzt.
::

`class` prop

Verwenden Sie `class` prop, um die Klassen des `root`-oder `base`-Slots zu überschreiben.

::component-code{slug="button"}
---
Props:
  Klasse: 'font-bold rounded-full'(font-bold gerunded-voll)
Slots auf:
  Markiert: Button
---
::

::note
In diesem Beispiel überschreibt die Klasse `font-bold` die voreingestellte Klasse `font-medium` auf dieser Schaltfläche.
::
