## Tailwind-Varianten

Nuxt UI-Komponenten werden mit der [Tailwind Variants](https://www.tailwind-variants.org/) API gestylt, die eine leistungsstarke Möglichkeit zum Erstellen von Varianten und Verwalten von Komponentenstilen bietet.

### Slots (englisch)

Komponenten können mehrere `slots` haben, die jeweils ein bestimmtes HTML-Element oder einen Abschnitt innerhalb der Komponente darstellen. Diese Slots ermöglichen flexibles Einfügen und Styling von Inhalten.

Nehmen wir als Beispiel die Komponente [Card](/docs/components/card), die mehrere Steckplätze hat:

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
Die realen Komponenten tragen auch `v-if`-Wachen an jedem Slot und das Thema definiert `variant`-Stile auf den Slots.
::

In diesem Fall definiert das Theme nur den `base`-Slot wie die [Container](/docs/components/container)-Komponente zum Beispiel:

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
Komponenten ohne Steckplätze haben immer noch einen [`ui` prop](#ui-prop). Es macht einen einzelnen `base`-Schlüssel anstelle eines Schlüssels pro Steckplatz aus. [Link](/docs/components/link) und [Icon](/docs/components/icon) sind die Ausnahmen: Sie haben keine `ui`-Prop, also verwenden Sie die [x062062xxph07xph07x, um ihre Prop-Stile zu überschreiben.
::

### Variants Bearbeiten

Komponenten unterstützen `variants`, die die Stile verschiedener `slots` basierend auf Komponenten-Requisiten dynamisch anpassen.

Zum Beispiel verwendet die Komponente [Avatar](/docs/components/avatar) eine `size`-Variante, um ihr Aussehen zu steuern:

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

Auf diese Weise wendet die `size`-Prop die entsprechenden Stile auf den `root`-Steckplatz an:

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/nuxt.png'
  size: lg
---
::

### Default-Varianten

Die `defaultVariants`-Eigenschaft legt den Standardwert für jede Variante fest, wenn keine Prop übergeben wird.

Die Standardgröße der Komponente [Avatar](/docs/components/avatar) ist beispielsweise auf `md` festgelegt:

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
Sie können die Option `theme.defaultVariants` in Ihrem `nuxt.config.ts` verwenden, um die Standardwerte `size` und `color` jeder Komponente zu überschreiben, die `md` und `primary` verwendet.
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
Sie können die Option `theme.defaultVariants` in Ihrem `vite.config.ts` verwenden, um die Standardwerte `size` und `color` jeder Komponente zu überschreiben, die `md` und `primary` verwendet.
:::
::

### Compound-Varianten

Einige Komponenten verwenden die `compoundVariants`-Eigenschaft, um Klassen anzuwenden, wenn mehrere Variantenbedingungen gleichzeitig erfüllt sind.

Beispielsweise verwendet die Komponente [Button](/docs/components/button) die Eigenschaft `compoundVariants`, um Klassen für eine bestimmte Kombination aus `color` und `variant` anzuwenden:

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## Customize Themes für Windows

Sie haben mehrere Möglichkeiten, das Erscheinungsbild von Nuxt UI-Komponenten anzupassen, Sie können dies für alle Komponenten gleichzeitig oder pro Komponente tun.

::note
Tailwind Variants verwendet [`tailwind-merge`](https://github.com/dcastil/tailwind-merge) unter der Haube, um Klassen zusammenzuführen, so dass Sie sich keine Sorgen über widersprüchliche Klassen machen müssen.
::

::tip
Sie können das Thema für jede Komponente auf zwei Arten untersuchen:

- Überprüfen Sie den Abschnitt `Theme` in der Dokumentation jeder einzelnen Komponente.
Durchsuchen Sie den Quellcode direkt im GitHub-Repository unter [`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme).
::

### Global config (Deutsche Übersetzung)

::framework-only
#nuxt
Sie können das Thema der Komponenten global in Ihrem `app.config.ts` überschreiben, indem Sie genau die gleiche Struktur wie das Theme-Objekt verwenden.
#vue
Sie können das Thema der Komponenten global in Ihrem `vite.config.ts` überschreiben, indem Sie genau die gleiche Struktur wie das Theme-Objekt verwenden.
::

Sie können die [`slots`](#slots), [`variants`](#variants), [`compoundVariants`]() und [`defaultVariants`](#default-variants) einer Komponente anpassen, um das Standarddesign einer Komponente zu ändern:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
In diesem Beispiel überschreibt `font-bold` `font-medium` auf allen Schaltflächen, `size-4` überschreibt die `size-5`-Klasse auf dem führenden Symbol, wenn `size="md"` und `ring-default hover:bg-accented` `ring-accented hover:bg-elevated` überschreibt, wenn `color="neutral"` und `variant="outline"`.
::

Standardmäßig werden diese Klassen mit den Standardwerten der Komponente zusammengeführt. Sie können einen Slot auch auf eine Funktion setzen, um sie stattdessen zu ersetzen. Er erhält die Standardklassen des Slots als Argument, sodass Sie einen Teil davon wiederverwenden können. Klassen von `variants` und `compoundVariants` gelten weiterhin oben, genau wie beim Übergeben einer Zeichenfolge.

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt
:::warning
Legen Sie einen Slot für eine Funktion nur an einer Stelle fest. Nuxt führt das `app.config.ts` von jedem [layer](https://nuxt.com/docs/getting-started/layers) mit `defuFn` zusammen, wodurch Ihre Funktion mit dem Wert aufgerufen wird, den der Schlüssel bereits unten hat, und behält nur das Ergebnis. Nuxt UI liest dann eine einfache Zeichenfolge, so dass seine Klassen mit den Standardwerten zusammengeführt werden, anstatt sie zu ersetzen.
:::
::

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
Um die Standardklassen aus allen Komponenten gleichzeitig zu entfernen, verwenden Sie die Option `theme.unstyled` in Ihrem `nuxt.config.ts`.
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
Um die Standardklassen aus allen Komponenten auf einmal zu entfernen, verwenden Sie die Option `theme.unstyled` in Ihrem `vite.config.ts`.
:::
::

### Theme-Komponente

Die [Theme](/docs/components/theme)-Komponente überschreibt Slots und Prop-Defaults für alle ihre Nachkommen, ohne den Rest der App zu beeinflussen. aber die `ui` und `class` Requisiten immer noch über it. Slots akzeptieren die gleiche Funktion Form, um ihre Klassen zu ersetzen, anstatt merging. It wird an der gleichen Stelle wie die [`ui` aufgelöst prop](#ui-prop), so verhält es sich auf die gleiche Weise.

### `ui` prop auf

Sie können auch die **slots** einer Komponente überschreiben, indem Sie die `ui`-Prop verwenden, die sowohl die globale Konfiguration als auch die aufgelöste `variants` bevorzugt.

::component-code{slug="button"}
---
prettier: true
ignore:
  - ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  trailingIcon: i-lucide-chevron-right
  size: md
  color: neutral
  variant: outline
  ui:
    trailingIcon: 'rotate-90 size-3'
slots:
  default: |

    Button
---
::

::note
In diesem Beispiel wird der `trailingIcon`-Steckplatz mit `size-3` überschrieben, obwohl die Größenvariante `md` eine `size-5`-Klasse darauf anwenden würde.
::

Ein Slot-Wert kann auch eine Funktion sein, um seine Klassen zu ersetzen, anstatt sie zusammenzuführen:

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
Die `ui`-Prop wird nach der `variants` aufgelöst, so dass im Gegensatz zur globalen Konfiguration hier eine Funktion die **resolved**-Klassen des Slots ersetzt.
::

### `class` prop (englisch)

Verwenden Sie die `class`-Prop, um die Klassen des `root`-oder `base`-Steckplatzes zu überschreiben. Dies hat Vorrang sowohl vor der globalen Konfiguration als auch vor dem aufgelösten `variants`.

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
In diesem Beispiel überschreibt die `font-bold`-Klasse die Standardklasse `font-medium` auf dieser Schaltfläche.
::
