@@ph002@@Nutzung

Nuxt UI liefert eine `Icon` Komponente, die von [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/) unterstützt wird, so dass keine zusätzliche Einrichtung erforderlich ist.

### Icon-Komponente

Sie können die Komponente [Icon](/docs/components/icon) mit einer `name` prop verwenden, um ein Symbol anzuzeigen:

::component-code{slug="icon"}
---
Props:
  Bezeichnung: I-Lucide-Lightbulb
  Klasse: Größe-5
---
::

::note
Durchsuchen Sie sie einfach auf <https://icones.js.org> oder suchen Sie direkt von Ihrem KI-Assistenten mit dem [`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP-Tool.
::

::warning
Wenn Sie Sammlungen mit einem Bindestrich (`-`) verwenden, müssen Sie den Symbolnamen mit einem Doppelpunkt (`:`) vom Namen der Sammlung trennen, da `@iconify/vue` diesen Fall nicht wie `@nuxt/icon` behandelt.

Erfahren Sie mehr über die [Iconify Namenskonvention ](https://iconify.design/docs/icon-components/vue/#icon).
::

### Komponenten-Props

Einige Komponenten haben auch ein `icon` prop, um ein Symbol anzuzeigen, wie zum Beispiel das [Button](/docs/components/button):

::component-code{slug="button"}
---
Ignoriert:
  @@ph039@gmail.de ist
  @@ph040@@variantenreich
Props:
  Bildnachweis: i-lucide-sun
  Variante: subtil
Die Slots:
  Fehler: Button
---
::

## Sammlungen

### Iconify dataset [Bearbeiten | Quelltext bearbeiten]

Es wird dringend empfohlen, die Symboldaten lokal zu installieren mit:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Um beispielsweise das `i-lucide-lightbulb`-Symbol zu verwenden, installieren Sie die Sammlung mit `@iconify-json/lucide`.

Durch die Installation der Sammlung kann Nuxt UI die verwendeten Symbole in Ihren Build einbetten, sodass sie während SSR sofort gerendert werden und vollständig offline arbeiten, anstatt zur Laufzeit von der Iconify API abgerufen zu werden.

Um andere Symbole zu bündeln, z. B. solche, die Sie überschreiben oder an anderer Stelle in Ihrer App verwenden, fügen Sie sie der Option `icon.clientBundle.icons` in Ihrem @@@ hinzu:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
Sie können entweder das Formular `i-{collection}-{name}` oder `{collection}:{name}` verwenden, z. B.`i-lucide-heart` oder `lucide:heart` und `i-material-symbols-menu` oder `material-symbols:menu`.
::

Um die verwendeten Symbole zu bündeln, ohne sie einzeln aufzulisten, aktivieren Sie `scan` instead. It scannt Ihre Quelle nach Symbolverwendungen aus Ihren installierten Sammlungen und bündelt sie auf die gleiche Weise `@nuxt/icon`'s `clientBundle.scan` funktioniert:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

Scannen liest nur `.vue`,`.jsx`,`.tsx`,`.md`,`.mdc`,`.mdx`,`.yml` und `.yaml` Dateien, und es passt nur Icon-Namen geschrieben als wörtliche strings. Icons definiert in einem `.ts` oder `.js` Datei, wie eine Liste von Navigationslinks, werden übersehen, wie Namen dynamisch wie `i-lucide-${name}`. Set `globInclude` erstellt werden, um diese Dateien zu scannen. Es ersetzt die Standardliste, so halten Sie die Erweiterungen, die Sie noch benötigen:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

Dynamische Namen können immer noch gebündelt werden, wenn Sie den gesamten Satz zur Build-Zeit kennen, indem Sie sie in `clientBundle.icons` auflisten. Namen, die nur zur Laufzeit existieren, wie Symbole, die von einer API kommen, können überhaupt nicht gebündelt werden und werden bei Bedarf von der Iconify API geladen.

Icons, deren Sammlung nicht installiert ist, werden zur Laufzeit immer noch von der Iconify API geladen, also installieren Sie jede Sammlung, die Sie verwenden, mit `@iconify-json/{collection_name}`. Um die Bündelung vollständig zu deaktivieren, setzen Sie `icon.clientBundle` auf `false`.
