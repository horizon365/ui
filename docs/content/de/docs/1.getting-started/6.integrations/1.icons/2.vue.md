## Usage (englisch)

Nuxt UI liefert eine `Icon`-Komponente, die von [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/) unterstützt wird, so dass keine zusätzliche Einrichtung erforderlich ist.

### Icon Komponente

Sie können die [Icon](/docs/components/icon)-Komponente mit einer `name`-Prop verwenden, um ein Symbol anzuzeigen:

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
Durchsuchen Sie sie einfach auf <https://icones.js.org> oder suchen Sie direkt von Ihrem KI-Assistenten mit dem [`search-icons`](](/docs/getting-started/ai/mcp#available-tools) MCP-Tool.
::

::warning
Wenn Sie Sammlungen mit einem Bindestrich (`-`) verwenden, müssen Sie den Symbolnamen mit einem Doppelpunkt (`:`) vom Namen der Sammlung trennen, da `@iconify/vue` diesen Fall nicht wie `@nuxt/icon` behandelt.

Erfahren Sie mehr über die [Iconify Namenskonvention ](https://iconify.design/docs/icon-components/vue/#icon).
::

### Component props (Deutsche Ausgabe)

Einige Komponenten haben auch eine `icon`-Stütze, um ein Symbol anzuzeigen, wie zum Beispiel das [Button](/docs/components/button):

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## Sammlungen

### Iconify Dateiendung

Es wird dringend empfohlen, die Symboldaten lokal zu installieren mit:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Um beispielsweise das Symbol `i-lucide-lightbulb` zu verwenden, installieren Sie die Sammlung mit `@iconify-json/lucide`.

Durch die Installation der Sammlung kann Nuxt UI die verwendeten Symbole in Ihren Build einbetten, sodass sie während SSR sofort gerendert werden und vollständig offline arbeiten, anstatt zur Laufzeit von der Iconify-API abgerufen zu werden.

Um andere Symbole zu bündeln, z. B. solche, die Sie überschreiben oder an anderer Stelle in Ihrer App verwenden, fügen Sie sie der Option `icon.clientBundle.icons` in Ihrem `vite.config.ts` hinzu:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
Sie können entweder das Formular `i-{collection}-{name}` oder `{collection}:{name}` verwenden, z. B. `i-lucide-heart` oder `lucide:heart` und `i-material-symbols-menu` oder `material-symbols:menu`.
::

Um die verwendeten Symbole zu bündeln, ohne sie einzeln aufzulisten, aktivieren Sie stattdessen `scan`. Es durchsucht Ihre Quelle nach Symbolverwendungen aus Ihren installierten Sammlungen und bündelt sie, genauso wie `@nuxt/icon` `clientBundle.scan` funktioniert:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

Beim Scannen werden nur die Dateien `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` und `.yaml` gelesen und nur Icon-Namen, die als wörtliche Zeichenfolgen geschrieben wurden, werden abgeglichen. wie Namen dynamisch wie `i-lucide-${name}`. Set `globInclude` gebaut, um diese Dateien als auch zu scannen. Es ersetzt die Standardliste, so halten Sie die Erweiterungen, die Sie noch brauchen:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

Dynamische Namen können immer noch gebündelt werden, wenn Sie den gesamten Satz zur Build-Zeit kennen, indem Sie sie in `clientBundle.icons` auflisten. Namen, die nur zur Laufzeit existieren, wie Symbole, die von einer API kommen, können überhaupt nicht gebündelt werden und werden bei Bedarf von der Iconify API geladen.

Icons, deren Sammlung nicht installiert ist, werden zur Laufzeit immer noch von der Iconify API geladen, also installieren Sie jede Sammlung, die Sie mit `@iconify-json/{collection_name}` verwenden.
