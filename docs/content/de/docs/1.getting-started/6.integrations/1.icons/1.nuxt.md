## Usage (Verwendung)

Nuxt UI registriert automatisch das [`@nuxt/icon`](https://github.com/nuxt/icon)-Modul für Sie, so dass keine zusätzliche Einrichtung erforderlich ist.

### Icon Komponenten

Sie können die [Icon](/docs/components/icon)-Komponente mit einer `name`-Prop verwenden, um ein Symbol anzuzeigen:

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
Durchsuchen Sie sie einfach auf <https://icones.js.org> oder suchen Sie direkt von Ihrem AI-Assistenten mit dem [`search-icons`](/docs/getting-started/ai/mcp#available-tools/docs/getting-started/ai/mcp#available-tools) MCP-Tool.
::

### Component Props (Deutsche Ausgabe)

Einige Komponenten haben auch eine `icon`-Prop, um ein Symbol anzuzeigen, wie zum Beispiel die [Button](/docs/components/button):

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## Sammlungen

### Iconify Dateiendung

Es wird dringend empfohlen, die Symboldaten lokal zu installieren mit:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Um beispielsweise das `i-uil-github`-Symbol zu verwenden, installieren Sie seine Sammlung mit `@iconify-json/uil`. Auf diese Weise können die Symbole lokal oder von Ihren serverlosen Funktionen aus bedient werden, was sowohl auf SSR-als auch auf Clientseite schneller und zuverlässiger ist.

Durch die Installation der Sammlung kann Nuxt UI auch die verwendeten Symbole zur Build-Zeit in das Client-Bundle einbetten, sodass sie beim ersten Rendern verfügbar sind, anstatt zur Laufzeit bei Bedarf geladen zu werden. Dies geschieht automatisch für die eigenen Symbole von Nuxt UI, standardmäßig aus der `lucide`-Sammlung. Um andere Symbole zu bündeln, z. B. solche, die Sie überschreiben oder an anderer Stelle in Ihrer App verwenden, Fügen Sie sie der `@nuxt/icon`-Option [`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle) in Ihrem `nuxt.config.ts` hinzu:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

Oder aktivieren Sie `clientBundle.scan`, um jedes Symbol, das in Ihrer App verwendet wird, zu bündeln, indem Sie Ihre Quelle scannen, damit Sie sie nicht einzeln auflisten müssen:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

Beim Scannen werden nur die Dateien `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` und `.yaml` gelesen, und es werden nur Icon-Namen, die als wörtliche Zeichenfolgen geschrieben sind, abgeglichen. Icons, die in einer `.ts`-oder `.js`-Datei definiert sind, wie eine Liste von Navigationslinks, werden übersehen, wie Namen dynamisch wie `i-lucide-${name}`. Set `globInclude` gebaut, um diese Dateien als auch zu scannen. Es ersetzt die Standardliste, so halten Sie die Erweiterungen, die Sie noch benötigen:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

Dynamische Namen können immer noch gebündelt werden, wenn Sie den gesamten Satz zur Build-Zeit kennen, indem Sie sie in `clientBundle.icons` auflisten. Namen, die nur zur Laufzeit existieren, wie Symbole, die von einer API kommen, können überhaupt nicht gebündelt werden. Sie werden bei Bedarf von der `/api/_nuxt_icon`-Route geladen, wenn Ihre App serverseitig gerendert wird, mit der Iconify API als Fallback und direkt von der Iconify API, wenn Sie `nuxt generate` oder `ssr: false` verwenden.

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
Lesen Sie mehr dazu in der `@nuxt/icon`-Dokumentation.
::

### Custom lokale Sammlungen

Sie können lokale SVG-Dateien verwenden, um eine benutzerdefinierte Iconify-Sammlung zu erstellen.

Platzieren Sie beispielsweise die SVG-Dateien Ihrer Icons in einem Ordner Ihrer Wahl, z. B. `./app/assets/icons`:

```bash
assets/icons
├── add.svg
└── remove.svg
```

Fügen Sie in Ihrer `nuxt.config.ts` ein Element in `icon.customCollections` hinzu:

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

Dann können Sie die Icons so verwenden:

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
Lesen Sie mehr dazu in der `@nuxt/icon` Dokumentation.
::
