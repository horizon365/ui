@@ph002@@Nutzung

Nuxt UI registriert automatisch das [`@nuxt/icon`](https://github.com/nuxt/icon) Modul für Sie, so dass keine zusätzliche Einrichtung erforderlich ist.

### Icon-Komponente

Sie können die [Icon](/docs/components/icon) Komponente mit einem `name` prop verwenden, um ein Symbol anzuzeigen:

::component-code{slug="icon"}
---
Props:
  Bezeichnung: I-Lucide-Lightbulb
  Klasse: Größe-5
---
::

::note
Durchsuchen Sie sie einfach auf <https://icones.js.org> oder suchen Sie direkt von Ihrem KI-Assistenten mit dem [`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP-Tool.
::

### Komponenten-Props

Einige Komponenten haben auch ein `icon` prop, um ein Symbol anzuzeigen, wie zum Beispiel das [Button](/docs/components/button):

::component-code{slug="button"}
---
Ignoriert:
  @@ph027@gmail.de
  @@ph028@@variantenreich
Props:
  Bildnachweis: i-lucide-sun
  Variante: subtil
Slots auf:
  Markiert: Button
---
::

@@ph029@@Sammlungen

### Iconify dataset [Bearbeiten | Quelltext bearbeiten]

Es wird dringend empfohlen, die Icon-Daten lokal zu installieren:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Um beispielsweise das `i-uil-github`-Symbol zu verwenden, installieren Sie seine Sammlung mit `@iconify-json/uil`. Auf diese Weise können die Symbole lokal oder von Ihren serverlosen Funktionen aus bereitgestellt werden, was sowohl auf SSR-als auch auf Clientseite schneller und zuverlässiger ist.

Durch die Installation der Sammlung kann Nuxt UI auch die verwendeten Symbole zur Build-Zeit in das Client-Bundle einbetten, sodass sie beim ersten Rendern verfügbar sind, anstatt bei Bedarf zur Laufzeit geladen zu werden. Dies geschieht automatisch für die eigenen Symbole von Nuxt UI, standardmäßig aus der @@@@ collection. Um andere Symbole zu bündeln, z. B. solche, die Sie überschreiben oder an anderer Stelle in Ihrer App verwenden,`@nuxt/icon`[`clientBundle.icons`](https://github.com/nuxt/icon?tab=readme-ov-file#client-bundle) Option in Ihrem `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      icons: ['lucide:heart', 'simple-icons:github']
    }
  }
})
```

Oder aktivieren Sie `clientBundle.scan`, um jedes in Ihrer App verwendete Symbol zu bündeln, indem Sie Ihre Quelle scannen, damit Sie sie nicht einzeln auflisten müssen:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: true
    }
  }
})
```

Scannen liest nur `.vue`,`.jsx`,`.tsx`,`.md`,`.mdc`,`.mdx`,`.yml` und `.yaml` Dateien, und es passt nur Icon-Namen geschrieben als wörtliche strings. Icons definiert in einem `.ts` oder `.js` Datei, wie eine Liste von Navigationslinks, werden übersehen, wie Namen dynamisch wie `i-lucide-${name}`. Set `globInclude` erstellt werden, um diese Dateien zu scannen. Es ersetzt die Standardliste, so halten Sie die Erweiterungen, die Sie noch benötigen:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    clientBundle: {
      scan: {
        globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
      }
    }
  }
})
```

Dynamische Namen können immer noch gebündelt werden, wenn Sie den gesamten Satz zur Build-Zeit kennen, indem Sie sie in `clientBundle.icons` auflisten. Namen, die nur zur Laufzeit existieren, wie Symbole, die von einer API kommen, können überhaupt nicht gebündelt werden. und von der Iconify API direkt, wenn Sie `nuxt generate` oder `ssr: false` verwenden.

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#iconify-dataset" target="_blank"}
Lesen Sie mehr dazu in der `@nuxt/icon`-Dokumentation.
::

### Benutzerdefinierte lokale Sammlungen

Sie können lokale SVG-Dateien verwenden, um eine benutzerdefinierte Iconify Sammlung zu erstellen.

Platzieren Sie beispielsweise die SVG-Dateien Ihrer Icons in einem Ordner Ihrer Wahl, z. B.`./app/assets/icons`:

```bash
assets/icons
├── add.svg
└── remove.svg
```

In Ihrem `nuxt.config.ts` fügen Sie einen Eintrag in `icon.customCollections` ein:

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  icon: {
    customCollections: [{
      prefix: 'custom',
      dir: './app/assets/icons'
    }]
  }
})
```

Dann können Sie die Icons so verwenden:

```vue
<template>
  <UIcon name="i-custom-add" />
</template>
```

::note{to="https://github.com/nuxt/icon?tab=readme-ov-file#custom-local-collections" target="_blank"}
Lesen Sie mehr dazu in der `@nuxt/icon`-Dokumentation.
::
