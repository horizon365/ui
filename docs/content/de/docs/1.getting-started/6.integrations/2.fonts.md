@@@ph000@@Verwendung

Nuxt UI registriert automatisch das Modul [`@nuxt/fonts`](https://github.com/nuxt/fonts) für Sie, so dass keine zusätzliche Einrichtung erforderlich ist.

@@ph006 @ Erklärung

Um eine Schriftart in Ihrer Nuxt UI-Anwendung zu verwenden, können Sie sie einfach in Ihrem CSS deklarieren. Sie wird automatisch geladen und für Sie optimiert.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

@@ph015@Konfiguration

Sie können das `@nuxt/fonts`-Modul mit der Option `ui.fonts` in Ihrem `nuxt.config.ts` deaktivieren:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
