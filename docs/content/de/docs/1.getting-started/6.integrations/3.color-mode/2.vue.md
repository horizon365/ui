@@ph002@@Nutzung

Nuxt UI registriert automatisch das [useDark](https://vueuse.org/core/useDark) composable als Vue-Plugin, so dass keine zusätzliche Einrichtung erforderlich ist.

### Komponenten

Sie können die integrierte [ColorModeAvatar](/docs/components/color-mode-avatar) oder [ColorModeImage](/docs/components/color-mode-image) Komponenten verwenden, um verschiedene Bilder für den hellen und dunklen Modus anzuzeigen, und die [ColorModeButton](/docs/components/color-mode-button),[ColorModeSwitch](/docs/components/color-mode-switch) oder [ColorModeSelect](/docs/components/color-mode-select) Komponenten, um zwischen hellen und dunklen Modi zu wechseln.

Sie können auch das [useColorMode](https://vueuse.org/core/useColorMode) composable verwenden, um Ihre eigene benutzerdefinierte Komponente zu erstellen:

```vue [ColorModeButton.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useColorMode } from '@vueuse/core'

const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark: boolean) {
    colorMode.value = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <UButton
    :icon="isDark ? 'i-lucide-moon' : 'i-lucide-sun'"
    color="neutral"
    variant="ghost"
    :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
    @click="isDark = !isDark"
  />
</template>
```

@@ph059@Konfiguration

Sie können dieses Plugin mit der Option `colorMode` in Ihrem `vite.config.ts` deaktivieren:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      colorMode: false
    })
  ]
})
```
