## Usage (englisch)

::note{to="/docs/components/app"}
Die Nuxt-Benutzeroberfläche bietet eine **App**-Komponente, die Ihre App umhüllt, um globale Konfigurationen bereitzustellen, einschließlich der `locale`-Prop.
::

### Locale ist

Verwenden Sie die `locale` prop mit dem Gebietsschema, das Sie von `@nuxt/ui/locale` verwenden möchten:

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
Jedes Gebietsschema hat eine `code`-Eigenschaft (z. B. `en`, `en-GB`, `fr`), die das Datums-/Uhrzeitformat in Komponenten wie [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) und [InputTimexph0333x/docs/components/input-time) bestimmt.
::

### Custom locale (englisch)

Sie können Ihr eigenes Gebietsschema mit dem Dienstprogramm [defineLocale](/docs/composables/define-locale) erstellen:

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
Schauen Sie sich den Parameter `code` an, dort müssen Sie den ISO-Code der Sprache übergeben. Beispiel:

* `hi` Hindi (Sprache)
* `de-AT`: Deutsch (Sprache) wie in Österreich (Region) verwendet

::

### Extend Gebietsschema

Sie können ein vorhandenes Gebietsschema anpassen, indem Sie dessen `messages` oder `code` mit dem Dienstprogramm [extendLocale](/docs/composables/extend-locale) überschreiben:

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### Dynamic locale (Deutsche Ausgabe)

Um dynamisch zwischen den Sprachen zu wechseln, können Sie das [Vue I18n](https://vue-i18n.intlify.dev/)-Plugin verwenden.

::steps{level="4"}

#### Installieren Sie das Vue I18n Paket

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### Verwenden Sie das Vue I18n-Plugin in Ihrem `main.ts`

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

#### Stellen Sie die `locale`-Prop mit `useI18n` ein

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

::

### Dynamische Ausrichtung

Jedes Gebietsschema hat eine `dir`-Eigenschaft, die von der `App`-Komponente verwendet wird, um die Richtungsabhängigkeit aller Komponenten festzulegen.

In einer mehrsprachigen Anwendung können Sie die Attribute `lang` und `dir` für das `<html>`-Element dynamisch basierend auf dem Gebietsschema des Benutzers festlegen, was Sie mit dem composable [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head) tun können:

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
