## Usage (Verwendung)

::note{to="/docs/components/app"}
Die Nuxt-Benutzeroberfläche bietet eine **App**-Komponente, die Ihre App umhüllt, um globale Konfigurationen bereitzustellen, einschließlich der `locale`-Prop.
::

### Locale ist ein

Verwenden Sie die `locale` prop mit dem Gebietsschema, das Sie von `@nuxt/ui/locale` verwenden möchten:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Jedes Gebietsschema hat eine `code`-Eigenschaft (z. B. `en`, `en-GB`, `fr`), die das Datums-/Uhrzeitformat in Komponenten wie [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) und [InputTimexph0333x/docs/components/input-time) bestimmt.
::

### Custom locale (englisch)

Sie können Ihr eigenes Gebietsschema mit dem Dienstprogramm [defineLocale](/docs/composables/define-locale) erstellen:

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Schauen Sie sich den Parameter `code` an, dort müssen Sie den ISO-Code der Sprache übergeben. Beispiel:

* `hi` Hindi (Sprache)
* `de-AT`: Deutsch (Sprache) wie in Österreich (Region) verwendet

::

### Extend Gebietsschema

Sie können ein vorhandenes Gebietsschema anpassen, indem Sie dessen `messages` oder `code` mit dem Dienstprogramm [extendLocale](/docs/composables/extend-locale) überschreiben:

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Dynamic locale (englisch)

Um dynamisch zwischen den Sprachen zu wechseln, können Sie das Modul [Nuxt I18n](https://i18n.nuxtjs.org/) verwenden.

::steps{level="4"}

#### Installieren Sie das Nuxt I18n-Paket

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### Fügen Sie das Nuxt I18n Modul in Ihrem `nuxt.config.ts`{lang="ts-type"} hinzu

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### Setzt die `locale`-Prop mit `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### Automatische Link-Lokalisierung: badge{label="4.7+" class="align-text-top"}

Wenn `@nuxtjs/i18n` installiert ist, lokalisiert die [Link](/docs/components/link)-Komponente interne Links automatisch mit dem `$localePath`-Helfer.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
Externe Links und absolute URLs werden automatisch erkannt und überspringen die Lokalisierung. Sie können bei Bedarf weiterhin manuell `localePath()` oder `localeRoute()` verwenden.
::

::

### Dynamische Ausrichtung

Jedes Gebietsschema hat eine `dir`-Eigenschaft, die von der `App`-Komponente verwendet wird, um die Richtungsabhängigkeit aller Komponenten festzulegen.

In einer mehrsprachigen Anwendung können Sie die Attribute `lang` und `dir` für das `<html>`-Element dynamisch basierend auf dem Gebietsschema des Benutzers festlegen, was Sie mit dem composable [useHead](https://nuxt.com/docs/api/composables/use-head) tun können:

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
