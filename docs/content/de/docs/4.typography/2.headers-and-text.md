## Headings Bearbeiten

Verwenden Sie Überschriften, um Ihre Inhalte zu organisieren und das Lesen zu erleichtern.

Überschriften können in einen Ankerlink eingewickelt werden, wenn sie einen `id` haben, mit einem Hash-Symbol, das auf Hover für `H2` und `H3` (auf großen Bildschirmen) angezeigt wird, so dass Leser direkt zu einem Abschnitt verlinken können.

Ankerlinks sind standardmäßig für `H2` bis `H4` aktiviert, wenn Sie `@nuxt/content` verwenden, und ansonsten deaktiviert, [Comark](https://comark.dev) enthalten. Verwenden Sie die Komponente [`Theme`](/docs/components/theme) mit der prop `anchor`, um sie für einen Abschnitt Ihrer App umzuschalten:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
Sie können ihre [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks) (zum Beispiel, um sie für AI-Chat-Schnittstellen zu deaktivieren) sowie die [toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc) in Ihrem `nuxt.config.ts` steuern:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
