@@ph000@@überschriften

Verwenden Sie Überschriften, um Ihre Inhalte zu organisieren und das Lesen zu erleichtern.

Überschriften können in einen Ankerlink eingewickelt werden, wenn sie ein `id` haben, mit einem Hash-Symbol, das auf dem Hover für `H2` und `H3`(auf großen Bildschirmen) angezeigt wird, so dass Leser direkt auf einen Abschnitt verweisen können.

Ankerlinks sind standardmäßig für `H2` bis `H4` aktiviert, wenn `@nuxt/content` verwendet wird, und ansonsten deaktiviert,[](https://comark.dev) included. Verwenden Sie die Komponente [`Theme`](/docs/components/theme)Prop, um sie für einen Abschnitt Ihrer App umzuschalten:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt sein
:::div

::::note
Bei Verwendung von `@nuxt/content` sind Ankerlinks für `H2`,`H3` und `H4` standardmäßig aktiviert. Sie können ihre [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks)(zum Beispiel, um sie für KI-Chat-Schnittstellen zu deaktivieren) sowie die [toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc) in Ihrem `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
