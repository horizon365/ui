## lists Bearbeiten

Markdown unterstützt ungeordnete, geordnete und verschachtelte Listen für verschiedene Inhaltsanforderungen.

### Unordered Lists (ungeordnete Listen)

Verwenden Sie ungeordnete Listen für Elemente ohne eine bestimmte Reihenfolge. Beginnen Sie jedes Element mit einem `-`-Symbol.

::tabs{class="gap-0"}

::code-preview{label="Vorschau Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I ist ein Listenelement.
- I ist ein weiteres Listenelement.
- I ist der letzte Listeneintrag.

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### Ordentliche Listen

Verwenden Sie geordnete Listen, wenn die Artikelreihenfolge wichtig ist, z. B. Schritte in einem Prozess.

::tabs{class="gap-0"}

::code-preview{label="Vorschau Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. I ist ein Listenelement.
2. I ist ein weiteres Listenelement.
3. I ist der letzte Listeneintrag.

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### Verschachtelte Listen

Erstellen Sie hierarchische Listen mit Unterelementen für komplexe Strukturen. Ziehen Sie Unterelemente zum Verschachteln um vier Leerzeichen ein.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- I ist ein Listenelement.
  - I ist ein verschachteltes Listenelement.
  - I ist ein weiteres verschachteltes Listenelement.
- I ist ein weiterer Listeneintrag.
  - Another nested item (Ein weiteres verschachteltes Element)
    - Tief verschachtelte Elemente
    - Another deep nested item (Ein weiteres tief verschachteltes Element)
  - Zurück zur zweiten Ebene

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### Gemischte Listen

Sie können geordnete und ungeordnete Listen für komplexe Hierarchien kombinieren.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Erster großer Schritt
   - Unteranforderung A
   - Unteranforderung B
2. Zweiter wichtiger Schritt
   - Another sub-item Weitere Unterpunkte
   - Letzter Unterabschnitt
3. Letzter Schritt.

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

## Tables Bearbeiten

Strukturierte Daten in Zeilen und Spalten übersichtlich darstellen. Tabellen sind ideal zum Vergleichen von Daten oder zum Auflisten von Eigenschaften.

::tabs{class="gap-0"}

::code-preview{label="Vorschau Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| prop    | Default sein   | Typen                     |
|---------|-----------|--------------------------|
| x070x nicht|           | `string`{lang="ts-type"} nicht|
| x073x nicht| x074x nicht      | `string`{lang="ts-type"} nicht|
| x077x ist| x078x nicht| `string`{lang="ts-type"} nicht|

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
