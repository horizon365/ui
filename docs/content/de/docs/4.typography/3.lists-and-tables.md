### ungeordnete Listen

Verwenden Sie ungeordnete Listen für Elemente ohne eine bestimmte Sequenz. Beginnen Sie jedes Element mit einem @@@@-Symbol.

::tabs{class="gap-0"}

::code-preview{label="Vorschau Preview" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Ich bin ein Listenelement.
- Ich bin ein anderer Listenpunkt.
@@ph006@@ich bin der letzte Eintrag auf der Liste.

#Der Code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### geschachtelte Listen

Erstellen Sie hierarchische Listen mit Unterelementen für komplexe Strukturen. Ziehen Sie Unterelemente zum Verschachteln um vier Leerzeichen ein.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Ich bin ein Listenelement.
  - Ich bin ein verschachteltes Listenelement.
  - Ich bin ein weiterer verschachtelter Listenpunkt.
- Ich bin ein anderer Listenpunkt.
  - Ein weiterer verschachtelter Artikel
    - tief verschachtelten Element
    - Ein weiterer tief verschachtelter Artikel
  - Zurück zur zweiten Ebene

#Der Code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### gemischte Listen

Sie können geordnete und ungeordnete Listen für komplexe Hierarchien kombinieren.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Erster großer Schritt
   -  Unteranforderung A
   -  Unteranforderung B
2. Zweiter großer Schritt
   @@ph050@@ein weiterer Unterpunkt
   - Letzter Unterpunkt
3. Letzter Schritt

#Der Code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```
