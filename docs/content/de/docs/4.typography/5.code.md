::tip
Standardmäßig werden `material-theme-lighter` und `material-theme-palenight` Shiki Themen für den hellen und dunklen Modus verwendet. Wenn Sie `@nuxt/content` verwenden, können Sie dies durch die ändern [`content.build.markdown.highlight`]() Taste in Ihrem `nuxt.config.ts`. Wenn Sie Standalone `@nuxtjs/mdc` verwenden,[`mdc.highlight`]() key. When using [Comark](https://comark.dev), configure themes through the `shiki` plugin options.

Um den Dark Mode mit Comark zu unterstützen, fügen Sie Ihrem Stylesheet das folgende CSS hinzu:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

::tip
Das Dateinamensymbol wird von der `ProseCodeIcon` Komponente gerendert und enthält eine Reihe vordefinierter Symbole, die Sie in Ihrer App-Konfiguration anpassen können:

::framework-only
#nuxt sein
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#Ansehen
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::

::note
Diese Dateinamensymbole stammen aus der Sammlung [`vscode-icons`https://icones.js.org/collection/vscode-icons), die von den übrigen Komponenten getrennt ist, und werden auf Anfrage von der Dateierweiterung aufgelöst.

@@ph135@copy-button (nicht vorhanden)

Jeder Codeblock hat eine eingebaute Kopiertaste, die den Code in Ihre Zwischenablage kopiert.

Setzen Sie `copy` prop auf `false`, um die Schaltfläche auszublenden, oder geben Sie [Button](/docs/components/button) props ein, um sie anzupassen.

::tip
Sie können das Symbol durch die Tasten `ui.icons.copy` und `ui.icons.copyCheck` in Ihrer App-Konfiguration ändern:

::framework-only
#nuxt sein
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#Ansehen
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```

### Linie Hervorhebung

Markieren Sie bestimmte Linien, um die Aufmerksamkeit auf wichtige Teile zu lenken.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

default export defineNuxtConfig ({Dateiendung})

+   '@nuxt/ui'
  ]
})
