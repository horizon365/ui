::tip
Standardmäßig werden die Shiki-Designs `material-theme-lighter` und `material-theme-palenight` für den hellen bzw. dunklen Modus verwendet. Wenn Sie `@nuxt/content` verwenden, können Sie dies über die Taste [`content.build.markdown.highlight`](xph0666xxph0x ändern. Um den Dark Mode mit Comark zu unterstützen, fügen Sie Ihrem Stylesheet das folgende CSS hinzu:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

### Filename (englisch)

Code-Blöcke unterstützen Dateinamenanzeige mit automatischer Icon-Erkennung.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts [nuxt.config.ts]
default export defineNuxtConfig ({Dateiendung})
  Module: ['@ nuxt/ui']
})
```
````

::

::tip
Das Dateinamensymbol wird von der `ProseCodeIcon`-Komponente gerendert und enthält eine Reihe vordefinierter Symbole, die Sie in Ihrer App-Konfiguration anpassen können:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Diese Dateinamensymbole stammen aus der Sammlung [`vscode-icons`](https://icones.js.org/collection/vscode-icons), die von den `lucide`-Symbolen getrennt ist, die der Rest der Komponenten verwendet, und werden bei Bedarf aus der Dateierweiterung aufgelöst. Installieren Sie `@iconify-json/vscode-icons`, um sie lokal und offline zu bedienen, genau wie jede andere Sammlung.
::

### Copy-Button hinzufügen

Jeder Codeblock hat eine eingebaute Kopiertaste, die den Code in Ihre Zwischenablage kopiert.

Setzen Sie die `copy`-Prop auf `false`, um die Schaltfläche auszublenden, oder übergeben Sie [Button](/docs/components/button)-Props, um sie anzupassen.

::tip
Sie können das Symbol über die Tasten `ui.icons.copy` und `ui.icons.copyCheck` in Ihrer App-Konfiguration ändern:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

### Line-Hervorhebung

Markieren Sie bestimmte Linien, um die Aufmerksamkeit auf wichtige Teile zu lenken.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
default export defineNuxtConfig ({Dateiendung})
  modules: ['@ nuxt/ui'],//Diese Zeile wird hervorgehoben
  css: ['~/assets/css/main.css']
})
```
````
