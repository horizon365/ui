Nuxt UI bietet schön gestaltete **Prose components** für Ihre markdown content. Whether you rendering markdown with a library or use prose components directly, Nuxt UI applies its design system so your content automatically adapts to your application's theme. Ob Sie Markdown mit einer Bibliothek rendern oder Prosa-Komponenten direkt verwenden, Nuxt UI wendet sein Designsystem an, so dass sich Ihre Inhalte automatisch an das Thema Ihrer Anwendung anpassen.

::framework-only

:::div

#vue
:::note
Um Prosa-Komponenten mit Vue zu verwenden, müssen Sie die Option [`prose`](/docs/getting-started/installation/vue#prose) in Ihrem `vite.config.ts` aktivieren:

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```

### With Inhaltsrenderer: badge{label="Nuxt only" color="warning" class="align-text-top"}

Wenn Sie [`@nuxt/content`](https://github.com/nuxt/content) verwenden, rendern Sie Ihre Sammlungsseiten mit der Komponente [`<ContentRenderer>`xph0777xhttps://content.nuxt.com/docs/components/content-renderer):

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### Mit MDC-Komponente: badge{label="Nuxt only" color="warning" class="align-text-top"}

Wenn Sie [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) oder [`@nuxt/content`](https://github.com/nuxt/content) verwenden, verwenden Sie die [`<MDC>`](https://github.com/nuxt-content/mdc)-Komponente, um Markdown-Zeichenfolgen zu rendern:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

### With Markdown-Komponente

[Comark](https://comark.dev) rendert Markdown mit integrierter Unterstützung für Streaming. It inkrementell rendert Token, wie sie ankommen, so dass es ideal für AI-Chat-Antworten und andere dynamische Markdown-Inhalte.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
Das `shiki`-Plugin fügt Syntax-Hervorhebung zu Codeblöcken hinzu. Verwenden Sie die `:streaming`-Prop, wenn Sie Inhalte rendern, die inkrementell ankommen, z. B. KI-Antworten.

Um den dunklen Modus zu unterstützen, fügen Sie Ihrem Stylesheet das folgende CSS hinzu:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
In der Komponente **Chat** finden Sie ein vollständiges Beispiel für die Verwendung von Comark zum Rendern von KI-Chatnachrichten.

### Mit MarkdownDocument

Verwenden Sie die [`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code)-Komponente, um ein voranalysiertes `MarkdownDocument` zu rendern, ohne Parser-oder Plugin-Code an den Browser zu senden.

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### Mit Prose-Komponenten

Verwenden Sie Prosa-Komponenten direkt in Vue-Vorlagen für maximale Kontrolle.

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## Theme Bearbeiten

Überschreiben Sie alle Prosa-Komponenten-Stylings in Ihrer App-Konfiguration:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
