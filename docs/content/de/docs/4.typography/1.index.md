Nuxt UI bietet schön gestaltete **Prose components** für Ihre markdown content. Whether Sie Markdown mit einer Bibliothek rendern oder Prosa-Komponenten direkt verwenden, Nuxt UI wendet sein Design-System, so dass Ihre Inhalte automatisch an das Thema Ihrer Anwendung anpasst.

2. **Direct Vue usage**: importieren und verwenden Sie Prosa-Komponenten direkt in Ihren Vue-Vorlagen

### Mit ContentRenderer: badge{label="Nuxt only" color="warning" class="align-text-top"}

Bei Verwendung von [`@nuxt/content`](https://github.com/nuxt/content), rendern Sie Ihre Sammlungsseiten mit der Komponente [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer):

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### Mit MDC-Komponente: badge{label="Nuxt only" color="warning" class="align-text-top"}

Bei Verwendung von [`@nuxtjs/mdc`]() oder [`@nuxt/content`https://github.com/nuxt/content) verwenden Sie die [`<MDC>`](https://github.com/nuxt-content/mdc), um die Komponentenmarkierung zu machen:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc` wird zugunsten von [Comark](https://comark.dev) verworfen.
::

### Mit Markdown-Komponente

[Comark](https://comark.dev) rendert Markdown mit integrierter Unterstützung für Streaming. It inkrementell rendert Token, wie sie ankommen, so dass es ideal für AI-Chat-Antworten und andere dynamische Markdown-Inhalte.

::framework-only
#nuxt sein
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#Ansehen
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
Das `shiki` Plugin fügt Syntax-Hervorhebung zu Codeblöcken hinzu. Verwenden Sie die `:streaming` prop, wenn Sie Inhalte rendern, die inkrementell ankommen, wie z. B. AI-Antworten.

Um den dunklen Modus zu unterstützen, fügen Sie Ihrem Stylesheet das folgende CSS hinzu:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
In der Komponente **Chat** finden Sie ein vollständiges Beispiel für die Verwendung von Comark zum Rendern von KI-Chatnachrichten.
::

### Mit MarkdownDocument

Verwenden Sie die Komponente [`<MarkdownDocument>`](), um eine voranalysierte `MarkdownDocument` zu rendern, ohne Parser-oder Plugin-Code an den Browser zu senden.

::framework-only
#nuxt sein
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#Ansehen
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### Mit Prosa-Komponenten

Verwenden Sie Prosa-Komponenten direkt in Vue-Vorlagen für maximale Kontrolle:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## MDC-Syntax

Markdown-Elemente werden automatisch Prosa-Komponenten zugeordnet: `# Heading` wird zu `<ProseH1>`,`**bold**` wird zu `<ProseStrong>`,```code``` wird zu `<ProseCode>`, und so weiter.

[MDC Syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) geht noch weiter, indem Sie Vue-Komponenten direkt in markdown verwenden können.
