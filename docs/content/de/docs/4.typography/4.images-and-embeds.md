### Zoom Bearbeiten

Standardmäßig unterstützen Bilder den interaktiven Zoom: Ein Klick auf ein Bild öffnet es in einer modalen Überlagerung mit fließenden Übergängen, sodass Benutzer Details genauer untersuchen können.

Um das Zoomen eines bestimmten Bildes zu verhindern, fügen Sie das Attribut `:zoom="false"` hinzu.

::code-preview{class="[&>div>p]:my-0"}
![Image ohne zoom](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}

#code

```mdc
![Image without zoom](/assets/templates/nuxt/dashboard-dark.png){:zoom="false"}
```

::
