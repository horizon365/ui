@@@@@18@@ZOOOM

Standardmäßig unterstützen Bilder den interaktiven Zoom: Ein Klick auf ein Bild öffnet es in einer modalen Überlagerung mit fließenden Übergängen, sodass Benutzer Details genauer untersuchen können.

Um den Zoom auf ein bestimmtes Bild zu verhindern, fügen Sie das @@@@ Attribut hinzu.

::code-preview{class="[&>div>p]:my-0"}
![](PH0222{:zoom="false"}

#Der Code

