## Opstelling

### Toevoegen aan een Nuxt-project

::steps{level="4"}

#### Installeer het Nuxt UI-pakket

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui tailwindcss
```

```bash [yarn]
yarn add @nuxt/ui tailwindcss
```

```bash [npm]
npm install @nuxt/ui tailwindcss
```

```bash [bun]
bun add @nuxt/ui tailwindcss
```

::

#### Voeg de Nuxt UI module toe aan uw `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

::note
Het is niet nodig om `@nuxt/icon`, `@nuxt/fonts` of `@nuxtjs/color-mode` aan uw `modules` array toe te voegen, aangezien Nuxt UI ze automatisch registreert.
U kunt deze modules nog steeds configureren in uw `nuxt.config.ts` met behulp van de `icon`, `fonts` en `colorMode` toetsen.
::

#### Importeer Tailwind CSS en Nuxt UI in uw CSS

::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css']
})
```

::

::tip{to="https://nuxt.com/docs/getting-started/layers" target="_blank"}
Wanneer u [Nuxt Layers](https://nuxt.com/docs/getting-started/layers) gebruikt, genereert de module automatisch [`@source`](https://tailwindcss.com/docs/functions-and-directives#source-directive) richtlijnen voor elke laagmap, zodat Tailwind CSS al uw laagbronbestanden scant op hulpprogramma-klassen.
::

::callout{icon="i-simple-icons-visualstudiocode"}
Het wordt aanbevolen om de [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) extensie voor VSCode te installeren en de volgende instellingen toe te voegen:

```json [.vscode/settings.json]
{
  "files.associations": {
    "*.css": "tailwindcss"
  },
  "editor.quickSuggestions": {
    "strings": "on"
  },
  "tailwindCSS.classAttributes": ["class", "ui"],
  "tailwindCSS.classFunctions": ["defineAppConfig"]
}
```

::

#### Wikkel uw app met App-component

```vue [app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

::note{to="/docs/components/app"}
De `App`-component stelt globale configuratie in en is vereist voor **Toast**, **Tooltip** en **programmatic overlays**.
::

::

## Opties

U kunt Nuxt UI aanpassen door opties aan te bieden in uw `nuxt.config.ts`.

### `prefix`

Gebruik de optie `prefix` om het voorvoegsel van de componenten te wijzigen.

- Standaard: `U`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prefix: 'Nuxt'
  }
})
```

### `fonts`

Gebruik de optie `fonts` om de [`@nuxt/fonts`](https://github.com/nuxt/fonts) in of uit te schakelen.

- Standaard: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    fonts: false
  }
})
```

### `colorMode`

Gebruik de optie `colorMode` om de [`@nuxt/color-mode`](https://github.com/nuxt-modules/color-mode) module in of uit te schakelen.

- Standaard: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    colorMode: false
  }
})
```

### `theme.colors`

Gebruik de optie `theme.colors` om de dynamische kleuraliassen te definiëren die worden gebruikt om het componententhema te genereren.

- Standaard: `['primary', 'secondary', 'success', 'info', 'warning', 'error']`{lang="ts-type" class="inline"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      colors: ['primary', 'error']
    }
  }
})
```

::note
Elke alias genereert een volledige set `--ui-color-*`-tinten en varianten in de componentthema 's met kleurvarianten, of uw app deze nu gebruikt of niet.
Knip de lijst bij naar de aliassen die u daadwerkelijk gebruikt en bewaar `error` als u formulieren gebruikt, aangezien validatiestijlen erop vertrouwen.
::

::tip{to="/docs/getting-started/theme/design-system#color-system"}
Lees meer over kleuraanpassing en thema 's in de sectie Thema.
::

### `theme.transitions`

Gebruik de optie `theme.transitions` om overgangen op componenten in of uit te schakelen.

- Standaard: `true`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      transitions: false
    }
  }
})
```

::note
Deze optie voegt de klasse `transition-colors` toe aan componenten met zweef- of actieve toestanden.
::

### `theme.unstyled`: badge{label="4.9+" class="align-text-top"}

Gebruik de optie `theme.unstyled` om alle standaard themaklassen uit componenten te verwijderen, waarbij alleen de structuur en de klassen die u via `class`, `ui` of `app.config.ui` aanbiedt behouden blijven.

- Standaard: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      unstyled: true
    }
  }
})
```

::warning
Dit verwijdert ook **structural** klassen (positionering, overgangen, flex / grid), niet alleen cosmetische.
Lay-out-zware componenten zoals `Modal`, `Drawer` of `Calendar` hebben je nodig om hun lay-out opnieuw te leveren, vergelijkbaar met de ongestyleerde modus van PrimeVue.
::

### `theme.defaultVariants`

Gebruik de optie `theme.defaultVariants` om de standaard `color`- en `size`-varianten voor componenten te overschrijven.

Alleen defaults die exact `primary` of `md` zijn worden vervangen, dus Avatar houdt `color: 'neutral'` en Separator houdt `size: 'xs'`.

- Standaard: `{ color: 'primary', size: 'md' }`{lang="ts-type"}

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      defaultVariants: {
        color: 'neutral',
        size: 'sm'
      }
    }
  }
})
```

### `theme.prefix`: badge{label="4.2+" class="align-text-top"}

Gebruik de optie `theme.prefix` om hetzelfde voorvoegsel te configureren dat u hebt ingesteld op uw Tailwind CSS-import. Dit zorgt ervoor dat Nuxt UI-componenten de juiste voorgeprogrammeerde hulpprogramma-klassen en CSS-variabelen gebruiken.

::code-group

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  }
})
```

```css [app/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@nuxt/ui";
```

::

::warning{to="https://fonts.nuxt.com/get-started/configuration#processcssvariables"}
Mogelijk moet u `fonts.processCSSVariables` inschakelen om de prefix-optie met de `@nuxt/fonts`-module te gebruiken:

```ts [nuxt.config.ts] {9-11}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    theme: {
      prefix: 'tw'
    }
  },
  fonts: {
    processCSSVariables: true
  }
})
```
::

Dit zal automatisch alle Tailwind-nutsklassen en CSS-variabelen in Nuxt UI-componentthema 's prefixeren:

```html
<!-- Without prefix -->
<button class="px-2 py-1 text-xs hover:bg-primary/75">Button</button>

<!-- With prefix: tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-primary/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Lees meer over het gebruik van een voorvoegsel in de Tailwind CSS-documentatie.
::

### `prose`

Gebruik de optie `prose` om de import van Nuxt UI [`Prose` te forceren components](/docs/typography) zelfs als `@nuxtjs/mdc`, `@nuxt/content` of `@comark/nuxt` niet is geïnstalleerd.

- Standaard: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    prose: true
  }
})
```

### `mdc`: badge{label="Deprecated" color="warning" class="align-text-top"}

Gebruik in plaats daarvan de [`prose`](#prose) optie.

### `content`

Gebruik de `content` optie om de import van de Nuxt UI proza en content componenten te forceren, zelfs als `@nuxt/content` niet is geïnstalleerd.

- Standaard: `false`{lang="ts-type"}

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    content: true
  }
})
```

### `experimental.componentDetection`: badge{label="4.1+" class="align-text-top"}

Gebruik de optie `experimental.componentDetection` om automatische componentdetectie in te schakelen voor het schudden van bomen.
Deze functie scant uw broncode om te detecteren welke componenten daadwerkelijk worden gebruikt en genereert alleen de benodigde CSS voor die componenten (inclusief hun afhankelijkheden).

- Standaard: `false`{lang="ts-type"}
- Type: `boolean | string[]`{lang="ts-type"}

**Automatische detectie inschakelen: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: true
    }
  }
})
```

**Inclusief extra componenten voor dynamisch gebruik: **

```ts [nuxt.config.ts] {4-8}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/main.css'],
  ui: {
    experimental: {
      componentDetection: ['Modal', 'DropdownMenu', 'Popover']
    }
  }
})
```

::note
Bij het verstrekken van een reeks componentnamen is automatische detectie ingeschakeld en worden deze componenten (samen met hun afhankelijkheden) gegarandeerd opgenomen.
Dit is handig voor dynamische componenten zoals `<component :is="..." />` die niet statisch kunnen worden geanalyseerd.
::

## Continue versies

Nuxt UI gebruikt [pkg.pr.new](https://github.com/stackblitz-labs/pkg.pr.new) voor continue preview-releases, waardoor ontwikkelaars direct toegang hebben tot de nieuwste functies en bugfixes zonder te wachten op officiële releases.

Automatische preview-releases worden gemaakt voor alle commits en PR 's naar de `v4`-branch. Gebruik ze door uw pakketversie te vervangen door de specifieke commit-hash of PR-nummer.

```diff [package.json]
{
  "dependencies": {
-   "@nuxt/ui": "^4.0.0",
+   "@nuxt/ui": "https://pkg.pr.new/@nuxt/ui@4c96909",
  }
}
```

::note
**pkg.pr.new** zal automatisch reageren op PR 's met de installatie-URL, waardoor het gemakkelijk is om wijzigingen te testen.
::
