## Wat is de gebruikersinterface van Nuxt?

Een moderne Vue UI-componentenbibliotheek gebouwd op [Reka UI](https://reka-ui.com/), [Tailwind CSS](https://tailwindcss.com/) en [Tailwind Variants](https://www.tailwind-variants.org/) om mooie en toegankelijke applicaties te verzenden met meer dan 125 productieklare componenten.
Werkt met Nuxt en gewone Vue apps (Vite, Inertia, SSR).

Als u een Vue-project bouwt met Tailwind CSS, is Nuxt UI een geweldige standaardkeuze.
Het biedt kant-en-klare componenten op hoog niveau (gegevenstabellen, formulieren, overlays, navigatie), terwijl het toch geavanceerde aanpassing mogelijk maakt wanneer dat nodig is.

## Wat is er nieuw in v4?

Nuxt UI v4 markeert een belangrijke mijlpaal: Nuxt UI en Nuxt UI Pro zijn nu verenigd in een enkele, volledig open-source en gratis bibliotheek met meer dan 125 productieklare componenten en
 een complete Figma Kit.

De migratie van v3 naar v4 zal veel soepeler verlopen dan van v2 naar v3. Lees meer in de [migratie guide](/docs/getting-started/migration).

## Core technologieën

Nuxt UI is gebouwd op drie fundamenten: Reka UI voor gedrag en toegankelijkheid, Tailwind CSS voor styling en Tailwind Variants voor het samenstellen van varianten.

### Reka gebruikersinterface

Nuxt UI is gebouwd bovenop [Reka UI](https://reka-ui.com/) als basis voor de componenten:

- **WAI-ARIA Compliance**: Volgt [WAI-ARIA authoring practices](https://reka-ui.com/docs/overview/accessibility) met de juiste semantiek en rollen
- **Keyboard Navigation**: Ingebouwde toetsenbordondersteuning voor complexe componenten zoals tabbladen en dialogen
- **Focus Management**: Intelligente focusbehandeling die de focus verplaatst op basis van gebruikersinteracties
- **Accessible Labels**: Abstracties om etiketteringsregelaars voor schermlezers te vereenvoudigen

### Tailwind CSS [bewerken]

Nuxt UI integreert de nieuwste [Tailwind CSS](https://tailwindcss.com/), met aanzienlijke verbeteringen:

- **5x Snellere Builds**: Volledige builds tot 5x sneller, incrementele builds meer dan 100x sneller
- **Unified Toolchain**: Ingebouwde importverwerking, leveranciersvoorfixatie en syntaxistransformaties
- **CSS-first Configuration**: direct aanpassen en uitbreiden in CSS in plaats van JavaScript
- **Modern Webkenmerken**: containerquery 's, cascadelagen, kleuren met een breed gamma en meer

### Tailwind Varianten

Nuxt UI maakt gebruik van [Tailwind Variants](https://www.tailwind-variants.org/) om een krachtig ontwerpsysteem te bieden:

- **Dynamic Styling**: Flexibele componentvarianten met een krachtige API
- **Type Safety**: Volledige TypeScript-ondersteuning met automatische aanvulling
- **Conflict Resolution**: Efficiënt samenvoegen van conflicterende stijlen

### Vue compatibiliteit (Nuxt optioneel)

Nuxt UI werkt met elk Vue-project, niet alleen Nuxt. Voeg eenvoudig de Vite- en Vue-plug-ins toe aan uw configuratie:

- **Auto-imports**: Componenten en composables worden automatisch geïmporteerd en wereldwijd beschikbaar
- **Design System**: volledige ondersteuning voor thema 's met aanpasbare kleuren, maten, varianten en meer
- **Developer Experience**: volledige TypeScript-ondersteuning met IntelliSense en automatische aanvulling

::tip{to="/docs/getting-started/installation/vue" aria-label="Vue installatiehandleiding"}
Leer hoe u Nuxt UI installeert en configureert in een Vue-project in de **Vue-installatiegids**.
::

### TypeScript Ondersteuning

Nuxt UI biedt uitgebreide TypeScript-integratie voor een superieure ontwikkelaarservaring:

- **Auto-completion**: Voor alle onderdelen rekwisieten, slots en evenementen
- **Generic Components**: [Vue gebruiken Generics](https://vuejs.org/api/sfc-script-setup.html#generics)
- **Type-safe Theming**: In `app.config.ts`
- **IntelliSense**: In je hele codebase

## Veelgestelde vragen

::accordion

:::accordion-item{label="Is Nuxt UI gratis te gebruiken?"}
Ja! Nuxt UI is volledig gratis en open source onder de MIT-licentie. Alle 125 + componenten zijn voor iedereen beschikbaar.
:::

:::accordion-item{label="Kan ik Nuxt UI gebruiken met Vue zonder Nuxt?"}
Ja! Hoewel geoptimaliseerd voor Nuxt, werkt Nuxt UI perfect met stand-alone Vue-projecten via onze Vite-plug-in. U kunt de [install volgen guide](/docs/getting-started/installation/vue) om aan de slag te gaan.
:::

:::accordion-item{label="Heeft Nuxt UI een Figma Kit?"}
Ja! Nuxt UI bevat een [complete Figma Kit](https://go.nuxt.com/figma-ui) met alle componenten, waardoor ontwerpers en ontwikkelaars gemakkelijk kunnen samenwerken.
:::

:::accordion-item{label="Hoe gaat Nuxt UI om met toegankelijkheid?"}
Door [Reka UI](https://reka-ui.com/docs/overview/accessibility) integratie biedt Nuxt UI automatische ARIA-kenmerken, toetsenbordnavigatie, focusbeheer en ondersteuning voor schermlezers.
Hoewel het een sterke basis biedt, blijft testen in uw specifieke use-case belangrijk.
:::

:::accordion-item{label="Is Nuxt UI klaar voor productie?"}
Ja! Nuxt UI wordt in productie gebruikt door duizenden applicaties met meer dan 1000 Vitest-tests, regelmatige updates en actief onderhoud.
:::

:::accordion-item{label="Wanneer moet ik alternatieven overwegen?"}
Overweeg **Vuetify** als u Material Design-styling wilt, **ant-design-vue** voor Ant Design-styling, **PrimeVue** of **Element Plus** als u geen Tailwind CSS wilt, **shadcn-vue** als u liever kopieert
 componenten in uw repo, **Quasar** voor platformonafhankelijke apps (web, mobiel, desktop) of **Reka UI** / **Headless UI** als u alleen ongestileerde primitieven nodig heeft.
:::

:::accordion-item{label="Waar kan ik hulp krijgen?"}
Stel vragen en krijg hulp in [GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a), chat met de community op [Discord](https://go.nuxt.com/discord) of meld bugs op [GitHub](https://github.com/nuxt/ui/issues).
:::
