## Tailwind CSS

Tailwind CSS maakt gebruik van een CSS-first configuratie, waarmee u uw ontwerptokens met de [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive) direct in uw CSS kunt definiëren. Dit maakt uw thema draagbaar, onderhoudbaar en gemakkelijk aan te passen
.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  /* Your custom design tokens go here */
}
```

::note{to="https://tailwindcss.com/docs/theme" target="_blank"}
Controleer de Tailwind CSS-documentatie voor alle beschikbare aanpassingsopties voor themavariabelen.
::

::tip
Tailwind CSS v4 veranderde zijn [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) zodat knoppen `cursor: default` gebruiken in plaats van `cursor: pointer` om de standaardwaarden van de browser te evenaren.
Als u de aanwijzercursor wereldwijd wilt herstellen, voegt u deze basisstijlen toe aan uw CSS:

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### Lettertypen

Gebruik de themavariabelen `--font-*` om de lettertypefamilie utilities](https://tailwindcss.com/docs/font-family#customizing-your-theme) in uw project aan te passen.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

::framework-only
#nuxt
:::note{to="/docs/getting-started/integrations/fonts"}
Hier gedefinieerde lettertypen worden automatisch geladen en geoptimaliseerd door de `@nuxt/fonts` module.
:::
::

### Kleuren

Gebruik de `--color-*` thema variabelen om [customize uw colors](https://tailwindcss.com/docs/colors#customizing-your-colors) of [override standaard colors](https://tailwindcss.com/docs/colors#overriding-default-colors).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme static {
  /* Override default green color */
  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;

  /* Define new custom color */
  --color-brand-50: #fef2f2;
  --color-brand-100: #fee2e2;
  --color-brand-200: #fecaca;
  --color-brand-300: #fca5a5;
  --color-brand-400: #f87171;
  --color-brand-500: #ef4444;
  --color-brand-600: #dc2626;
  --color-brand-700: #b91c1c;
  --color-brand-800: #991b1b;
  --color-brand-900: #7f1d1d;
  --color-brand-950: #450a0a;
}
```

::warning
Zorg ervoor dat u bij het toevoegen van aangepaste kleuren alle tinten van `50` tot `950` voor elke kleur definieert.
::

### Breekpunten

Gebruik de `--breakpoint-*` thema variabelen om [customize uw breakpoints](https://tailwindcss.com/docs/responsive-design#customizing-your-theme).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

### Motie

Gebruik de `--ease-*`-themavariabelen om de easing](https://tailwindcss.com/docs/transition-timing-function#customizing-your-theme) van de animaties en bewegingsovergangen in uw project aan te passen.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
}
```

Animaties invoeren en afsluiten draaien op `--ease-out`, onbepaald laden van animaties op `--ease-in-out`, dus overschrijven deze twee retimes de bibliotheek.

::note
Wanneer `prefers-reduced-motion` is ingesteld, vervagen overlays op hun plaats in plaats van schalen of glijden en worden bewegingsovergangen uitgeschakeld.
::

## Color Systeem

Het kleursysteem van Nuxt UI is ontworpen rond **semantic naming** in plaats van specifieke kleurwaarden. Deze aanpak maakt uw gebruikersinterface beter onderhoudbaar en maakt het wisselen van thema 's eenvoudig.

### Semantische kleuren

Nuxt UI biedt semantische kleuraliassen die de **purpose** van de kleur beschrijven.
Elke alias wordt gedefinieerd op basis van een kleur uit uw `@theme`-configuratie, die elke kleur kan zijn die u definieert naast de [default Tailwind CSS palette](https://tailwindcss.com/docs/colors).

| Kleur | Standaard | Omschrijving |
| --- | --- | --- |
| `primary`{color="primary"} | `green` | Belangrijkste CTA 's, actieve navigatie, merkelementen, belangrijke links |
| `secondary`{color="secondary"} | `blue` | Secundaire knoppen, alternatieve acties, complementaire UI-elementen |
| `success`{color="success"} | `green` | Succesberichten, voltooide staten, positieve bevestigingen |
| `info`{color="info"} | `blue` | Infoalerts, tooltips, helptekst, neutrale meldingen |
| `warning`{color="warning"} | `yellow` | Waarschuwingsberichten, wachtende staten, aandachtspunten |
| `error`{color="error"} | `red` | Foutmeldingen, validatiefouten, destructieve acties |
| `neutral` | `slate` | Tekst, randen, achtergronden, uitgeschakelde staten |

Deze semantische kleuren zijn beschikbaar in de `color` prop van Nuxt UI-componenten:

::component-code{slug="button"}
---
props:
  color: primary
slots:
  default: Save Changes
---
::

::note
Probeer het themamenu: prose-icon{name="i-lucide-palette" class="text-primary"} in de koptekst om direct te zien hoe verschillende kleurenschema 's de hele gebruikersinterface beïnvloeden, of open de [theme editor](/theme) om alles tegelijk aan te passen!
::

### Runtime configuratie

::framework-only
#nuxt
:::div
U kunt deze kleuren tijdens runtime configureren in uw [`app.config.ts`](https://nuxt.com/docs/4.x/directory-structure/app/app-config) bestand onder de `ui.colors`-sleutel, waardoor dynamische thema-aanpassing mogelijk is zonder de server opnieuw op te starten:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      neutral: 'zinc'
    }
  }
})
```
:::

#vue
:::div
U kunt deze kleuren tijdens runtime configureren in uw `vite.config.ts`-bestand onder de `ui.colors`-sleutel, waardoor dynamische thema-aanpassing mogelijk is:

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          neutral: 'zinc'
        }
      }
    })
  ]
})
```
:::
::

::caution
Je kunt alleen kleuren gebruiken die in je thema bestaan. Ofwel:
- De standaard colors](https://tailwindcss.com/docs/colors) van [Tailwind gebruiken (zoals `blue`, `green`, `zinc`)
- Definieer eerst aangepaste kleuren met de `@theme`-richtlijn (zoals `brand` in ons voorbeeld hierboven)
::

### Kleuren uitbreiden

Mogelijk wilt u extra semantische kleuren definiëren die verder gaan dan de standaardwaarden, zoals het toevoegen van een `tertiary`-kleur:

::framework-only
#nuxt
:::div
Registreer eerst de nieuwe kleur in je `nuxt.config.ts` onder de `ui.theme.colors` toets:

```ts [nuxt.config.ts] {7}
export default defineNuxtConfig({
  ui: {
    theme: {
      colors: [
        'primary',
        'secondary',
        'tertiary',
        'info',
        'success',
        'warning',
        'error'
      ]
    }
  }
})
```

Wijs het vervolgens toe in uw `app.config.ts` onder de `ui.colors`-toets:

```ts [app/app.config.ts] {6}
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      secondary: 'purple',
      tertiary: 'indigo'
    }
  }
})
```
:::

#vue
:::div
Registreer en wijs de nieuwe kleur toe in je `vite.config.ts` bestand:

```ts [vite.config.ts] {13,24}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      theme: {
        colors: [
          'primary',
          'secondary',
          'tertiary',
          'info',
          'success',
          'warning',
          'error'
        ]
      },
      ui: {
        colors: {
          primary: 'blue',
          secondary: 'purple',
          tertiary: 'indigo'
        }
      }
    })
  ]
})
```
:::
::

Gebruik ten slotte deze nieuwe kleur in componenten die de `color` prop of [as een class](/docs/getting-started/theme/css-variables) ondersteunen:

```vue
<UButton color="tertiary">
  Special Action
</UButton>
```
