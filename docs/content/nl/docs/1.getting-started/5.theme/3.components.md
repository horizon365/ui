## Tailwind Varianten

Nuxt UI-componenten worden gestyled met behulp van de [Tailwind Variants](https://www.tailwind-variants.org/) API, die een krachtige manier biedt om varianten te maken en componentstijlen te beheren.

### Slots

Componenten kunnen meerdere `slots` hebben, die elk een afzonderlijk HTML-element of -sectie binnen de component vertegenwoordigen. Deze slots zorgen voor flexibele invoeging en styling van inhoud.

Laten we de [Card](/docs/components/card) als voorbeeld nemen met meerdere slots:

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-highlighted font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="root" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
De bovenstaande fragmenten zijn ingekort. De echte componenten dragen ook `v-if`-bewakers op elke sleuf en het thema definieert `variant`-stijlen bovenop de sleuven.
::

Sommige componenten hebben geen slots, ze zijn gewoon samengesteld uit een enkel root-element. In dit geval definieert het thema alleen de `base`-sleuf zoals de [Container](/docs/components/container) component bijvoorbeeld:

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--ui-container) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <Primitive :as="props.as" :class="ui({ class: [props.ui?.base, props.class] })">
    <slot />
  </Primitive>
</template>
```

::

::note
Componenten zonder sleuven hebben nog steeds een [`ui` prop](#ui-prop).
Het belicht een enkele `base`-sleutel in plaats van één sleutel per slot. [Link](/docs/components/link) en [Icon](/docs/components/icon) zijn de uitzonderingen: ze hebben geen `ui` prop, dus gebruik de [`class` prop](#class-prop) om hun
 stijlen.
::

### Varianten

Componenten ondersteunen `variants`, die de stijlen van verschillende `slots` dynamisch aanpassen op basis van componentsteunen.

De [Avatar](/docs/components/avatar) component gebruikt bijvoorbeeld een `size`-variant om het uiterlijk te regelen:

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

Op deze manier past de `size` prop de bijbehorende stijlen toe op de `root`-sleuf:

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/nuxt.png'
  size: lg
---
::

### Standaard varianten

De eigenschap `defaultVariants` stelt de standaardwaarde in voor elke variant wanneer er geen prop is doorgegeven.

De standaardgrootte van de [Avatar](/docs/components/avatar) component is bijvoorbeeld ingesteld op `md`:

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none overflow-hidden rounded-full align-middle bg-elevated',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themedefaultvariants"}
U kunt de optie `theme.defaultVariants` in uw `nuxt.config.ts` gebruiken om de standaard `size` en `color` te overschrijven van elk onderdeel dat `md` en `primary` gebruikt.
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themedefaultvariants"}
U kunt de optie `theme.defaultVariants` in uw `vite.config.ts` gebruiken om de standaard `size` en `color` te overschrijven van elk onderdeel dat `md` en `primary` gebruikt.
:::
::

### Samengestelde Varianten

Sommige componenten gebruiken de eigenschap `compoundVariants` om klassen toe te passen wanneer tegelijkertijd aan meerdere variantvoorwaarden wordt voldaan.

De [Button](/docs/components/button) gebruikt bijvoorbeeld de eigenschap `compoundVariants` om klassen toe te passen voor een specifieke combinatie van `color` en `variant`:

```ts [src/theme/button.ts] {27-31}
import type { ModuleOptions } from '../module'

export default (options: Required<ModuleOptions>) => ({
  slots: {
    base: ['rounded-md font-medium inline-flex items-center disabled:cursor-not-allowed aria-disabled:cursor-not-allowed disabled:opacity-75 aria-disabled:opacity-75', options.theme.transitions && 'transition-colors']
  },
  variants: {
    color: {
      ...Object.fromEntries((options.theme.colors || []).map((color: string) => [color, ''])),
      neutral: ''
    },
    variant: {
      solid: '',
      outline: '',
      soft: '',
      subtle: '',
      ghost: '',
      link: ''
    }
  },
  compoundVariants: [
    ...(options.theme.colors || []).map((color: string) => ({
      color,
      variant: 'outline',
      class: `ring ring-inset ring-${color}/50 text-${color} hover:bg-${color}/10 active:bg-${color}/10 disabled:bg-transparent aria-disabled:bg-transparent dark:disabled:bg-transparent dark:aria-disabled:bg-transparent outline-${color}/25 focus-visible:outline-3 focus-visible:ring-${color}`
    })),
    {
      color: 'neutral',
      variant: 'outline',
      class: 'ring ring-inset ring-accented text-default bg-default hover:bg-elevated active:bg-elevated disabled:bg-default aria-disabled:bg-default outline-inverted/25 focus-visible:outline-3 focus-visible:ring-inverted'
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
})
```

## Thema aanpassen

U hebt meerdere manieren om het uiterlijk van Nuxt UI-componenten aan te passen, u kunt dit voor alle componenten tegelijk of per component doen.

::note
Tailwind Variants gebruikt [`tailwind-merge`](https://github.com/dcastil/tailwind-merge) onder de motorkap om klassen samen te voegen, zodat u zich geen zorgen hoeft te maken over tegenstrijdige klassen.
::

::tip
U kunt het thema voor elk onderdeel op twee manieren verkennen:

- Controleer de sectie `Theme` in de documentatie van elk afzonderlijk onderdeel.
- Blader direct door de broncode in de GitHub-repository op [`src/theme`](https://github.com/nuxt/ui/tree/v4/src/theme).
::

### Globale configuratie

::framework-only
#nuxt
U kunt het thema van componenten wereldwijd in uw `app.config.ts` overschrijven door exact dezelfde structuur te gebruiken als het thema-object.
#vue
U kunt het thema van componenten wereldwijd in uw `vite.config.ts` overschrijven door exact dezelfde structuur te gebruiken als het thema-object.
::

U kunt de [`slots`](#slots), [`variants`](#variants), [`compoundVariants`](#compound-variants) en [`defaultVariants`](#default-variants) van een component aanpassen om het standaardthema van een component te wijzigen:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      compoundVariants: [{
        color: 'neutral',
        variant: 'outline',
        class: 'ring-default hover:bg-accented'
      }],
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          variants: {
            size: {
              md: {
                leadingIcon: 'size-4'
              }
            }
          },
          compoundVariants: [{
            color: 'neutral',
            variant: 'outline',
            class: 'ring-default hover:bg-accented'
          }],
          defaultVariants: {
            color: 'neutral',
            variant: 'outline'
          }
        }
      }
    })
  ]
})
```
:::
::

::note
In dit voorbeeld overschrijft `font-bold` `font-medium` op alle knoppen, `size-4` overschrijft `size-5` klasse op het leidende pictogram wanneer `size="md"` en `ring-default hover:bg-accented` `ring-accented hover:bg-elevated` overschrijven wanneer `color="neutral"` en `variant="outline"`.
De knoppen zijn nu standaard ingesteld op `color="neutral"` en `variant="outline"`.
::

Standaard worden deze klassen samengevoegd met de standaardwaarden van de component. U kunt ook een slot instellen op een functie om ze in plaats daarvan te vervangen.
Het ontvangt de standaardklassen van de slot als argument, dus u kunt een deel ervan hergebruiken.
Klassen van `variants` en `compoundVariants` gelden nog steeds bovenop, precies zoals wanneer je een string passeert.

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        button: {
          slots: {
            label: () => 'text-base font-bold'
          }
        }
      }
    })
  ]
})
```
:::
::

::framework-only
#nuxt
:::warning
Stel een slot in op een functie op slechts één plaats.
Nuxt voegt de `app.config.ts` van elke [layer](https://nuxt.com/docs/getting-started/layers) samen met `defuFn`, die uw functie aanroept met de waarde die de toets al lager heeft en alleen het resultaat behoudt.
Nuxt UI leest vervolgens een gewone string, zodat de klassen worden samengevoegd met de standaardinstellingen in plaats van ze te vervangen.
:::
::

::framework-only
#nuxt
:::tip{to="/docs/getting-started/installation/nuxt#themeunstyled"}
Als u de standaardklassen van alle componenten tegelijk wilt verwijderen, gebruikt u de optie `theme.unstyled` in uw `nuxt.config.ts`.
:::

#vue
:::tip{to="/docs/getting-started/installation/vue#themeunstyled"}
Als u de standaardklassen van alle componenten tegelijk wilt verwijderen, gebruikt u de optie `theme.unstyled` in uw `vite.config.ts`.
:::
::

### Thema onderdeel

De [Theme](/docs/components/theme) component heeft voorrang op slots en prop-standaardinstellingen voor al zijn nakomelingen, zonder de rest van de app te beïnvloeden. Dit heeft voorrang op de globale configuratie, maar de `ui` en
 `class` rekwisieten winnen er nog steeds van. Slots accepteren hetzelfde functieformulier om hun klassen te vervangen in plaats van samen te voegen. Het is opgelost op hetzelfde punt als de [`ui` prop](#ui-prop), dus het gedraagt zich op dezelfde manier.

### `ui` voor

Je kunt ook de **slots** van een component overschrijven met de `ui` prop. Dit heeft voorrang op zowel de globale configuratie als de opgeloste `variants`.

::component-code{slug="button"}
---
prettier: true
ignore:
  - ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  trailingIcon: i-lucide-chevron-right
  size: md
  color: neutral
  variant: outline
  ui:
    trailingIcon: 'rotate-90 size-3'
slots:
  default: |

    Button
---
::

::note
In dit voorbeeld wordt de `trailingIcon`-sleuf overschreven met `size-3`, hoewel de `md`-groottevariant er een `size-5`-klasse op zou toepassen.
::

Een slotwaarde kan ook een functie zijn om zijn klassen te vervangen in plaats van ze samen te voegen:

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::note
De `ui` prop is opgelost na de `variants`, dus in tegenstelling tot de globale configuratie vervangt een functie hier de **resolved** klassen van de slot.
Het argument bevat wat de `variants` en `compoundVariants` overeenkwamen. Een `class` prop op hetzelfde slot wordt nog steeds samengevoegd bovenop de geretourneerde klassen.
::

### `class` prop

Gebruik de `class` prop om de klassen van de `root` of `base` slot te overschrijven. Dit heeft voorrang op zowel globale config als opgeloste `variants`.

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
In dit voorbeeld zal de klasse `font-bold` de standaard klasse `font-medium` op deze knop overschrijven.
::
