## Wat zijn Vaardigheden?

Vaardigheden zijn gestructureerde kennisbestanden die AI-coderingsagenten context geven over een bibliotheek, framework of codebase.
In tegenstelling tot MCP-servers die realtime tooltoegang bieden, worden vaardigheden rechtstreeks in de context van de agent geladen, zodat deze er tijdens het gesprek naar kan verwijzen.

Nuxt UI biedt een **use skill** die AI-agenten leert hoe ze UI 's kunnen bouwen met Nuxt UI: installatie, theming, componenten, composables, formulieren, overlays en lay-outs.

## Gebruik

De gebruiksvaardigheid geeft AI-agenten uitgebreide kennis over bouwen met Nuxt UI v4. Het omvat:

- Installatie voor Nuxt, Vue, Laravel en AdonisJS
- Theming en branding met semantische kleuren en CSS-variabelen
- Alle 125 + componenten met rekwisieten en gebruikspatronen
- Componenten (`useToast`, `useOverlay`, `defineShortcuts`)
- Form validatie met standaardschema
- Layout samenstelling (Dashboard, Documenten, Chat, Editor)
- Officiële startsjablonen

De vaardigheid bevat aanvullende referenties die de AI-agent op verzoek laadt op basis van de taak, waardoor de reacties gefocust en contextefficiënt blijven.

::note
Eenmaal geïnstalleerd, kunt u de vaardigheid aanroepen door `/nuxt-ui` in de chat van uw agent te typen.
::

### Vaardigheden CLI

De [`skills`](https://skills.sh) CLI is de gemakkelijkste manier om de Nuxt UI-vaardigheid te installeren. Het ondersteunt meer dan 35 agenten, waaronder Cursor, Claude Code, Codex, Windsurf, Cline en meer.

```bash
npx skills add nuxt/ui
```

U kunt specifieke agenten targeten met de vlag `--agent`:

```bash
npx skills add nuxt/ui --agent cursor
npx skills add nuxt/ui --agent claude-code
```

Of installeer wereldwijd zodat de vaardigheid beschikbaar is voor al uw projecten:

```bash
npx skills add nuxt/ui --global
```

Als het klonen vanuit GitHub traag is op uw netwerk, kunt u in plaats daarvan rechtstreeks vanaf de website installeren:

```bash
npx skills add https://ui.nuxt.com
```

::tip
Bezoek [skills.sh](https://skills.sh) om meer te leren over het ecosysteem van vaardigheden en door beschikbare vaardigheden te bladeren.
::

### Cursor

#### Snel installeren

Klik op de onderstaande knop om de Nuxt UI-vaardigheid rechtstreeks in Cursor te installeren:

::u-button
---
to: "cursor://anysphere.cursor-deeplink/install-skill?url=https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui"
label: Install Skill
color: neutral
icon: i-simple-icons-cursor
---
::

#### Handmatig instellen

1. Open Cursor en ga naar "Instellingen" > "Vaardigheden"
2. Klik op "Vaardigheid toevoegen" en voer de volgende URL in:

```
https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```

### Claude-code

::note{icon="i-lucide-info"}
**Zorg ervoor dat Claude Code is geïnstalleerd.** Bezoek [Anthropic 's documentation](https://docs.anthropic.com/en/docs/claude-code/quickstart) voor installatie-instructies.
::

Voeg de vaardigheid toe met het CLI-commando:

```bash
claude skill add https://github.com/nuxt/ui/tree/v4/skills/nuxt-ui
```
