## Gebruik

Nuxt UI registreert automatisch de [`@nuxt/fonts`](https://github.com/nuxt/fonts) module voor u, dus er is geen extra installatie vereist.

### Aangifte

Om een lettertype in uw Nuxt UI-applicatie te gebruiken, kunt u het eenvoudig in uw CSS declareren. Het wordt automatisch geladen en voor u geoptimaliseerd.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

### Configuration

U kunt de `@nuxt/fonts` module uitschakelen met de `ui.fonts` optie in uw `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
