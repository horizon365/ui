## Gebruik

::note{to="/docs/components/app"}
Nuxt UI biedt een **App**-component die uw app omhult om wereldwijde configuraties te bieden, inclusief de `locale`-prop.
::

### Lokaal

Gebruik de `locale` prop met de locale die je wilt gebruiken van `@nuxt/ui/locale`:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Elke landinstelling heeft een eigenschap `code` (bijv. `en`, `en-GB`, `fr`) die de datum / tijd-indeling bepaalt in componenten zoals [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) en [InputTime](/docs/components/input-time).
::

### Aangepaste landinstelling

U kunt uw eigen landinstelling maken met het [defineLocale](/docs/composables/define-locale) hulpprogramma:

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

::tip
Kijk naar de `code` parameter, daar moet je de iso code van de taal doorgeven. Voorbeeld:

* `hi` Hindi (taal)
* `de-AT`: Duits (taal) zoals gebruikt in Oostenrijk (regio)

::

### Lokaal uitbreiden

U kunt een bestaande landinstelling aanpassen door de `messages` of `code` te overschrijven met behulp van het [extendLocale](/docs/composables/extend-locale) :

```vue [app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

### Dynamische landinstelling

Om dynamisch tussen talen te schakelen, kunt u de [Nuxt I18n](https://i18n.nuxtjs.org/) module gebruiken.

::steps{level="4"}

#### Installeer het Nuxt I18n-pakket

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### Voeg de Nuxt I18n module toe aan uw `nuxt.config.ts`{lang="ts-type"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [{
      code: 'de',
      name: 'Deutsch'
    }, {
      code: 'en',
      name: 'English'
    }, {
      code: 'fr',
      name: 'Français'
    }]
  }
})
```

#### Stel de `locale` prop in met `useI18n`

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```

#### Automatische link lokalisatie: badge{label="4.7+" class="align-text-top"}

Wanneer `@nuxtjs/i18n` is geïnstalleerd, lokaliseert de [Link](/docs/components/link) component automatisch interne links met behulp van de `$localePath` helper. Dit betekent dat u uw links niet handmatig hoeft in te pakken met `localePath()` of `localeRoute()`.

```vue
<template>
  <!-- Automatically becomes /en/about or /fr/about based on current locale -->
  <ULink to="/about">About</ULink>
  <UButton to="/contact">Contact</UButton>
</template>
```

::tip
Externe links en absolute URL 's worden automatisch gedetecteerd en slaan lokalisatie over. U kunt `localePath()` of `localeRoute()` indien nodig nog steeds handmatig gebruiken.
::

::

### Dynamische richting

Elke landinstelling heeft een `dir`-eigenschap die door de `App`-component zal worden gebruikt om de richting van alle componenten in te stellen.

In een meertalige applicatie wilt u misschien de kenmerken `lang` en `dir` op het `<html>`-element dynamisch instellen op basis van de landinstelling van de gebruiker, wat u kunt doen met de [useHead](https://nuxt.com/docs/api/composables/use-head) 
samen te stellen:

```vue [app.vue]
<script setup lang="ts">
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <NuxtPage />
  </UApp>
</template>
```
