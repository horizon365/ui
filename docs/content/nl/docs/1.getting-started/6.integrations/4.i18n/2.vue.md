## Gebruik

::note{to="/docs/components/app"}
Nuxt UI biedt een **App**-component die uw app omhult om wereldwijde configuraties te bieden, inclusief de `locale`-prop.
::

### Lokaal

Gebruik de `locale` prop met de locale die je wilt gebruiken van `@nuxt/ui/locale`:

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@nuxt/ui/locale'
</script>

<template>
  <UApp :locale="fr">
    <RouterView />
  </UApp>
</template>
```

::tip
Elke landinstelling heeft een eigenschap `code` (bijv. `en`, `en-GB`, `fr`) die de datum / tijd-indeling bepaalt in componenten zoals [Calendar](/docs/components/calendar), [InputDate](/docs/components/input-date) en [InputTime](/docs/components/input-time).
::

### Aangepaste landinstelling

U kunt uw eigen landinstelling maken met het [defineLocale](/docs/composables/define-locale) hulpprogramma:

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@nuxt/ui'
import { defineLocale } from '@nuxt/ui/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  dir: 'ltr',
  messages: {
    // implement pairs
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

::tip
Kijk naar de `code` parameter, daar moet je de iso code van de taal doorgeven. Voorbeeld:

* `hi` Hindi (taal)
* `de-AT`: Duits (taal) zoals gebruikt in Oostenrijk (regio)

::

### Lokaal uitbreiden

U kunt een bestaande landinstelling aanpassen door de `messages` of `code` te overschrijven met behulp van het [extendLocale](/docs/composables/extend-locale) :

```vue [App.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { extendLocale } from '@nuxt/ui/composables'

const locale = extendLocale(en, {
  code: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <UApp :locale="locale">
    <RouterView />
  </UApp>
</template>
```

### Dynamische landinstelling

Om dynamisch tussen talen te schakelen, kunt u de [Vue I18n](https://vue-i18n.intlify.dev/) plugin gebruiken.

::steps{level="4"}

#### Installeer het Vue I18n pakket

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### Gebruik de Vue I18n plugin in uw `main.ts`

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import ui from '@nuxt/ui/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(ui)

app.mount('#app')
```

#### Stel de `locale` prop in met `useI18n`

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```

::

### Dynamische richting

Elke landinstelling heeft een `dir`-eigenschap die door de `App`-component zal worden gebruikt om de richting van alle componenten in te stellen.

In een meertalige toepassing wilt u misschien de kenmerken `lang` en `dir` op het `<html>`-element dynamisch instellen op basis van de landinstelling van de gebruiker, wat u kunt doen met de [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head) 
samen te stellen:

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import * as locales from '@nuxt/ui/locale'

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].code)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <UApp :locale="locales[locale]">
    <RouterView />
  </UApp>
</template>
```
