## Gebruik

Nuxt UI levert een `Icon`-component die wordt ondersteund door [`@iconify/vue`](https://iconify.design/docs/icon-components/vue/), dus er is geen extra installatie vereist.

### Icon onderdeel

U kunt de [Icon](/docs/components/icon) component met een `name` prop gebruiken om een pictogram weer te geven:

::component-code{slug="icon"}
---
props:
  name: 'i-lucide-lightbulb'
  class: 'size-5'
---
::

::note
U kunt elke naam uit de <https://iconify.design>-collectie gebruiken. Blader ze gemakkelijk op <https://icones.js.org> of zoek rechtstreeks vanuit uw AI-assistent met behulp van de [`search-icons`](/docs/getting-started/ai/mcp#available-tools) MCP-tool.
::

::warning
Wanneer u collecties met een streepje (`-`) gebruikt, moet u de pictogramnaam van de verzamelnaam scheiden met een dubbele punt (`:`), aangezien `@iconify/vue` dit geval niet behandelt zoals
 `@nuxt/icon`. In plaats van `i-simple-icons-github` moet je bijvoorbeeld `i-simple-icons:github` of `simple-icons:github` schrijven.

Meer informatie over de naamgeving van [Iconify convention](https://iconify.design/docs/icon-components/vue/#icon).
::

### Component rekwisieten

Sommige componenten hebben ook een `icon` prop om een pictogram weer te geven, zoals de [Button](/docs/components/button) bijvoorbeeld:

::component-code{slug="button"}
---
ignore:
  - color
  - variant
props:
  icon: i-lucide-sun
  variant: subtle
slots:
  default: Button
---
::

## Collecties

### Iconify gegevensset

Het wordt ten zeerste aanbevolen om de pictogramgegevens lokaal te installeren met:

::code-group{sync="pm"}

```bash [pnpm]
pnpm i @iconify-json/{collection_name}
```

```bash [yarn]
yarn add @iconify-json/{collection_name}
```

```bash [npm]
npm install @iconify-json/{collection_name}
```

::

Als u bijvoorbeeld het `i-lucide-lightbulb`-pictogram wilt gebruiken, installeert u de collectie met `@iconify-json/lucide`.

Door de collectie te installeren, kan Nuxt UI de pictogrammen die het gebruikt in uw build insluiten, zodat ze meteen worden weergegeven tijdens SSR en volledig offline werken in plaats van te worden opgehaald uit de Iconify
 API tijdens runtime. Dit gebeurt automatisch voor Nuxt UI 's eigen iconen, standaard uit de `lucide` collectie.

Om andere pictogrammen te bundelen, zoals pictogrammen die u overschrijft of elders in uw app gebruikt, voegt u ze toe aan de `icon.clientBundle.icons`-optie in uw `vite.config.ts`:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          icons: ['lucide:heart', 'simple-icons:github']
        }
      }
    })
  ]
})
```

::note
U kunt het `i-{collection}-{name}`- of `{collection}:{name}`-formulier gebruiken, bijvoorbeeld `i-lucide-heart` of `lucide:heart`, en `i-material-symbols-menu` of `material-symbols:menu`. Installeer elke verzameling waarnaar u verwijst met `@iconify-json/{collection_name}`.
::

Om de pictogrammen die u gebruikt te bundelen zonder ze één voor één te vermelden, schakelt u in plaats daarvan `scan` in.
Het scant uw bron voor pictogramgebruik van uw geïnstalleerde collecties en bundelt ze, op dezelfde manier `@nuxt/icon` 's `clientBundle.scan` werkt:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: true
        }
      }
    })
  ]
})
```

Scannen leest alleen `.vue`, `.jsx`, `.tsx`, `.md`, `.mdc`, `.mdx`, `.yml` en `.yaml` bestanden, en het komt alleen overeen met pictogramnamen die zijn geschreven als letterlijke tekenreeksen.
Pictogrammen die zijn gedefinieerd in een `.ts`- of `.js`-bestand, zoals een lijst met navigatielinks, worden gemist, evenals namen die dynamisch zijn gebouwd zoals `i-lucide-${name}`.
Stel `globInclude` in om die bestanden ook te scannen. Het vervangt de standaardlijst, dus bewaar de extensies die je nog nodig hebt:

```ts [vite.config.ts]
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    ui({
      icon: {
        clientBundle: {
          scan: {
            globInclude: ['**/*.{vue,jsx,tsx,md,mdc,mdx,yml,yaml,ts,js}']
          }
        }
      }
    })
  ]
})
```

Dynamische namen kunnen nog steeds worden gebundeld wanneer u de hele set tijdens het bouwen kent, door ze in `clientBundle.icons` te vermelden.
Namen die alleen tijdens runtime bestaan, zoals pictogrammen die afkomstig zijn van een API, kunnen helemaal niet worden gebundeld en worden op verzoek vanuit de Iconify API geladen.

Pictogrammen waarvan de verzameling niet is geïnstalleerd, worden tijdens runtime nog steeds geladen vanuit de Iconify API, dus installeer elke verzameling die u gebruikt met `@iconify-json/{collection_name}`.
Als u zich wilt afmelden voor volledige bundeling, stelt u `icon.clientBundle` in op `false`.
