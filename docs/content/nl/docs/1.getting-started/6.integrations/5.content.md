## Installatie

Om te beginnen kunt u de officiële [guide](https://content.nuxt.com/docs/getting-started/installation) of samenvattend volgen:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/content
```

```bash [yarn]
yarn add @nuxt/content
```

```bash [npm]
npm install @nuxt/content
```

```bash [bun]
bun add @nuxt/content
```

::

Voeg vervolgens de `@nuxt/content`-module toe aan uw `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxt/content'
  ],
  css: ['~/assets/css/main.css']
})
```

::caution
U moet `@nuxt/content` na `@nuxt/ui` registreren in de `modules`-array, anders zijn de proza-componenten niet beschikbaar.
::

## Configuration

Wanneer u Tailwind CSS-klassen gebruikt in uw markdown-inhoudsbestanden, moet u ervoor zorgen dat Tailwind de benodigde hulpprogramma-klassen kan detecteren en genereren.
Standaard haalt de automatische inhoudsdetectie van Tailwind mogelijk geen klassen op die zijn geschreven in markdown-bestanden.

Om dit op te lossen, gebruikt u de [`@source` directive](https://tailwindcss.com/docs/functions-and-directives#source-directive) in uw CSS-bestand om uw inhoudsmap expliciet op te nemen:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@source "../../../content/**/*";
```

Dit zorgt ervoor dat:
- Tailwind scant alle markdown-bestanden in uw inhoudsmap
- Alle hulpprogramma klassen die worden gebruikt in uw markdown (zoals `text-primary`) worden opgenomen in de uiteindelijke CSS
- Dynamische klassen in MDC-componenten of aangepaste Vue-componenten binnen uw inhoud werken correct

::tip
U kunt ook glob-patronen gebruiken om specifieker te zijn over welke bestanden u wilt scannen:
- `@source "../../../content/docs/**/*.md"` - Scan alleen markdown in de docs map
- `@source "../../../content/**/*.{md,yml}"` - Inclusief zowel markdown als YAML bestanden
::

::note{to="https://tailwindcss.com/docs/detecting-classes-in-source-files" target="_blank"}
Lees meer over de automatische inhoudsdetectie van Tailwind en praktische tips voor het optimaliseren van de bouwprestaties.
::

## Componenten

Mogelijk gebruikt u `@nuxt/content` om een documentatie te bouwen. Om u daarbij te helpen, hebben we enkele componenten gebouwd die u in uw pagina 's kunt gebruiken:

- a ingebouwd full-text zoekcommandopalet met [ContentSearch](/docs/components/content-search), ter vervanging van de behoefte aan Algolia DocSearch
- a navigatiestructuur met de [ContentNavigation](/docs/components/content-navigation) component
- a sticky Inhoudsopgave met de [ContentToc](/docs/components/content-toc) component
- a vorige / volgende navigatie met de [ContentSurround](/docs/components/content-surround) component

## Typografie

Nuxt UI biedt zijn eigen implementaties van alle prozacomponenten, dus markdown gerenderd door `@nuxt/content` pikt hetzelfde thema op als de rest van uw componenten.

::note{to="/docs/typography"}
Ontdek het volledige **Typography** en verken alle beschikbare prozacomponenten voor een rijke, consistente inhoudspresentatie.
::

## Utils

Nuxt UI verzendt helpers om de door `@nuxt/content` geretourneerde gegevens om te vormen naar het formaat dat de componenten verwachten.

### `mapContentNavigation`

Dit util brengt de navigatie van `queryCollectionNavigation` in kaart en transformeert deze recursief in een reeks objecten die door verschillende componenten kunnen worden gebruikt.

`mapContentNavigation(navigation, options?)`
- `navigation`: De navigatiestructuur (array van ContentNavigationItem).
- `options` (optioneel):
- `labelAttribute`: (string) Welk veld te gebruiken als label (standaard `title`)
- `deep`: (aantal of ongedefinieerd) Bepaalt hoeveel navigatieniveaus zijn inbegrepen (`undefined` standaard, omvat alle niveaus)

**Voorbeeld: ** Zoals weergegeven in het onderstaande breadcrumb-voorbeeld, wordt het vaak gebruikt om de navigatiegegevens in het juiste formaat om te zetten.

```vue [app.vue]
<script setup lang="ts">
import { mapContentNavigation } from '@nuxt/ui/utils/content'
import { findPageBreadcrumb } from '@nuxt/content/utils'

const route = useRoute()

const { data: navigation } = await useAsyncData('navigation', () => queryCollectionNavigation('content'))
const { data: page } = await useAsyncData(route.path, () => queryCollection('content').path(route.path).first())

const breadcrumb = computed(() => mapContentNavigation(
  findPageBreadcrumb(navigation.value, page.value?.path, { indexAsChild: true }),
  { deep: 0 }
).map(({ icon, ...link }) => link))
</script>

<template>
  <UPage>
    <UPageHeader v-bind="page">
      <template #headline>
        <UBreadcrumb :items="breadcrumb" />
      </template>
    </UPageHeader>
  </UPage>
</template>
```
