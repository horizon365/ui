## Gebruik

De ChangelogVersions-component biedt een flexibele lay-out om een lijst met [ChangelogVersion](/docs/components/changelog-version) componenten weer te geven met behulp van de standaardsleuf of de `versions`-prop.

```vue {2,8}
<template>
  <UChangelogVersions>
    <UChangelogVersion
      v-for="(version, index) in versions"
      :key="index"
      v-bind="version"
    />
  </UChangelogVersions>
</template>
```

## Voorbeelden

::note
Hoewel deze voorbeelden [Nuxt Content](https://content.nuxt.com) gebruiken, kunnen de componenten worden geïntegreerd met elk contentbeheersysteem.
::

### Binnen een pagina

Gebruik de ChangelogVersions-component op een pagina om een changelog-pagina te maken:

```vue [pages/changelog.vue]{10-17}
<script setup lang="ts">
const { data: versions } = await useAsyncData('versions', () => queryCollection('versions').all())
</script>

<template>
  <UPage>
    <UPageHero title="Changelog" />

    <UPageBody>
      <UChangelogVersions>
        <UChangelogVersion
          v-for="(version, index) in versions"
          :key="index"
          v-bind="version"
          :to="version.path"
        />
      </UChangelogVersions>
    </UPageBody>
  </UPage>
</template>
```

::note
In dit voorbeeld worden de `versions` opgehaald met `queryCollection` uit de `@nuxt/content` module.
::

::tip
De `to` prop wordt hier overschreven omdat `@nuxt/content` de `path` eigenschap gebruikt.
::

### Met schuifcontainer: badge{label="4.4+" class="align-text-top"}

Geef een object door aan de `indicator` prop om de scrollcontainer te configureren. Standaard volgt de indicator het venster / paginascroll (https://motion.dev/docs/vue-use-scroll#page-scroll).

```vue
<script setup lang="ts">
const scrollContainer = ref<HTMLElement>()
</script>

<template>
  <div ref="scrollContainer" class="max-h-96 overflow-y-auto">
    <UChangelogVersions v-if="scrollContainer" :indicator="{ container: scrollContainer }" />
  </div>
</template>
```

::warning
Wanneer u een aangepaste `container` gebruikt, moet u ervoor zorgen dat het containerelement vóór `UChangelogVersions` is gemonteerd.
::

### Slots

:component-slots

::tip
U kunt alle slots van de [`ChangelogVersion`](/docs/components/changelog-version#slots) component in ChangelogVersions gebruiken, ze worden automatisch doorgestuurd, zodat u individuele versies kunt aanpassen wanneer u de `versions`-prop gebruikt.

```vue{3-5}
<template>
  <UChangelogVersions :versions="versions">
    <template #body="{ version }">
      <Markdown :value="version.content" />
    </template>
  </UChangelogVersions>
</template>
```
::
