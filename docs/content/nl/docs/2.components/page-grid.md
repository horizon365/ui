## Gebruik

De PageGrid-component biedt een responsieve rasterlay-out voor het weergeven van [PageCard](/docs/components/page-card) componenten of andere elementen, waarbij automatisch wordt aangepast van 1 tot 3 kolommen op basis van schermgrootte.

::component-example
---
name: 'page-grid-example'
class: 'p-8'
---
::

U kunt het ook gebruiken om een lijst met kaarten in een bento-stijl lay-out weer te geven met behulp van `col-span-*` en `row-span-*` utility classes.

::component-example
---
collapse: true
name: 'page-grid-bento-example'
class: 'p-8'
---
::
