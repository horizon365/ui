## Gebruik

Gebruik de standaardsleuf om de breedte van uw inhoud te centreren en te beperken.

::tip{to="/docs/getting-started/theme/css-variables#container"}
De maximale breedte wordt geregeld door de `--ui-container` CSS variabele.
::

  class: 'w-full'
