## Opmaak

Kernstructurele componenten voor het organiseren van de lay-out van uw applicatie en het leggen van een consistente basis voor uw gebruikersinterface.

:components-list{category="layout"}

## Element

Essentiële UI-bouwstenen, waaronder knoppen, badges, avatars, pictogrammen en andere fundamentele interface-elementen voor het creëren van intuïtieve en consistente gebruikerservaringen.

:components-list{category="element"}

## Formulier

Uitgebreide formuliercomponenten voor het bouwen van interactieve gebruikersinvoerervaringen, inclusief tekstinvoer, selecties, selectievakjes, radiogroepen, schakelaars, schuifregelaars en volledige formuliervalidatie.

:components-list{category="form"}

## Data

Componenten voor het weergeven en organiseren van gegevens, waaronder tabellen, accordeons, carrousels, tijdlijnen, bomen en gebruikersprofielen.

:components-list{category="data"}

## Navigatie

Componenten voor gebruikersnavigatie en bewegwijzering, inclusief menu 's, broodkruimels, paginering, tabbladen, steppers, links en opdrachtpaletten.

:components-list{category="navigation"}

## Overlay

Drijvende UI-elementen die boven de hoofdinhoud verschijnen, inclusief modals, popovers, tooltips, lades, slideovers en contextmenu 's.

:components-list{category="overlay"}

## Pagina

Vooraf gebouwde marketing- en inhoudssecties voor het maken van bestemmingspagina 's, blogs, prijspagina 's en ander marketingmateriaal.

:components-list{category="page"}

::note{to="https://github.com/nuxt-ui-templates/saas" target="_blank"}
Bekijk de **SaaS template** op GitHub voor een realistisch voorbeeld.
::

## Dashboard

Gespecialiseerde componenten voor het bouwen van dynamische dashboards met aanpasbare panelen, opvouwbare zijbalken, werkbalken en zoekfunctionaliteit.

:components-list{category="dashboard"}

::note{icon="i-simple-icons-github"}
Bekijk de [`Nuxt`](https://github.com/nuxt-ui-templates/dashboard) en [`Vue`](https://github.com/nuxt-ui-templates/dashboard-vue) Dashboard-sjablonen op GitHub voor een realistisch voorbeeld.
::

## AI Chatten

Componenten voor het bouwen van gespreksinterfaces en chatbots, mogelijk gemaakt door de [Vercel AI SDK](https://ai-sdk.dev/).

:components-list{category="chat"}

::note{icon="i-simple-icons-github"}
Bekijk de [`Nuxt`](https://github.com/nuxt-ui-templates/chat) en [`Vue`](https://github.com/nuxt-ui-templates/chat-vue) AI Chat-sjablonen op GitHub voor een realistisch voorbeeld.
::

## Editor: badge{label="4.3+" class="align-text-top"}

Componenten voor het bouwen van een rich text-editor met ondersteuning voor markdown-, HTML- en JSON-inhoudstypen, mogelijk gemaakt door [TipTap](https://tiptap.dev/).

:components-list{category="editor"}

::note{to="https://github.com/nuxt-ui-templates/editor" target="_blank"}
Bekijk de **Editor template** op GitHub voor een realistisch voorbeeld.
::

## Inhoud

Componenten die integreren met [Content](/docs/getting-started/integrations/content) voor documentatiesites, waaronder inhoudsopgave, zoeken, navigatiebomen en omliggende paginalinks.

:components-list{category="content"}

::note{to="https://github.com/nuxt-ui-templates/docs" target="_blank"}
Bekijk de **Docs template** op GitHub voor een realistisch voorbeeld.
::
