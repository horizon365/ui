Nuxt UI biedt prachtig vormgegeven **Prose-componenten** voor uw markdown-inhoud.
Of u nu markdown weergeeft met een bibliotheek of prozacomponenten rechtstreeks gebruikt, Nuxt UI past het ontwerpsysteem toe, zodat uw inhoud zich automatisch aanpast aan het thema van uw applicatie.

::framework-only
#nuxt
:::div

::::note
Proza-componenten worden automatisch ingeschakeld bij gebruik van [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc), [`@nuxt/content`](https://github.com/nuxt/content) of [`@comark/nuxt`](https://comark.dev/rendering/nuxt).<br><br>Otherwise, schakel de [`prose`](/docs/getting-started/installation/nuxt#prose) optie in uw `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
::::

::::tip{to="/docs/getting-started/integrations/content"}
Raadpleeg de **Content integration**-handleiding voor installatie en installatie van Nuxt-inhoud.
::::

:::

#vue
:::note
Om proza-componenten met Vue te gebruiken, moet u de [`prose`](/docs/getting-started/installation/vue#prose) optie in uw `vite.config.ts` inschakelen:

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::
::

## Gebruik

::framework-only
#nuxt
:::div
Er zijn meerdere manieren om gestileerde inhoud weer te geven:

1. **Markdown rendering**: gebruik ContentRenderer, MDC, Markdown of MarkdownDocument om markdown weer te geven met automatische proza-styling
2. **Direct Vue usage**: importeer en gebruik proza-componenten rechtstreeks in uw Vue-sjablonen
:::

:::div

### Met inhoudRenderer: badge{label="Nuxt only" color="warning" class="align-text-top"}

Geef bij het gebruik van [`@nuxt/content`](https://github.com/nuxt/content) uw verzamelpagina 's weer met de [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer) :

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### Met MDC component: badge{label="Nuxt only" color="warning" class="align-text-top"}

Gebruik bij gebruik van [`@nuxtjs/mdc`](https://github.com/nuxt-content/mdc) of [`@nuxt/content`](https://github.com/nuxt/content) de [`<MDC>`](https://github.com/nuxt-content/mdc) component om markdown-strings weer te geven:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-content/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::tip{to="https://comark.dev" target="_blank"}
`@nuxtjs/mdc` wordt afgeschaft ten gunste van [Comark](https://comark.dev). Uw bestaande markdown-bestanden zijn compatibel, geen inhoudswijzigingen nodig.
::

### Met Markdown component

[Comark](https://comark.dev) geeft markdown weer met ingebouwde ondersteuning voor streaming. Het geeft stapsgewijs tokens weer wanneer ze aankomen, waardoor het ideaal is voor AI-chatreacties en andere dynamische markdown-inhoud.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import shiki from '@comark/nuxt/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Markdown } from '@comark/vue'
import shiki from '@comark/vue/plugins/shiki'

const plugins = [shiki()]

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Markdown :value="markdown" :plugins="plugins" />
</template>
```
::

::note
De `shiki`-plug-in voegt syntaxisaccentuering toe aan codeblokken. Gebruik de `:streaming`-prop bij het renderen van inhoud die stapsgewijs aankomt, zoals AI-reacties.

Om de donkere modus te ondersteunen, voegt u de volgende CSS toe aan uw stylesheet:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```
::

::tip{to="/docs/components/chat"}
Zie de **Chat**-component voor een volledig voorbeeld van het gebruik van Comark om AI-chatberichten weer te geven.
::

### Met MarkdownDocument

Gebruik de [`<MarkdownDocument>`](https://comark.dev/rendering/vue#code-markdowndocument-code) component om een vooraf geparseerde `MarkdownDocument` weer te geven zonder parser- of plug-incode naar de browser te sturen.
Dit is handig wanneer het parseren plaatsvindt op de server, in een buildstap of via een API.

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { MarkdownDocument } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <MarkdownDocument v-if="tree" :value="tree" />
</template>
```
::

### Met Proza onderdelen

Gebruik prozacomponenten rechtstreeks in Vue-sjablonen voor maximale controle:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## MDC-syntaxis

Markdown elementen worden automatisch toegewezen aan proza-componenten: `# Heading` wordt `<ProseH1>`, `**bold**` wordt `<ProseStrong>`, `` `code` `` wordt `<ProseCode>`, enzovoort.

[MDC Syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) gaat verder door u Vue-componenten direct in markdown te laten gebruiken. Het wordt ondersteund door Nuxt Content, Nuxt MDC en Comark.

## Thema

Overschrijd elke styling van prozacomponenten in uw app-configuratie:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          h1: {
            slots: {
              base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
            }
          },
          p: {
            base: 'leading-7 [&:not(:first-child)]:mt-6'
          }
        }
      }
    })
  ]
})
```
