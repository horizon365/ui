## Lijsten

Markdown ondersteunt ongeordende, geordende en geneste lijsten voor verschillende inhoudsbehoeften.

### Ongeordende lijsten

Gebruik ongeordende lijsten voor items zonder een specifieke volgorde. Start elk item met een `-`-symbool.

::tabs{class="gap-0"}

::code-preview{label="Voorbeeld" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Ik ben een lijstitem.
- Ik ben een ander lijstitem.
- Ik ben het laatste lijstitem.

#code

```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```

### Bestelde lijsten

Gebruik geordende lijsten wanneer de bestelling belangrijk is, zoals stappen in een proces. Begin elk item met een nummer.

::tabs{class="gap-0"}

::code-preview{label="Voorbeeld" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Ik ben een lijstitem.
2. Ik ben een ander lijstitem.
3. Ik ben het laatste lijstitem.

#code

```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```

### Genestelde lijsten

Maak hiërarchische lijsten met subitems voor complexe structuren. Indent subitems met vier spaties om te nestelen.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Ik ben een lijstitem.
- Ik ben een geneste lijst item.
- Ik ben een ander geneste lijstitem.
- Ik ben een ander lijstitem.
- Een ander genest item
- Diep genest item
- Nog een diep genest item
- Terug naar tweede niveau

#code

```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item.
- I'm another list item.
  - Another nested item
    - Deep nested item
    - Another deep nested item
  - Back to second level
```

::

### Gemengde lijsten

U kunt geordende en ongeordende lijsten combineren voor complexe hiërarchieën.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Eerste grote stap
- Sub-requirement A
- Sub-requirement B
2. Tweede grote stap
- Nog een subitem
- Laatste subitem
3. Laatste stap

#code

```mdc
1. First major step
   - Sub-requirement A
   - Sub-requirement B
2. Second major step
   - Another sub-item
   - Final sub-item
3. Final step
```

::

## Tabellen

Geef gestructureerde gegevens duidelijk weer in rijen en kolommen. Tabellen zijn ideaal voor het vergelijken van gegevens of het aanbieden van eigenschappen.

::tabs{class="gap-0"}

::code-preview{label="Voorbeeld" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| Prop | Standaard | Type |
|---------|-----------|--------------------------|
| `name` | | `string`{lang="ts-type"} |
| `size` | `md` | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |

#code

```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
