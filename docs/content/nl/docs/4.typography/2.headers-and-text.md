## Koppen

Gebruik koppen om uw inhoud te ordenen en het leesbaarder te maken.

Koppen kunnen worden verpakt in een ankerlink wanneer ze een `id` hebben, met een hash-pictogram dat wordt weergegeven op hover voor `H2` en `H3` (op grote schermen), zodat lezers kunnen linken
 rechtstreeks naar een rubriek.

Ankerkoppelingen zijn standaard ingeschakeld voor `H2` naar `H4` bij gebruik van `@nuxt/content`, en anders uitgeschakeld, [Comark](https://comark.dev) inbegrepen.
Gebruik de [`Theme`](/docs/components/theme) component met de `anchor` prop om ze te wisselen voor een gedeelte van je app:

```vue
<template>
  <UTheme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- your rendered markdown -->
  </UTheme>
</template>
```

::framework-only
#nuxt
:::div

::::note
Bij gebruik van `@nuxt/content` zijn ankerkoppelingen standaard ingeschakeld voor `H2`, `H3` en `H4`.
Je kunt hun [generation](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks) (bijvoorbeeld om ze uit te schakelen voor AI-chatinterfaces) en de [toc generation](https://content.nuxt.com/docs/getting-started/configuration#toc) in je `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::::
