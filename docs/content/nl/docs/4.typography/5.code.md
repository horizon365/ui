## Code blokken

Codeblokken worden weergegeven door de `ProsePre`-component met syntaxisaccentuering aangedreven door [Shiki](https://github.com/shikijs/shiki).

::tabs{class="gap-0"}

```ts
  modules: ['@nuxt/ui']
})
```

### Taal

Syntaxisaccentuering is beschikbaar voor tientallen programmeertalen.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <UButton @click="updateMessage">
      Click me
    </UButton>
  </div>
</template>
```

#code

````html
```vue
<script setup lang="ts">
const message = ref ('Hallo Wereld!')

functie updateMessage () {
message.value = 'Knop aangeklikt!'
}

<template>
<div>
<h1> {{ message }} </h1>

````

::

::tip
Standaard worden `material-theme-lighter` en `material-theme-palenight` Shiki thema 's gebruikt voor respectievelijk de lichte en donkere modus. Wanneer u `@nuxt/content` gebruikt, kunt u dit wijzigen via de [`content.build.markdown.highlight`](https://content.nuxt.com/docs/getting-started/configuration#highlight) in uw `nuxt.config.ts`.
Wanneer u standalone `@nuxtjs/mdc` gebruikt, configureert u thema 's via de [`mdc.highlight`](https://github.com/nuxt-content/mdc#configurations) . Wanneer u [Comark](https://comark.dev) gebruikt, configureert u thema 's via de `shiki`-plug-inopties.

Om de donkere modus met Comark te ondersteunen, voegt u de volgende CSS toe aan uw stylesheet:

```css [main.css]
html.dark .shiki span {
  color: var(--shiki-dark) !important;
  background-color: var(--shiki-dark-bg) !important;
  font-style: var(--shiki-dark-font-style) !important;
  font-weight: var(--shiki-dark-font-weight) !important;
  text-decoration: var(--shiki-dark-text-decoration) !important;
}
```

### Bestandsnaam

Codeblokken ondersteunen bestandsnaamweergave met automatische pictogramdetectie.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code

````mdc
```ts [nuxt.config.ts]
export standaard defineNuxtConfig ({
modules: ['@ nuxt / ui']
})
```
````

::

::tip
Het bestandsnaampictogram wordt weergegeven door de `ProseCodeIcon`-component en bevat een set vooraf gedefinieerde pictogrammen die u kunt aanpassen in uw app-configuratie:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-lucide-square-terminal',
        config: 'i-lucide-settings',
        package: 'i-lucide-package'
      }
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        prose: {
          codeIcon: {
            terminal: 'i-lucide-square-terminal',
            config: 'i-lucide-settings',
            package: 'i-lucide-package'
          }
        }
      }
    })
  ]
})
```
:::
::
::

::note
Deze bestandsnaampictogrammen komen uit de [`vscode-icons`](https://icones.js.org/collection/vscode-icons) collectie, die los staat van de `lucide`-pictogrammen die de rest van de componenten gebruikt, en worden op verzoek opgelost vanuit de bestandsextensie.
Installeer `@iconify-json/vscode-icons` om ze lokaal en offline te bedienen, net als elke andere collectie.
::

### Kopieer knop

Elk codeblok heeft een ingebouwde kopieerknop die de code naar uw klembord kopieert.

Stel de `copy` prop in op `false` om de knop te verbergen, of geef [Button](/docs/components/button) rekwisieten door om het aan te passen.

::tip
U kunt het pictogram wijzigen via de `ui.icons.copy`- en `ui.icons.copyCheck`-toetsen in uw app-configuratie:

::framework-only
#nuxt
:::div{class="*:my-0"}
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    icons: {
      copy: 'i-lucide-copy',
      copyCheck: 'i-lucide-copy-check'
    }
  }
})
```
:::

#vue
:::div{class="*:my-0"}
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      ui: {
        icons: {
          copy: 'i-lucide-copy',
          copyCheck: 'i-lucide-copy-check'
        }
      }
    })
  ]
})
```
:::

### Line accentuering

Markeer specifieke lijnen om de aandacht te vestigen op belangrijke onderdelen.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'], // This line is highlighted
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
export standaard defineNuxtConfig ({
modules: ['@ nuxt / ui'], / / Deze regel is gemarkeerd
css: ['~ / assets / css / hoofd.css']
})
```
````

### Code diff

Gebruik de `diff`-taal om wijzigingen tussen codeversies weer te geven.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@nuxt/ui-pro'
+   '@nuxt/ui'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export standaard defineNuxtConfig ({
modules: [
-    '@ nuxt / ui-pro'
+    '@ nuxt / uit'
  ]
})
```
````
